# Modelo Pedagógico

Esta carpeta contiene el marco pedagógico oficial de **Maker Academy**. Aquí se explica la visión educativa del programa, sus fundamentos, la metodología **XperiencED Kids**, la relación con la cultura maker, el PNFT, las 4P del aprendizaje creativo, la evaluación, los roles y las condiciones generales de implementación.

El modelo pedagógico orienta las decisiones del programa y da coherencia a los bloques temáticos, el Programa Anual K11, los proyectos, las guías docentes, las evidencias, las insignias y los procesos de mejora continua.

## Idea central

El modelo pedagógico de **Maker Academy** busca que cada experiencia maker tenga sentido educativo.

No se trata solo de usar herramientas o construir prototipos. Se trata de crear experiencias donde los estudiantes puedan imaginar, diseñar, experimentar, equivocarse, mejorar, documentar y compartir aprendizajes conectados con su vida, su escuela y su comunidad.
