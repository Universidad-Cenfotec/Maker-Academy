# Checklist de organización

> Este archivo pertenece a: **Maker Academy**  
> Ruta: `11. Comunidad Show Your Work/Checklist de organización.md`

---

## Estado

**Estado:** Borrador  
**Versión:** v1.0

---

## Información general

- [ ] Definir la fecha.
- [ ] Definir el horario.
- [ ] Reservar el espacio.
- [ ] Nombrar a la persona coordinadora.
- [ ] Confirmar los niveles participantes.
- [ ] Estimar la cantidad de proyectos.
- [ ] Estimar la cantidad de visitantes.
- [ ] Definir el formato del evento.

---

## Proyectos

- [ ] Seleccionar los proyectos participantes.
- [ ] Confirmar los nombres de los equipos.
- [ ] Revisar que cada proyecto tenga un nombre.
- [ ] Verificar que cada equipo pueda explicar su proceso.
- [ ] Seleccionar fotografías, bocetos o evidencias.
- [ ] Preparar las demostraciones.
- [ ] Identificar los proyectos que requieren electricidad.
- [ ] Identificar los proyectos que requieren internet.
- [ ] Identificar los proyectos que necesitan supervisión especial.

---

## Preparación estudiantil

- [ ] Explicar el propósito del evento.
- [ ] Practicar las presentaciones.
- [ ] Distribuir los roles.
- [ ] Preparar tarjetas o apoyos visuales.
- [ ] Ensayar el funcionamiento de los proyectos.
- [ ] Practicar posibles respuestas.
- [ ] Recordar que los errores también pueden compartirse.

---

## Espacio

- [ ] Distribuir las estaciones.
- [ ] Asignar una mesa o superficie a cada equipo.
- [ ] Preparar la señalización.
- [ ] Revisar la circulación.
- [ ] Proteger los cables.
- [ ] Confirmar el acceso a electricidad.
- [ ] Confirmar el acceso a internet.
- [ ] Preparar el punto de bienvenida.
- [ ] Mantener libres las rutas de evacuación.
- [ ] Verificar la accesibilidad.

---

## Seguridad

- [ ] Revisar las estructuras.
- [ ] Revisar las conexiones eléctricas.
- [ ] Revisar cables y baterías.
- [ ] Proteger piezas móviles.
- [ ] Eliminar bordes peligrosos.
- [ ] Supervisar herramientas.
- [ ] Identificar superficies calientes.
- [ ] Asignar personas adultas responsables.
- [ ] Realizar una prueba final antes de abrir el evento.

---

## Familias y visitantes

- [ ] Preparar la invitación.
- [ ] Comunicar la fecha y el horario.
- [ ] Explicar el propósito de Show Your Work.
- [ ] Preparar preguntas sugeridas.
- [ ] Preparar tarjetas o formularios de retroalimentación.
- [ ] Definir el recorrido.

---

## Evidencias

- [ ] Confirmar los permisos para fotografías.
- [ ] Asignar a una persona para tomar fotografías.
- [ ] Grabar videos breves.
- [ ] Registrar la cantidad de visitantes.
- [ ] Recopilar comentarios.
- [ ] Guardar la lista de proyectos.
- [ ] Registrar aprendizajes y oportunidades de mejora.

---

## Después del evento

- [ ] Realizar una reflexión con las personas estudiantes.
- [ ] Recopilar la opinión del personal docente.
- [ ] Organizar las evidencias.
- [ ] Seleccionar fotografías para compartir.
- [ ] Registrar recomendaciones para la siguiente edición.
- [ ] Reconocer la participación de estudiantes y docentes.
