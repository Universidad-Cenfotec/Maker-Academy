## Descripción

Este documento explica cómo convertir una idea en una primera versión sencilla para probarla y mejorarla.

## Contenido

Un prototipo es una primera versión de una idea. Sirve para probar, conversar y mejorar.

No prototipamos para mostrar algo perfecto. Prototipamos para aprender más rápido.

## Materiales útiles

- Papel y cartón.
- Cinta adhesiva.
- Paletas de madera.
- LEGO o bloques.
- Material reutilizable.
- Plastilina o arcilla.
- Componentes simples, si el reto lo requiere.

## Ciclo maker

**Idea → Prototipo → Prueba → Mejora → Comparte**

## Reglas para prototipar

- Empezar simple.
- Probar pronto.
- Escuchar comentarios.
- Cambiar lo necesario.
- Guardar evidencia de cada versión.
