# Checklist para la activación de un reto maker

Este archivo pertenece a: Bloque Temático Pensamiento Maker  
Ruta: 01. Bloques Temáticos/01. Pensamiento Maker/03. Recursos para Docentes/checklist-activacion-reto.md

## Estado

**Estado:** Borrador  
**Versión:** v1.0  
**Bloque:** Pensamiento Maker

## Descripción

Este recurso permite verificar que una experiencia maker esté preparada antes de presentarla al estudiantado.

La lista contempla aspectos pedagógicos, organización del espacio, materiales, seguridad, inclusión, documentación y uso responsable de tecnologías e inteligencia artificial.

No es necesario que todos los retos utilicen herramientas digitales o equipos especializados. Lo importante es que exista un desafío claro, oportunidades para crear, probar, aprender del error y mejorar una solución.

## Propósito

Apoyar al docente en la preparación de experiencias maker seguras, claras, inclusivas y coherentes con la metodología XperiencED Kids.

## Cuándo utilizar este recurso

Se recomienda completar esta lista:

- Durante la planificación de una práctica guiada o proyecto maker.
- Antes de iniciar una sesión en el aula, laboratorio o makerspace.
- Cuando se implemente un reto por primera vez.
- Cuando cambien los materiales, el espacio o el grupo de estudiantes.
- Antes de utilizar herramientas, equipos de fabricación digital, robótica o inteligencia artificial.

## Instrucciones

Marque con una `X` cada aspecto que se encuentre preparado.

Si algún elemento fundamental todavía no está listo, realice los ajustes antes de iniciar el reto.

---

## 1. Claridad pedagógica

- [ ] El reto tiene un propósito de aprendizaje claramente definido.
- [ ] El reto se relaciona con el bloque de Pensamiento Maker.
- [ ] Se identificaron las competencias o habilidades que se desean desarrollar.
- [ ] La situación planteada permite crear, construir, modificar o mejorar una solución.
- [ ] El reto admite diferentes respuestas o maneras de resolverlo.
- [ ] El nivel de dificultad es adecuado para la edad y experiencia del grupo.
- [ ] Se definieron criterios sencillos para reconocer una solución funcional.
- [ ] Se planificaron los momentos de Inspiración, Experimentación y Reflexión.

## 2. Presentación del desafío

- [ ] El reto puede explicarse con una frase clara y comprensible.
- [ ] Se preparó una pregunta provocadora, historia, caso o situación inicial.
- [ ] El problema se relaciona con una necesidad real, cercana o significativa.
- [ ] Las instrucciones indican qué se debe lograr sin imponer una única solución.
- [ ] El estudiantado conocerá las restricciones de tiempo, materiales y seguridad.
- [ ] Se preparó un ejemplo únicamente cuando es necesario para comprender el desafío.
- [ ] El ejemplo no limita la creatividad ni presenta una respuesta que deba copiarse.

## 3. Materiales y herramientas

- [ ] Los materiales necesarios están disponibles y organizados.
- [ ] La cantidad de materiales es suficiente para el número de estudiantes.
- [ ] Los materiales están clasificados, identificados o distribuidos por estaciones.
- [ ] Se revisó el funcionamiento de equipos, dispositivos y herramientas.
- [ ] Se prepararon materiales alternativos en caso de fallos o faltantes.
- [ ] Los materiales permiten construir más de una posible solución.
- [ ] Se priorizó el aprovechamiento responsable y la reutilización de materiales.
- [ ] Se definió cómo se entregarán, compartirán y devolverán los materiales.

## 4. Espacio de trabajo

- [ ] El espacio permite desplazarse y trabajar con seguridad.
- [ ] Las mesas o estaciones están organizadas según la actividad.
- [ ] Las herramientas de uso frecuente son accesibles.
- [ ] Las herramientas que requieren supervisión están bajo control del docente.
- [ ] Las rutas de evacuación y salidas permanecen despejadas.
- [ ] Se definió un lugar para guardar prototipos en proceso.
- [ ] Se preparó un espacio para presentar, probar o documentar las creaciones.
- [ ] Se estableció un procedimiento para ordenar y limpiar al finalizar.

## 5. Seguridad

- [ ] Se identificaron los riesgos asociados con los materiales y herramientas.
- [ ] Se explicarán las normas de seguridad antes de comenzar.
- [ ] El estudiantado conoce cuáles herramientas puede utilizar de manera autónoma.
- [ ] Se identificaron las herramientas que requieren acompañamiento directo.
- [ ] Se dispone del equipo de protección necesario.
- [ ] Los cables, extensiones y conexiones eléctricas están en buen estado.
- [ ] Los materiales cortantes, calientes o eléctricos se utilizarán con supervisión.
- [ ] Se estableció qué hacer ante un accidente, daño o situación inesperada.
- [ ] Se recordó que detenerse y pedir ayuda también es una decisión segura.

## 6. Organización de los equipos

- [ ] Se definió si el reto será individual, colaborativo o combinará ambas modalidades.
- [ ] Los equipos tienen una cantidad adecuada de integrantes.
- [ ] Se consideraron las características y necesidades del grupo.
- [ ] Se establecieron roles flexibles cuando son necesarios.
- [ ] Los roles permiten que todas las personas participen en la toma de decisiones.
- [ ] Se evitará que una sola persona controle permanentemente las herramientas.
- [ ] Se explicará cómo solicitar materiales, ayuda o retroalimentación.
- [ ] Se promoverá el intercambio de ideas desde el enfoque DIWO: hacerlo con otras personas.

## 7. Mediación docente

- [ ] Se prepararon preguntas para orientar sin dar directamente la respuesta.
- [ ] Se planificaron momentos para observar el proceso de los equipos.
- [ ] Se definió cómo acompañar a quienes tengan dificultades para comenzar.
- [ ] Se evitará corregir inmediatamente cada error.
- [ ] Se promoverá que el estudiantado pruebe sus propias ideas.
- [ ] Se prepararon preguntas para ayudar a comparar, justificar y mejorar decisiones.
- [ ] Se reconocerá el esfuerzo, la colaboración, la iteración y la documentación.
- [ ] Se planificó cómo intervenir ante conflictos o participación desigual.

## 8. Inclusión y accesibilidad

- [ ] Las instrucciones se presentarán de manera oral, escrita o visual según las necesidades.
- [ ] El lenguaje utilizado es claro y apropiado para el nivel.
- [ ] Se ofrecen distintas maneras de participar en el reto.
- [ ] Se consideraron adaptaciones para manipular materiales o herramientas.
- [ ] Se dispone de tiempo adicional o apoyos cuando son necesarios.
- [ ] Los equipos permiten que cada estudiante aporte desde sus fortalezas.
- [ ] El reto evita estereotipos relacionados con género, capacidad o experiencia tecnológica.
- [ ] Se valoran diferentes tipos de soluciones y formas de comunicar el aprendizaje.

## 9. Documentación y evidencias

- [ ] Se definió qué evidencias se recopilarán durante la experiencia.
- [ ] El estudiantado sabe cuándo debe registrar su proceso.
- [ ] Se prepararon hojas, bitácoras, dispositivos u otros medios de documentación.
- [ ] Se solicitarán evidencias del proceso y no únicamente del producto final.
- [ ] Se registrarán pruebas, errores, modificaciones y decisiones importantes.
- [ ] Se definió cómo se protegerá la privacidad al tomar fotografías o videos.
- [ ] Se estableció dónde se guardarán o compartirán las evidencias.
- [ ] La documentación será proporcional a la duración y complejidad del reto.

## 10. Uso de tecnología e inteligencia artificial

Complete esta sección únicamente cuando el reto incluya recursos digitales o inteligencia artificial.

- [ ] La tecnología tiene una función clara dentro del reto.
- [ ] Se comprobó el acceso a dispositivos, aplicaciones y conexión.
- [ ] Se preparó una alternativa en caso de problemas tecnológicos.
- [ ] El recurso digital es apropiado para la edad del estudiantado.
- [ ] Se revisaron las condiciones de privacidad y protección de datos.
- [ ] No se ingresará información personal o sensible en herramientas de IA.
- [ ] Se explicará que las respuestas generadas por IA pueden contener errores.
- [ ] El estudiantado deberá revisar, adaptar y justificar el contenido generado.
- [ ] La IA apoyará el proceso creativo sin sustituir la construcción, la reflexión o la toma de decisiones.
- [ ] Se documentará cuándo y para qué se utilizó la inteligencia artificial.

## 11. Cierre y reflexión

- [ ] Se reservó tiempo para detener la construcción y ordenar el espacio.
- [ ] Se prepararon preguntas para analizar el proceso.
- [ ] El estudiantado podrá explicar qué creó y por qué tomó ciertas decisiones.
- [ ] Se conversará sobre los errores, pruebas y cambios realizados.
- [ ] Se promoverá la retroalimentación respetuosa entre equipos.
- [ ] Se reconocerán diferentes soluciones para un mismo desafío.
- [ ] Se identificará qué podría mejorarse en una siguiente versión.
- [ ] Se conectará el aprendizaje con otras situaciones, asignaturas o problemas.

---

## Verificación final

Antes de comenzar, seleccione una opción:

- [ ] **Listo para implementar:** los elementos esenciales están preparados.
- [ ] **Requiere ajustes menores:** se puede implementar después de realizar pequeñas modificaciones.
- [ ] **Requiere reorganización:** faltan materiales, condiciones de seguridad o claridad pedagógica.
- [ ] **Debe reprogramarse:** no existen todavía las condiciones necesarias para desarrollar el reto de forma segura.
