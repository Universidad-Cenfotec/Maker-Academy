## Descripción

Este documento reúne palabras clave para comprender y comunicar las ideas principales del Pensamiento Maker.

## Contenido

| Palabra | Significado breve |
|---|---|
| Maker | Persona que aprende creando, reparando, probando o inventando. |
| Makerspace | Espacio para imaginar, construir, experimentar y compartir proyectos. |
| DIY | “Hazlo tú mismo”: crear o reparar con tus propias manos. |
| DIWO | “Hazlo con otros”: crear colaborando y compartiendo ideas. |
| Prototipo | Primera versión de una idea para probarla. |
| Iteración | Mejora que se realiza después de probar. |
| Boceto | Dibujo rápido de una idea. |
| Usuario | Persona que usará o se beneficiará de una solución. |
| Retroalimentación | Comentario que ayuda a mejorar. |
| Documentación | Registro del proceso mediante fotos, notas, dibujos o videos. |
