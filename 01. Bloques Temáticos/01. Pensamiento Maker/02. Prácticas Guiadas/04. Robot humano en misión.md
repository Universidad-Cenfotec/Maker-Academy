# Guía del Estudiante: Robot humano en misión

## Mi Desafío de Hoy

Creá una secuencia de instrucciones claras para que un robot humano complete una misión sin confundirse.

## Materiales y Herramientas

Marcá con una X dentro de los corchetes `[ ]` conforme vayás alistando tu equipo:

- [ ] Tarjetas o pequeños trozos de papel.
- [ ] Lápiz o marcador.
- [ ] Cinta adhesiva.
- [ ] Objetos para crear obstáculos.
- [ ] Una cuadrícula marcada en el piso o sobre una mesa.
- [ ] Un objeto que represente la meta.

## Fase 1: Inspiración (Conectando ideas)

Antes de empezar a construir, preparemos nuestra mente:

**La gran pregunta:** ¿Qué sucede cuando una instrucción no es suficientemente clara para una persona, una máquina o un robot?

**¡Para pensar!** Las computadoras y los robots necesitan recibir instrucciones ordenadas y precisas. Una secuencia de pasos utilizada para completar una tarea se llama **algoritmo**.

Conversá con tu equipo: ¿Qué instrucciones necesitaría un robot para avanzar desde un punto de inicio hasta una meta?

## Fase 2: Experimentación (Manos a la obra)

> ⚠️ **Regla de Oro Maker:** ¡Aprender del error es parte del juego! Si el robot no llega a la meta, no significa que el reto terminó. Revisá las instrucciones, encontrá el error y corregí el algoritmo.

Seguí estos pasos para desarrollar la misión:

### Paso 1. Construcción

Creá un recorrido con un punto de inicio, una meta y algunos obstáculos.

Podés utilizar instrucciones como:

- Avanzar un espacio.
- Girar a la derecha.
- Girar a la izquierda.
- Recoger un objeto.
- Detenerse.

**Tip:** Cada tarjeta debe contener una sola instrucción.

### Paso 2. Programación

Ordená las tarjetas para crear el algoritmo que deberá seguir el robot humano.

Una persona será el robot y deberá seguir exactamente las instrucciones, sin interpretar ni agregar movimientos.

### Paso 3. La prueba

Ejecutá el algoritmo.

Observá:

- ¿El robot llegó a la meta?
- ¿Alguna instrucción estaba incompleta?
- ¿Faltó indicar una dirección?
- ¿Había pasos innecesarios?
- ¿En qué parte apareció el error?

Corregí las instrucciones y realizá una segunda prueba.

## Fase 3: Reflexión (Show your work)

Llegó el momento de compartir lo que descubriste y documentar tu programa:

**¡Mostrá tu trabajo!** Ejecutá el algoritmo frente a tus compañeros y explicá qué error encontraste y cómo lo corregiste.

### Mi Bitácora Maker

Respondé estas preguntas clave para guardar tu evidencia:

1. ¿Qué parte del algoritmo funcionó mejor?
2. ¿Qué instrucción provocó un error o una confusión?
3. ¿Cómo identificaste y corregiste el error?
4. ¿Cómo podrías completar la misma misión con menos instrucciones?

## Sugerencias de profundidad por nivel

- **Preescolar a tercer grado:** Utilizar flechas o imágenes para representar movimientos sencillos.
- **Cuarto a sexto grado:** Crear y depurar secuencias que incluyan giros y obstáculos.
- **Sétimo a noveno año:** Incorporar repeticiones, condiciones y búsqueda de rutas más cortas.
- **Décimo y undécimo año:** Representar el algoritmo mediante pseudocódigo, diagramas de flujo o un lenguaje de programación.
