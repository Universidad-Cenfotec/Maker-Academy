## Descripción

Pensar como maker es observar un reto y reconocer que es posible imaginar una solución, construir una primera versión, probarla y mejorarla.

El **pensamiento maker** es una forma de aprender mediante la creación. Invita al estudiantado a explorar su entorno, formular preguntas, experimentar con materiales y tecnologías, construir prototipos, aprender de los errores y compartir sus descubrimientos.

Este bloque constituye la base de Maker Academy. No se limita al uso de herramientas o a la fabricación de objetos, sino que promueve una actitud activa, curiosa, colaborativa y responsable frente a los retos.

También permite comprender que la tecnología no es solamente algo que se consume. Puede explorarse, modificarse, repararse, programarse y utilizarse para responder a necesidades reales.

---

## Propósito del bloque

Desarrollar en el estudiantado una forma de aprender basada en la curiosidad, la creación, la colaboración, la experimentación y la mejora continua.

A través de este bloque se busca que pueda:

- Imaginar distintas soluciones ante un reto.
- Transformar ideas en prototipos.
- Probar, identificar errores y realizar mejoras.
- Trabajar con otras personas.
- Documentar y comunicar su proceso.
- Utilizar materiales, herramientas y tecnologías de forma segura.
- Diseñar considerando las necesidades de las personas y del entorno.

---

## Ideas clave

- Crear es una forma de aprender.
- El error brinda información para mejorar.
- Un prototipo permite probar una idea; no necesita ser perfecto.
- Las ideas evolucionan mediante pruebas y nuevas versiones.
- La colaboración amplía las posibilidades de creación.
- Documentar ayuda a recordar, explicar y compartir.
- La seguridad y el cuidado son parte de la cultura maker.
- La tecnología debe utilizarse con propósito.

## Progresión del pensamiento maker

El desarrollo del pensamiento maker debe adaptarse a la edad, la experiencia y el nivel de autonomía del estudiantado.

| Nivel de desarrollo | Énfasis |
|---|---|
| **Inicial** | Explorar materiales, construir soluciones sencillas, seguir acuerdos de seguridad y explicar lo realizado. |
| **Intermedio** | Diseñar, construir, probar y mejorar propuestas con apoyos parciales. |
| **Avanzado** | Identificar necesidades, tomar decisiones, integrar tecnologías, documentar el proceso y justificar las mejoras. |

La progresión no depende únicamente del grado escolar. También debe considerar la experiencia previa del grupo y la complejidad del reto.

## Relación con XperiencED Maker

**XperiencED Maker** integra la cultura maker con el aprendizaje vivencial. En este bloque, sus tres momentos se desarrollan de la siguiente manera:

| Momento | En este bloque se vive cuando... |
|---|---|
| **Inspiración** | Se observa el entorno, se activan conocimientos previos y se identifica una curiosidad, necesidad o reto. |
| **Experimentación** | Se imaginan ideas, se construyen prototipos, se prueban soluciones, se aprende del error y se realizan mejoras. |
| **Reflexión** | Se comparte lo creado, se documenta el proceso, se explican decisiones y se reconocen los aprendizajes. |

## Cómo utilizar este bloque

Para iniciar, se recomienda:

1. Leer este README para comprender el propósito del bloque.
2. Revisar el mapa de progresión y ajustar la profundidad al nivel del grupo.
3. Introducir los conceptos necesarios mediante una mini lección.
4. Establecer acuerdos de seguridad antes de comenzar una actividad práctica.
5. Seleccionar una práctica guiada que permita explorar, construir y probar.
6. Facilitar la experiencia mediante preguntas, apoyos y retroalimentación.
7. Cerrar con documentación, socialización y reflexión.

No es necesario desarrollar todos los recursos de forma consecutiva. La persona docente puede seleccionar y adaptar aquellos que respondan al propósito de aprendizaje, al contexto y a la experiencia del grupo.

## Articulación con otros bloques

Pensamiento Maker es la base para avanzar hacia experiencias relacionadas con:

- Fabricación digital.
- Electrónica.
- Programación y microcontroladores.
- Robótica.
- Internet de las cosas.
- Inteligencia artificial.
- Creatividad digital.
- Proyectos interdisciplinarios.

Antes de utilizar máquinas, sensores o lenguajes de programación, es importante que el estudiantado comprenda cómo colaborar, cuidar los recursos, probar ideas, aprender del error y mejorar sus creaciones.

---

## Nota docente

El pensamiento maker no se desarrolla mediante una única actividad. Requiere experiencias progresivas donde el estudiantado pueda explorar, tomar decisiones, construir, probar, documentar y reflexionar.

La pregunta central para revisar una experiencia de este bloque es:

> ¿El estudiantado tuvo una oportunidad real de imaginar, crear, probar y mejorar una idea?
