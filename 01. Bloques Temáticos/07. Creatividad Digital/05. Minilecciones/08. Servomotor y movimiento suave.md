## Propósito de aprendizaje

Que los estudiantes controlen el ángulo de un servo y programen un movimiento suave que parezca natural.

---

## Objetivo de aprendizaje

Al finalizar la minilección, los estudiantes serán capaces de:

- Mover el servo a 0°, 90° y 180°.
- Programar un movimiento suave entre dos ángulos.

---

## Concepto clave

- **Concepto principal:** Servomotor.
- **Explicación sencilla:** Motor que gira a un ángulo exacto entre 0° y 180° según la señal que recibe. Tiene tres cables: café (GND), rojo (5 V) y naranja (señal).
- **Ejemplo cotidiano:** Las aspas de una barrera de parqueo que suben y bajan a una posición fija.

### Pasos de la experimentación

**Paso 1.** En la IdeaBoard, conecten el servo directo en una fila del bloque de conectores de servo (por ejemplo IO04) con el puente SELECT en Vin.

**Paso 2.** Programen `write(0)`, `write(90)` y `write(180)` con un segundo de pausa.

**Paso 3.** Observen que el servo salta de golpe entre posiciones.

**Paso 4.** Usen la función `moverSuave`, que avanza en 20 pasos con una curva coseno: arranca y frena despacio.

**Paso 5.** Cambien la pausa entre pasos para hacerlo más rápido o más lento.

### Código base

```cpp
void moverSuave(Servo &s, int desde, int hasta) {
  for (int i = 0; i <= 20; i++) {
    float k = (1 - cos(i * PI / 20)) / 2;   // curva suave de 0 a 1
    s.write(desde + (hasta - desde) * k);
    delay(12);
  }
}
```

## Adaptaciones y apoyos

- **Para estudiantes que requieren más apoyo:** usar los bloques de servo de MakeCode.
- **Para estudiantes que avanzan más rápido:** mover dos servos en espejo.
- **Para accesibilidad:** describir el movimiento en voz alta mientras se prueba.
