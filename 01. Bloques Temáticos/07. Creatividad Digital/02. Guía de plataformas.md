### Plataformas del bloque

| Plataforma | Cuándo se usa | Se programa con |

#### IdeaBoard

Los proyectos del bloque usan esos componentes y otros de uso común.

### Preparar el entorno de programación

#### Arduino IDE paso a paso

Arduino IDE es el programa con el que se escribe el código, se carga en la IdeaBoard o en un Arduino, y se ven los mensajes que envía la placa. Esta sección explica lo básico; las librerías propias de cada proyecto se indican en su guía.

**1. Instalar Arduino IDE.** Descargue Arduino IDE 2 desde la [página oficial de Arduino](https://www.arduino.cc/en/software), elija la versión para su sistema (Windows, macOS o Linux) e instálela con las opciones que trae. Si Windows pregunta si desea instalar controladores, acepte.

> *Insertar próximamente una imagen: página de descarga de Arduino IDE 2 en arduino.cc con el botón de descarga para Windows señalado.*

**2. Conocer la ventana.** Arriba a la izquierda están los botones **Verificar** (revisa que el código no tenga errores) y **Subir** (lo carga en la placa); a su lado, el selector de placa. En la barra de la izquierda están, en orden: archivos del proyecto, **gestor de placas**, **gestor de librerías**, depuración y búsqueda. Arriba a la derecha está el botón del **monitor serie**.

<img width="700" alt="ventana de Arduino IDE con los botones Verificar y Subir marcados y el monitor serie abierto abajo" src="./08.%20Instalaciones%20interactivas/04.%20Proyecto%203%20-%20Bosque%20sonoro/06.%20Im%C3%A1genes/arduino-ide-subir-y-monitor-serie.png" />

**3. Instalar el paquete de placas ESP32.** La IdeaBoard usa un ESP32, que Arduino IDE no trae de fábrica.

1. Abra el **gestor de placas** (segundo ícono de la barra izquierda).
2. Escriba `esp32` en el buscador.
3. Instale **esp32 by Espressif Systems**. La descarga puede tardar varios minutos.
4. Si no aparece en la búsqueda, abra **File > Preferences**, pegue en **Additional boards manager URLs** la dirección `https://espressif.github.io/arduino-esp32/package_esp32_index.json`, presione OK y vuelva a buscar.

<img width="550" alt="gestor de placas con esp32 by Espressif Systems instalado" src="./08.%20Instalaciones%20interactivas/04.%20Proyecto%203%20-%20Bosque%20sonoro/06.%20Im%C3%A1genes/arduino-ide-gestor-de-placas.png" />

Para un Arduino Uno no hace falta este paso: su paquete viene instalado.

**4. Elegir la placa y el puerto.** Conecte la placa con un cable USB de datos. En el selector de placa elija **Select other board and port**, busque **ESP32 Dev Module** (para la IdeaBoard) o **Arduino Uno**, marque el puerto **COM** de la placa y presione **OK**.

<img width="550" alt="ventana Select Other Board and Port con ESP32 Dev Module y el puerto COM7 seleccionados" src="./08.%20Instalaciones%20interactivas/04.%20Proyecto%203%20-%20Bosque%20sonoro/06.%20Im%C3%A1genes/arduino-ide-placa-y-puerto.png" />

Para saber cuál puerto es, desconecte la placa y fíjese cuál COM desaparece; al volver a conectarla, elija ese. Si no aparece ningún puerto, el cable puede ser solo de carga o falta el controlador **CH340**: cambie el cable o instale el controlador.

**5. Instalar librerías.** Las librerías agregan funciones que el código usa, como sensores, servos o MIDI.

- **Desde el gestor de librerías:** abra el tercer ícono de la barra izquierda, escriba el nombre de la librería y presione **Install**. Fíjese en el autor: varias librerías tienen nombres parecidos.

<img width="450" alt="gestor de librerías de Arduino IDE con una librería instalada" src="./08.%20Instalaciones%20interactivas/04.%20Proyecto%203%20-%20Bosque%20sonoro/06.%20Im%C3%A1genes/arduino-ide-midi-library.png" />

- **Desde un archivo ZIP:** algunas librerías se descargan de GitHub (botón **Code > Download ZIP**). Sin descomprimir el archivo, entre a **Sketch > Include Library > Add .ZIP Library** y elíjalo.

<img width="550" alt="menú Sketch, Include Library, Add .ZIP Library" src="./08.%20Instalaciones%20interactivas/04.%20Proyecto%203%20-%20Bosque%20sonoro/06.%20Im%C3%A1genes/arduino-ide-agregar-zip.png" />

**6. Verificar y subir el código.** Pegue el código en la ventana, presione **Verificar** y, si no hay errores, **Subir**. Abajo aparece el avance de la carga; al terminar dice "Done uploading" o "Hard resetting via RTS pin". Si la carga se queda en "Connecting...", mantenga presionado el botón **BOOT** de la placa hasta que empiece a cargar.

**7. Abrir el monitor serie.** Presione el ícono de la lupa arriba a la derecha (o **Tools > Serial Monitor**) y elija la velocidad que indica el código, normalmente **115200 baud**. Ahí aparecen los mensajes que envía la placa con `Serial.println()`. Ciérrelo antes de usar otro programa que necesite el mismo puerto, como un juego o un programa de Python.

| Problema | Solución |
|---|---|
| No aparece el puerto COM | Cambie a un cable USB de datos e instale el controlador CH340. |
| Error de compilación por una librería | Instale la librería que indica el mensaje y revise que la placa elegida sea la correcta. |
| La carga se queda en "Connecting..." | Mantenga presionado BOOT al iniciar la carga. |
| El monitor serie muestra símbolos raros | Elija la misma velocidad del código (115200 baud). |

#### MakeCode para micro:bit

Se usa en línea en makecode.microbit.org. Las extensiones necesarias (por ejemplo, "sonar" o "servo") se agregan desde el botón **Extensiones**.

### Cuidados eléctricos con ESP32

- El ESP32 trabaja con 3,3 V. El pin ECHO de los sensores ultrasónicos entrega 5 V: se conecta con un divisor de voltaje (resistencia de 1 kilohmio hacia el pin y de 2 kilohmios hacia GND).
- Cuando se usa Wi-Fi, las entradas analógicas deben ir en los GPIO 32 a 39.
- El servomotor se alimenta desde 5 V o desde el conector de servo de la IdeaBoard, nunca desde 3,3 V.

### Cómo se organizan las guías por placa

Cada proyecto con electrónica tiene una carpeta `05. Plataformas/` con un archivo por placa. Todos siguen la misma estructura: componentes equivalentes, conexiones, entorno y librerías, código base comentado, prueba de funcionamiento y limitaciones. La ficha de cada proyecto incluye una tabla "Elige tu plataforma" con los enlaces.

El Proyecto 1 no usa placa y por eso no tiene esta carpeta.
