### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

| Componente | Conexión | Pin de la IdeaBoard |
|---|---|---|
| Grupo de luces 1 | Dos LEDs, cada uno con su resistencia de 220 Ω | Fila IO04: señal y GND |
| Grupo de luces 2 | Dos LEDs, cada uno con su resistencia de 220 Ω | Fila IO05: señal y GND |
| Grupo de luces 3 | Dos LEDs, cada uno con su resistencia de 220 Ω | Fila IO18: señal y GND |
| HC-SR05 | VCC y GND | Fila IO26: V+ y GND |
| HC-SR05 | TRIG | IO26 (señal) |
| HC-SR05 | ECHO | 1 kΩ hacia IO35; 2 kΩ de IO35 a GND |

Cada LED lleva su propia resistencia: pata larga hacia la señal, pata corta hacia GND.

### Programación con IdeaCode (CircuitPython)

```python
# Proyecto 7: Volcan Poas vivo, Secundaria (IdeaBoard con IdeaCode / CircuitPython)
# El sensor detecta al publico, enciende las luces del crater y avisa a la
# computadora con el mensaje "ERUPCION" para que la proyeccion cambie.
import time
import math
import random
import board
import digitalio
import pulseio
import pwmio

DISTANCIA_CM = 80          # el publico activa la erupcion a menos de esto
DURACION = 15              # segundos de erupcion
ESPERA = 20                # segundos antes de poder repetir

# Tres grupos de LEDs (cada grupo: 2 LEDs con su resistencia de 220 Ohm)
luces = [pwmio.PWMOut(p, frequency=1000, duty_cycle=0) for p in (board.IO4, board.IO5, board.IO18)]
trig = digitalio.DigitalInOut(board.IO26)
trig.direction = digitalio.Direction.OUTPUT
eco = pulseio.PulseIn(board.IO35, maxlen=2)     # ECHO con divisor 1 kOhm / 2 kOhm
eco.pause()


def medir_distancia_cm():
    eco.clear()
    eco.resume()
    trig.value = True
    time.sleep(0.00001)
    trig.value = False
    t0 = time.monotonic()
    while len(eco) == 0:
        if time.monotonic() - t0 > 0.05:
            eco.pause()
            return 999
    eco.pause()
    return eco[0] / 58


def brillo(luz, nivel):
    """nivel de 0 a 1"""
    luz.duty_cycle = int(max(0, min(1, nivel)) * 65535)


def calma(t):
    """Brillo suave que sube y baja: el calor dentro del crater."""
    for i, luz in enumerate(luces):
        brillo(luz, 0.05 + 0.05 * math.sin(t * 1.2 + i))


def erupcion():
    print("ERUPCION")
    fin = time.monotonic() + DURACION
    while time.monotonic() < fin:
        for luz in luces:
            brillo(luz, random.uniform(0.3, 1.0))
        time.sleep(random.uniform(0.03, 0.12))
    print("CALMA")


ultima = -ESPERA
print("Volcan listo")
while True:
    ahora = time.monotonic()
    calma(ahora)
    if ahora - ultima > ESPERA and medir_distancia_cm() < DISTANCIA_CM:
        erupcion()
        ultima = time.monotonic()
    time.sleep(0.05)
```

### La proyección

Abra [`proyeccion.html`](../07.%20C%C3%B3digo/proyeccion.html) en Chrome o Edge con el proyector conectado como segunda pantalla.

| Tecla | Acción |
|---|---|
| M | Mostrar u ocultar las esquinas para ajustar la imagen a la maqueta |
| E | Erupción manual (para probar sin la placa) |
| F | Pantalla completa |
| H | Ocultar el panel |

Para unir la placa: cierre IdeaCode, presione **Conectar IdeaBoard** y elija el puerto. Cada vez que la placa envía `ERUPCION`, la proyección cambia de escena por 15 segundos.

### Prueba de funcionamiento

1. Con IdeaCode abierto, acérquese a menos de 80 cm: la consola muestra ERUPCION, los LEDs parpadean 15 segundos y luego muestra CALMA.
2. Durante 20 segundos no se puede repetir: así la escena no se reinicia con cada movimiento.
3. Con la proyección conectada, la erupción en pantalla empieza al mismo tiempo que las luces.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| No aparece el puerto en la proyección | Cierre IdeaCode. |
| La placa se reinicia al conectar | Es normal al abrir el puerto: el programa vuelve a empezar. |
| Los LEDs brillan poco | Revise que cada LED tenga su resistencia y la pata larga hacia la señal. |
| La erupción se repite sola | Suba `ESPERA` o baje `DISTANCIA_CM`. |
