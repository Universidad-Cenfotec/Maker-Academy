## Propósito

Explicar cómo usar la micro:bit para lanzar la erupción: con Scratch en Primaria y con un sensor en Secundaria.

---

## Contenido

### Primaria: botón de erupción en Scratch

1. Instale Scratch Link y cargue en la micro:bit el HEX de Scratch desde [scratch.mit.edu/microbit](https://scratch.mit.edu/microbit).
2. En Scratch agregue la extensión **micro:bit** y conecte la placa por Bluetooth.
3. Use el bloque "cuando se presione el botón A" para enviar el mensaje `erupción` a todos los objetos.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Secundaria: sensor y luces con la micro:bit

Agregue la extensión **sonar**. El HC-SR05 necesita 5 V de una placa de expansión y un divisor en ECHO (1 kΩ y 2 kΩ). Un LED con resistencia de 220 Ω va en P0.

```javascript
// Volcan Poas vivo: micro:bit como disparador de la proyeccion (vista JavaScript de MakeCode)
let ultima = -20000
serial.redirectToUSB()
serial.setBaudRate(BaudRate.BaudRate115200)
basic.forever(function () {
    let d = sonar.ping(DigitalPin.P1, DigitalPin.P2, PingUnit.Centimeters)
    if (d > 0 && d < 80 && input.runningTime() - ultima > 20000) {
        serial.writeLine("ERUPCION")
        basic.showIcon(IconNames.Triangle)
        for (let i = 0; i < 120; i++) {
            pins.analogWritePin(AnalogPin.P0, randint(300, 1023))
            basic.pause(randint(30, 120))
        }
        serial.writeLine("CALMA")
        ultima = input.runningTime()
        basic.clearScreen()
    }
    pins.analogWritePin(AnalogPin.P0, 60)
    basic.pause(100)
})
```

La proyección `proyeccion.html` recibe `ERUPCION` igual que con la IdeaBoard.

### Limitaciones y soluciones

- Un pin de la micro:bit da poca corriente: use un solo LED por pin.
- Si Scratch no encuentra la placa, revise Scratch Link y el Bluetooth.
