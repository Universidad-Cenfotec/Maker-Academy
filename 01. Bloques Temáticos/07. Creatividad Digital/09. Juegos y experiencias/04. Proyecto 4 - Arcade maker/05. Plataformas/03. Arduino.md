## Contenido

### Diferencias con la IdeaBoard

El Arduino Uno envía el mismo formato que la IdeaBoard, así que funciona con el mismo juego. Su conversor analógico va de 0 a 1023 y el código lo lleva a 0 a 1000.

<img width="380" alt="Arduino Uno" src="https://upload.wikimedia.org/wikipedia/commons/3/38/Arduino_Uno_-_R3.jpg" />

### Conexiones

| Componente | Conexión |
|---|---|
| Botones 1 a 4 | Pines 2, 3, 4 y 5, y GND |
| Potenciómetro | Extremos a 5V y GND, centro a A0 |

### Código

```cpp
// Proyecto 4: Arcade maker, control (Arduino Uno)
// Envia "b1,b2,b3,b4,pot" 30 veces por segundo. pot va de 0 a 1000.
const int BOTONES[4] = {2, 3, 4, 5};   // cada pulsador entre el pin y GND
const int PIN_POT = A0;                // potenciometro: extremos a 5 V y GND, centro a A0

void setup() {
  Serial.begin(115200);
  for (int i = 0; i < 4; i++) pinMode(BOTONES[i], INPUT_PULLUP);
}

void loop() {
  for (int i = 0; i < 4; i++) {
    Serial.print(digitalRead(BOTONES[i]) == LOW ? 1 : 0);   // presionado = LOW
    Serial.print(",");
  }
  Serial.println(map(analogRead(PIN_POT), 0, 1023, 0, 1000));
  delay(33);
}
```

### Prueba de funcionamiento

Abra el monitor serie a 115200 baudios: deben aparecer líneas como `0,0,0,0,512`. Ciérrelo antes de conectar el juego.

### Limitaciones y soluciones

- Solo un programa puede usar el puerto: cierre el monitor serie antes de abrir el juego.
