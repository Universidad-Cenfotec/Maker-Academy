## Contenido

### Primaria: micro:bit con Scratch

Scratch tiene una extensión oficial para la micro:bit que funciona por Bluetooth.

1. Instale **Scratch Link** en la computadora (Windows o macOS) y encienda el Bluetooth.
2. Desde [scratch.mit.edu/microbit](https://scratch.mit.edu/microbit) descargue el archivo HEX de Scratch y cópielo a la micro:bit.
3. En Scratch, agregue la extensión **micro:bit** y conecte la placa.
4. Use los bloques "cuando el pin 0 se conecte", "cuando se presione el botón A" o "cuando se incline" en lugar de las teclas.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

#### Botones de cartón con aluminio

| Botón | Conexión |
|---|---|
| Izquierda | Aluminio de arriba a P0 |
| Derecha | Aluminio de arriba a P1 |
| Acción | Aluminio de arriba a P2 |
| Tierra común | Tira de aluminio de abajo a GND |

Al presionar, el aluminio de arriba toca la tira de GND y Scratch recibe "pin conectado".

### Secundaria: micro:bit con el juego en p5.js

La micro:bit también puede enviar el formato del juego (`b1,b2,b3,b4,pot`) por USB:

```javascript
// Arcade maker: micro:bit como control del juego en p5.js (vista JavaScript de MakeCode)
// Botones A y B de la placa, pulsadores en P0 y P1 (a GND) y potenciometro en P2.
serial.redirectToUSB()
serial.setBaudRate(BaudRate.BaudRate115200)
pins.setPull(DigitalPin.P0, PinPullMode.PullUp)
pins.setPull(DigitalPin.P1, PinPullMode.PullUp)
basic.forever(function () {
    let b1 = input.buttonIsPressed(Button.A) ? 1 : 0
    let b2 = input.buttonIsPressed(Button.B) ? 1 : 0
    let b3 = pins.digitalReadPin(DigitalPin.P0) == 0 ? 1 : 0
    let b4 = pins.digitalReadPin(DigitalPin.P1) == 0 ? 1 : 0
    let pot = Math.round(Math.map(pins.analogReadPin(AnalogPin.P2), 0, 1023, 0, 1000))
    serial.writeLine("" + b1 + "," + b2 + "," + b3 + "," + b4 + "," + pot)
    basic.pause(33)
})
```

### Prueba de funcionamiento

1. **Primaria:** en Scratch, al presionar cada botón de cartón se ejecuta su bloque "cuando el pin se conecte".
2. **Secundaria:** abra el juego en Chrome, conecte la micro:bit y gire el potenciómetro.

### Limitaciones y soluciones

- Si Scratch no encuentra la placa, revise que tenga el HEX de Scratch y que Scratch Link esté abierto.
- Los eventos de pin de Scratch se activan una vez por toque: para moverse varias veces, hay que presionar varias veces.
