## Contenido

### Diferencias con la IdeaBoard

Usa los mismos pines que la guía de la IdeaBoard. El conversor del ESP32 va de 0 a 4095 y el código lo lleva a 0 a 1000.

<img width="380" alt="placa ESP32 DevKit" src="https://upload.wikimedia.org/wikipedia/commons/thumb/2/20/ESP32_Espressif_ESP-WROOM-32_Dev_Board.jpg/960px-ESP32_Espressif_ESP-WROOM-32_Dev_Board.jpg" />

### Conexiones

| Componente | Pin del ESP32 |
|---|---|
| Botones 1 a 4 | 4, 5, 18 y 19, y GND |
| Potenciómetro | Extremos a 3.3V y GND, centro a 34 |

### Código

```cpp
// Proyecto 4: Arcade maker, control (ESP32 generico, Arduino IDE)
// Envia "b1,b2,b3,b4,pot" 30 veces por segundo. pot va de 0 a 1000.
const int BOTONES[4] = {4, 5, 18, 19};  // cada pulsador entre el pin y GND
const int PIN_POT = 34;                 // potenciometro: extremos a 3.3 V y GND, centro a 34

void setup() {
  Serial.begin(115200);
  for (int i = 0; i < 4; i++) pinMode(BOTONES[i], INPUT_PULLUP);
}

void loop() {
  for (int i = 0; i < 4; i++) {
    Serial.print(digitalRead(BOTONES[i]) == LOW ? 1 : 0);
    Serial.print(",");
  }
  Serial.println(map(analogRead(PIN_POT), 0, 4095, 0, 1000));
  delay(33);
}
```

### Prueba de funcionamiento

Abra el monitor serie a 115200 baudios y presione los botones. Ciérrelo antes de conectar el juego.

### Limitaciones y soluciones

- El pin 34 solo es de entrada: sirve para el potenciómetro, no para un botón con pull-up interno.
