### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

Cada fila de servo tiene GND junto a la señal: el botón se conecta entre esos dos pines y no necesita resistencia, porque el programa activa la resistencia interna (pull-up).

| Componente | Pin del componente | Pin de la IdeaBoard |
|---|---|---|
| Botón 1 (iniciar) | Terminal 1 / terminal 2 | Fila IO04: señal / GND |
| Botón 2 (escudo) | Terminal 1 / terminal 2 | Fila IO05: señal / GND |
| Botón 3 (pausa) | Terminal 1 / terminal 2 | Fila IO18: señal / GND |
| Botón 4 (sonido) | Terminal 1 / terminal 2 | Fila IO19: señal / GND |
| Potenciómetro 10 kΩ | Lado / centro / lado | Fila IO34: 3.3 V / señal / GND |

### Programación con IdeaCode (CircuitPython)

1. Abra [IdeaCode](https://ideacode.crcibernetica.com/) en Chrome o Edge y conecte la IdeaBoard.
2. Pegue el programa en `code.py` y guárdelo. En la consola aparecen líneas como `0,0,0,0,512`.
3. Cierre IdeaCode antes de abrir el juego: el juego necesita el puerto.

```python
# Proyecto 4: Arcade maker, control (IdeaBoard con IdeaCode / CircuitPython)
# Envia el estado del control a la computadora 30 veces por segundo:
#   b1,b2,b3,b4,pot   por ejemplo: 0,1,0,0,512
# b = 1 cuando el boton esta presionado. pot va de 0 a 1000.
import time
import board
import digitalio
import analogio
import neopixel

# Cada pulsador va entre la senal y GND de una fila de servo (no necesita resistencia)
PINES_BOTONES = [board.IO4, board.IO5, board.IO18, board.IO19]
pot = analogio.AnalogIn(board.IO34)     # potenciometro: fila IO34 (3.3 V, GND y senal)
luz = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.2)

botones = []
for pin in PINES_BOTONES:
    b = digitalio.DigitalInOut(pin)
    b.switch_to_input(pull=digitalio.Pull.UP)
    botones.append(b)

luz[0] = (0, 0, 80)
while True:
    estados = [0 if b.value else 1 for b in botones]   # presionado = 0 V = False
    valor = pot.value * 1000 // 65535
    print(",".join(str(x) for x in estados) + "," + str(valor))
    luz[0] = (0, 120, 0) if any(estados) else (0, 0, 80)
    time.sleep(0.033)
```

### El juego

El archivo [`juego.html`](../07.%20C%C3%B3digo/juego.html) se abre con doble clic en Chrome o Edge. Presione **Conectar control** y elija el puerto de la IdeaBoard. Sin control, se juega con las flechas, la barra espaciadora, E y P.

<img width="500" alt="pantalla de inicio del juego Tortuga baula" src="../06.%20Im%C3%A1genes/juego-inicio.png" />

El protocolo es una línea de texto por lectura: `b1,b2,b3,b4,pot`, donde cada botón vale 1 si está presionado y `pot` va de 0 a 1000. Cualquier placa que envíe ese formato a 115200 baudios funciona con el juego.

### Prueba de funcionamiento

1. Con IdeaCode abierto, presione cada botón: cambia su número de 0 a 1 y el LED de la placa se pone verde.
2. Gire el potenciómetro de un extremo al otro: el último número va de 0 a 1000.
3. Cierre IdeaCode, abra el juego, conecte y presione el botón 1 para empezar.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| No aparece el puerto en el juego | Cierre IdeaCode o cualquier monitor serie. |
| La placa se reinicia al conectar el juego | Es normal: al abrir el puerto el ESP32 se reinicia y el programa vuelve a empezar. |
| El potenciómetro salta | Revise que el centro esté en IO34 y los extremos en 3.3 V y GND. |
