### Componentes

| Componente | Cantidad |
|---|---|
| IdeaBoard con cable USB-C de datos | 1 |
| Botones de arcade de 30 mm con microswitch | 2 |
| Jumpers hembra-hembra (con un extremo pelado) | 3 o 4 |
| Placa de acrílico o MDF con dos agujeros de 30 mm | 1 |

### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

Cada fila de servo tiene tres pines: señal, V+ (en el medio) y GND. Para un botón se usan solo la **señal** y **GND**; el pin del medio (V+) no se usa. El botón no necesita resistencia, porque el programa activa la resistencia interna (pull-up), y no tiene polaridad.

| Botón | Terminal 1 | Terminal 2 | Acción en el juego |
|---|---|---|---|
| Izquierdo | Señal de la fila IO05 | GND | Mover a la izquierda |
| Derecho | Señal de la fila IO18 | GND | Mover a la derecha |
| Los dos a la vez | — | — | Iniciar la partida y, durante el juego, activar el escudo |

Los dos cables de GND pueden unirse a un solo jumper.

### Construcción del control

No se necesita soldar. Cada botón se conecta con jumpers:

1. **Montar los botones.** Inserte los dos botones de arcade en los agujeros de 30 mm de la placa y asegúrelos.
2. **Preparar los jumpers.** Corte cada jumper hembra-hembra cerca de uno de sus extremos y pele aproximadamente 1 cm del cable. El otro extremo conserva su conector hembra para conectarse a la IdeaBoard.
3. **Unir los jumpers a los botones.** Enrolle el cobre pelado en un terminal del microswitch, apriételo con el alicate y cúbralo con cinta aislante para que los dos cables del mismo botón no se toquen.
4. **Revisar.** Tire suavemente de cada jumper para comprobar que el cobre está firme en el terminal.

<img width="450" alt="parte posterior de los botones de arcade con cables conectados a los terminales del microswitch" src="../06.%20Im%C3%A1genes/foto-s-botones-arcade-cableado-1.jpg" />

### Nombres de los pines en CircuitPython

Los nombres `board.IO4`, `board.IO5`, `board.IO18`, `board.IO19`, `board.IO23` y `board.IO34` corresponden a la definición oficial de la placa CRCibernética IdeaBoard en CircuitPython (archivo `ports/espressif/boards/crcibernetica-ideaboard/pins.c` del repositorio de CircuitPython). Si una versión distinta del firmware muestra un error con el nombre de un pin, ejecute en la consola de IdeaCode:

```python
import board; print(dir(board))
```

### Programación con IdeaCode (CircuitPython)

1. Con los botones ya conectados, conecte la IdeaBoard a la computadora con el cable USB-C de datos.
2. Abra [IdeaCode](https://ideacode.crcibernetica.com/) en Chrome o Edge, presione **Connect** y elija el puerto de la placa.
3. Copie el programa en el archivo `code.py` de la placa y guárdelo con **Save**. En la consola aparecen líneas como `0,0,0,0,500`.
4. Cierre la pestaña de IdeaCode antes de abrir el juego: el juego necesita el puerto libre.

<img width="600" alt="editor IdeaCode con los botones Connect, Save, Run y Stop" src="../06.%20Im%C3%A1genes/ideacode-editor.png" />

El programa está en [`control_botones_code.py`](../07.%20C%C3%B3digo/control_botones_code.py). `VELOCIDAD` controla qué tan rápido se mueve la tortuga. Los botones de iniciar (IO04), escudo (IO19) y pausa (IO23) son opcionales: si no se conectan, el programa funciona igual.

```python
# Arcade maker: control SIN joystick (IdeaBoard, CircuitPython)
# Dos botones de arcade mueven la tortuga a la izquierda y a la derecha.
# El programa convierte esos botones en el valor "pot" que espera el juego.
#
# Formato que se envia al juego: b1,b2,b3,b4,pot
#   b1 = iniciar  -> boton IO04 (opcional) o los dos botones azules a la vez
#   b2 = escudo   -> boton IO19 (opcional)
#   b3 = pausa    -> boton IO23 (opcional)
#   b4 = sonido   -> sin usar
#   pot = posicion de la tortuga, de 0 (izquierda) a 1000 (derecha)
#
# Conexion de cada boton: un terminal a la senal y el otro a GND de la misma
# fila. NO usar el pin del medio de la fila (V+).
#   Boton IZQUIERDA -> IO05
#   Boton DERECHA   -> IO18
#   (opcionales)  INICIAR -> IO04, ESCUDO -> IO19, PAUSA -> IO23

import time
import board
import digitalio

VELOCIDAD = 30        # cuanto se mueve la tortuga en cada lectura (subir = mas rapida)

# Si un boton de la caja industrial funciona al reves (marca 1 suelto),
# es "normalmente cerrado": pongan True en su linea.
INICIAR_NC = False
ESCUDO_NC = False
PAUSA_NC = False

def boton(pin):
    b = digitalio.DigitalInOut(pin)
    b.switch_to_input(pull=digitalio.Pull.UP)   # resistencia interna
    return b

def presionado(b, nc=False):
    # Con pull-up: suelto = True, presionado = False (unido a GND)
    if nc:
        return 1 if b.value else 0
    return 0 if b.value else 1

izquierda = boton(board.IO5)
derecha = boton(board.IO18)
iniciar = boton(board.IO4)
escudo = boton(board.IO19)
pausa = boton(board.IO23)

posicion = 500        # la tortuga empieza en el centro

while True:
    izq = presionado(izquierda)
    der = presionado(derecha)

    if izq and not der:
        posicion = max(0, posicion - VELOCIDAD)
    elif der and not izq:
        posicion = min(1000, posicion + VELOCIDAD)

    # Iniciar: el boton de IO04, o los dos botones azules al mismo tiempo
    b1 = 1 if (presionado(iniciar, INICIAR_NC) or (izq and der)) else 0
    b2 = presionado(escudo, ESCUDO_NC)
    b3 = presionado(pausa, PAUSA_NC)

    print("{},{},{},0,{}".format(b1, b2, b3, posicion))
    time.sleep(0.03)
```

### El juego

El archivo [`juego.html`](../07.%20C%C3%B3digo/juego.html) se abre en Chrome o Edge de computadora. Presione **Conectar control** y elija el puerto de la IdeaBoard.

 Sin control, se juega con el teclado: flechas o A y D para mover, E o barra espaciadora para iniciar, barra espaciadora para el escudo, P para pausar y M para el sonido.

<img width="500" alt="pantalla de inicio del juego Tortuga baula" src="../06.%20Im%C3%A1genes/juego-inicio.png" />

El protocolo es una línea de texto por lectura, a 115200 baudios: `b1,b2,b3,b4,pot`.

| Valor | Función en el juego |
|---|---|
| `b1` | Inicia la partida y, durante el juego, activa el escudo. |
| `b2` | Activa el escudo. |
| `b3` | Pausa o continúa. |
| `b4` | Activa o desactiva el sonido. |
| `pot` | Posición horizontal de la tortuga, de 0 (izquierda) a 1000 (derecha). |

Cualquier placa que envíe ese formato funciona con el juego.

### Alternativa con joystick

Si el makerspace dispone de un joystick analógico, puede usarse para mover la tortuga con el programa [`control_joystick_botones_code.py`](../07.%20C%C3%B3digo/control_joystick_botones_code.py).

| Componente | Pin del componente | Pin de la IdeaBoard |
|---|---|---|
| Joystick | VRx | Señal de la fila IO34 |
| Joystick | SW (botón) | Señal de la fila IO04 |
| Joystick | +5V o VCC | 3.3 V |
| Joystick | GND | GND |
| Botón de escudo | Terminales | Fila IO05: señal y GND |
| Botón de pausa | Terminales | Fila IO18: señal y GND |

El joystick se alimenta con 3.3 V, no con 5 V, para que la lectura de IO34 no supere el voltaje que admite el pin.

```python
# Arcade maker: control con joystick y caja de dos botones (IdeaBoard, CircuitPython)
# Envia al juego una linea por lectura con el formato: b1,b2,b3,b4,pot
#   b1 = iniciar  -> boton del joystick (SW) en IO04
#   b2 = escudo   -> boton VERDE en IO05
#   b3 = pausa    -> boton ROJO en IO18
#   b4 = sonido   -> sin usar (siempre 0)
#   pot = movimiento izquierda/derecha del joystick (VRx en IO34), de 0 a 1000
#
# Conexion de cada boton de la caja: un terminal a la senal (IO05 o IO18) y el
# otro al GND de la misma fila. NO usar el pin del medio de la fila (V+).

import time
import board
import digitalio
import analogio

# Muchas cajas industriales traen el boton rojo "normalmente cerrado" (NC):
# conduce cuando esta suelto y se abre al presionarlo. Si el rojo funciona al
# reves (marca 1 suelto y 0 presionado), cambien False por True.
ROJO_NC = False
VERDE_NC = False

def boton(pin):
    b = digitalio.DigitalInOut(pin)
    b.switch_to_input(pull=digitalio.Pull.UP)   # resistencia interna: no hace falta otra
    return b

def presionado(b, nc):
    # Con pull-up: suelto = True (3.3 V), presionado = False (unido a GND)
    if nc:
        return 1 if b.value else 0
    return 0 if b.value else 1

sw = boton(board.IO4)
verde = boton(board.IO5)
rojo = boton(board.IO18)
vrx = analogio.AnalogIn(board.IO34)

while True:
    b1 = 0 if sw.value else 1
    b2 = presionado(verde, VERDE_NC)
    b3 = presionado(rojo, ROJO_NC)
    pot = int(vrx.value * 1000 / 65535)
    print("{},{},{},0,{}".format(b1, b2, b3, pot))
    time.sleep(0.03)
```

### Otros componentes como control

El juego solo necesita recibir líneas con el formato `b1,b2,b3,b4,pot`. Por eso, el programa [`control_botones_code.py`](../07.%20C%C3%B3digo/control_botones_code.py) puede adaptarse para leer otros componentes. En cada caso, toda conexión se hace con la placa desconectada.

#### Potenciómetro

Girar una perilla mueve la tortuga. Conecte el centro del potenciómetro a la señal de IO34 y los extremos a 3.3 V y GND. En el programa, agregue la lectura analógica y reemplace el cálculo de `posicion` por la lectura del potenciómetro:

```python
import analogio

perilla = analogio.AnalogIn(board.IO34)

# Dentro del ciclo while, en lugar de sumar o restar VELOCIDAD:
posicion = int(perilla.value * 1000 / 65535)
```

#### Sensor táctil (papel aluminio, frutas o plantas)

Tocar un objeto a la izquierda o a la derecha mueve la tortuga, como en el Proyecto 3 "Bosque sonoro". Conecte cada objeto con un cable lagarto a IO32 e IO33, que son pines táctiles. No toque los objetos mientras la placa arranca, porque en ese momento se calibra la lectura sin contacto.

```python
import touchio

toque_izq = touchio.TouchIn(board.IO32)
toque_der = touchio.TouchIn(board.IO33)

# Dentro del ciclo while, en lugar de leer los botones:
izq = 1 if toque_izq.value else 0
der = 1 if toque_der.value else 0
```

#### Sensor ultrasónico

Acercar o alejar la mano mueve la tortuga sin tocar nada. El sensor HC-SR04 trabaja con 5 V, por lo que la señal ECHO se conecta a IO35 con un divisor de voltaje (resistencias de 1 kΩ y 2 kΩ) y TRIG a IO26, como en el Proyecto 3 "Bosque sonoro". La función que mide la distancia está en [`secundaria_code.py`](../../../08.%20Instalaciones%20interactivas/04.%20Proyecto%203%20-%20Bosque%20sonoro/07.%20C%C3%B3digo/secundaria_code.py) de ese proyecto. Para el juego, la distancia entre 5 y 30 cm se convierte en la posición:

```python
distancia = medir_distancia_cm()
if distancia < 100:
    posicion = int(min(1000, max(0, (distancia - 5) * 1000 / 25)))
```

La opción con joystick ya está programada en [`control_joystick_botones_code.py`](../07.%20C%C3%B3digo/control_joystick_botones_code.py) y se describe en la sección "Alternativa con joystick".

> **Nota:** estos ejemplos parten de código usado en otros proyectos del bloque, pero no se han probado con el juego. Verifique primero en la consola de IdeaCode que el último número de cada línea cambie entre 0 y 1000 al usar el componente.

### Prueba de funcionamiento

1. Con IdeaCode abierto, observe la consola: sin presionar nada aparece `0,0,0,0,500`.
2. Mantenga presionado el botón izquierdo: el último número baja hasta 0. Con el derecho, sube hasta 1000.
3. Presione los dos botones a la vez: el primer número cambia a 1.
4. Cierre IdeaCode, abra el juego, presione **Conectar control** y presione los dos botones para empezar.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| El botón Conectar control muestra un aviso de navegador | Use Chrome o Edge en una computadora; Web Serial no funciona en Firefox, Safari ni en teléfonos. |
| No aparece el puerto en el juego | Cierre IdeaCode o cualquier monitor serie, y use un cable USB-C de datos. |
| El juego se conecta, pero la tortuga no se mueve | Antes de conectar el juego, verifique en la consola de IdeaCode que aparezcan líneas como `0,0,0,0,500` y que cambien al presionar. |
| Web Serial no funciona con el archivo abierto con doble clic | En la carpeta `07. Código`, ejecute `py -m http.server` y abra `http://localhost:8000/juego.html`. |
| La placa se reinicia al conectar el juego | Es normal: al abrir el puerto el ESP32 se reinicia y el programa vuelve a empezar. |
| Las lecturas no cambian al presionar | Revise que el botón esté en la señal y en GND, no en el pin del medio (V+). |
| Error con el nombre de un pin | Ejecute `import board; print(dir(board))` y use el nombre que aparece. |
