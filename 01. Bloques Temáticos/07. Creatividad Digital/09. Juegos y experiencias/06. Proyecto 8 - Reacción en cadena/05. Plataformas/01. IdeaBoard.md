### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

| Componente | Conexión | Pin de la IdeaBoard |
|---|---|---|
| Servo (compuerta) | Café / rojo / naranja | Fila IO25: GND / V+ / señal |
| Microswitch | COM y NO | IO27 (señal) y GND de la misma fila |
| Módulo de luz | VCC / GND / AO | Fila IO34: 3.3 V / GND / señal |
| HC-SR05 | VCC, GND y TRIG | Fila IO26: V+, GND y señal |
| HC-SR05 | ECHO | 1 kΩ hacia IO35; 2 kΩ de IO35 a GND |

Conecte solo el sensor que eligió y escriba su tipo en `TIPO_SENSOR`. El puente SELECT debe estar en Vin.

### Plantilla de etapa (IdeaCode / CircuitPython)

```python
# Proyecto 8: Reaccion en cadena, plantilla de etapa electronica
# (IdeaBoard con IdeaCode / CircuitPython)
# La etapa espera una senal de entrada (sensor) y produce una salida (servo que abre
# una compuerta y suelta la canica de la siguiente etapa).
import time
import board
import digitalio
import analogio
import pulseio
import pwmio
import neopixel
from adafruit_motor import servo

NUMERO_ETAPA = 3                 # numero de su etapa en la maquina
TIPO_SENSOR = "boton"            # "boton" (microswitch), "luz" o "distancia"
COMPUERTA_CERRADA = 0            # angulos del servo (se calibran)
COMPUERTA_ABIERTA = 90
TIEMPO_ABIERTA = 1.5             # segundos que la compuerta queda abierta
UMBRAL_LUZ = 0.7                 # la sombra baja la luz a menos del 70 %
UMBRAL_DISTANCIA = 8             # cm

# ---------- Salida: servo en IO25 ----------
pwm = pwmio.PWMOut(board.IO25, duty_cycle=0, frequency=50)
compuerta = servo.Servo(pwm, min_pulse=500, max_pulse=2400)
led = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.3)

# ---------- Entrada segun el tipo de sensor ----------
if TIPO_SENSOR == "boton":
    boton = digitalio.DigitalInOut(board.IO27)          # microswitch entre IO27 y GND
    boton.switch_to_input(pull=digitalio.Pull.UP)
elif TIPO_SENSOR == "luz":
    luz = analogio.AnalogIn(board.IO34)                 # modulo de luz: salida AO
    base_luz = luz.value                                # valor con la luz sin tapar
elif TIPO_SENSOR == "distancia":
    trig = digitalio.DigitalInOut(board.IO26)
    trig.direction = digitalio.Direction.OUTPUT
    eco = pulseio.PulseIn(board.IO35, maxlen=2)         # ECHO con divisor 1 kOhm / 2 kOhm
    eco.pause()


def medir_distancia_cm():
    eco.clear()
    eco.resume()
    trig.value = True
    time.sleep(0.00001)
    trig.value = False
    t0 = time.monotonic()
    while len(eco) == 0:
        if time.monotonic() - t0 > 0.05:
            eco.pause()
            return 999
    eco.pause()
    return eco[0] / 58


def entrada_activa():
    if TIPO_SENSOR == "boton":
        return not boton.value                          # presionado = 0 V
    if TIPO_SENSOR == "luz":
        return luz.value < base_luz * UMBRAL_LUZ
    return medir_distancia_cm() < UMBRAL_DISTANCIA


VERDE, AMARILLO, AZUL = (0, 120, 0), (120, 90, 0), (0, 0, 120)
compuerta.angle = COMPUERTA_CERRADA
estado = "LISTA"
led[0] = VERDE
inicio = time.monotonic()
print(f"Etapa {NUMERO_ETAPA} lista. Sensor: {TIPO_SENSOR}")

while True:
    t = time.monotonic() - inicio
    if estado == "LISTA" and entrada_activa():
        print(f"ETAPA {NUMERO_ETAPA}: entrada a los {t:.2f} s")
        estado = "ACTIVANDO"
        led[0] = AMARILLO
        compuerta.angle = COMPUERTA_ABIERTA
        time.sleep(TIEMPO_ABIERTA)
        compuerta.angle = COMPUERTA_CERRADA
        print(f"ETAPA {NUMERO_ETAPA}: salida a los {time.monotonic() - inicio:.2f} s")
        estado = "REARMANDO"
        led[0] = AZUL
        libre_desde = time.monotonic()
    elif estado == "REARMANDO":
        # espera 2 s seguidos sin senal antes de quedar lista otra vez
        if entrada_activa():
            libre_desde = time.monotonic()
        elif time.monotonic() - libre_desde > 2:
            estado = "LISTA"
            led[0] = VERDE
            print(f"ETAPA {NUMERO_ETAPA}: lista otra vez")
    time.sleep(0.01)
```

### Cómo funciona la plantilla

| Estado | LED de la placa | Qué hace |
|---|---|---|
| LISTA | Verde | Espera la señal de entrada. |
| ACTIVANDO | Amarillo | Abre la compuerta 1.5 s y la cierra. |
| REARMANDO | Azul | Espera 2 s sin señal para no activarse dos veces con el mismo rebote. |

La consola muestra la hora de entrada y de salida de la etapa: sirve para medir cuánto tarda.

### Prueba de funcionamiento

1. Al encender, la compuerta se cierra y el LED queda verde.
2. Active el sensor: el LED pasa a amarillo, la compuerta se abre y vuelve a cerrar, y el LED pasa a azul.
3. Dos segundos después de soltar el sensor, el LED vuelve a verde.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| Con el sensor de luz no se activa | Encienda la placa con el canal vacío: guarda la luz sin tapar al iniciar. |
| La compuerta golpea la rampa | Cambie `COMPUERTA_ABIERTA` a un ángulo menor. |
| Se activa sola con el HC-SR05 | Baje `UMBRAL_DISTANCIA` o apunte el sensor al canal. |
