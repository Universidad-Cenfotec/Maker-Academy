## Contenido

### Diferencias con la IdeaBoard

La micro:bit necesita una placa de expansión con salida de 5 V para el servo. El microswitch va entre P2 y GND. El servo va en P1 para no compartir el pin P0, que la micro:bit V2 usa para el sonido.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Conexiones

| Componente | Conexión |
|---|---|
| Servo | Café a GND, rojo a 5 V, naranja a P1 (placa de expansión) |
| Microswitch | COM a GND, NO a P2 |

### Código en MakeCode

```javascript
// Reaccion en cadena: compuerta automatica con micro:bit (vista JavaScript de MakeCode)
pins.setPull(DigitalPin.P2, PinPullMode.PullUp)
pins.servoWritePin(AnalogPin.P1, 0)          // compuerta cerrada
basic.showIcon(IconNames.Yes)
basic.forever(function () {
    if (pins.digitalReadPin(DigitalPin.P2) == 0) {   // la canica aprieta el microswitch
        basic.showIcon(IconNames.Happy)
        music.play(music.tonePlayable(880, music.beat(BeatFraction.Quarter)), music.PlaybackMode.InBackground)
        pins.servoWritePin(AnalogPin.P1, 90)    // abre la compuerta
        basic.pause(1500)
        pins.servoWritePin(AnalogPin.P1, 0)     // cierra la compuerta
        basic.pause(2000)                       // espera para no activarse dos veces
        basic.showIcon(IconNames.Yes)
    }
})
```

### Prueba de funcionamiento

Apriete el microswitch con el dedo: suena un tono, la compuerta se abre 1.5 segundos y se cierra.

### Limitaciones y soluciones

- Si el servo tiembla, alimente la placa de expansión con pilas y no solo por USB.
