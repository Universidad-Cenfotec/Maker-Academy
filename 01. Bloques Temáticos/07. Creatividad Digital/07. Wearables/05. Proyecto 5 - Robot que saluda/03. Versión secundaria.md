## Objetivo general

Construir un robot que detecte con un sensor ultrasónico a una persona a menos de 40 cm y la salude moviendo el brazo, con luz y sonido, programado en Arduino IDE sobre la IdeaBoard.

- Programar y ajustar el saludo automático, en la sesión 5.

---

## Conceptos clave a reforzar

- **Sensor ultrasónico:** mide distancia con el tiempo del eco. Distancia (cm) = tiempo (µs) / 58.
- **Condición:** si la distancia es menor que 40 cm, el robot saluda.
- **Servomotor y PWM:** la placa indica el ángulo con pulsos de 50 Hz.
- **Buzzer activo y pasivo:** el activo da un pitido fijo; el pasivo toca notas según la frecuencia.
- **Alimentación:** el servo consume más corriente de la que da el USB; por eso se usa un portapilas.
- **Centro de gravedad:** un peso abajo evita que el robot se vuelque.

**Paso 21. Cargar el programa del robot (estudiantes).** Abran [`07. Código/robot_que_saluda_ideaboard.ino`](./07.%20C%C3%B3digo/robot_que_saluda_ideaboard.ino) y cárguenlo. Lean los comentarios: al inicio están los valores que se pueden ajustar.

```cpp
// Robot que saluda: version Secundaria (IdeaBoard, Arduino IDE)
// Cuando alguien se acerca a menos de DISTANCIA_CM, el robot saluda:
// LED verde y el brazo saluda dos veces; en cada saludo suena una nota.
// Luego descansa (LED naranja) y vuelve a esperar (LED azul).
//
// Librerias (Arduino IDE > Library Manager): ESP32Servo y Adafruit NeoPixel.
// Placa: ESP32 Dev Module. Puente SELECT de la IdeaBoard en Vin.
//
// Conexiones (siempre con la IdeaBoard desconectada):
//   Servo SG90:   cafe GND, rojo V+, naranja senal  -> fila IO25
//   HC-SR05:      VCC y GND -> V+ y GND de la fila IO26; TRIG -> senal IO26
//                 ECHO -> senal IO27 (directo). Si el sensor tiene pin OUT, no se conecta.
//   Buzzer (activo o pasivo): + -> senal IO05, - -> GND de la fila IO05
//   Portapilas 4 AA en la bornera verde de la IdeaBoard (energia extra para el servo).
//   LED RGB: integrado en la placa (IO02), no se conecta nada.
//   Los ojos del robot son los dos cilindros del sensor ultrasonico.

#include <ESP32Servo.h>
#include <Adafruit_NeoPixel.h>

// ---------- Valores que se pueden ajustar ----------
const int DISTANCIA_CM   = 40;    // saluda si alguien esta mas cerca que esto
const int BRAZO_REPOSO   = 90;    // angulo del brazo abajo
const int BRAZO_ARRIBA   = 150;   // angulo del brazo arriba (bajarlo si choca)
const int TIEMPO_MOVIDA_MS = 250; // tiempo para que el brazo llegue arriba o abajo
const int VECES_SALUDO   = 2;     // cuantas veces sube y baja
const int DESCANSO_MS    = 5000;  // tiempo sin saludar despues de un saludo
// Buzzer ACTIVO (suena solo con darle energia, siempre el mismo pitido): true.
// Buzzer PASIVO (puede tocar notas distintas): false.
const bool BUZZER_ACTIVO = true;
// ----------------------------------------------------

const int PIN_SERVO  = 25;
const int PIN_TRIG   = 26;
const int PIN_ECHO   = 27;
const int PIN_BUZZER = 5;
const int PIN_LED    = 2;

Servo brazo;
ESP32PWM buzzer;
Adafruit_NeoPixel led(1, PIN_LED, NEO_GRB + NEO_KHZ800);

void color(int r, int g, int b) {
  led.setPixelColor(0, led.Color(r, g, b));
  led.show();
}

void nota(double frecuencia, int duracionMs) {
  if (BUZZER_ACTIVO) {
    // El buzzer activo no cambia de nota: solo se enciende y se apaga
    digitalWrite(PIN_BUZZER, HIGH);
    delay(duracionMs);
    digitalWrite(PIN_BUZZER, LOW);
  } else {
    buzzer.writeTone(frecuencia);
    delay(duracionMs);
    buzzer.writeScaled(0.0);   // silencio
  }
  delay(30);
}

int medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long duracion = pulseIn(PIN_ECHO, HIGH, 30000);   // espera maximo 30 ms
  if (duracion == 0) return 999;                    // nada delante
  return duracion / 58;                             // microsegundos a cm
}

void saludar(int distancia) {
  Serial.print("Hola! Persona a ");
  Serial.print(distancia);
  Serial.println(" cm");
  color(0, 150, 0);                 // verde

  // Saluda de una vez: el brazo sube, suena una nota arriba y baja.
  // Notas agudas: el buzzer piezo suena mas fuerte entre 1000 y 4000 Hz.
  const double notas[] = {1047, 1319, 1568, 2093};   // Do, Mi, Sol, Do agudo
  for (int i = 0; i < VECES_SALUDO; i++) {
    brazo.write(BRAZO_ARRIBA);             // sube a la velocidad del servo
    delay(TIEMPO_MOVIDA_MS);
    nota(notas[i % 4], 120);               // pitido o nota con el brazo arriba
    brazo.write(BRAZO_REPOSO);             // baja
    delay(TIEMPO_MOVIDA_MS);
  }
  nota(1568, 200);                                         // nota final

  color(150, 60, 0);                // naranja: descansando
  delay(DESCANSO_MS);
  color(0, 0, 150);                 // azul: esperando
}

void setup() {
  Serial.begin(115200);

  // Reserva los 4 temporizadores para que el servo (50 Hz) y el buzzer
  // no compartan el mismo y no se estorben
  ESP32PWM::allocateTimer(0);
  ESP32PWM::allocateTimer(1);
  ESP32PWM::allocateTimer(2);
  ESP32PWM::allocateTimer(3);
  brazo.setPeriodHertz(50);
  brazo.attach(PIN_SERVO, 500, 2400);
  brazo.write(BRAZO_REPOSO);

  if (BUZZER_ACTIVO) {
    pinMode(PIN_BUZZER, OUTPUT);
    digitalWrite(PIN_BUZZER, LOW);
  } else {
    buzzer.attachPin(PIN_BUZZER, 1000, 10);
    buzzer.writeScaled(0.0);
  }

  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);

  led.begin();
  led.setBrightness(60);
  color(0, 0, 150);                 // azul: esperando

  Serial.println("Robot listo");
}

void loop() {
  int distancia = medirDistanciaCm();
  if (distancia < DISTANCIA_CM) {
    saludar(distancia);
  }
  delay(100);
}
```

**Paso 22. Indicar el tipo de buzzer (estudiantes).** Si el buzzer da siempre el mismo pitido es **activo**: dejen `BUZZER_ACTIVO = true`. Si es **pasivo** y puede tocar notas, cámbienlo a `false` para escuchar una melodía.

**Paso 23. Probar con el monitor serie (ambos).** Abran el monitor serie a 115200. Debe aparecer "Robot listo". Acerquen la mano: a menos de 40 cm el LED se pone verde, el brazo saluda dos veces y suena el buzzer; luego el LED queda naranja 5 segundos y vuelve a azul.

## Problemas frecuentes y soluciones

| Problema | Causa probable | Solución |
|---|---|---|
| Error `ESP32Servo.h: No such file` | Falta la librería | Instálela desde el Library Manager. |
| El servo no se mueve y el buzzer suena bajito | Falta energía | Revise el puente SELECT en Vin y el portapilas en la bornera. |
| El saludo es muy lento | Tiempo de movida alto | Baje `TIEMPO_MOVIDA_MS`. |
| El buzzer solo da un pitido | Es un buzzer activo | Es normal; deje `BUZZER_ACTIVO = true` o use un buzzer pasivo. |
| Saluda sin que nadie se acerque | Lecturas falsas o distancia grande | Baje `DISTANCIA_CM` y revise que nada esté frente al sensor. |
| No saluda nunca | Trig y Echo invertidos | Trig va en IO26 y Echo en IO27. |
| Error de compilación `cc1plus.exe` | Instalación incompleta del soporte ESP32 | Reinstale el paquete esp32 o pruebe una versión anterior. |
| El robot se cae | Cuerpo liviano | Meta un objeto pesado en el cuerpo. |

## Seguridad

- Todas las conexiones se hacen con la IdeaBoard **desconectada de la computadora** y sin baterías en el portapilas.
- Se revisa la polaridad del portapilas antes de ponerle baterías.
- La pistola de silicón se usa con supervisión.
- El Echo del HC-SR05 llega directo a IO27, como en el prototipo. Si el sensor se alimenta con 5 V, su Echo también sale a 5 V; para proteger la placa se puede conectar el VCC del sensor a 3,3 V, ya que el HC-SR05 funciona con ese voltaje.
- No se fuerza el brazo con la mano con el servo energizado.

## Adaptaciones y apoyos

- **Para estudiantes que requieren más apoyo:** entregar el programa completo y pedir que cambien solo los valores ajustables.
- **Para estudiantes que avanzan más rápido:** que el robot salude distinto según la distancia, o que cuente cuántas personas saludó.
- **Para accesibilidad:** aumentar `DISTANCIA_CM` para personas en silla de ruedas o que se acercan de lado.
