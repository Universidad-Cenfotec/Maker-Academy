### Componentes

| Componente | Cantidad |
|---|---|
| IdeaBoard con cable USB-C | 1 |
| Servo SG90 | 1 |
| Sensor ultrasónico HC-SR05 | 1 |
| Buzzer pasivo | 1 |
| Resistencias de 1 kΩ y 2 kΩ | 1 de cada una |
| Protoboard pequeña y jumpers | 1 y 10 |

El LED RGB no se compra: la IdeaBoard trae uno integrado (WS2812B) conectado a IO02.

### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

El puente **SELECT** debe estar en **Vin** para que los conectores de servo entreguen 5 V.

| Componente | Pin del componente | Pin de la IdeaBoard |
|---|---|---|
| Servo | Café / rojo / naranja | Fila IO25: GND / V+ / señal |
| HC-SR05 | VCC y GND | Fila IO26: V+ y GND |
| HC-SR05 | TRIG | IO26 (señal) |
| HC-SR05 | ECHO | 1 kΩ hacia IO27; 2 kΩ de IO27 a GND |
| Buzzer pasivo | + / − | Fila IO05: señal / GND |
| LED RGB | Integrado | IO02 (no se conecta nada) |

### Programación con IdeaCode (CircuitPython)

[IdeaCode](https://ideacode.crcibernetica.com/) es el editor de CRCibernética y la Universidad Cenfotec para programar la IdeaBoard en CircuitPython desde el navegador.

1. Abra IdeaCode en Chrome o Edge y conecte la IdeaBoard con el cable USB-C.
2. Conecte la placa desde IdeaCode y elija su puerto. Si la placa no tiene CircuitPython, instálelo primero desde la [página de la IdeaBoard en circuitpython.org](https://circuitpython.org/board/crcibernetica-ideaboard/).
3. Las librerías `adafruit_motor` (servo), `neopixel` (LED RGB) y `simpleio` (buzzer) ya vienen incluidas en CircuitPython para la IdeaBoard: no hay que instalarlas.
4. Pegue el programa en el archivo `code.py` y guárdelo. La placa lo ejecuta al guardar y los mensajes aparecen en la consola.

#### Posición inicial (IdeaCode)

```python
# Posicion inicial: deja el servo en 90 grados para colocar la patita
import board
import pwmio
from adafruit_motor import servo

pwm = pwmio.PWMOut(board.IO25, duty_cycle=0, frequency=50)
motor = servo.Servo(pwm, min_pulse=500, max_pulse=2400)
motor.angle = 90
print("Servo en 90 grados")
```

#### Programa principal (IdeaCode)

```python
# Proyecto 5: Robot que saluda (IdeaBoard con IdeaCode / CircuitPython)
import time
import math
import board
import digitalio
import pulseio
import pwmio
import neopixel
import simpleio
from adafruit_motor import servo

# Ajustes (se calibran con el robot real)
BRAZO_ABAJO = 90       # posicion de reposo
BRAZO_ARRIBA = 150     # posicion mas alta del saludo
DISTANCIA_CM = 40      # saluda si alguien esta mas cerca que esto
SALUDOS = 3            # veces que sube y baja el brazo
PASOS = 20             # pasos de cada movimiento
ESPERA_PASO = 0.015    # 20 x 0.015 s = 0.3 s por movimiento
DESCANSO = 5           # segundos antes de volver a saludar

PIN_BUZZER = board.IO5                      # buzzer pasivo en el conector IO05
pwm = pwmio.PWMOut(board.IO25, duty_cycle=0, frequency=50)
brazo = servo.Servo(pwm, min_pulse=500, max_pulse=2400)   # hombro en IO25

trig = digitalio.DigitalInOut(board.IO26)   # ultrasonico: TRIG
trig.direction = digitalio.Direction.OUTPUT
eco = pulseio.PulseIn(board.IO27, maxlen=2)  # ECHO con divisor 1 kOhm / 2 kOhm
eco.pause()

ojos = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.3)  # LED RGB integrado (IO02)

AZUL = (0, 0, 120)
VERDE = (0, 150, 0)
NARANJA = (120, 60, 0)


def color(c):
    ojos[0] = c


def medir_distancia_cm():
    eco.clear()
    eco.resume()
    trig.value = True
    time.sleep(0.00001)
    trig.value = False
    inicio = time.monotonic()
    while len(eco) == 0:
        if time.monotonic() - inicio > 0.05:
            eco.pause()
            return 999          # sin eco: no hay nadie cerca
    eco.pause()
    return eco[0] / 58


def mover_suave(desde, hasta):
    for i in range(PASOS + 1):
        s = (1 - math.cos(i * math.pi / PASOS)) / 2
        brazo.angle = desde + (hasta - desde) * s
        time.sleep(ESPERA_PASO)


def nota(frecuencia, segundos):
    simpleio.tone(PIN_BUZZER, frecuencia, duration=segundos)
    time.sleep(0.03)


def sonido_hola():
    nota(523, 0.12)   # do
    nota(659, 0.12)   # mi
    nota(784, 0.20)   # sol


def saludar():
    color(VERDE)
    sonido_hola()
    for _ in range(SALUDOS):
        mover_suave(BRAZO_ABAJO, BRAZO_ARRIBA)
        mover_suave(BRAZO_ARRIBA, BRAZO_ABAJO)
    color(NARANJA)


brazo.angle = BRAZO_ABAJO
color(AZUL)
print("Robot listo")

while True:
    distancia = medir_distancia_cm()
    if distancia < DISTANCIA_CM:
        print("Hola! Persona a", int(distancia), "cm")
        saludar()
        time.sleep(DESCANSO)
        color(AZUL)
    time.sleep(0.06)
```

### Alternativa: programación con Arduino IDE

1. Instale Arduino IDE y agregue las placas ESP32 desde el gestor de tarjetas.
2. Instale las librerías **ESP32Servo** y **Adafruit NeoPixel**.
3. Seleccione la placa **ESP32 Dev Module** y el puerto de la IdeaBoard.

#### Posición inicial (Arduino IDE)

```cpp
// Posicion inicial: deja el servo en 90 grados para colocar la patita y el brazo
#include <ESP32Servo.h>
Servo brazo;
void setup() {
  brazo.attach(25, 500, 2400);   // conector de servo IO25
  brazo.write(90);
}
void loop() {}
```

#### Programa principal (Arduino IDE)

```cpp
// Proyecto 5: Robot que saluda (IdeaBoard / ESP32)
#include <ESP32Servo.h>
#include <Adafruit_NeoPixel.h>

// Pines de la IdeaBoard
const int PIN_SERVO  = 25;  // conector de servo IO25 (hombro del robot)
const int PIN_TRIG   = 26;  // ultrasonico: TRIG
const int PIN_ECHO   = 27;  // ultrasonico: ECHO (con divisor 1 kOhm / 2 kOhm)
const int PIN_BUZZER = 5;   // buzzer pasivo en el conector IO05
const int PIN_LED    = 2;   // LED RGB integrado de la IdeaBoard (WS2812B)

// Ajustes (se calibran con el robot real)
const int BRAZO_ABAJO  = 90;    // posicion de reposo
const int BRAZO_ARRIBA = 150;   // posicion mas alta del saludo
const int DISTANCIA_CM = 40;    // saluda si alguien esta mas cerca que esto
const int SALUDOS = 3;          // veces que sube y baja el brazo
const int PASOS = 20;           // pasos de cada movimiento
const int ESPERA_PASO_MS = 15;  // 20 x 15 ms = 0.3 s por movimiento
const unsigned long DESCANSO_MS = 5000;  // espera antes de volver a saludar

Servo brazo;
ESP32PWM bocina;               // buzzer (no usar tone(): choca con el servo)
Adafruit_NeoPixel ojos(1, PIN_LED, NEO_GRB + NEO_KHZ800);

void color(int r, int g, int b) {
  ojos.setPixelColor(0, ojos.Color(r, g, b));
  ojos.show();
}

long medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long tiempo = pulseIn(PIN_ECHO, HIGH, 30000);
  if (tiempo == 0) return 999;   // sin eco: no hay nadie cerca
  return tiempo / 58;
}

void moverSuave(int desde, int hasta) {
  for (int i = 0; i <= PASOS; i++) {
    float s = (1 - cos(i * PI / PASOS)) / 2;
    brazo.write(desde + (hasta - desde) * s);
    delay(ESPERA_PASO_MS);
  }
}

void nota(int frecuencia, int ms) {
  bocina.writeTone(frecuencia);
  delay(ms);
  bocina.writeScaled(0);
  delay(30);
}

void sonidoHola() {
  nota(523, 120);   // do
  nota(659, 120);   // mi
  nota(784, 200);   // sol
}

void saludar() {
  color(0, 150, 0);              // verde: saludando
  sonidoHola();
  for (int i = 0; i < SALUDOS; i++) {
    moverSuave(BRAZO_ABAJO, BRAZO_ARRIBA);
    moverSuave(BRAZO_ARRIBA, BRAZO_ABAJO);
  }
  color(40, 20, 0);              // naranja: descansando
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  ojos.begin();
  ESP32PWM::allocateTimer(0);
  ESP32PWM::allocateTimer(1);
  brazo.setPeriodHertz(50);
  bocina.attachPin(PIN_BUZZER, 1000, 10);
  bocina.writeScaled(0);
  brazo.attach(PIN_SERVO, 500, 2400);
  brazo.write(BRAZO_ABAJO);
  color(0, 0, 40);               // azul: esperando
  Serial.println("Robot listo");
}

void loop() {
  long distancia = medirDistanciaCm();
  if (distancia < DISTANCIA_CM) {
    Serial.print("Hola! Persona a ");
    Serial.print(distancia);
    Serial.println(" cm");
    saludar();
    delay(DESCANSO_MS);
    color(0, 0, 40);
  }
  delay(60);
}
```

### Prueba de funcionamiento

1. Al encender, el LED se pone azul y la consola de IdeaCode (o el monitor serie) muestra "Robot listo".
2. Acérquese a menos de 40 cm: el LED se pone verde, suena la melodía y el brazo sube y baja tres veces.
3. Después del saludo, el LED queda naranja 5 segundos y luego vuelve a azul.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| El servo deja de moverse cuando suena el buzzer | No use `tone()`: use `ESP32PWM`, como en el código. |
| El servo no se mueve | Revise que el puente SELECT esté en Vin. |
| El sensor marca siempre 999 | Revise el divisor y que TRIG y ECHO no estén invertidos. |
| Saluda a objetos que no son personas | Baje `DISTANCIA_CM` o apunte el sensor más alto. |
