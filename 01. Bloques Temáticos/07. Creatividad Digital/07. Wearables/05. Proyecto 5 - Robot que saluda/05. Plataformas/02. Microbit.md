## Contenido

### Diferencias con la IdeaBoard

La micro:bit saluda al presionar el botón A. Su pantalla hace de cara del robot y, en la versión V2, su parlante toca la melodía. El servo se conecta con una placa de expansión que tenga salida de 5 V.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Conexiones

| Componente | Pin del componente | Placa de expansión de la micro:bit |
|---|---|---|
| Servo | Café / rojo / naranja | GND / 5 V / P0 |

### Código en MakeCode

En la vista de bloques se arma con: "al presionar el botón A", "repetir 3 veces", "servo escribir pin P0 a" y "pausa". Esta es la misma lógica en la vista JavaScript:

```javascript
// Robot que saluda: micro:bit (vista JavaScript de MakeCode)
function saludar () {
    basic.showIcon(IconNames.Happy)
    music.play(music.stringPlayable("C E G - - - - - ", 240), music.PlaybackMode.InBackground)
    for (let i = 0; i < 3; i++) {
        pins.servoWritePin(AnalogPin.P0, 150)
        basic.pause(400)
        pins.servoWritePin(AnalogPin.P0, 90)
        basic.pause(400)
    }
    basic.showIcon(IconNames.Asleep)
}
input.onButtonPressed(Button.A, function () {
    saludar()
})
pins.servoWritePin(AnalogPin.P0, 90)
basic.showIcon(IconNames.Asleep)
```

### Prueba de funcionamiento

1. Al encender, la pantalla muestra una cara dormida y el servo va a 90°: coloque en ese momento la patita y el brazo.
2. Presione el botón A: aparece una cara feliz, suena la melodía y el brazo sube y baja tres veces.

### Limitaciones y soluciones

- La micro:bit V1 no tiene parlante: quite el bloque de música o conecte un buzzer en P1.
- Para usar el sensor ultrasónico con micro:bit se necesita la extensión **sonar** y alimentar el sensor a 5 V desde la placa de expansión.
