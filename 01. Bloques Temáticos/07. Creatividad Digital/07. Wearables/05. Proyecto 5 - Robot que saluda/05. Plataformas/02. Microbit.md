## Conexiones

> **Importante:** antes de hacer cualquier conexión, revise que la placa **todavía no esté conectada a la computadora** ni a las baterías. Se conecta todo primero, se revisa con el docente y solo después se enchufa.

<img width="600" alt="conexiones en la micro:bit" src="../06.%20Im%C3%A1genes/conexion-microbit-general.png" />

| Componente | Pin de la micro:bit |
|---|---|
| Servo naranja (señal) | P0 |
| Servo rojo | + del portapilas de 4 AA |
| Servo café | − del portapilas y GND |
| Ojo izquierdo (pata larga con 220 Ω) | P1 |
| Ojo derecho (pata larga con 220 Ω) | P2 |
| Patas cortas de los LEDs | GND, cada una con su propio lagarto |

El servo necesita su propio portapilas. El + del portapilas va solo al servo, nunca a la micro:bit.

> **Cuidado con los lagartos:** cada lagarto debe morder solo su pin o su pata. Si toca un pin vecino o la pata de al lado se produce un cortocircuito. Siempre que se pueda, es mejor sujetar un jumper con cinta a la pieza y morder el jumper.

## Programa

Archivo: [`07. Código/robot_que_saluda_microbit.js`](../07.%20C%C3%B3digo/robot_que_saluda_microbit.js). Se pega en la vista JavaScript de MakeCode.

```javascript
// Robot que saluda: version Primaria (micro:bit, MakeCode)
// Al presionar el boton A: cara feliz, melodia, el brazo saluda tres veces
// y los ojos LED se encienden cada vez que el brazo sube.
//
// Conexiones (con la micro:bit desconectada):
//   Servo: naranja -> P0; rojo -> + del portapilas de 4 AA;
//          cafe -> - del portapilas y tambien GND de la micro:bit
//   Ojo izquierdo: pata larga con su resistencia de 220 ohm -> P1, pata corta -> GND
//   Ojo derecho:   pata larga con su resistencia de 220 ohm -> P2, pata corta -> GND

function ojos (encendidos: number) {
    pins.digitalWritePin(DigitalPin.P1, encendidos)
    pins.digitalWritePin(DigitalPin.P2, encendidos)
}

function saludar () {
    basic.showIcon(IconNames.Happy)
    music.play(music.stringPlayable("C E G - - - - - ", 240), music.PlaybackMode.InBackground)
    for (let index = 0; index < 3; index++) {
        pins.servoWritePin(AnalogPin.P0, 150)   // brazo arriba (bajar el numero si choca)
        ojos(1)
        basic.pause(400)
        pins.servoWritePin(AnalogPin.P0, 90)    // brazo abajo
        ojos(0)
        basic.pause(400)
    }
    basic.showIcon(IconNames.Asleep)
}

input.onButtonPressed(Button.A, function () {
    saludar()
})

// En la micro:bit V2, P0 tambien saca el sonido. Como ahi esta el servo,
// se desactiva: la melodia sigue sonando por el parlante de la placa.
pins.setAudioPinEnabled(false)
pins.servoWritePin(AnalogPin.P0, 90)
ojos(0)
basic.showIcon(IconNames.Asleep)
```

`pins.setAudioPinEnabled(false)` evita que la micro:bit mande sonido por P0, que es el pin del servo.
