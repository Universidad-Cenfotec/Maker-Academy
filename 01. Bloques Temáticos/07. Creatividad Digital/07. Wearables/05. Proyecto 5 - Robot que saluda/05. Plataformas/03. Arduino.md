## Contenido

### Diferencias con la IdeaBoard

El Arduino Uno trabaja a 5 V: el ECHO va directo, sin divisor. Se usa un LED RGB de cátodo común con tres resistencias de 220 Ω y la función `tone()`, que en el Arduino Uno no choca con el servo.

<img width="380" alt="placa Arduino Uno" src="https://upload.wikimedia.org/wikipedia/commons/3/38/Arduino_Uno_-_R3.jpg" />

### Conexiones

| Componente | Pin del componente | Pin del Arduino Uno |
|---|---|---|
| Servo | Café / rojo / naranja | GND / 5V / D9 |
| HC-SR05 | VCC / GND / TRIG / ECHO | 5V / GND / D7 / D8 |
| Buzzer pasivo | + / − | D11 / GND |
| LED RGB | R / G / B / cátodo | D4 / D5 / D6 (con 220 Ω) / GND |

### Código

```cpp
// Proyecto 5: Robot que saluda (Arduino Uno)
#include <Servo.h>
const int PIN_SERVO = 9, PIN_TRIG = 7, PIN_ECHO = 8, PIN_BUZZER = 11;
const int PIN_R = 4, PIN_G = 5, PIN_B = 6;
const int BRAZO_ABAJO = 90, BRAZO_ARRIBA = 150, DISTANCIA_CM = 40, SALUDOS = 3;
Servo brazo;
void color(bool r, bool g, bool b) { digitalWrite(PIN_R, r); digitalWrite(PIN_G, g); digitalWrite(PIN_B, b); }
long medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW); delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long t = pulseIn(PIN_ECHO, HIGH, 30000);
  return t == 0 ? 999 : t / 58;
}
void moverSuave(int desde, int hasta) {
  for (int i = 0; i <= 20; i++) {
    float s = (1 - cos(i * PI / 20)) / 2;
    brazo.write(desde + (hasta - desde) * s);
    delay(15);
  }
}
void saludar() {
  color(0, 1, 0);
  tone(PIN_BUZZER, 523, 120); delay(150);
  tone(PIN_BUZZER, 659, 120); delay(150);
  tone(PIN_BUZZER, 784, 200); delay(250);
  for (int i = 0; i < SALUDOS; i++) { moverSuave(BRAZO_ABAJO, BRAZO_ARRIBA); moverSuave(BRAZO_ARRIBA, BRAZO_ABAJO); }
  color(1, 1, 0); delay(5000); color(0, 0, 1);
}
void setup() {
  pinMode(PIN_TRIG, OUTPUT); pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_R, OUTPUT); pinMode(PIN_G, OUTPUT); pinMode(PIN_B, OUTPUT);
  brazo.attach(PIN_SERVO); brazo.write(BRAZO_ABAJO); color(0, 0, 1);
}
void loop() {
  if (medirDistanciaCm() < DISTANCIA_CM) saludar();
  delay(60);
}
```

### Limitaciones y soluciones

- La librería Servo desactiva el PWM de D9 y D10; por eso el LED RGB usa D4, D5 y D6 solo encendidos o apagados.
