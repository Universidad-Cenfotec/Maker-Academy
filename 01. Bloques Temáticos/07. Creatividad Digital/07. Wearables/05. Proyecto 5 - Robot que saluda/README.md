## Descripción

Carpeta del Proyecto 5 del Bloque 7. Contiene la ficha, las guías paso a paso para Primaria y Secundaria, la lista de materiales, las guías por placa, los modelos 3D y las imágenes del proyecto.

---

## Propósito

Este proyecto integra electrónica en un objeto: un robot de cartón que mueve el brazo para saludar. En Primaria saluda cuando alguien presiona un botón; en Secundaria lo hace solo, cuando el sensor ultrasónico detecta que alguien se acerca, y además cambia de color y emite un sonido.

## Cómo usar esta carpeta

Lee primero la ficha. Luego abre la versión del nivel que vas a implementar y revisa la lista de materiales. Para la parte electrónica, abre la guía de la placa que usará el grupo en `05. Plataformas/`.

---

## Relación con XperiencED Maker

- **Inspiración:** se conversa sobre robots amigables y se diseña un robot propio.
- **Experimentación:** se construye el cuerpo de cartón, se monta el servo y se programa el saludo; en Secundaria se simula antes de conectar.
- **Reflexión:** se prueba con visitantes, se mejora y se presenta en el Demo Day.
