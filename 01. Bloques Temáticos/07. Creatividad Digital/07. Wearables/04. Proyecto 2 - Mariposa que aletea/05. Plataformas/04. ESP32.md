## Contenido

### Diferencias con la IdeaBoard

El ESP32 genérico no tiene conectores de servo ni puente SELECT. Todo se conecta en una protoboard y el servo se alimenta desde el pin **VIN (5 V)**.

<img width="380" alt="placa ESP32 DevKit" src="https://upload.wikimedia.org/wikipedia/commons/thumb/2/20/ESP32_Espressif_ESP-WROOM-32_Dev_Board.jpg/960px-ESP32_Espressif_ESP-WROOM-32_Dev_Board.jpg" />

### Conexiones

| Componente | Pin del componente | Pin del ESP32 |
|---|---|---|
| Servo | Café / rojo / naranja | GND / VIN / GPIO 4 |
| HC-SR05 | VCC / GND / TRIG | VIN / GND / GPIO 26 |
| HC-SR05 | ECHO | 1 kΩ hacia GPIO 27; 2 kΩ de GPIO 27 a GND |
| KY-038 | VCC / GND / DO | 3V3 / GND / GPIO 34 |
| Capacitor 1000 µF | Pata larga / corta | VIN / GND |

<img width="550" alt="circuito con ESP32 en Wokwi" src="../06.%20Im%C3%A1genes/circuito-wokwi.png" />

### Código

Se usa el mismo programa de la [`guía de la IdeaBoard`](./01.%20IdeaBoard.md), sin cambios: los números de pin coinciden.

### Limitaciones y soluciones

- Si el servo hace reiniciar la placa, alimente el servo con una fuente de 5 V aparte y una las tierras.
- GPIO 34 solo funciona como entrada: no lo use para el TRIG.
