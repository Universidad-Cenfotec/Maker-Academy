### Dónde conectar en la IdeaBoard

<img width="650" alt="IdeaBoard: conectores de servo en naranja, pines de 3.3 V en azul y conector STEMMA QT en verde" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

- **Bloque naranja (1):** 7 filas de 3 pines (GND, V+ y señal) en IO04, IO05, IO18, IO19, IO23, IO25 e IO26. Están hechos para conectar servos directamente.
- **Bloque azul (2):** pines de 3.3 V (señal, 3.3 V y GND) en IO27, IO33, IO32, IO35, IO34, IO39 e IO36. IO34, IO35, IO39 e IO36 solo funcionan como entrada.
- **Puente SELECT:** debe estar en **Vin** para que V+ entregue 5 V al servo y al sensor ultrasónico.

### Conexiones

| Componente | Pin del componente | Pin de la IdeaBoard |
|---|---|---|
| Servo | Café / rojo / naranja | Fila IO04: GND / V+ / señal |
| HC-SR05 | VCC y GND | Fila IO26: V+ y GND |
| HC-SR05 | TRIG | IO26 (señal) |
| HC-SR05 | ECHO | 1 kΩ hacia IO27; 2 kΩ de IO27 a GND |
| KY-038 | VCC, GND y DO | Fila IO34: 3.3 V, GND y señal |
| Capacitor 1000 µF | Pata larga / pata corta | 5 V (V+) / GND, junto al servo |

### Programación con IdeaCode (CircuitPython)

[IdeaCode](https://ideacode.crcibernetica.com/) es el editor de CRCibernética y la Universidad Cenfotec para programar la IdeaBoard en CircuitPython desde el navegador.

1. Abra IdeaCode en Chrome o Edge y conecte la IdeaBoard con el cable USB-C.
2. Conecte la placa desde IdeaCode y elija su puerto. Si la placa no tiene CircuitPython, instálelo primero desde la [página de la IdeaBoard en circuitpython.org](https://circuitpython.org/board/crcibernetica-ideaboard/).
3. La librería `adafruit_motor` (servo) ya viene incluida en CircuitPython para la IdeaBoard: no hay que instalar nada.
4. Pegue el programa en el archivo `code.py` y guárdelo. La placa lo ejecuta al guardar y los mensajes aparecen en la consola.

#### Posición inicial (IdeaCode)

```python
# Posicion inicial: deja el servo en 0 grados para colocar la patita
import board
import pwmio
from adafruit_motor import servo

pwm = pwmio.PWMOut(board.IO4, duty_cycle=0, frequency=50)
motor = servo.Servo(pwm, min_pulse=500, max_pulse=2400)
motor.angle = 0
print("Servo en 0 grados")
```

#### Programa principal (IdeaCode)

```python
# Proyecto 2: Mariposa que aletea (IdeaBoard con IdeaCode / CircuitPython)
import time
import math
import board
import digitalio
import pulseio
import pwmio
import countio
from adafruit_motor import servo

# Ajustes (se calibran con el prototipo real)
ALAS_ABIERTAS = 0      # posicion de reposo
ALAS_CERRADAS = 70     # angulo maximo del aleteo
DISTANCIA_CM = 25      # la mano activa la mariposa a menos de esto
TIEMPO_ALETEO = 4.0    # segundos de aleteo
PASOS = 20             # pasos de cada movimiento
ESPERA_PASO = 0.012    # 20 x 0.012 s = 0.24 s por movimiento

# Servo en el conector IO04
pwm = pwmio.PWMOut(board.IO4, duty_cycle=0, frequency=50)
alas = servo.Servo(pwm, min_pulse=500, max_pulse=2400)

# Sensor ultrasonico: TRIG en IO26, ECHO en IO27 (con divisor 1 kOhm / 2 kOhm)
trig = digitalio.DigitalInOut(board.IO26)
trig.direction = digitalio.Direction.OUTPUT
eco = pulseio.PulseIn(board.IO27, maxlen=2)
eco.pause()

# Sensor de sonido KY-038: salida digital DO en IO34. Cuenta los aplausos.
aplausos = countio.Counter(board.IO34, edge=countio.Edge.RISE)


def medir_distancia_cm():
    eco.clear()
    eco.resume()
    trig.value = True
    time.sleep(0.00001)
    trig.value = False
    inicio = time.monotonic()
    while len(eco) == 0:
        if time.monotonic() - inicio > 0.05:
            eco.pause()
            return 999          # sin eco: no hay nada cerca
    eco.pause()
    return eco[0] / 58          # microsegundos a centimetros


def mover_suave(desde, hasta):
    for i in range(PASOS + 1):
        s = (1 - math.cos(i * math.pi / PASOS)) / 2
        alas.angle = desde + (hasta - desde) * s
        time.sleep(ESPERA_PASO)


def aletear():
    inicio = time.monotonic()
    while time.monotonic() - inicio < TIEMPO_ALETEO:
        mover_suave(ALAS_ABIERTAS, ALAS_CERRADAS)
        mover_suave(ALAS_CERRADAS, ALAS_ABIERTAS)
    time.sleep(0.5)
    aplausos.reset()            # ignora el ruido del propio servo


alas.angle = ALAS_ABIERTAS
aplausos.reset()
print("Mariposa lista")

while True:
    distancia = medir_distancia_cm()
    if distancia < DISTANCIA_CM:
        print("Mano detectada a", int(distancia), "cm")
        aletear()
    elif aplausos.count > 0:
        print("Aplauso detectado")
        aletear()
    time.sleep(0.06)
```

### Alternativa: programación con Arduino IDE

1. Instale Arduino IDE y agregue las placas ESP32 desde el gestor de tarjetas.
2. Instale la librería **ESP32Servo** desde el gestor de librerías.
3. Seleccione la placa **ESP32 Dev Module** y el puerto de la IdeaBoard.

#### Posición inicial (Arduino IDE)

Se carga antes de colocar la patita y el engranaje 1, para que el servo quede en 0°.

```cpp
// Posicion inicial: deja el servo en 0 grados para colocar la patita
#include <ESP32Servo.h>
Servo alas;
void setup() {
  alas.attach(4, 500, 2400);   // conector de servo IO04
  alas.write(0);
}
void loop() {}
```

#### Programa principal (Arduino IDE)

```cpp
// Proyecto 2: Mariposa que aletea (IdeaBoard / ESP32)
#include <ESP32Servo.h>

// Pines de la IdeaBoard
const int PIN_SERVO  = 4;   // conector de servo IO04
const int PIN_TRIG   = 26;  // ultrasonico: TRIG
const int PIN_ECHO   = 27;  // ultrasonico: ECHO (con divisor 1 kOhm / 2 kOhm)
const int PIN_SONIDO = 34;  // sensor de sonido KY-038: salida digital DO

// Ajustes (se calibran con el prototipo real)
const int ALAS_ABIERTAS = 0;     // posicion de reposo
const int ALAS_CERRADAS = 70;    // angulo maximo del aleteo
const int DISTANCIA_CM = 25;     // la mano activa la mariposa a menos de esto
const unsigned long TIEMPO_ALETEO_MS = 4000;
const int PASOS = 20;            // pasos de cada movimiento
const int ESPERA_PASO_MS = 12;   // 20 x 12 ms = 0.24 s por movimiento

Servo alas;
volatile bool aplauso = false;

void IRAM_ATTR detectarAplauso() {
  aplauso = true;
}

long medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long tiempo = pulseIn(PIN_ECHO, HIGH, 30000);
  if (tiempo == 0) return 999;   // sin eco: no hay nada cerca
  return tiempo / 58;
}

void moverSuave(int desde, int hasta) {
  for (int i = 0; i <= PASOS; i++) {
    float s = (1 - cos(i * PI / PASOS)) / 2;
    alas.write(desde + (hasta - desde) * s);
    delay(ESPERA_PASO_MS);
  }
}

void aletear() {
  unsigned long inicio = millis();
  while (millis() - inicio < TIEMPO_ALETEO_MS) {
    moverSuave(ALAS_ABIERTAS, ALAS_CERRADAS);
    moverSuave(ALAS_CERRADAS, ALAS_ABIERTAS);
  }
  delay(500);
  aplauso = false;   // ignora el ruido del propio servo
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_SONIDO, INPUT);
  attachInterrupt(digitalPinToInterrupt(PIN_SONIDO), detectarAplauso, RISING);
  alas.attach(PIN_SERVO, 500, 2400);
  alas.write(ALAS_ABIERTAS);
  Serial.println("Mariposa lista");
}

void loop() {
  long distancia = medirDistanciaCm();
  if (distancia < DISTANCIA_CM) {
    Serial.print("Mano detectada a ");
    Serial.print(distancia);
    Serial.println(" cm");
    aletear();
  } else if (aplauso) {
    Serial.println("Aplauso detectado");
    aletear();
  }
  delay(60);
}
```

### Prueba de funcionamiento

1. Abra la consola de IdeaCode (o el monitor serie a 115200 baudios en Arduino IDE): debe aparecer "Mariposa lista".
2. Acerque la mano a menos de 25 cm: aparece "Mano detectada" y las alas aletean unos 4 segundos.
3. Aplauda cerca del sensor: aparece "Aplauso detectado".

### Simulación

El mismo circuito y código se pueden probar en Wokwi antes de conectar. Wokwi no tiene el KY-038 ni el capacitor: el sensor de sonido se representa con un botón y una resistencia de 10 kΩ a GND, que no se usan en el circuito real.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| El servo tiembla o la placa se reinicia | Revise el capacitor y use una fuente USB de al menos 1 A. |
| El servo no se mueve | Revise que el puente SELECT esté en Vin. |
| El sensor ultrasónico marca 999 siempre | Revise el divisor y que TRIG y ECHO no estén invertidos. |
| Se activa solo | Gire el tornillo del KY-038 para bajar la sensibilidad. |
