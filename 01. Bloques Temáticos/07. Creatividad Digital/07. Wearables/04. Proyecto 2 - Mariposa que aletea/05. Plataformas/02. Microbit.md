## Contenido

### Diferencias con la IdeaBoard

La micro:bit V2 tiene micrófono integrado, así que se activa con un aplauso sin sensor extra. El botón A reemplaza al sensor ultrasónico. El servo se conecta con una placa de expansión que tenga salida de 5 V; no se alimenta desde el pin de 3 V.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Conexiones

| Componente | Pin del componente | Placa de expansión de la micro:bit |
|---|---|---|
| Servo | Café / rojo / naranja | GND / 5 V / P0 |

### Código en MakeCode (vista JavaScript)

```javascript
function aletear () {
    for (let i = 0; i < 8; i++) {
        pins.servoWritePin(AnalogPin.P0, 70)
        basic.pause(250)
        pins.servoWritePin(AnalogPin.P0, 0)
        basic.pause(250)
    }
}
input.onSound(DetectedSound.Loud, function () {
    aletear()
})
input.onButtonPressed(Button.A, function () {
    aletear()
})
input.setSoundThreshold(SoundThreshold.Loud, 150)
pins.servoWritePin(AnalogPin.P0, 0)
```

### Prueba de funcionamiento

1. Al encender, el servo va a 0°: coloque en ese momento la patita y el engranaje 1.
2. Presione el botón A: las alas aletean 8 veces.
3. Aplauda: si no reacciona, baje el número de `setSoundThreshold`.

### Limitaciones y soluciones

- La micro:bit V1 no tiene micrófono: use solo el botón A.
- El movimiento es menos suave que en la IdeaBoard porque el código mueve el servo de un salto.
