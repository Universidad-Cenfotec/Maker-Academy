## Contenido

### Diferencias con la IdeaBoard

El Arduino Uno trabaja a 5 V, así que el ECHO se conecta directo, sin divisor. Se usa la librería **Servo**, que ya viene instalada.

<img width="380" alt="placa Arduino Uno" src="https://upload.wikimedia.org/wikipedia/commons/3/38/Arduino_Uno_-_R3.jpg" />

### Conexiones

| Componente | Pin del componente | Pin del Arduino Uno |
|---|---|---|
| Servo | Café / rojo / naranja | GND / 5V / D3 |
| HC-SR05 | VCC / GND / TRIG / ECHO | 5V / GND / D7 / D8 |
| KY-038 | VCC / GND / DO | 5V / GND / D2 |
| Capacitor 1000 µF | Pata larga / corta | 5V / GND |

### Código

```cpp
// Proyecto 2: Mariposa que aletea (Arduino Uno)
#include <Servo.h>
const int PIN_SERVO = 3, PIN_TRIG = 7, PIN_ECHO = 8, PIN_SONIDO = 2;
const int ALAS_ABIERTAS = 0, ALAS_CERRADAS = 70, DISTANCIA_CM = 25;
const unsigned long TIEMPO_ALETEO_MS = 4000;
const int PASOS = 20, ESPERA_PASO_MS = 12;
Servo alas;
volatile bool aplauso = false;
void detectarAplauso() { aplauso = true; }
long medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW); delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long t = pulseIn(PIN_ECHO, HIGH, 30000);
  return t == 0 ? 999 : t / 58;
}
void moverSuave(int desde, int hasta) {
  for (int i = 0; i <= PASOS; i++) {
    float s = (1 - cos(i * PI / PASOS)) / 2;
    alas.write(desde + (hasta - desde) * s);
    delay(ESPERA_PASO_MS);
  }
}
void aletear() {
  unsigned long inicio = millis();
  while (millis() - inicio < TIEMPO_ALETEO_MS) {
    moverSuave(ALAS_ABIERTAS, ALAS_CERRADAS);
    moverSuave(ALAS_CERRADAS, ALAS_ABIERTAS);
  }
  delay(500); aplauso = false;
}
void setup() {
  Serial.begin(9600);
  pinMode(PIN_TRIG, OUTPUT); pinMode(PIN_ECHO, INPUT); pinMode(PIN_SONIDO, INPUT);
  attachInterrupt(digitalPinToInterrupt(PIN_SONIDO), detectarAplauso, RISING);
  alas.attach(PIN_SERVO); alas.write(ALAS_ABIERTAS);
}
void loop() {
  if (medirDistanciaCm() < DISTANCIA_CM || aplauso) aletear();
  delay(60);
}
```

### Limitaciones y soluciones

- En el Arduino Uno solo D2 y D3 admiten interrupciones; por eso el sensor de sonido va en D2.
- Para la posición inicial, cargue un programa con `alas.write(0);` en `setup()` antes de colocar la patita.
