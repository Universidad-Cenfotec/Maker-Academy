## Contenido

### Diferencias con la IdeaBoard

La micro:bit V2 trae sensor de luz (la pantalla), de temperatura y micrófono. No necesita componentes extra. Guarda las mediciones en su memoria con la extensión **datalogger**, sin Wi-Fi.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Código en MakeCode

Con el botón B se elige el lugar (1, 2 o 3) y con el botón A se guarda una medición. El ruido es el valor más alto durante un segundo.

```javascript
// El retrato de mi escuela: micro:bit V2 (vista JavaScript de MakeCode)
let lugar = 1
datalogger.setColumnTitles("lugar", "luz", "temperatura", "ruido")
input.onButtonPressed(Button.B, function () {
    lugar += 1
    if (lugar > 3) {
        lugar = 1
    }
    basic.showNumber(lugar)
})
input.onButtonPressed(Button.A, function () {
    let ruido = 0
    for (let i = 0; i < 20; i++) {
        ruido = Math.max(ruido, input.soundLevel())
        basic.pause(50)
    }
    let luz = input.lightLevel()
    datalogger.log(
        datalogger.createCV("lugar", lugar),
        datalogger.createCV("luz", Math.round(luz * 100 / 255)),
        datalogger.createCV("temperatura", input.temperature()),
        datalogger.createCV("ruido", Math.round(ruido * 100 / 255))
    )
    basic.showIcon(IconNames.Yes)
    basic.pause(500)
    basic.showNumber(lugar)
})
basic.showNumber(lugar)
```

### Ver y descargar los datos

1. Conecte la micro:bit a la computadora y abra la unidad **MICROBIT**.
2. Abra el archivo **MY_DATA.HTM** en el navegador: muestra la tabla y permite descargarla como CSV.
3. El CSV se puede abrir en la obra `obra.html` cambiando los números de lugar por nombres.

### Limitaciones y soluciones

- Al cargar un programa nuevo se borran los datos: descargue MY_DATA antes.
- La temperatura incluye el calor del procesador: suele marcar unos grados de más.
- La micro:bit V1 no tiene micrófono ni datalogger: anote los datos a mano mostrando cada valor en la pantalla.
