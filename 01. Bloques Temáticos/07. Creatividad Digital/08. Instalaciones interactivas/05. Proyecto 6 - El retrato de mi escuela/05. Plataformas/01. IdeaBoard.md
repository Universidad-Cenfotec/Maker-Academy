### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

Los tres sensores van al bloque azul (3.3 V). IO34 e IO35 son entradas analógicas que funcionan con el Wi-Fi encendido.

| Componente | Pin del componente | Pin de la IdeaBoard |
|---|---|---|
| Sensor de luz | VCC / GND / AO | Fila IO34: 3.3 V / GND / señal |
| KY-038 | + / G / AO | Fila IO35: 3.3 V / GND / señal |
| DS18B20 | Rojo / negro / amarillo (datos) | Fila IO27: 3.3 V / GND / señal |
| Resistencia 4.7 kΩ | Entre datos y 3.3 V | En la protoboard |

### Paso 1. Hoja de cálculo y Apps Script

1. Cree una hoja de cálculo de Google con una pestaña llamada `Datos` y los encabezados: fecha, lugar, luz, temperatura, ruido.
2. Abra **Extensiones > Apps Script**, borre lo que haya y pegue:

```javascript
// Proyecto 6: recibe los datos de la estacion y los guarda en la hoja "Datos".
// Extensiones > Apps Script, pegue este codigo e implemente como "Aplicacion web".
function doGet(e) {
  var hoja = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Datos");
  hoja.appendRow([
    new Date(),
    e.parameter.lugar,
    Number(e.parameter.luz),
    Number(e.parameter.temp),
    Number(e.parameter.ruido)
  ]);
  return ContentService.createTextOutput("ok");
}
```

3. Presione **Implementar > Nueva implementación**, elija **Aplicación web**, ejecutar como **Yo** y acceso **Cualquier usuario**. Autorice y copie la dirección que termina en `/exec`.
4. Pruébela en el navegador agregando `?lugar=prueba&luz=1&temp=2&ruido=3`: debe aparecer una fila.

### Paso 2. Configurar la IdeaBoard

1. En IdeaCode, instale las librerías `adafruit_onewire` y `adafruit_ds18x20`.
2. Edite el archivo `settings.toml` de la placa:

```toml
# Archivo settings.toml de la IdeaBoard (se edita desde IdeaCode)
CIRCUITPY_WIFI_SSID = "nombre-de-la-red"
CIRCUITPY_WIFI_PASSWORD = "clave-de-la-red"
URL_HOJA = "https://script.google.com/macros/s/CODIGO-DE-SU-SCRIPT/exec"
```

3. Pegue el programa en `code.py`, cambie `LUGAR` y guárdelo.

```python
# Proyecto 6: El retrato de mi escuela, estacion de datos
# (IdeaBoard con IdeaCode / CircuitPython)
# Mide luz, temperatura y ruido cada 5 minutos y los envia a una hoja de calculo.
# Antes de usar: escriba la red Wi-Fi y la direccion de la hoja en settings.toml.
# Librerias que hay que instalar desde IdeaCode: adafruit_onewire y adafruit_ds18x20.
import os
import time
import board
import analogio
import neopixel
import wifi
import adafruit_connection_manager
import adafruit_requests
from adafruit_onewire.bus import OneWireBus
from adafruit_ds18x20 import DS18X20

LUGAR = "biblioteca"            # cambie el nombre segun donde coloque la estacion
INTERVALO = 300                 # segundos entre mediciones (300 = 5 minutos)

luz_sensor = analogio.AnalogIn(board.IO34)     # sensor de luz: salida AO
ruido_sensor = analogio.AnalogIn(board.IO35)   # KY-038: salida AO
bus = OneWireBus(board.IO27)                   # DS18B20 con resistencia de 4.7 kOhm a 3.3 V
termometro = DS18X20(bus, bus.scan()[0])
led = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.2)


def medir_luz():
    """0 = oscuro, 100 = mucha luz. Si su modulo da al reves, use 100 - valor."""
    return round(luz_sensor.value * 100 / 65535)


def medir_ruido():
    """Diferencia entre el valor mas alto y el mas bajo durante medio segundo (0 a 100)."""
    alto, bajo = 0, 65535
    fin = time.monotonic() + 0.5
    while time.monotonic() < fin:
        v = ruido_sensor.value
        alto = max(alto, v)
        bajo = min(bajo, v)
    return round((alto - bajo) * 100 / 65535)


def conectar():
    led[0] = (80, 60, 0)                      # amarillo: conectando
    wifi.radio.connect(os.getenv("CIRCUITPY_WIFI_SSID"), os.getenv("CIRCUITPY_WIFI_PASSWORD"))
    print("Conectado, IP:", wifi.radio.ipv4_address)


conectar()
pool = adafruit_connection_manager.get_radio_socketpool(wifi.radio)
ssl_context = adafruit_connection_manager.get_radio_ssl_context(wifi.radio)
requests = adafruit_requests.Session(pool, ssl_context)
URL = os.getenv("URL_HOJA")

print("lugar,luz,temperatura,ruido")
while True:
    luz = medir_luz()
    temperatura = round(termometro.temperature, 1)
    ruido = medir_ruido()
    print(f"{LUGAR},{luz},{temperatura},{ruido}")       # copia de respaldo en la consola
    try:
        if not wifi.radio.connected:
            conectar()
        r = requests.get(f"{URL}?lugar={LUGAR}&luz={luz}&temp={temperatura}&ruido={ruido}")
        r.close()
        led[0] = (0, 80, 0)                   # verde: dato enviado
    except Exception as e:
        print("No se pudo enviar:", e)
        led[0] = (80, 0, 0)                   # rojo: revisar la red
    time.sleep(INTERVALO)
```

### Prueba de funcionamiento

1. La consola muestra "Conectado" y una línea `lugar,luz,temperatura,ruido` cada intervalo.
2. El LED se pone amarillo al conectar, verde al enviar y rojo si falla el envío.
3. En la hoja aparece una fila nueva por cada medición.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| Red con página de inicio de sesión | No funciona con la placa: use otra red o la zona Wi-Fi de un teléfono. |
| `IndexError` al iniciar | No se encontró el DS18B20: revise la resistencia y el pin IO27. |
| Valores de luz al revés | Use `100 - valor` en `medir_luz()`. |
| La temperatura sube con el sol | Ponga la estación a la sombra y con ventilación. |
