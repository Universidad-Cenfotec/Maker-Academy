### Pines táctiles de la IdeaBoard

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

Los pines IO04, IO27, IO32 e IO33 son táctiles: detectan el toque sin componentes extra. La lectura de `touchRead()` **baja** cuando alguien toca el metal o la planta conectada.

### Secundaria: planta musical

| Componente | Conexión |
|---|---|
| Planta (hoja) | Jumper hembra-macho o cable lagarto al pin **27** |
| Computadora | Cable USB-C de datos |

> **Importante antes de conectar la planta:**
> - Haga todas las conexiones con la IdeaBoard **desconectada de la computadora**. Conecte el cable USB solo cuando todo esté revisado.
> - Lo más recomendable es usar un **jumper hembra-macho**: el lado hembra va en el pin 27 y la punta metálica del lado macho se pega sobre la hoja con un pedazo de cinta adhesiva.
> - En el prototipo se usó un **cable lagarto** (también llamado cocodrilo). Si usa uno, revise que la pinza muerda **solo el pin 27** y no toque ningún otro pin cercano (GND, 3.3 V, 26, RX0 o TX0). Si toca otro pin puede provocar un cortocircuito y dañar la placa.

<img width="420" alt="cable lagarto mordiendo solo el pin 27 de la IdeaBoard" src="../06.%20Im%C3%A1genes/planta-lagarto-pin-27.jpg" />

Se programa con **Arduino IDE** ([guía de instalación y uso](../../../02.%20Gu%C3%ADa%20de%20plataformas.md#arduino-ide-paso-a-paso)), placa **ESP32 Dev Module**, con las librerías **MIDI Library** y **Arduino-BLE-MIDI**. El paso a paso completo, con GarageBand y con la versión para computadora, está en [`03. Versión secundaria.md`](../03.%20Versi%C3%B3n%20secundaria.md).

#### Programa de prueba del sensor

```cpp
// Proyecto 3: Bosque sonoro, Secundaria. Prueba del sensor de la planta.
// Muestra en el monitor serie la lectura capacitiva del pin 27.
// Tambien sirve para la version con computadora: Python lee estas lineas por USB.
const int pinPlanta = 27;

void setup() {
  Serial.begin(115200);
  delay(1000);
}

void loop() {
  int lectura = touchRead(pinPlanta);   // baja cuando alguien toca la planta

  Serial.print("Lectura de planta: ");
  Serial.println(lectura);

  delay(100);
}
```

#### Programa musical (Bluetooth MIDI)

```cpp
// Proyecto 3: Bosque sonoro, Secundaria. Planta musical por Bluetooth MIDI.
// La IdeaBoard aparece en GarageBand con el nombre de abajo y envia notas al tocar la planta.
// Librerias: MIDI Library (FortySevenEffects) y Arduino-BLE-MIDI (lathoub).
#include <BLEMIDI_Transport.h>
#include <hardware/BLEMIDI_ESP32.h>

// NOMBRE EN BLUETOOTH. Si el bosque tiene varias plantas, cada IdeaBoard necesita
// un nombre distinto para no confundirlas en GarageBand:
// "IdeaBoard Planta 1", "IdeaBoard Planta 2", "IdeaBoard Planta 3"...
BLEMIDI_CREATE_INSTANCE("IdeaBoard Planta", MIDI)

const int pinPlanta = 27;

// AJUSTES DE SU PLANTA. Calculelos con las lecturas de su planta
// (tabla de calibracion de la guia). Estos son los de la planta del prototipo:
// sin tocar = 1123, tocando = 853.
const int umbralTocar = 1000;   // por debajo de este valor la planta esta tocada
const int umbralSoltar = 1050;  // por encima de este valor la planta se solto
const int pasoNota = 40;        // cuanto debe bajar la lectura para subir una nota

// Escala pentatonica de Do mayor: Do, Re, Mi, Sol, La
const byte notas[] = {60, 62, 64, 67, 69};

bool conectado = false;
bool tocando = false;
int notaActual = -1;

unsigned long ultimoCambio = 0;

void setup() {
  Serial.begin(115200);

  BLEMIDI.setHandleConnected([]() {
    conectado = true;
    Serial.println("Bluetooth conectado");
  });

  BLEMIDI.setHandleDisconnected([]() {
    conectado = false;
    tocando = false;
    notaActual = -1;
    Serial.println("Bluetooth desconectado");
  });

  MIDI.begin(1);

  Serial.println("IdeaBoard Planta iniciada");
}

void loop() {
  MIDI.read();

  int lectura = touchRead(pinPlanta);

  if (lectura < umbralTocar) {
    tocando = true;
  } else if (lectura > umbralSoltar) {
    tocando = false;
  }

  if (conectado) {
    int nuevaNota = -1;

    if (tocando) {
      // Mientras mas fuerte el contacto, mas baja la lectura y mas aguda la nota
      int indice = constrain(
        (umbralTocar - lectura) / pasoNota, 0, 4
      );

      nuevaNota = notas[indice];
    }

    if (nuevaNota != notaActual &&
        millis() - ultimoCambio >= 150) {

      if (notaActual >= 0) {
        MIDI.sendNoteOff(notaActual, 0, 1);
      }

      if (nuevaNota >= 0) {
        MIDI.sendNoteOn(nuevaNota, 90, 1);
      }

      notaActual = nuevaNota;
      ultimoCambio = millis();
    }
  }

  delay(30);
}
```

#### Prueba de funcionamiento

1. Con el programa de prueba, el monitor serie a 115200 baud muestra unos 1123 sin tocar y unos 853 al tocar (valores del prototipo).
2. Con el programa musical, el monitor serie muestra "IdeaBoard Planta iniciada" y, al conectar GarageBand, "Bluetooth conectado".
3. Al tocar la hoja, GarageBand toca una nota; al soltarla, la nota se detiene.

### Primaria: adaptación de "El guardián del bosque"

La plataforma principal de Primaria es la **micro:bit V2** (ver [`02. Microbit.md`](./02.%20Microbit.md)). Si el makerspace solo tiene IdeaBoard, el guardián puede adaptarse: la IdeaBoard no tiene pantalla de LEDs ni sensor de luz integrado, por lo que se agregan una fotorresistencia y un buzzer, y la cara del guardián se reemplaza por el color del LED de la placa.

| Componente | Conexión en la IdeaBoard |
|---|---|
| Planta 1 (pájaro) | IO04 (pin táctil) |
| Planta 2 (mono) | IO27 (pin táctil) |
| Planta 3 (abeja) | IO32 (pin táctil) |
| Buzzer pasivo | Fila IO05: señal y GND |
| Fotorresistencia | Entre 3.3 V y la señal de IO34 |
| Resistencia de 10 kΩ | Entre la señal de IO34 y GND (forma el divisor de voltaje con la fotorresistencia) |

| Estado | LED de la IdeaBoard |
|---|---|
| Día (guardián dormido) | Verde tenue |
| Noche (guardián despierto) | Azul |
| Planta tocada | Color de cada animal |

> **Importante antes de encender:**
> - Toda conexión se hace con la placa desconectada de la computadora y de las pilas.
> - Cada pinza toca solo su pin y ningún otro, porque puede provocar un cortocircuito.
> - El papel aluminio de una planta no debe tocar el de otra planta ni la roca de la placa.

El docente carga el programa [`guardian_ideaboard_code.py`](../07.%20C%C3%B3digo/guardian_ideaboard_code.py) con [IdeaCode](https://ideacode.crcibernetica.com/) como `code.py`. Igual que en la micro:bit, la placa se enciende con la luz del aula encendida, sin tapar la fotorresistencia y sin tocar las plantas, porque al arrancar guarda esos valores. Si el módulo de luz da más valor con menos luz, se cambia `SENSOR_INVERTIDO` a `True`.

```python
# Guardian del bosque: adaptacion para IdeaBoard (IdeaCode / CircuitPython)
# Version de Primaria del Proyecto 3: Bosque sonoro. La plataforma principal de
# Primaria es la micro:bit; este programa es una alternativa para makerspaces
# que solo tienen IdeaBoard.
#
# DIA (luz encendida): el guardian duerme (LED verde tenue). Las plantas de
#   papel aluminio en IO04, IO27 e IO32 suenan al tocarlas: pajaro, mono y abeja.
# NOCHE (luz apagada o sensor tapado): el guardian despierta (LED azul) y suena
#   el bosque nocturno: buho, grillos, ranas y jaguar. De noche las plantas no suenan.
#
# Conexiones (con la placa desconectada):
#   Plantas: IO04, IO27 e IO32 (pines tactiles), con jumper o cable lagarto.
#   Buzzer pasivo: fila IO05, senal y GND.
#   Sensor de luz: fotorresistencia entre 3.3 V y la senal de IO34, y una
#   resistencia de 10 kOhm entre la senal de IO34 y GND (divisor de voltaje).
#
# IMPORTANTE: encender la placa con la luz del aula encendida, sin tapar el
# sensor y sin tocar las plantas, porque al arrancar guarda esos valores.
import time
import board
import touchio
import analogio
import neopixel
import simpleio

PIN_BUZZER = board.IO5
UMBRAL_NOCHE = 0.4        # igual que en la micro:bit: 0.6 si no despierta, 0.3 si despierta solo
SENSOR_INVERTIDO = False  # True si el sensor da MAS valor con menos luz (algunos modulos)
SENSIBILIDAD = 0.15       # cuanto debe cambiar una planta al tocarla (0.15 = 15 %)

luz = analogio.AnalogIn(board.IO34)
led = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.3)

# Sonidos: lista de (frecuencia en Hz, duracion en segundos). 0 = silencio.
DIA = {
    "pajaro": [(1320, 0.1), (1570, 0.1), (1760, 0.15), (0, 0.05), (1570, 0.1)],
    "mono": [(300, 0.12), (450, 0.12), (300, 0.12), (450, 0.12), (600, 0.2)],
    "abeja": [(220, 0.1), (240, 0.1), (220, 0.1), (240, 0.1), (220, 0.1), (240, 0.1)],
}
BUHO = [(392, 0.25), (330, 0.5)]
GRILLOS = [(3000, 0.06), (0, 0.06)] * 6
RANAS = [(150, 0.12), (0, 0.12)] * 3
JAGUAR = [(f, 0.05) for f in range(400, 80, -20)]

PLANTAS = [
    (board.IO4, "pajaro", (255, 200, 0)),
    (board.IO27, "mono", (255, 80, 0)),
    (board.IO32, "abeja", (200, 200, 0)),
]


def sonar(notas):
    for frecuencia, duracion in notas:
        if frecuencia == 0:
            time.sleep(duracion)
        else:
            simpleio.tone(PIN_BUZZER, frecuencia, duration=duracion)


def nivel_luz():
    valor = luz.value
    return 65535 - valor if SENSOR_INVERTIDO else valor


# Preparacion: guardar la luz normal del aula y el valor de cada planta sin tocar
time.sleep(0.5)
luz_base = nivel_luz()
sensores = []
for pin, animal, color in PLANTAS:
    t = touchio.TouchIn(pin)
    sensores.append([t, t.raw_value, animal, color])

DORMIDO = (0, 20, 0)
DESPIERTO = (0, 60, 255)
led[0] = DORMIDO
noche = False
print("Guardian listo. Luz base:", luz_base)

while True:
    if nivel_luz() < luz_base * UMBRAL_NOCHE:
        noche = True
        led[0] = DESPIERTO
        sonar(BUHO)
        sonar(GRILLOS)
        sonar(RANAS)
        sonar(JAGUAR)
        time.sleep(1)
    elif noche:
        noche = False
        led[0] = DORMIDO
    else:
        for sensor, base, animal, color in sensores:
            if abs(sensor.raw_value - base) > base * SENSIBILIDAD:
                print("Planta tocada:", animal)
                led[0] = color
                sonar(DIA[animal])
                led[0] = DORMIDO
                time.sleep(0.3)
    time.sleep(0.05)
```

> **Nota:** esta adaptación usa los mismos pines y funciones que otros programas del bloque para la IdeaBoard, pero no se ha probado con el guardián completo. Verifíquela antes de implementarla con el grupo.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| Lecturas que no cambian | Revise que el cable esté en el pin correcto y haga contacto con la hoja o el aluminio. |
| La planta suena sola | Baje `umbralTocar` o separe la hoja de otras hojas y de la maceta mojada. |
| No compila el programa musical | Instale MIDI Library y Arduino-BLE-MIDI, y elija ESP32 Dev Module. |
| Una planta suena sola (Primaria) | Reinicie la placa sin tocar las plantas y separe su aluminio de otras plantas. |
| El guardián no despierta (Primaria) | Tape la fotorresistencia o cambie `UMBRAL_NOCHE` a 0.6; si despierta al revés, cambie `SENSOR_INVERTIDO`. |
