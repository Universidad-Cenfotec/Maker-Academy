### Pines táctiles de la IdeaBoard

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

Los pines IO04, IO27, IO32 e IO33 son táctiles: detectan el toque sin componentes extra. La lectura de `touchRead()` **baja** cuando alguien toca el metal o la planta conectada.

### Secundaria: planta musical

| Componente | Conexión |
|---|---|
| Planta (hoja) | Jumper hembra-macho o cable lagarto al pin **27** |
| Computadora | Cable USB-C de datos |

> **Importante antes de conectar la planta:**
> - Haga todas las conexiones con la IdeaBoard **desconectada de la computadora**. Conecte el cable USB solo cuando todo esté revisado.
> - Lo más recomendable es usar un **jumper hembra-macho**: el lado hembra va en el pin 27 y la punta metálica del lado macho se pega sobre la hoja con un pedazo de cinta adhesiva.
> - En el prototipo se usó un **cable lagarto** (también llamado cocodrilo). Si usa uno, revise que la pinza muerda **solo el pin 27** y no toque ningún otro pin cercano (GND, 3.3 V, 26, RX0 o TX0). Si toca otro pin puede provocar un cortocircuito y dañar la placa.

<img width="420" alt="cable lagarto mordiendo solo el pin 27 de la IdeaBoard" src="../06.%20Im%C3%A1genes/planta-lagarto-pin-27.jpg" />

Se programa con **Arduino IDE** ([guía de instalación y uso](../../../02.%20Gu%C3%ADa%20de%20plataformas.md#arduino-ide-paso-a-paso)), placa **ESP32 Dev Module**, con las librerías **MIDI Library** y **Arduino-BLE-MIDI**. El paso a paso completo, con GarageBand y con la versión para computadora, está en [`03. Versión secundaria.md`](../03.%20Versi%C3%B3n%20secundaria.md).

#### Programa de prueba del sensor

```cpp
// Proyecto 3: Bosque sonoro, Secundaria. Prueba del sensor de la planta.
// Muestra en el monitor serie la lectura capacitiva del pin 27.
// Tambien sirve para la version con computadora: Python lee estas lineas por USB.
const int pinPlanta = 27;

void setup() {
  Serial.begin(115200);
  delay(1000);
}

void loop() {
  int lectura = touchRead(pinPlanta);   // baja cuando alguien toca la planta

  Serial.print("Lectura de planta: ");
  Serial.println(lectura);

  delay(100);
}
```

#### Programa musical (Bluetooth MIDI)

```cpp
// Proyecto 3: Bosque sonoro, Secundaria. Planta musical por Bluetooth MIDI.
// La IdeaBoard aparece en GarageBand con el nombre de abajo y envia notas al tocar la planta.
// Librerias: MIDI Library (FortySevenEffects) y Arduino-BLE-MIDI (lathoub).
#include <BLEMIDI_Transport.h>
#include <hardware/BLEMIDI_ESP32.h>

// NOMBRE EN BLUETOOTH. Si el bosque tiene varias plantas, cada IdeaBoard necesita
// un nombre distinto para no confundirlas en GarageBand:
// "IdeaBoard Planta 1", "IdeaBoard Planta 2", "IdeaBoard Planta 3"...
BLEMIDI_CREATE_INSTANCE("IdeaBoard Planta", MIDI)

const int pinPlanta = 27;

// AJUSTES DE SU PLANTA. Calculelos con las lecturas de su planta
// (tabla de calibracion de la guia). Estos son los de la planta del prototipo:
// sin tocar = 1123, tocando = 853.
const int umbralTocar = 1000;   // por debajo de este valor la planta esta tocada
const int umbralSoltar = 1050;  // por encima de este valor la planta se solto
const int pasoNota = 40;        // cuanto debe bajar la lectura para subir una nota

// Escala pentatonica de Do mayor: Do, Re, Mi, Sol, La
const byte notas[] = {60, 62, 64, 67, 69};

bool conectado = false;
bool tocando = false;
int notaActual = -1;

unsigned long ultimoCambio = 0;

void setup() {
  Serial.begin(115200);

  BLEMIDI.setHandleConnected([]() {
    conectado = true;
    Serial.println("Bluetooth conectado");
  });

  BLEMIDI.setHandleDisconnected([]() {
    conectado = false;
    tocando = false;
    notaActual = -1;
    Serial.println("Bluetooth desconectado");
  });

  MIDI.begin(1);

  Serial.println("IdeaBoard Planta iniciada");
}

void loop() {
  MIDI.read();

  int lectura = touchRead(pinPlanta);

  if (lectura < umbralTocar) {
    tocando = true;
  } else if (lectura > umbralSoltar) {
    tocando = false;
  }

  if (conectado) {
    int nuevaNota = -1;

    if (tocando) {
      // Mientras mas fuerte el contacto, mas baja la lectura y mas aguda la nota
      int indice = constrain(
        (umbralTocar - lectura) / pasoNota, 0, 4
      );

      nuevaNota = notas[indice];
    }

    if (nuevaNota != notaActual &&
        millis() - ultimoCambio >= 150) {

      if (notaActual >= 0) {
        MIDI.sendNoteOff(notaActual, 0, 1);
      }

      if (nuevaNota >= 0) {
        MIDI.sendNoteOn(nuevaNota, 90, 1);
      }

      notaActual = nuevaNota;
      ultimoCambio = millis();
    }
  }

  delay(30);
}
```

#### Prueba de funcionamiento

1. Con el programa de prueba, el monitor serie a 115200 baud muestra unos 1123 sin tocar y unos 853 al tocar (valores del prototipo).
2. Con el programa musical, el monitor serie muestra "IdeaBoard Planta iniciada" y, al conectar GarageBand, "Bluetooth conectado".
3. Al tocar la hoja, GarageBand toca una nota; al soltarla, la nota se detiene.

### Primaria: árbol con hojas de aluminio

| Componente | Pin de la IdeaBoard |
|---|---|
| Hojas 1 a 4 | IO04, IO27, IO32 e IO33 (cable lagarto y jumper macho-hembra) |
| Buzzer pasivo | Fila IO05: señal y GND |

En Primaria el docente carga el programa con [IdeaCode](https://ideacode.crcibernetica.com/) (CircuitPython) y los estudiantes cambian los números de la lista `SONIDOS`. No toque las hojas mientras la placa arranca.

```python
# Proyecto 3: Bosque sonoro, Primaria (IdeaBoard con IdeaCode / CircuitPython)
# Cada hoja de papel aluminio se conecta con un cable lagarto a un pin tactil.
# Al tocar una hoja suena su animal y el LED de la IdeaBoard cambia de color.
import time
import board
import touchio
import neopixel
import simpleio

PIN_BUZZER = board.IO5          # buzzer pasivo en el conector IO05 (senal y GND)
SENSIBILIDAD = 0.15             # 0.15 = la hoja cambia 15 % al tocarla

# Sonidos: lista de (frecuencia en Hz, duracion en segundos). 0 = silencio.
# Los estudiantes pueden cambiar los numeros para inventar su propio sonido.
SONIDOS = {
    "yiguirro": [(1320, 0.12), (1570, 0.12), (1320, 0.12), (1050, 0.25), (0, 0.1), (1400, 0.2)],
    "rana": [(180, 0.08), (0, 0.06), (180, 0.08), (0, 0.06), (220, 0.15)],
    "mono congo": [(110, 0.3), (130, 0.3), (150, 0.4), (120, 0.4)],
    "tucan": [(700, 0.06), (500, 0.06), (700, 0.06), (500, 0.06), (700, 0.1)],
}

# Hojas: (pin, animal, color del LED)
HOJAS = [
    (board.IO4, "yiguirro", (120, 80, 0)),
    (board.IO27, "rana", (0, 150, 0)),
    (board.IO32, "mono congo", (120, 30, 0)),
    (board.IO33, "tucan", (0, 60, 150)),
]

luz = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.3)
sensores = []
for pin, animal, color in HOJAS:
    t = touchio.TouchIn(pin)
    sensores.append([t, t.raw_value, animal, color])   # guarda el valor sin tocar


def tocada(s):
    sensor, base = s[0], s[1]
    return abs(sensor.raw_value - base) > base * SENSIBILIDAD


def sonar(animal):
    for frecuencia, duracion in SONIDOS[animal]:
        if frecuencia == 0:
            time.sleep(duracion)
        else:
            simpleio.tone(PIN_BUZZER, frecuencia, duration=duracion)


luz[0] = (0, 20, 0)
print("Bosque listo: toque una hoja")

while True:
    for s in sensores:
        if tocada(s):
            print("Hoja tocada:", s[2])
            luz[0] = s[3]
            sonar(s[2])
            luz[0] = (0, 20, 0)
            time.sleep(0.3)              # evita que un toque suene dos veces
    time.sleep(0.02)
```

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| Lecturas que no cambian | Revise que el cable esté en el pin correcto y haga contacto con la hoja o el aluminio. |
| La planta suena sola | Baje `umbralTocar` o separe la hoja de otras hojas y de la maceta mojada. |
| No compila el programa musical | Instale MIDI Library y Arduino-BLE-MIDI, y elija ESP32 Dev Module. |
| Una hoja de aluminio suena sola (Primaria) | Reinicie la placa sin tocar las hojas. |
