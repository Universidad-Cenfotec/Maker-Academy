### Componentes

| Componente | Primaria | Secundaria |
|---|---|---|
| IdeaBoard con cable USB-C | 1 | 1 |
| Hojas de aluminio con cable lagarto y jumper macho-hembra | 4 | 4 |
| Buzzer pasivo | 1 | 1 |
| Tira LED WS2812B de 30 LEDs | — | 1 |
| Sensor ultrasónico HC-SR05 | — | 1 |
| Resistencias de 1 kΩ y 2 kΩ, protoboard y jumpers | — | 1 juego |

### Dónde conectar

<img width="650" alt="IdeaBoard: conectores de servo, pines de 3.3 V y conector STEMMA QT" src="../06.%20Im%C3%A1genes/ideaboard-conectores.png" />

Los pines IO04, IO27, IO32 e IO33 son táctiles: detectan el toque sin componentes extra. El puente **SELECT** debe estar en **Vin** para que las filas de servo entreguen 5 V a la tira y al sensor.

| Componente | Pin del componente | Pin de la IdeaBoard |
|---|---|---|
| Hoja 1 | Cable lagarto | IO04 (señal) |
| Hoja 2 | Cable lagarto | IO27 (señal, bloque azul) |
| Hoja 3 | Cable lagarto | IO32 (señal, bloque azul) |
| Hoja 4 | Cable lagarto | IO33 (señal, bloque azul) |
| Buzzer pasivo | + / − | Fila IO05: señal / GND |
| Tira WS2812B (Secundaria) | 5V / GND / DIN | Fila IO18: V+ / GND / señal |
| HC-SR05 (Secundaria) | VCC y GND | Fila IO26: V+ y GND |
| HC-SR05 (Secundaria) | TRIG | IO26 (señal) |
| HC-SR05 (Secundaria) | ECHO | 1 kΩ hacia IO35; 2 kΩ de IO35 a GND |

Para conectar un cable lagarto a un pin de la IdeaBoard, ponga un jumper macho-hembra en el pin y muerda la punta macho con el lagarto.

### Programación con IdeaCode (CircuitPython)

1. Abra [IdeaCode](https://ideacode.crcibernetica.com/) en Chrome o Edge y conecte la IdeaBoard con el cable USB-C.
2. Conecte la placa desde IdeaCode. Si no tiene CircuitPython, instálelo desde la [página de la IdeaBoard en circuitpython.org](https://circuitpython.org/board/crcibernetica-ideaboard/).
3. Las librerías `neopixel` y `simpleio` ya vienen incluidas: no hay que instalar nada.
4. Pegue el programa en `code.py` y guárdelo. **No toque las hojas mientras la placa arranca:** en ese momento guarda el valor de cada hoja sin tocar.

#### Programa de Primaria

```python
# Proyecto 3: Bosque sonoro, Primaria (IdeaBoard con IdeaCode / CircuitPython)
# Cada hoja de papel aluminio se conecta con un cable lagarto a un pin tactil.
# Al tocar una hoja suena su animal y el LED de la IdeaBoard cambia de color.
import time
import board
import touchio
import neopixel
import simpleio

PIN_BUZZER = board.IO5          # buzzer pasivo en el conector IO05 (senal y GND)
SENSIBILIDAD = 0.15             # 0.15 = la hoja cambia 15 % al tocarla

# Sonidos: lista de (frecuencia en Hz, duracion en segundos). 0 = silencio.
# Los estudiantes pueden cambiar los numeros para inventar su propio sonido.
SONIDOS = {
    "yiguirro": [(1320, 0.12), (1570, 0.12), (1320, 0.12), (1050, 0.25), (0, 0.1), (1400, 0.2)],
    "rana": [(180, 0.08), (0, 0.06), (180, 0.08), (0, 0.06), (220, 0.15)],
    "mono congo": [(110, 0.3), (130, 0.3), (150, 0.4), (120, 0.4)],
    "tucan": [(700, 0.06), (500, 0.06), (700, 0.06), (500, 0.06), (700, 0.1)],
}

# Hojas: (pin, animal, color del LED)
HOJAS = [
    (board.IO4, "yiguirro", (120, 80, 0)),
    (board.IO27, "rana", (0, 150, 0)),
    (board.IO32, "mono congo", (120, 30, 0)),
    (board.IO33, "tucan", (0, 60, 150)),
]

luz = neopixel.NeoPixel(board.NEOPIXEL, 1, brightness=0.3)
sensores = []
for pin, animal, color in HOJAS:
    t = touchio.TouchIn(pin)
    sensores.append([t, t.raw_value, animal, color])   # guarda el valor sin tocar


def tocada(s):
    sensor, base = s[0], s[1]
    return abs(sensor.raw_value - base) > base * SENSIBILIDAD


def sonar(animal):
    for frecuencia, duracion in SONIDOS[animal]:
        if frecuencia == 0:
            time.sleep(duracion)
        else:
            simpleio.tone(PIN_BUZZER, frecuencia, duration=duracion)


luz[0] = (0, 20, 0)
print("Bosque listo: toque una hoja")

while True:
    for s in sensores:
        if tocada(s):
            print("Hoja tocada:", s[2])
            luz[0] = s[3]
            sonar(s[2])
            luz[0] = (0, 20, 0)
            time.sleep(0.3)              # evita que un toque suene dos veces
    time.sleep(0.02)
```

#### Programa de Secundaria

```python
# Proyecto 3: Bosque sonoro, Secundaria (IdeaBoard con IdeaCode / CircuitPython)
# Instalacion con tres estados: DORMIDO, DESPIERTO y TORMENTA.
import time
import math
import random
import board
import digitalio
import pulseio
import touchio
import neopixel
import simpleio

# ---------- Pines ----------
PIN_BUZZER = board.IO5            # buzzer pasivo: fila IO05 (senal y GND)
PIN_TIRA = board.IO18             # tira LED WS2812B: fila IO18 (V+, GND y senal)
PIN_TRIG = board.IO26             # ultrasonico TRIG: fila IO26 (V+ alimenta el sensor)
PIN_ECHO = board.IO35             # ultrasonico ECHO con divisor 1 kOhm / 2 kOhm
PINES_HOJAS = [board.IO4, board.IO27, board.IO32, board.IO33]

# ---------- Ajustes (se calibran con la obra real) ----------
NUM_LEDS = 30
BRILLO = 0.4                      # 0 a 1. Mas brillo = mas consumo
DIST_DESPIERTO = 120              # cm: alguien se acerca y el bosque despierta
DIST_TORMENTA = 40                # cm: alguien muy cerca...
TIEMPO_CERCA = 3                  # ...durante 3 s provoca la tormenta
TOQUES_TORMENTA = 6               # o 6 toques en 10 s
DURACION_TORMENTA = 6             # s
SENSIBILIDAD = 0.15

ANIMALES = [
    ("yiguirro", (255, 180, 0), [(1320, 0.12), (1570, 0.12), (1320, 0.12), (1050, 0.25)]),
    ("rana", (0, 255, 40), [(180, 0.08), (0, 0.06), (180, 0.08), (0, 0.06), (220, 0.15)]),
    ("mono congo", (255, 60, 0), [(110, 0.3), (130, 0.3), (150, 0.4)]),
    ("tucan", (0, 120, 255), [(700, 0.06), (500, 0.06), (700, 0.06), (500, 0.1)]),
]

# ---------- Preparacion ----------
tira = neopixel.NeoPixel(PIN_TIRA, NUM_LEDS, brightness=BRILLO, auto_write=False)
trig = digitalio.DigitalInOut(PIN_TRIG)
trig.direction = digitalio.Direction.OUTPUT
eco = pulseio.PulseIn(PIN_ECHO, maxlen=2)
eco.pause()

hojas = []
for pin in PINES_HOJAS:
    t = touchio.TouchIn(pin)
    hojas.append([t, t.raw_value, False])     # sensor, valor sin tocar, estaba tocada

estado = "DORMIDO"
inicio_cerca = None
inicio_tormenta = 0
toques = []                                   # momentos de los ultimos toques


def medir_distancia_cm():
    eco.clear()
    eco.resume()
    trig.value = True
    time.sleep(0.00001)
    trig.value = False
    t0 = time.monotonic()
    while len(eco) == 0:
        if time.monotonic() - t0 > 0.05:
            eco.pause()
            return 999
    eco.pause()
    return eco[0] / 58


def hoja_nueva(i):
    """True solo en el momento en que la hoja empieza a ser tocada."""
    sensor, base, antes = hojas[i]
    ahora = abs(sensor.raw_value - base) > base * SENSIBILIDAD
    hojas[i][2] = ahora
    return ahora and not antes


def sonar(notas):
    for f, d in notas:
        if f == 0:
            time.sleep(d)
        else:
            simpleio.tone(PIN_BUZZER, f, duration=d)


def tramo(i):
    """Parte de la tira que corresponde a la hoja i."""
    n = NUM_LEDS // len(PINES_HOJAS)
    return range(i * n, (i + 1) * n)


def luz_dormido(t):
    v = int(10 + 25 * (1 + math.sin(t * 1.5)) / 2)      # respira despacio
    tira.fill((0, v, v // 3))
    tira.show()


def luz_despierto():
    tira.fill((40, 90, 10))                               # luz de manana en el bosque
    tira.show()


def tormenta_paso():
    if random.random() < 0.15:                            # relampago
        tira.fill((255, 255, 255))
        tira.show()
        time.sleep(0.05)
        simpleio.tone(PIN_BUZZER, random.randint(60, 120), duration=0.25)   # trueno
    tira.fill((0, 0, random.randint(10, 40)))             # lluvia azul oscura
    tira.show()


def cambiar(nuevo):
    global estado
    if nuevo != estado:
        print("Estado:", estado, "->", nuevo)
        estado = nuevo


print("Bosque sonoro listo")
while True:
    ahora = time.monotonic()
    d = medir_distancia_cm()

    # Toques en las hojas (cuentan en cualquier estado)
    for i, (nombre, color, notas) in enumerate(ANIMALES):
        if hoja_nueva(i):
            toques.append(ahora)
            print("Hoja:", nombre, "| estado:", estado)
            if estado == "DESPIERTO":
                for k in tramo(i):
                    tira[k] = color
                tira.show()
                sonar(notas)
    toques = [t for t in toques if ahora - t < 10]

    # Cambios de estado
    if estado == "TORMENTA":
        tormenta_paso()
        if ahora - inicio_tormenta > DURACION_TORMENTA:
            toques = []
            cambiar("DESPIERTO")
    else:
        if d < DIST_TORMENTA:
            if inicio_cerca is None:
                inicio_cerca = ahora
        else:
            inicio_cerca = None
        muy_cerca = inicio_cerca is not None and ahora - inicio_cerca > TIEMPO_CERCA
        if muy_cerca or len(toques) >= TOQUES_TORMENTA:
            inicio_tormenta = ahora
            inicio_cerca = None
            cambiar("TORMENTA")
        elif d < DIST_DESPIERTO:
            if estado == "DORMIDO":
                cambiar("DESPIERTO")
                sonar([(523, 0.1), (659, 0.1), (784, 0.15)])  # el bosque despierta
            luz_despierto()
        else:
            cambiar("DORMIDO")
            luz_dormido(ahora)
    time.sleep(0.03)
```

### Prueba de funcionamiento

1. **Primaria:** la consola muestra "Bosque listo". Al tocar una hoja aparece su nombre, suena el animal y el LED de la placa cambia de color.
2. **Secundaria:** lejos del sensor, la tira respira en verde (DORMIDO). A menos de 120 cm suena una melodía y la tira se pone de color de mañana (DESPIERTO). Cada hoja pinta su tramo y suena.
3. Quédese a menos de 40 cm durante 3 segundos o toque seis veces en 10 segundos: empiezan los relámpagos y truenos (TORMENTA) por 6 segundos.

### Limitaciones y soluciones

| Problema | Solución |
|---|---|
| Una hoja suena sola | Reinicie sin tocar las hojas o suba `SENSIBILIDAD`. |
| Las hojas no responden | Revise que el lagarto muerda metal y que el cable no supere 50 cm. |
| La tira se reinicia o parpadea | Baje `BRILLO` o alimente la tira con una fuente de 5 V aparte (GND común). |
| El sensor marca 999 | Revise el divisor y que TRIG esté en IO26 y ECHO en IO35. |
