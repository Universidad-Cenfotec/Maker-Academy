## Contenido

### Diferencias con la IdeaBoard

La micro:bit V2 tiene tres pines táctiles grandes (P0, P1 y P2), un logo táctil y un parlante. Alcanza para cuatro hojas sin componentes extra: tres hojas con cable lagarto y el logo como cuarta hoja (se toca directamente).

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Conexiones

| Hoja | Conexión |
|---|---|
| Hoja 1 | Cable lagarto a P0 |
| Hoja 2 | Cable lagarto a P1 |
| Hoja 3 | Cable lagarto a P2 |

### Código en MakeCode

En bloques se arma con "al presionar el pin", "reproducir melodía" y "mostrar ícono". Esta es la misma lógica en la vista JavaScript:

```javascript
// Bosque sonoro: micro:bit V2 (vista JavaScript de MakeCode)
pins.setAudioPinEnabled(false)    // el sonido sale solo por el parlante, no por P0
input.touchSetMode(TouchTarget.P0, TouchTargetMode.Capacitive)
input.touchSetMode(TouchTarget.P1, TouchTargetMode.Capacitive)
input.touchSetMode(TouchTarget.P2, TouchTargetMode.Capacitive)

// Hoja 1: yiguirro (agudo y melodioso)
input.onPinPressed(TouchPin.P0, function () {
    basic.showIcon(IconNames.Happy)
    music.play(music.stringPlayable("C5 B A G - B C5 - ", 300), music.PlaybackMode.UntilDone)
    basic.showIcon(IconNames.Asleep)
})
// Hoja 2: rana (corto y cortado)
input.onPinPressed(TouchPin.P1, function () {
    basic.showIcon(IconNames.Square)
    music.play(music.stringPlayable("C - C - D - - - ", 400), music.PlaybackMode.UntilDone)
    basic.showIcon(IconNames.Asleep)
})
// Hoja 3: mono congo (grave y lento)
input.onPinPressed(TouchPin.P2, function () {
    basic.showIcon(IconNames.Surprised)
    music.play(music.stringPlayable("C D E D C - - - ", 120), music.PlaybackMode.UntilDone)
    basic.showIcon(IconNames.Asleep)
})
// Hoja 4 (logo): tucan (rapido y repetido)
input.onLogoEvent(TouchButtonEvent.Pressed, function () {
    basic.showIcon(IconNames.Butterfly)
    music.play(music.stringPlayable("A F A F A - - - ", 600), music.PlaybackMode.UntilDone)
    basic.showIcon(IconNames.Asleep)
})
basic.showIcon(IconNames.Asleep)
```

### Versión de Secundaria

La planta musical de Secundaria necesita Bluetooth MIDI y un pin táctil sensible: se hace con la IdeaBoard o con un ESP32. Vea [`01. IdeaBoard.md`](./01.%20IdeaBoard.md).

### Prueba de funcionamiento

1. Al encender aparece una cara dormida.
2. Al tocar cada hoja aparece un ícono y suena una melodía distinta.

### Limitaciones y soluciones

- Si su versión de MakeCode no tiene el bloque `setAudioPinEnabled`, use solo P1, P2 y el logo, y deje P0 libre.
- La micro:bit V1 no tiene parlante ni logo táctil: conecte un buzzer a P0 y use solo P1 y P2 como hojas.
