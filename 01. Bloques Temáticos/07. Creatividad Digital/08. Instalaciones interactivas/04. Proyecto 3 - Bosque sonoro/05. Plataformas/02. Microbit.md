## Propósito

Explicar cómo hacer "El guardián del bosque", la versión de Primaria del Bosque sonoro, con micro:bit V2: la plataforma principal de Primaria porque se programa con bloques y trae sensor de luz, pines táctiles y parlante.

## Contenido

### Qué usa de la micro:bit

| Parte de la micro:bit | Función en el guardián |
|---|---|
| Pantalla de LEDs | Muestra la cara del guardián y, además, mide la luz (`nivel de luz`, de 0 a 255). |
| Pines P0, P1 y P2 | Detectan el toque de las tres plantas en modo capacitivo. |
| Parlante integrado | Reproduce los sonidos de los animales. |
| Conector JST | Recibe el portapilas de 2 pilas AAA. |

Se necesita una **micro:bit V2**, que tiene parlante integrado y pines táctiles capacitivos.

<img width="380" alt="placa micro:bit V2" src="https://upload.wikimedia.org/wikipedia/commons/thumb/7/71/BBC_micro_bit_v2.jpg/960px-BBC_micro_bit_v2.jpg" />

### Conexiones

| Planta | Pin de la micro:bit | Sonido |
|---|---|---|
| Pájaro | P0 | "destello" |
| Mono | P1 | "risa" |
| Abeja | P2 | Sonido de onda de sierra con vibrato |
| Portapilas de 2 pilas AAA | Conector JST | — |

Cada planta se conecta con un cable lagarto con punta de jumper: la pinza muerde el pin y la punta metálica del jumper se pega con cinta a la pestaña de aluminio. Con el modo capacitivo no hace falta conectar GND.

> **Importante antes de encender:**
> - Toda conexión se hace con la placa desconectada de la computadora y de las pilas.
> - Cada pinza toca solo su pin y ningún otro, porque puede provocar un cortocircuito.
> - El papel aluminio de una planta no debe tocar el de otra planta ni la roca de la placa.

### Programa en MakeCode

El programa completo está en [`guardian_del_bosque.js`](../07.%20C%C3%B3digo/guardian_del_bosque.js). Se pega en la vista **JavaScript** de [makecode.microbit.org](https://makecode.microbit.org) y luego se cambia a **Bloques**. El paso a paso para armarlo con bloques está en [`02. Versión primaria.md`](../02.%20Versi%C3%B3n%20primaria.md).

```javascript
// Guardian del bosque: Bosque sonoro, version Primaria (micro:bit V2, MakeCode)
// Pegar en la vista JavaScript de makecode.microbit.org y luego cambiar a Bloques.
//
// DIA (luz encendida): el guardian duerme. Las plantas de papel aluminio
//   conectadas a P0, P1 y P2 suenan al tocarlas: pajaro, mono y abeja.
// NOCHE (luz apagada o pantalla tapada): el guardian abre los ojos y suena la
//   secuencia del bosque nocturno: buho, grillos, ranas y jaguar. Mientras es
//   de noche, las plantas no suenan.
//
// IMPORTANTE: encender la micro:bit con la luz del aula encendida y sin tapar
// la pantalla, porque al arrancar guarda la luz normal del aula.

// Las plantas se detectan por toque (modo capacitivo de la micro:bit V2).
// P0 tambien saca sonido por defecto: se desactiva para usarlo como planta.
pins.setAudioPinEnabled(false)
pins.touchSetMode(TouchTarget.P0, TouchTargetMode.Capacitive)
pins.touchSetMode(TouchTarget.P1, TouchTargetMode.Capacitive)
pins.touchSetMode(TouchTarget.P2, TouchTargetMode.Capacitive)
let noche = false
// La primera lectura de luz puede salir en 0 mientras el sensor arranca:
// se lee una vez, se espera y se vuelve a leer para guardar la luz del aula.
let luzBase = input.lightLevel()
basic.pause(500)
luzBase = input.lightLevel()
basic.showIcon(IconNames.Asleep)

function buho () {
    music.play(music.tonePlayable(392, music.beat(BeatFraction.Half)), music.PlaybackMode.UntilDone)
    music.play(music.tonePlayable(330, music.beat(BeatFraction.Whole)), music.PlaybackMode.UntilDone)
}

function grillos () {
    for (let index = 0; index < 6; index++) {
        music.play(music.tonePlayable(3000, music.beat(BeatFraction.Sixteenth)), music.PlaybackMode.UntilDone)
        basic.pause(60)
    }
}

function ranas () {
    for (let index = 0; index < 3; index++) {
        music.play(music.tonePlayable(150, music.beat(BeatFraction.Eighth)), music.PlaybackMode.UntilDone)
        basic.pause(120)
    }
}

function jaguar () {
    music.play(music.createSoundExpression(WaveShape.Noise, 400, 80, 255, 0, 1200, SoundExpressionEffect.Warble, InterpolationCurve.Logarithmic), music.PlaybackMode.UntilDone)
}

basic.forever(function () {
    // 0.4 = que tan oscuro debe estar para que sea de noche.
    // Si el guardian no despierta al tapar la pantalla, subir a 0.6.
    // Si despierta solo con la luz normal, bajar a 0.3.
    if (input.lightLevel() < luzBase * 0.4) {
        noche = true
        basic.showIcon(IconNames.Surprised)
        buho()
        grillos()
        ranas()
        jaguar()
        basic.pause(1000)
    } else if (noche) {
        noche = false
        basic.showIcon(IconNames.Asleep)
    }
    basic.pause(200)
})

// Planta 1 (P0): pajaro
input.onPinPressed(TouchPin.P0, function () {
    if (!(noche)) {
        basic.showIcon(IconNames.Happy)
        music.play(music.builtinPlayableSoundEffect(soundExpression.twinkle), music.PlaybackMode.UntilDone)
        basic.showIcon(IconNames.Asleep)
    }
})

// Planta 2 (P1): mono
input.onPinPressed(TouchPin.P1, function () {
    if (!(noche)) {
        basic.showIcon(IconNames.Silly)
        music.play(music.builtinPlayableSoundEffect(soundExpression.giggle), music.PlaybackMode.UntilDone)
        basic.showIcon(IconNames.Asleep)
    }
})

// Planta 3 (P2): abeja
input.onPinPressed(TouchPin.P2, function () {
    if (!(noche)) {
        basic.showIcon(IconNames.Butterfly)
        music.play(music.createSoundExpression(WaveShape.Sawtooth, 220, 240, 120, 120, 800, SoundExpressionEffect.Vibrato, InterpolationCurve.Linear), music.PlaybackMode.UntilDone)
        basic.showIcon(IconNames.Asleep)
    }
})
```

### Prueba en el simulador

1. En el simulador de MakeCode, el círculo con un número en la esquina superior izquierda es el control de luz. Arrástrelo hacia abajo: con poca luz aparece la carita sorprendida y suena la noche.
2. Súbalo de nuevo: el guardián vuelve a dormir.
3. Con luz, presione con el mouse los pines 0, 1 y 2 del simulador: cada uno muestra su ícono y suena su animal.

### Versión de Secundaria

La planta musical de Secundaria necesita Bluetooth MIDI y un pin táctil sensible: se hace con la IdeaBoard o con un ESP32. Vea [`01. IdeaBoard.md`](./01.%20IdeaBoard.md).

### Prueba de funcionamiento

1. Encienda la micro:bit con la luz del aula encendida y sin tapar la pantalla: aparece la carita dormida.
2. Toque cada planta: aparece su ícono y suena su animal.
3. Tape la pantalla o apague la luz: aparece la carita sorprendida y suena el bosque nocturno; mientras tanto, las plantas no suenan.

### Problemas frecuentes y soluciones

| Problema | Solución |
|---|---|
| Una planta suena sola | Separe su aluminio de otras plantas, de la roca y de superficies mojadas. |
| Una planta no suena | Vuelva a pegar la punta del jumper o muerda mejor la pestaña de aluminio. |
| El guardián no despierta al apagar la luz | Tape la pantalla con la mano o cambie el 0.4 por 0.6. |
| El guardián se despierta solo | Reinicie la micro:bit con la luz encendida y sin tapar la pantalla, o cambie el 0.4 por 0.3. |
| No se oye bien | Acerque el público o use el bosque en un aula callada. |
| Solo hay micro:bit V1 | Conecte un parlante o buzzer entre P0 y GND, y use P1 y P2 como interruptores: cada planta suena al tocarla junto con una tira de aluminio conectada a GND. |
