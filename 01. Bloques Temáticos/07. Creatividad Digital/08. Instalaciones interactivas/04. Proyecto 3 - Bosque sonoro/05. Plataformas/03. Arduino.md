## Contenido

El Proyecto 3 no tiene una versión para Arduino Uno:

- **Primaria, "El guardián del bosque":** se realiza con **micro:bit V2**, que trae sensor de luz, pines táctiles y parlante, y se programa con bloques. Vea [`02. Microbit.md`](./02.%20Microbit.md). Si el makerspace solo tiene IdeaBoard, existe una adaptación en [`01. IdeaBoard.md`](./01.%20IdeaBoard.md).
- **Secundaria, planta musical:** necesita pines táctiles y Bluetooth, por lo que se realiza con la IdeaBoard o con un ESP32. Vea [`01. IdeaBoard.md`](./01.%20IdeaBoard.md) y [`04. ESP32.md`](./04.%20ESP32.md).

El Arduino Uno no tiene pines táctiles, sensor de luz integrado ni Bluetooth, por lo que no se recomienda para este proyecto.
