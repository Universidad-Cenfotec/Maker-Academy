## Descripción

Este bloque explica **qué es la soldadura y para qué sirve** en electrónica. Soldar es **unir** dos piezas metálicas con **estaño** (una aleación que se derrite y se solidifica) para hacer una conexión eléctrica y mecánica firme. Es la técnica que convierte un prototipo (hecho con protoboard y cables jumper) en un circuito **permanente y confiable**.



> **Importante:** en este bloque se aprende la técnica de soldadura **THT** (through-hole technology,, la más común para componentes con patitas), la **seguridad** necesaria y cómo **desoldar** (quitar el estaño) para corregir errores.

## ¿Por qué es importante la soldadura?

- Convierte los **prototipos** (protoboard y cables) en circuitos **permanentes**.
- Es la técnica que se usa en los **PCBs** (placas de circuito impreso) reales.
- Permite que los componentes queden **fijos** y con **buen contacto eléctrico** que no se afloja con el tiempo.

## Notas docentes

- La soldadura es el paso de **prototipo a producto**: primero se prueba con protoboard, luego se suelda para hacerlo permanente.|
- La **seguridad** es lo primero: el cautín alcanza temperaturas altas y el estaño libera humos; hay que protegerse y ventilar.|
- La técnica **THT** es la más adecuada para empezar: los componentes tienen patitas que se insertan en la placa y se sueldan por el otro lado.|
- **Desoldar** es tan importante como soldar: permite corregir errores sin dañar la placa ni los componentes.|
- Este bloque prepara el terreno para el **bloque 05 (Introducción a PCB)**, donde la soldadura se aplica sobre placas reales.|
