## Descripción

Este documento explica **qué es Fritzing y para qué sirve** dentro del diseño de PCB. Fritzing es un programa de **diseño electrónico** pensado principalmente para el aprendizaje, la documentación y el prototipado. Permite representar un circuito de forma visual y avanzar desde un montaje en protoboard hasta el diseño de una placa PCB.

Fritzing es un proyecto de **código abierto** cuyo código fuente está disponible bajo la licencia **GNU GPL v3**. La versión compilada del programa se distribuye desde el sitio oficial y su descarga puede tener un costo que contribuye al mantenimiento y desarrollo del proyecto.

Es la primera herramienta de diseño que se presenta en este módulo, antes de pasar a KiCad.

> **Importante:** en este documento se aprenden los **conceptos** de Fritzing. La práctica paso a paso y los ejemplos reales se desarrollan en las **mini-lecciones y prácticas guiadas**, donde se usa el programa directamente.

## Contenido

### 1. ¿Qué es Fritzing?

**Fritzing** es un programa de diseño electrónico de **código abierto**, pensado para el aprendizaje, la documentación y el prototipado de circuitos.

Una de sus principales características es la **vista de prototipo**, que representa los componentes de una manera similar a como se colocan físicamente en un protoboard. Esto facilita que una persona que ya conoce los montajes básicos pueda representar sus circuitos de forma digital.

Fritzing permite trabajar con diferentes representaciones del mismo circuito:

* **Vista de prototipo (Protoboard):** representa el circuito de una forma similar a un protoboard real. Es la vista más intuitiva para comenzar.
* **Vista de esquemático:** representa las conexiones mediante símbolos electrónicos y líneas. Permite analizar la relación eléctrica entre los componentes.
* **Vista de PCB:** permite organizar los componentes sobre una placa y trabajar con las pistas de cobre para preparar el diseño de la PCB.

**Analogía:** Fritzing es como un **taller de diseño** donde puedes observar tu circuito de diferentes maneras: como lo armas físicamente (prototipo), como se representa eléctricamente (esquemático) y como se organiza sobre una placa (PCB).

**Idea clave:** Fritzing permite representar un circuito mediante las vistas de **prototipo, esquemático y PCB**, facilitando la comprensión del paso de un montaje a una placa.

---

### 2. ¿Para qué sirve Fritzing?

Fritzing se utiliza para **representar, documentar y diseñar circuitos electrónicos** de forma visual.

Entre sus usos principales se encuentran:

* **Armar un circuito virtualmente**, utilizando una representación similar a un protoboard.
* **Documentar circuitos**, mostrando de forma clara cómo están conectados los componentes.
* **Pasar del prototipo al diseño de PCB**, organizando los componentes y las conexiones sobre una placa.
* **Preparar archivos para la fabricación de una PCB**, incluyendo archivos Gerber cuando el diseño está listo para exportarse.
* **Enseñar y aprender electrónica**, gracias a su enfoque visual.

**Idea clave:** Fritzing ayuda a conectar el **prototipo** que conocemos de la protoboard con el **diseño de una PCB**, haciendo más sencillo comprender este proceso.

---

### 3. Las tres vistas de Fritzing

Para entender Fritzing, es importante conocer sus tres vistas principales y cómo se relacionan:

**Vista de prototipo (Protoboard):**

* Representa el circuito como un montaje sobre un breadboard.
* Los componentes se colocan en los orificios y se conectan mediante cables.
* Es una de las vistas más fáciles de comprender para principiantes.

**Vista de esquemático:**

* Representa el circuito mediante símbolos electrónicos.
* La posición física de los componentes deja de ser lo más importante.
* Permite concentrarse en las conexiones eléctricas del circuito.

**Vista de PCB:**

* Representa la placa donde se colocarán los componentes.
* Permite organizar los componentes y trabajar con las pistas de cobre.
* Es la vista relacionada con la preparación del diseño para fabricar la placa.

**Idea clave:** las tres vistas permiten observar el circuito desde diferentes perspectivas y ayudan a comprender la relación entre el montaje, el esquema eléctrico y la placa.

---

### 4. De prototipo a PCB: el paso clave

Una de las características más útiles de Fritzing es que permite utilizar un circuito realizado en la vista de prototipo como punto de partida para diseñar una PCB.

Cuando el circuito está correctamente conectado:

1. Se revisa el circuito en la **vista de prototipo**.
2. Se cambia a la **vista de PCB**.
3. Los componentes se organizan sobre la placa.
4. Se ajustan las posiciones y orientaciones de los componentes.
5. Se trazan y revisan las **pistas de cobre**.
6. Se comprueba que las conexiones sean correctas.
7. Cuando el diseño está listo, se pueden **exportar los archivos necesarios para la fabricación**, como los archivos Gerber.

**Analogía:** es como **organizar una habitación**: primero tienes todos los objetos (prototipo), después decides dónde colocarlos (PCB) y finalmente estableces las rutas que permiten conectar cada elemento (pistas).

**Idea clave:** Fritzing facilita el paso desde un prototipo hacia un diseño de PCB, pero el diseñador debe revisar y ajustar el diseño antes de fabricarlo.

---

### 5. Ventajas y limitaciones de Fritzing

**Ventajas:**

* **Fácil de aprender:** la representación del protoboard resulta familiar para quienes ya han trabajado con circuitos físicos.
* **Visual:** permite observar los componentes y sus conexiones de una manera intuitiva.
* **Útil para documentar:** facilita la creación de representaciones visuales de circuitos.
* **Ideal para comenzar:** es apropiado para aprender conceptos básicos de circuitos, prototipado y PCB.

**Limitaciones:**

* **Menos potente** que herramientas profesionales como KiCad para diseños electrónicos complejos.
* La organización y trazado de las pistas requiere revisión y ajustes por parte del diseñador.
* Está más orientado al **aprendizaje, documentación y prototipado** que a flujos de diseño electrónico industrial de alta complejidad.

> **Nota:** Fritzing no es el único programa de diseño de PCB. Existen otras herramientas como KiCad, EAGLE, EasyEDA o Altium. En este módulo usamos Fritzing por su facilidad para aprender y representar circuitos visualmente, y posteriormente KiCad para conocer un flujo de diseño de PCB más completo.

**Idea clave:** Fritzing es una buena herramienta para **aprender, documentar y prototipar**, mientras que herramientas como KiCad ofrecen mayores capacidades para diseños electrónicos más complejos.
