Este documento explica **qué es KiCad y para qué sirve** dentro del diseño de PCB. ## Contenido

### 1. ¿Qué es KiCad?

**KiCad** es un programa de diseño electrónico **profesional y de código abierto**. A diferencia de Fritzing, que se enfoca en la vista visual de prototipo, KiCad está pensado para el **flujo completo de diseño**: se empieza por el esquemático, se pasa al layout de la placa y se terminan generando los archivos para fabricar.

KiCad es **gratuito** y funciona en Windows, macOS y Linux. Es usado tanto por aficionados como por profesionales, y es una de las herramientas de diseño de PCB más populares del mundo del software libre.

**Analogía:** si Fritzing es como **dibujar a mano alzada** (fácil y visual), KiCad es como **usar un software de arquitectura profesional**: más potente, con más control y pensado para proyectos serios.

**Idea clave:** KiCad es una herramienta **profesional, gratuita y de código abierto** para el diseño completo de PCB.

---

### 2. El flujo de diseño en KiCad

KiCad organiza el trabajo en un **flujo de etapas** que van de lo lógico a lo físico:

**1. Esquemático (Eeschema):**
- Se dibuja el circuito con **símbolos** y se conectan los componentes.
- Es el "plano eléctrico": aquí importan las **conexiones**, no la posición física.
- Cada componente se elige de una **biblioteca** de símbolos.

**2. Asignación de huellas (Footprints):**
- A cada símbolo del esquemático se le asigna una **huella** (footprint): la forma física real del componente sobre la placa.
- Es el puente entre el mundo lógico y el físico.

**3. Layout de la placa (Pcbnew):**
- Se colocan los componentes sobre la placa y se **traza** el recorrido de las pistas de cobre.
- Aquí importa el **espacio, el tamaño y la posición**.
- KiCad ayuda a verificar que las conexiones coincidan con el esquemático.

**4. Verificación y fabricación:**
- Se revisa que no haya errores (por ejemplo, pistas que se cruzan sin conexión).
- Se generan los **archivos Gerber** (documento [03. Gerber: Introducción.md](03.%20Gerber%20Introducci%C3%B3n.md)) para fabricar la placa.

**Idea clave:** KiCad sigue un **flujo ordenado**: esquemático → huellas → layout → fabricación. Cada etapa depende de la anterior.

---

### 3. Esquemático vs. Layout: la diferencia clave

Al igual que vimos en el README del módulo, el diseño de un PCB tiene **dos etapas** que en KiCad son dos herramientas separadas:

**El esquemático (Eeschema):**
- Es el **diagrama lógico** del circuito.
- Muestra los componentes y cómo se conectan, usando **símbolos**.
- No importa la posición física, solo las **conexiones**.

**El layout (Pcbnew):**
- Es la **disposición física** de la placa.
- Muestra dónde va cada componente y cómo se trazan las **pistas de cobre**.
- Importa el **espacio, el tamaño y la posición**.

**La conexión entre ambos:** el layout debe **respetar las conexiones** definidas en el esquemático. KiCad mantiene esa coherencia automáticamente: si en el esquemático dos componentes están conectados, en el layout esa conexión debe existir.

**Idea clave:** el **esquemático** dice *qué* se conecta; el **layout** dice *dónde* se coloca y *cómo* se une físicamente.

---

### 4. KiCad vs. Fritzing: ¿cuándo usar cada uno?

Ambas herramientas llegan al mismo destino (un PCB listo para fabricar), pero con enfoques distintos:

| | **Fritzing** | **KiCad** |
|---|---|---|
| **Enfoque** | Visual e intuitivo | Profesional y completo |
| **Curva de aprendizaje** | Baja | Mayor |
| **Vista principal** | Prototipo (breadboard) | Esquemático y layout |
| **Uso ideal** | Aprender y prototipar | Proyectos serios y complejos |
| **Costo** | Gratuito / de pago | Gratuito (open source) |

**Analogía:** Fritzing es como **aprender a andar en bicicleta con rueditas**; KiCad es como **conducir un auto profesional**. Ambos te llevan a tu destino, pero con distinta potencia y control.

**Idea clave:** se empieza con **Fritzing** para entender los conceptos, y se pasa a **KiCad** cuando se necesita más potencia y control.

---

### 5. Ventajas y limitaciones de KiCad

**Ventajas:**
- **Gratuito y de código abierto:** sin costo y con una comunidad activa.
- **Completo:** cubre todo el flujo, desde el esquemático hasta la fabricación.
- **Profesional:** usado en proyectos reales y con gran flexibilidad.
- **Multiplataforma:** funciona en Windows, macOS y Linux.

**Limitaciones:**
- **Curva de aprendizaje mayor:** es más complejo que Fritzing.
- **Menos visual:** no tiene una vista de prototipo tipo breadboard tan intuitiva.
- Requiere **más práctica** para dominarlo.

**Idea clave:** KiCad es **potente y completo**, pero requiere más tiempo de aprendizaje que Fritzing.
