## Misión creativa

Nuestro museo necesita inventos que comuniquen algo con una luz.

Cada equipo creará un objeto, decidirá qué significa cuando está encendido y lo probará con otras personas.

La misión no consiste en iluminar una escena. Consiste en inventar una señal que alguien pueda entender.

El estudiantado diseña y construye la cubierta del objeto. La persona docente prepara, revisa e incorpora el dispositivo luminoso.

### Pregunta del reto

¿Cómo podemos usar una luz para comunicar un mensaje sin hablar?

### Acuerdo de la actividad

Cada equipo inventa su propio código y lo explica antes de probarlo.

Los mensajes utilizados son acuerdos del juego. No representan necesariamente el significado de señales utilizadas fuera del aula.

## Inspiración

### Una visita inesperada

La persona docente presenta un muñeco y cuenta:

> «Este personaje quiere avisar algo sin hablar. Puede encender una luz, pero todavía no sabemos qué quiere decir. ¿Lo ayudamos a inventar una señal?».

1. Mostrar una luz apagada.
2. Encenderla sin explicar un significado.
3. Preguntar qué podría querer decir.
4. Escuchar diferentes interpretaciones.
5. Acordar un mensaje y repetir la demostración.

### Preguntas para conversar

- ¿Todas las personas pensamos que la luz quería decir lo mismo?
- ¿Qué necesitamos acordar para entenderla?
- ¿Qué podría comunicar nuestro invento?
- ¿Cómo comprobaremos que otra persona lo entiende?

### Tiempo estimado

5 a 8 minutos.

## Retos para elegir

Cada equipo elige una situación o propone otra con acompañamiento docente.

| Situación del juego | Invento posible | Luz encendida | Luz apagada |
|---|---|---|---|
| Un muñeco quiere pedir ayuda | Una casita con señal luminosa | «Necesito ayuda». | «No estoy pidiendo ayuda». |
| El rincón de lectura necesita un recordatorio | Un personaje luminoso | «Recordemos hablar bajito». | «El recordatorio no está activado». |
| Un espacio de juego está preparado | Una puerta de cartón con luz | «El espacio está listo». | «El espacio todavía no está listo». |

Se recomienda trabajar con una sola luz por invento y dos estados: encendido y apagado.

No es necesario que todos los equipos elijan mensajes diferentes.

## Preparación del prototipo docente

### Dispositivo utilizado

Para esta versión se utiliza una luz LED comercial a pilas, con interruptor integrado y compartimento de pilas asegurado.

No se arma un circuito desde cero ni se modifica el circuito interno. La preparación consiste en integrar el dispositivo a una estructura diseñada por el equipo.

### Paso 1: Revisar el dispositivo

1. Seleccionar una luz de intensidad suave.
2. Revisar que la carcasa esté completa.
3. Comprobar que el compartimento de pilas pueda quedar asegurado.
4. Colocar las pilas indicadas por el fabricante.
5. Encender y apagar varias veces.
6. Retirar cualquier dispositivo dañado o con funcionamiento irregular.

### Paso 2: Preparar una base de prueba

1. Cortar una base de cartón firme.
2. Colocar la luz sobre la base.
3. Identificar por dónde sale la luz.
4. Identificar dónde está el interruptor.
5. Marcar dos zonas que deben quedar libres: la salida de luz y el acceso al interruptor.

### Paso 3: Preparar la cubierta con el equipo

1. Revisar el dibujo del invento.
2. Presentar la cubierta alrededor del dispositivo, sin pegarla todavía.
3. Marcar una abertura para que la luz sea visible.
4. Marcar una abertura o espacio para accionar el interruptor.
5. Realizar los cortes que requieran una herramienta de uso adulto.
6. Comprobar que la cubierta no presione ni bloquee el dispositivo.

### Paso 4: Integrar el dispositivo

1. Fijar el dispositivo a la base sin abrirlo ni perforarlo.
2. Utilizar una sujeción que permita retirarlo para mantenimiento.
3. Colocar la cubierta.
4. Mantener visibles la salida de luz y el interruptor.
5. Verificar que el conjunto sea estable.
6. Encender y apagar el invento terminado.

### Paso 5: Ensayar el uso

1. Colocar el invento en la posición de exposición.
2. Verificar que la luz se distinga con la iluminación habitual del aula.
3. Comprobar que se pueda accionar sin levantar ni desmontar el objeto.
4. Revisar que no haya piezas sueltas o bordes cortantes.
5. Entregarlo al equipo únicamente después de la revisión.

---

## Seguridad y cuidado

- Utilizar dispositivos preparados y revisados por la persona docente.
- No utilizar pilas de botón en esta propuesta.
- Mantener las pilas y las herramientas de uso adulto fuera del alcance del estudiantado.
- No abrir ni modificar el dispositivo durante la actividad.
- No conectar el invento a un tomacorriente.
- Mantener los materiales alejados del agua.
- No dirigir la luz a los ojos.
- No cubrir el dispositivo con materiales que impidan su uso según las indicaciones del fabricante.
- Retirar el invento si se calienta, se daña o presenta funcionamiento irregular.
- Apagar los dispositivos al terminar.

## Exploración guiada

### Paso 1: Elegir un problema

1. Escuchar las situaciones propuestas.
2. Elegir a quién ayudará el invento.
3. Decidir qué necesita comunicar ese personaje o espacio.
4. Expresar la decisión mediante palabras, dibujos o tarjetas.

Pregunta de apoyo:

> ¿Qué queremos que otra persona entienda cuando vea la luz?

### Paso 2: Acordar el mensaje

Completar con acompañamiento:

| Estado | Nuestro acuerdo |
|---|---|
| Cuando la luz está encendida… | ______________________________ |
| Cuando la luz está apagada… | ______________________________ |

La persona docente escribe las ideas expresadas por el equipo.

### Paso 3: Dibujar el invento

1. Elegir una forma: personaje, casita, cartel u otra.
2. Dibujar el objeto.
3. Marcar dónde aparecerá la luz.
4. Señalar dónde se accionará el interruptor.
5. Explicar el dibujo a la persona docente.

No se solicita dibujar un circuito eléctrico.

### Paso 4: Construir la cubierta

1. Elegir los materiales.
2. Construir la forma del invento.
3. Decorarla con elementos relacionados con su mensaje.
4. Dejar libre el lugar de la luz.
5. Solicitar ayuda para los cortes que requieran intervención adulta.

### Paso 5: Incorporar la luz

1. Entregar la cubierta a la persona docente.
2. Observar cómo integra el dispositivo preparado.
3. Identificar el interruptor.
4. Probar el encendido y apagado.
5. Confirmar que el invento se mantiene estable.

### Paso 6: Predecir la respuesta

Antes de invitar a otro equipo, conversar:

- ¿Qué creemos que entenderán?
- ¿Qué les explicaremos primero?
- ¿Desde dónde podrán ver la luz?
- ¿Qué haremos si no comprenden el mensaje?

### Paso 7: Probar con otro equipo

1. Presentar el invento.
2. Explicar el significado de encendido y apagado.
3. Representar una situación con un muñeco.
4. Accionar la señal sin decir el mensaje.
5. Pedir al equipo visitante que interprete lo ocurrido.
6. Comparar su respuesta con el acuerdo inicial.

La interpretación se comprueba después de explicar el código, no mediante una adivinanza.

### Paso 8: Mejorar

Elegir un cambio a partir de lo observado:

- Cambiar la ubicación de la luz.
- Despejar la abertura para verla mejor.
- Agregar un dibujo que recuerde el mensaje.
- Hacer más clara la explicación.
- Simplificar el acuerdo.
- Facilitar el acceso al interruptor.

Probar nuevamente después del cambio.

### Paso 9: Abrir el museo

Cada equipo presenta:

1. El nombre de su invento.
2. A quién ayuda.
3. Qué significa la luz encendida.
4. Qué significa la luz apagada.
5. Qué mejoró después de probarlo.

---

## Punto de revisión antes de la prueba

- [ ] La persona docente revisó el dispositivo.
- [ ] El compartimento de pilas está asegurado.
- [ ] La base es estable.
- [ ] La salida de luz está libre.
- [ ] El interruptor es accesible.
- [ ] No hay bordes cortantes ni piezas sueltas.
- [ ] El equipo acordó los dos estados de la señal.
- [ ] La tarjeta del mensaje coincide con ese acuerdo.

---

## Prueba y observación

| Qué comprobar | Pregunta para el equipo | Posible mejora |
|---|---|---|
| Funcionamiento | ¿La luz enciende y apaga? | Solicitar revisión docente. |
| Visibilidad | ¿Las visitas distinguen si está encendida? | Cambiar la ubicación o despejar la abertura. |
| Acceso | ¿Podemos accionar el interruptor? | Ajustar la cubierta con ayuda docente. |
| Comprensión | Después de conocer el acuerdo, ¿las visitas interpretan el mensaje? | Simplificar la explicación o agregar un dibujo. |
| Estabilidad | ¿El invento permanece en su lugar al utilizarlo? | Reforzar la base con ayuda docente. |

Si el dispositivo no funciona, el estudiantado no lo abre ni intenta repararlo.

## Personalización y adaptaciones

### Apoyo inicial

Ofrecer una cubierta previamente recortada y dos mensajes entre los cuales elegir.

### Mayor autonomía

Permitir que el equipo proponga su propia situación y diseñe la cubierta.

### Comunicación diversa

Aceptar explicaciones orales, gestuales, dibujadas o apoyadas con tarjetas.

### Participación compartida

Distribuir tareas flexibles:

- Proponer el mensaje.
- Dibujar.
- Decorar.
- Accionar el dispositivo.
- Explicar a las visitas.

No es necesario que todas las personas realicen la misma tarea.

### Accesibilidad

- No depender únicamente del color para comunicar el acuerdo.
- Ofrecer una figura o símbolo de apoyo.
- Ajustar la ubicación del interruptor a las posibilidades de participación.
- Utilizar una luz suave y evitar destellos.
- Permitir que otra persona accione el dispositivo cuando sea necesario.

---

## Reflexión

- ¿Qué problema quisimos resolver?
- ¿Qué significa nuestra luz?
- ¿Por qué explicamos el acuerdo antes de probar?
- ¿Qué entendió el equipo visitante?
- ¿Qué cambiamos después de la prueba?
- ¿Cómo ayudó ese cambio?

No se espera una explicación técnica del circuito. Se valora la relación entre intención, señal, interpretación y mejora.

## Evidencias

| Evidencia | Qué muestra |
|---|---|
| Dibujo inicial | La idea del invento y la ubicación prevista de la luz. |
| Tarjeta del mensaje | El significado acordado para encendido y apagado. |
| Prototipo | La construcción de una cubierta integrada al dispositivo preparado. |
| Prueba entre equipos | La interpretación del mensaje después de conocer el acuerdo. |
| Explicación de la mejora | Un cambio realizado a partir de la prueba. |

Las evidencias pueden recogerse mediante observación docente, dibujos y explicaciones del equipo.

---

## Evaluación

### Criterios de éxito

- El equipo propone un mensaje para su invento.
- Relaciona encendido y apagado con el acuerdo elegido.
- Participa en el diseño o construcción.
- Prueba el invento con otras personas.
- Propone o realiza una mejora con acompañamiento.

### Registro docente sugerido

| Criterio | Con acompañamiento | Con autonomía creciente | Observaciones |
|---|---|---|---|
| Expresa el mensaje del invento | | | |
| Diferencia los dos estados acordados | | | |
| Participa en la construcción | | | |
| Escucha la interpretación de otro equipo | | | |
| Propone o explica una mejora | | | |

No se evalúan la construcción de circuitos, el uso de vocabulario técnico ni la calidad estética del objeto.
