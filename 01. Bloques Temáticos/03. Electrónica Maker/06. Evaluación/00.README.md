## Propósito

Esta carpeta contiene los instrumentos de evaluación del bloque de Electrónica Maker. Están diseñados para evaluar tanto el proceso como el resultado del trabajo con circuitos, reconociendo que en electrónica maker el camino importa tanto como el producto final: un circuito que funciona sin comprensión de fondo no es suficiente, y un circuito que no funciona pero con un proceso reflexivo puede ser un gran aprendizaje.

Los dos instrumentos se complementan: la lista de cotejo captura el proceso paso a paso (¿qué hizo el estudiante en cada etapa?), mientras que la rúbrica evalúa la calidad del circuito, el uso de las herramientas y el pensamiento técnico detrás de él (¿qué tan bien lo hizo y con qué comprensión?).

## Cuándo y cómo usar cada instrumento

**Lista de cotejo de circuitos**

Tiene ítems organizados en momentos del proceso (antes de armar, durante y después). Es ideal para usarla como herramienta formativa, no solo sumativa. Cuando los estudiantes la completan antes de conectar el circuito, actúa como lista de verificación que previene errores (polaridad, cortocircuitos, valores de componentes). Cuando la completan después, genera reflexión sobre el proceso.

Se recomienda introducirla desde la primera práctica (por ejemplo, el circuito LED con resistencia) con solo los ítems más relevantes, para que el estudiante se familiarice con el formato antes de usarla completa.

**Rúbrica de electrónica**

Evalúa criterios con niveles de desempeño: correcta construcción del circuito, uso adecuado de las herramientas de medición (multímetro), comprensión de los conceptos (ley de Ohm, componentes) y comunicación del diseño. Los pesos de cada criterio son ajustables según la práctica.

Es más apropiada para prácticas de mayor complejidad (circuito con pulsador, sensor, o protoboard completa), donde hay suficiente proceso de diseño para evaluar. Para el primer circuito LED, puede aplicarse de forma parcial.

---

## Modalidades de evaluación

Los instrumentos admiten tres modalidades:

**Autoevaluación:** el estudiante evalúa su propio proceso y resultado. Desarrolla metacognición y honestidad sobre las propias fortalezas y áreas de mejora. Funciona mejor cuando el docente ha normalizado que el error es información, no fracaso.

**Coevaluación (evaluación entre pares):** un equipo evalúa el trabajo de otro usando los mismos instrumentos. Genera conversaciones técnicas ricas y obliga a ambos equipos a articular criterios de calidad con precisión.

**Evaluación docente:** el docente aplica la rúbrica al trabajo del estudiante. Para que sea válida, el docente necesita ver el circuito armado, las mediciones realizadas y escuchar al estudiante explicar sus decisiones.

---

## Evidencia recomendada por práctica

Para aplicar la rúbrica con fundamento, se sugiere pedir al estudiante que entregue:

| Práctica | Evidencia digital | Evidencia física | Evidencia reflexiva |
|---|---|---|---|
| Circuito LED con resistencia | Foto del circuito + valor calculado de R | El circuito funcionando | Lista de cotejo completada |
| Circuito con pulsador | Foto del circuito + esquema | El circuito funcionando | Lista de cotejo + nota de funcionamiento |
| Sensor de temperatura | Foto + mediciones del multímetro | El circuito funcionando | Lista de cotejo + tabla de mediciones |

Con estos tres tipos de evidencia combinados, los criterios de la rúbrica pueden evaluarse sin necesidad de haber observado el proceso completo en tiempo real.
