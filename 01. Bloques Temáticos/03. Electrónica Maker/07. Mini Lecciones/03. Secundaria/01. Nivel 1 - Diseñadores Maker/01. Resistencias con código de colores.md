
# 01. Resistencias con código de colores

> **Nivel:** 4. Diseñadores Maker

> **Nivel institucional:** Diseñadores Maker

> **Duración estimada:** 25–30 min

> **Grados:** 7.º–9.º

---

## Descripción

El estudiantado aprende a **identificar el valor aproximado de una resistencia** usando sus bandas de colores. Cada color representa un número, y con ellos se puede saber cuánto "frena" la corriente cada resistencia. Es la primera herramienta de lectura de componentes y la base para elegir la resistencia correcta en un circuito.

## Contenido

### ¿Por qué colores y no números?

Las resistencias son muy pequeñas para imprimirles un número, así que usan **bandas de colores** que se leen como un código. Cada color tiene un valor, igual que un código secreto. Aprender a leerlo es aprender el "lenguaje" de las resistencias.

Pregunta detonadora: **"¿Cómo sabríamos qué resistencia usar si no tienen números escritos?"**

### El código de colores

Cada color representa un número:

| Color | Número |
|---|---|
| Negro | 0 |
| Marrón | 1 |
| Rojo | 2 |
| Naranja | 3 |
| Amarillo | 4 |
| Verde | 5 |
| Azul | 6 |
| Violeta | 7 |
| Gris | 8 |
| Blanco | 9 |

### Cómo leer una resistencia

Una resistencia típica tiene **4 bandas** de colores:

1. **1.ª banda:** el primer número.
2. **2.ª banda:** el segundo número.
3. **3.ª banda (multiplicador):** cuántos ceros se agregan.
4. **4.ª banda (tolerancia):** qué tan precisa es (dorado = ±5 %, plateado = ±10 %).

**Ejemplo:** una resistencia con bandas **rojo, rojo, marrón, dorado**:

- Rojo = 2, Rojo = 2, Marrón = agregar 1 cero → **220 Ω**, tolerancia ±5 %.

**Pregunta clave:** "¿Qué nos dice la tercera banda?" → Cuántos ceros agregar.

**Preguntas de exploración:**

- "¿Qué número es el rojo?" → 2.
- "¿Cómo se lee una resistencia?" → Por sus bandas de colores.
- "¿Para qué sirve saber leer resistencias?" → Para elegir la correcta y proteger los componentes.

## Notas docentes

- **Preguntas detonadoras:** "¿Cómo sabríamos qué resistencia usar si no tienen números escritos?", "¿Qué crees que significan los colores?".
- **Actividad de cierre:** cada estudiante recibe varias resistencias y debe anotar su valor leyendo las bandas; se verifica con el multímetro.
- **Gestión de error:** si el estudiantado confunde el orden, recordar que se lee de izquierda a derecha desde la banda más cercana al extremo.
- **Seguridad:** usar solo pilas AA o AAA y componentes de bajo voltaje; supervisar siempre.
