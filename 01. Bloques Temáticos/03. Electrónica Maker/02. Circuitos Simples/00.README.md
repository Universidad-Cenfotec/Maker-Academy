## Descripción

Este bloque es la **parte práctica** del módulo de Electrónica Maker. Después de aprender los fundamentos (voltaje, corriente, resistencia, ley de Ohm y los componentes), aquí se **construyen y se prueban circuitos reales** sobre el simulador **Tinkercad**.

Cada documento presenta un circuito sencillo, paso a paso: qué componentes se usan, cómo se conectan y qué se observa. Se trabaja con **LEDs, resistencias, pulsadores, fotoresistores y sensores de temperatura**, siempre con explicaciones claras y ejemplos visuales para que cualquier persona pueda seguirlos.

> **Nota de alcance:** en este bloque los circuitos se construyen y se **simulan en Tinkercad**. El uso del **protoboard físico y del multímetro** se trabaja en el siguiente bloque (Protoboard y Medición), para no mezclar dos herramientas nuevas a la vez.

## Ruta de aprendizaje

Los documentos se leen **en orden**, de menor a mayor dificultad:

1. **01. LED y resistencia** → el circuito más simple: enciende un LED.
2. **02. Pulsador y switch** → aprendemos a **controlar** el encendido y apagado.
3. **03. Fotoresistor** → el circuito **reacciona a la luz**.
4. **04. Sensor de temperatura** → el circuito **reacciona al calor**.
5. **05. Pull-up y pull-down** → un concepto clave para que los pulsadores se lean bien.

Cada documento usa lo aprendido en el anterior, así que conviene seguirlos en este orden.

## ¿Qué NO cubre este bloque?

Para evitar confusión, este bloque **no** incluye (se tratan en otros bloques):

- **Protoboard físico** y cómo conectarlo → bloque **03. Protoboard y Medición**.
- **Multímetro** y cómo medir voltaje, corriente y resistencia → bloque **03. Protoboard y Medición**.
- **Soldadura** y montaje definitivo → bloque de **Fabricación Digital**.
- **Programación** de microcontroladores (Arduino, etc.) → bloque **04. Electrónica Programable** (o el que corresponda).

## Notas docentes

- Este bloque es **eminentemente práctico**: se recomienda que cada estudiante abra Tinkercad y siga el circuito mientras se explica.
- Cada documento incluye **capturas de pantalla** de los circuitos en Tinkercad, para que se vea exactamente cómo conectarlos.
- Se sugiere **repetir cada circuito** al menos una vez sin mirar la guía, para fijar el aprendizaje.
- Los conceptos de pull-up y pull-down (documento 05) son los más avanzados; se recomienda dedicarles tiempo y ejemplos extra.
- Este bloque prepara el terreno para el **protoboard físico**: lo que se simula aquí, después se arma en la realidad en el bloque 03.
