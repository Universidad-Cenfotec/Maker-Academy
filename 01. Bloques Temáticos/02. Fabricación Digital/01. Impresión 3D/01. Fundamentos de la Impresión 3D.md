## Descripción

La impresión 3D es una tecnología de fabricación digital que permite transformar diseños creados en computadora en objetos físicos capa por capa.

Actualmente se utiliza en áreas como educación, ingeniería, medicina, arquitectura, robótica, diseño industrial y emprendimiento, permitiendo desarrollar prototipos, herramientas, piezas funcionales y productos personalizados.

En Makerspace Academy, la impresión 3D se utiliza como una herramienta para fomentar la creatividad, el pensamiento de diseño, la resolución de problemas y el desarrollo de proyectos con propósito.

# ¿Qué es la Impresión 3D?

La impresión 3D es un proceso de fabricación aditiva.

Esto significa que los objetos se construyen agregando material capa por capa hasta formar una pieza completa.

A diferencia de otros métodos donde el material se corta o elimina, en la impresión 3D el objeto se construye progresivamente desde la base.

---

# Fabricación Aditiva vs Fabricación Sustractiva

| Fabricación Aditiva | Fabricación Sustractiva |
|---------------------|-------------------------|
| Agrega material | Elimina material |
| Menor desperdicio | Mayor desperdicio |
| Ideal para prototipos | Ideal para producción industrial |
| Permite diseños complejos | Puede tener limitaciones geométricas |

### Ejemplo

Una impresora 3D construye un llavero agregando material.

Una máquina CNC fabrica una pieza eliminando material de un bloque.

# ¿Cómo funciona una impresora 3D?

El proceso básico consta de cinco etapas:

## 1. Diseño

Se crea un modelo tridimensional utilizando software de diseño como:

- Tinkercad
- Fusion
- FreeCAD

## 2. Exportación

El diseño se exporta normalmente como un archivo:

```text
.stl
```

## 3. Laminado

Un programa llamado **slicer** convierte el modelo en instrucciones para la impresora.

Ejemplos:

- Cura
- PrusaSlicer

## 4. Impresión

La impresora deposita material capa por capa siguiendo las instrucciones generadas.

## 5. Evaluación

Se revisa el resultado y se identifican posibles mejoras.
