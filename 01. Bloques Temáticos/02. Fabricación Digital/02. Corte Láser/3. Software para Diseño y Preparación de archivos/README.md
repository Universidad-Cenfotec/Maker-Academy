## Descripción

Esta carpeta reúne el video y el recurso visual sobre los tipos de archivo, el software de diseño y de control de máquina, y las técnicas de optimización de diseño para el corte láser.

> Todo el contenido audiovisual del módulo vive en la [lista de reproducción de Corte Láser en YouTube](https://www.youtube.com/playlist?list=PLPrvH3WPEA_0).

---

## Contenido

### 3-1 Software, Apps y Preparación (7:18)

Explica la diferencia entre imágenes de mapa de bits (rasterizadas, compuestas por píxeles) e imágenes vectoriales (compuestas por fórmulas matemáticas, editables y escalables sin perder calidad), y por qué el formato vectorial es el recomendado para fabricación digital. Presenta el software vectorial (Illustrator, Inkscape) y el software CAM —computer aided manufacturing— que traduce el diseño en instrucciones para la máquina (CNC Láser, LightBurn), incluyendo cómo cada uno genera trayectorias, parámetros de corte y archivos G-code. Cierra con tres técnicas de optimización de diseño para ahorrar tiempo y material: bordes compartidos, grabado por columnas y corte de piezas interiores antes que las exteriores.
