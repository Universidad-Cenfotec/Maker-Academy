## Descripción

El sensor de distancia es el sensor que le permite al robot percibir qué tan lejos está un objeto frente a él, sin necesidad de tocarlo. Es la base de la evasión de obstáculos y del comportamiento de búsqueda del adversario en el SumoBot.

**Si el sensor de distancia fuera un eco en una cueva: uno grita y mide cuánto tarda en regresar el sonido para saber qué tan grande es la cueva. El sensor ultrasónico hace exactamente eso, miles de veces por segundo, con sonido que el oído humano no puede escuchar.**

## Cómo funciona el sensor ultrasónico (HC-SR04)

El HC-SR04 tiene dos "ojos" redondos visibles en el módulo: uno emite y otro recibe.

1. El pin `TRIG` envía un pulso ultrasónico (una onda de sonido de frecuencia muy alta, inaudible para las personas).
2. La onda viaja hasta chocar con un objeto sólido y rebota.
3. El pin `ECHO` recibe el eco y mide cuánto tiempo pasó entre la emisión y la recepción.
4. Con ese tiempo y la velocidad del sonido, se calcula la distancia.

**Fórmula básica:** como el sonido viaja de ida y de vuelta, la distancia real es la mitad del recorrido total.

```
distancia (cm) = (tiempo del eco en microsegundos) / 58
```

Este número (58) sale de la velocidad del sonido en el aire y de la conversión de unidades; no hay que memorizarlo, solo usarlo en el código.

## Código de lectura de distancia en Arduino

```cpp
const int pinTrig = 9;
const int pinEcho = 10;

void setup() {
  Serial.begin(9600);
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
}

long medirDistancia() {
  // Enviar el pulso ultrasónico
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);

  // Medir cuánto tarda en regresar el eco
  long duracion = pulseIn(pinEcho, HIGH);

  // Convertir el tiempo en distancia (cm)
  long distanciaCm = duracion / 58;
  return distanciaCm;
}

void loop() {
  long distancia = medirDistancia();
  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.println(" cm");
  delay(200);
}
```

## Sensor IR de proximidad (mención breve)

Existe también el sensor IR de proximidad, que funciona parecido al sensor de línea pero apuntando al frente: emite luz infrarroja y detecta si algo la refleja de vuelta a corta distancia. A diferencia del ultrasónico, **no entrega una distancia en centímetros**, solo una señal digital de "hay algo cerca" o "no hay nada".

| Característica | Ultrasónico (HC-SR04) | IR de proximidad |
|---|---|---|
| Tipo de dato | Distancia en cm | Digital (0 o 1) |
| Rango típico | 2 cm a 400 cm | Pocos centímetros |
| Precisión | Alta | Baja, solo detecta presencia |
| Sensible a color/material | Poco | Sí, superficies oscuras reflejan menos |
| Uso típico | Evasión de obstáculos, SumoBot avanzado | Detección simple de cercanía |

## Umbral para detectar obstáculos

Un umbral es la distancia a partir de la cual el programa decide que "hay un obstáculo" y debe reaccionar. Un umbral típico para un robot pequeño en un salón es entre 15 y 25 cm, pero conviene ajustarlo según la velocidad del robot y el espacio disponible.

```cpp
const int umbralObstaculo = 20; // centímetros

void loop() {
  long distancia = medirDistancia();

  if (distancia < umbralObstaculo && distancia > 0) {
    // Hay un obstáculo cerca: detener y girar
    detener();
    pivoteDerecha(150);
    delay(400);
  } else {
    avanzar();
  }
}
```

**Nota técnica:** cuando no hay ningún objeto dentro del rango del sensor, `pulseIn()` puede devolver 0. Por eso el código anterior revisa que `distancia > 0` antes de considerarla un obstáculo real.

## Aplicaciones principales

### Evasión de obstáculos

El robot avanza en línea recta y, cuando el sensor detecta que un objeto está más cerca que el umbral, se detiene, gira una cantidad fija (o aleatoria) y continúa en la nueva dirección. Es la actividad clásica para introducir la idea de un sensor que cambia el comportamiento del programa en tiempo real.

### SumoBot: detección del adversario

En SumoBot, el sensor de distancia apunta hacia el frente para detectar al robot rival. Cuando detecta algo dentro de un rango cercano, el programa interpreta que encontró al adversario y cambia de "modo búsqueda" (girando en el lugar) a "modo ataque" (avanzar a máxima velocidad hacia el objeto detectado).

```cpp
const int umbralAdversario = 30; // cm

void loop() {
  long distancia = medirDistancia();

  if (distancia < umbralAdversario && distancia > 0) {
    avanzar(); // modo ataque: avanzar hacia el adversario
  } else {
    pivoteDerecha(150); // modo búsqueda: girar buscando al rival
  }
}
```

## Nota docente

Una confusión frecuente en el grupo es pensar que el sensor ultrasónico "ve" objetos como una cámara. Conviene aclarar que solo detecta lo que está directamente frente a él, en un cono relativamente angosto: un obstáculo a un lado, aunque esté cerca, puede no ser detectado. Esa limitación es justamente lo que hace interesante combinar el sensor de distancia con otros sensores o con movimientos de barrido.
