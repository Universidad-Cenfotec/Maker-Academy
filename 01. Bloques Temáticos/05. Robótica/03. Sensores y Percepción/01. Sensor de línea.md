## Descripción

El sensor de línea es el componente que le permite al robot "ver" el piso frente a él y distinguir entre una superficie clara y una franja oscura. Es, junto con el sensor de distancia, uno de los dos sensores más usados en robótica educativa, porque habilita dos de las actividades más populares del bloque: el seguimiento de línea y el SumoBot.

**Si el sensor de línea fuera un ojo entrecerrado mirando fijamente el piso: no ve formas ni colores complejos, solo distingue entre "aquí hay mucha luz reflejada" y "aquí casi no regresa luz". Con esa única distinción, el robot construye toda su capacidad de seguir un camino.**

## Cómo funciona el sensor de línea

El sensor de línea más común en robótica educativa es un módulo infrarrojo (IR) reflectivo. Tiene dos componentes montados uno junto al otro:

- **Un LED emisor**, que emite luz infrarroja hacia abajo, directo al piso.
- **Un fototransistor receptor**, que mide cuánta de esa luz regresa reflejada.

La clave está en el contraste de color de la superficie:

| Superficie | Reflexión de luz IR | Lectura del sensor |
|---|---|---|
| Piso blanco o claro | Alta (refleja mucho) | Valor bajo de "oscuridad" (no hay línea) |
| Franja negra | Baja (absorbe casi toda la luz) | Valor alto de "oscuridad" (hay línea) |

**Importante:** el sensor no "ve" la línea como una forma. Solo mide una cantidad de luz reflejada. Es el programa el que interpreta ese número y decide si es línea o no.

---

## Tipos de salida

| Tipo de módulo | Qué entrega | Pin de Arduino |
|---|---|---|
| Digital (con comparador integrado) | 0 o 1 (línea o no línea) | Entrada digital |
| Analógico | Valor de 0 a 1023 | Entrada analógica |

Los módulos digitales son más simples de programar, pero los analógicos permiten un control más fino porque el programa puede establecer su propio umbral según las condiciones de luz del salón.

## Calibración del umbral

Con un sensor analógico, calibrar significa encontrar el número que separa "veo piso claro" de "veo línea negra". Este número **no es fijo**: cambia según la luz ambiental del salón, el color exacto del piso, la altura del sensor sobre la superficie y hasta el desgaste del propio módulo.

**Procedimiento sencillo de calibración:**

1. Colocar el sensor sobre el piso claro y leer el valor con `Serial.print()`.
2. Colocar el sensor sobre la línea negra y leer el valor.
3. Elegir un umbral intermedio entre ambos números.
4. Probar el robot y ajustar el umbral si se equivoca con frecuencia.

```cpp
const int pinSensorIzq = A0;
const int pinSensorDer = A1;
const int umbral = 500; // ajustar según la calibración realizada

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lecturaIzq = analogRead(pinSensorIzq);
  int lecturaDer = analogRead(pinSensorDer);

  Serial.print("Izquierdo: ");
  Serial.print(lecturaIzq);
  Serial.print(" | Derecho: ");
  Serial.println(lecturaDer);

  delay(200);
}
```

## Seguimiento de línea con dos sensores

La forma más sencilla de seguir una línea usa dos sensores, uno a cada lado del frente del robot, apuntando al piso. La lógica básica es de corrección: si un sensor detecta la línea y el otro no, el robot gira hacia el lado que la detectó.

```cpp
const int pinSensorIzq = A0;
const int pinSensorDer = A1;
const int umbral = 500;

void avanzar() {
  // Ambos motores hacia adelante
  analogWrite(ENA, 150); analogWrite(ENB, 150);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void corregirIzquierda() {
  // Motor derecho más rápido, gira hacia la izquierda
  analogWrite(ENA, 80);  analogWrite(ENB, 180);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void corregirDerecha() {
  // Motor izquierdo más rápido, gira hacia la derecha
  analogWrite(ENA, 180); analogWrite(ENB, 80);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void loop() {
  int izq = analogRead(pinSensorIzq);
  int der = analogRead(pinSensorDer);

  bool veoLineaIzq = izq > umbral;
  bool veoLineaDer = der > umbral;

  if (!veoLineaIzq && !veoLineaDer) {
    avanzar(); // ningún sensor ve línea: seguir recto
  } else if (veoLineaIzq && !veoLineaDer) {
    corregirIzquierda(); // la línea se desvió a la izquierda
  } else if (!veoLineaIzq && veoLineaDer) {
    corregirDerecha(); // la línea se desvió a la derecha
  }
  // Si ambos ven línea a la vez, puede ser una intersección o el final de la pista
}
```

**Idea pedagógica clave:** el robot no "sabe" dónde está la línea en un sentido amplio. Solo reacciona, sensor por sensor, a lo que ve en ese instante. El comportamiento de "seguir la línea" emerge de muchas correcciones pequeñas y rápidas, no de un plan.

## Usos principales en Maker Academy

### Pistas de seguimiento de línea

El uso más directo: una pista con una franja negra sobre piso blanco (o al revés) que el robot debe recorrer de inicio a fin sin salirse. Es la actividad clásica para introducir el concepto de retroalimentación (el robot corrige su rumbo constantemente con base en lo que percibe).

### SumoBot: detección del borde del dohyo

En SumoBot, el sensor de línea no sigue una línea, sino que detecta el **borde del dohyo** (el círculo de competencia, generalmente negro con un borde blanco). Cuando el sensor detecta el color del borde, el robot debe interpretar que está a punto de salirse y reaccionar retrocediendo o girando, en lugar de seguir avanzando hacia el adversario.

**Diferencia clave de lógica:** en seguimiento de línea, el robot busca mantenerse sobre la línea. En SumoBot, el robot busca **alejarse** en cuanto detecta el borde. Es la misma pieza de hardware, con una interpretación de programación opuesta.

---

## Aplicación en Maker Academy

El sensor de línea se introduce después de que el grupo ya domina el movimiento básico y los giros, porque el seguimiento de línea exige que el estudiante combine ambos conceptos con una decisión basada en un sensor. Es también el sensor de entrada al SumoBot, donde adquiere un significado distinto (evitar el borde en lugar de seguirlo).

## Nota docente

Un error muy común entre estudiantes es calibrar el umbral en un solo punto del salón (por ejemplo, cerca de una ventana) y luego probar el robot en otra zona con luz distinta, donde el umbral ya no funciona. Vale la pena mostrar esto de forma explícita: mover la pista de un lugar a otro y observar que el robot empieza a fallar, para que el grupo entienda que la calibración depende del entorno y no es un ajuste que se hace "una sola vez para siempre".
