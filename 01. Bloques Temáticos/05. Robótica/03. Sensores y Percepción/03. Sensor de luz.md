## Descripción

El sensor de luz permite que el robot perciba cuánta luz hay en el ambiente, o compare la cantidad de luz que llega desde distintas direcciones. Es un sensor más sencillo que el de línea o el de distancia, pero abre posibilidades muy vistosas: robots que buscan una linterna, que se "asustan" en la oscuridad o que giran hacia la ventana más iluminada.

**Si el sensor de luz fuera una planta girando hacia el sol: la planta no "ve" el sol, solo reacciona a la cantidad de luz que recibe de un lado y del otro, y crece hacia donde hay más. El robot con sensores de luz hace lo mismo, comparando dos lecturas y girando hacia la que tiene más luz.**

## Qué es el LDR (fotoresistor)

LDR significa "Light Dependent Resistor" (resistencia dependiente de la luz). Es un componente cuya resistencia eléctrica cambia según cuánta luz recibe:

| Condición de luz | Resistencia del LDR | Efecto en el circuito |
|---|---|---|
| Mucha luz (día, foco cercano) | Baja | Deja pasar más corriente |
| Poca luz (oscuridad, sombra) | Alta | Deja pasar menos corriente |

Esta variación de resistencia no se puede leer directamente como un número; Arduino solo puede leer voltaje. Por eso el LDR se conecta en un **circuito divisor de voltaje**, junto con una resistencia fija (típicamente de 10 kΩ), de forma que el voltaje en el punto medio cambia según la cantidad de luz.

## Lectura analógica en Arduino

```cpp
const int pinLDR = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(pinLDR); // valor entre 0 y 1023

  Serial.print("Nivel de luz: ");
  Serial.println(lectura);

  delay(200);
}
```

**Importante:** a diferencia del sensor de línea, el LDR no tiene un "lado correcto" fijo de la escala. Dependiendo de cómo se arme el circuito divisor de voltaje, un valor alto puede significar mucha luz o poca luz. Siempre hay que probar con la mano tapando el sensor para confirmar qué representa cada extremo antes de programar cualquier lógica con él.

## Aplicaciones principales

### Detectar oscuridad

La aplicación más simple: comparar la lectura contra un umbral y encender un LED o activar un comportamiento cuando el ambiente está oscuro.

```cpp
const int pinLDR = A0;
const int umbralOscuridad = 300; // ajustar según el circuito y el ambiente

void loop() {
  int luz = analogRead(pinLDR);

  if (luz < umbralOscuridad) {
    encenderLuzRobot(); // está oscuro: activar iluminación propia
  } else {
    apagarLuzRobot();
  }

  delay(200);
}
```

### Seguir una fuente de luz con dos sensores

Con dos LDR, uno a cada lado del frente del robot, se puede programar un comportamiento de "seguir la luz": el robot compara ambas lecturas y gira hacia el lado donde hay más intensidad.

```cpp
const int pinLDRIzq = A0;
const int pinLDRDer = A1;
const int diferenciaMinima = 40; // evita reacciones por ruido de lectura

void loop() {
  int luzIzq = analogRead(pinLDRIzq);
  int luzDer = analogRead(pinLDRDer);

  int diferencia = luzIzq - luzDer;

  if (abs(diferencia) < diferenciaMinima) {
    avanzar(); // luz pareja en ambos lados: seguir recto
  } else if (diferencia > 0) {
    // Recordar: en este circuito, más luz = valor MÁS ALTO
    corregirIzquierda(); // hay más luz del lado izquierdo
  } else {
    corregirDerecha(); // hay más luz del lado derecho
  }

  delay(150);
}
```

**Nota sobre polaridad:** según el circuito divisor de voltaje usado, "más luz" puede corresponder a un valor más alto o más bajo. Antes de programar la comparación, conviene probar cada sensor por separado, tapándolo y destapándolo, para confirmar en qué dirección se mueve el número.

## Comparación con otros sensores del bloque

| Sensor | Qué mide | Tipo de dato | Precisión de dirección |
|---|---|---|---|
| Sensor de línea | Reflexión de luz IR en el piso | Digital o analógico | Puntual (justo debajo del sensor) |
| Sensor de distancia | Tiempo de rebote de ultrasonido | Distancia en cm | Direccional (cono frontal) |
| Sensor de luz (LDR) | Intensidad de luz ambiental | Analógico | Relativa (comparación entre dos puntos) |

El sensor de luz es el único de los tres cuyo valor depende fuertemente de las condiciones externas del salón (si hay luz natural, si las luces están encendidas, la hora del día), por lo que su calibración es la más variable de recalibrar entre sesiones.

## Aplicación en Maker Academy

El sensor de luz se usa como una introducción más ligera y vistosa al concepto de comparación entre dos sensores del mismo tipo, antes de combinarlo con sensores de naturaleza distinta (como en Múltiples Sensores). Es también un buen puente hacia conversaciones sobre energía solar y sensores ambientales en proyectos de ciencias.

## Nota docente

Una demostración simple y efectiva: pedir a un estudiante que camine lentamente con una linterna encendida alrededor del robot mientras este sigue la luz. La reacción del grupo suele ser muy positiva porque el comportamiento parece "inteligente", aunque en realidad es solo una comparación de dos números. Es un buen momento para reforzar que un comportamiento que parece complejo puede surgir de una lógica de programación muy simple.
