## Descripción

El día de una competencia SumoBot no es el momento para descubrir que la batería está descargada o que el robot pesa más de lo permitido. Este archivo ofrece una lista de verificación previa a la competencia, para que cada equipo confirme que su robot está listo antes de entrar al dohyo.

**Si el SumoBot fuera un avión antes de despegar: el piloto no confía en la memoria, sigue una lista de verificación en el mismo orden cada vez. Un SumoBot antes de competir merece el mismo cuidado.**

## Propósito

Que el docente cuente con una lista de verificación clara para revisar junto con cada equipo antes de que su robot entre a competir, reduciendo fallas evitables por falta de preparación previa.

## Checklist previo a la competencia

### Energía y componentes

- [ ] La batería está cargada y probada (no solo conectada, sino verificada con una prueba de movimiento reciente).
- [ ] Hay una batería de repuesto cargada disponible, si el kit lo permite.
- [ ] Todos los cables están firmes en sus conectores, sin falsos contactos.

### Sensores

- [ ] El sensor de línea fue calibrado directamente sobre el dohyo real de competencia.
- [ ] El sensor de distancia fue probado con el umbral correcto para detectar al rival esperado.
- [ ] Ambos sensores están limpios (sin polvo ni residuos que afecten la lectura).

### Estructura física

- [ ] Todos los tornillos del chasis están ajustados.
- [ ] Las ruedas giran libremente, sin rozar el chasis.
- [ ] La rueda loca está bien fijada y toca el piso de forma pareja.
- [ ] No hay bordes filosos que puedan dañar al robot rival.

### Programa y comportamiento

- [ ] El código final está cargado en el microcontrolador (no una versión de prueba anterior).
- [ ] Se realizó al menos una prueba combinada completa (ver tabla de pruebas) el mismo día.
- [ ] El robot recupera correctamente su comportamiento después de detectar el borde.

### Reglamento

- [ ] El robot cumple con el peso máximo permitido.
- [ ] El robot cumple con el tamaño máximo permitido en la línea de salida.
- [ ] El equipo conoce las reglas de victoria y descalificación de la competencia.

### Seguridad

- [ ] El equipo conoce el protocolo para apagar el robot si se atasca contra un objeto o persona.
- [ ] Ninguna persona del equipo tiene previsto tocar el robot dentro del dohyo durante la ronda.

---

## Cómo usar este checklist

Se recomienda que un integrante del equipo (o el docente) revise cada casilla en voz alta con el grupo justo antes de la ronda, y no varios minutos antes cuando aún puede haber cambios de último momento. Si alguna casilla no se puede marcar, es preferible resolverla antes de competir que arriesgarse a una falla durante la ronda.

---

## Aplicación en Maker Academy

Este checklist se aplica el mismo día del evento de competencia, como último paso antes de que cada equipo entre al dohyo. Complementa, pero no reemplaza, la calibración y las pruebas realizadas en sesiones previas.

## Nota docente

Este checklist funciona mejor cuando se imprime y se coloca físicamente junto al área de espera, no solo como un archivo digital. Ver las casillas marcadas una por una, en voz alta y en equipo, reduce la ansiedad de último momento y refuerza una cultura de preparación disciplinada antes que de improvisación.
