## Descripción

Antes de hablar de calidad o de nivel de logro, hay una pregunta más básica: ¿el estudiante hizo lo que tenía que hacer? Esta lista de cotejo revisa el proceso general de trabajo con robots educativos, desde el manejo seguro de herramientas hasta la documentación final, sin entrar todavía en niveles de desempeño.

**Si la lista de cotejo fuera una lista de empaque para un viaje: no evalúa qué tan bien doblaste la ropa, solo confirma que no olvidaste nada esencial antes de salir.**

## Propósito

Que el docente cuente con un instrumento rápido y objetivo para verificar que un estudiante o equipo cumplió con los pasos esenciales del proceso de trabajo con robótica, antes o en paralelo a una evaluación más profunda con rúbrica.

---

## Cómo usar este instrumento

Se marca cada criterio como **Logrado**, **En proceso** o **No logrado** durante la observación directa del trabajo del estudiante, idealmente mientras arma y programa el robot, no solo al final. No busca calificar la calidad del resultado, sino confirmar que cada paso del proceso ocurrió. Un criterio en "No logrado" es una señal de que el docente debe intervenir antes de avanzar a la siguiente etapa.

## Lista de cotejo

### Seguridad

| Criterio | Logrado | En proceso | No logrado |
|---|---|---|---|
| Manipula la batería siguiendo las indicaciones (sin forzar conectores, sin exponerla a golpes). | | | |
| Usa las herramientas del kit (destornillador, pinzas) de forma correcta y cuidadosa. | | | |
| Mantiene el área de trabajo ordenada, sin piezas sueltas que puedan perderse o dañarse. | | | |
| Desconecta o apaga el robot antes de hacer ajustes en el chasis o el cableado. | | | |

### Armado del chasis

| Criterio | Logrado | En proceso | No logrado |
|---|---|---|---|
| Identifica correctamente las piezas del kit antes de iniciar el armado. | | | |
| Ensambla el chasis siguiendo la guía o el diagrama de referencia. | | | |
| Fija los motores y las ruedas de forma firme y alineada. | | | |
| Verifica que el robot esté estable y que las ruedas toquen el piso de forma pareja. | | | |

### Comprensión conceptual

| Criterio | Logrado | En proceso | No logrado |
|---|---|---|---|
| Explica con sus palabras qué es un robot y qué lo distingue de un aparato simple. | | | |
| Identifica en su propio robot las partes de entrada, proceso y salida (modelo EPO). | | | |
| Reconoce la función del microcontrolador como el "cerebro" que procesa la información. | | | |

### Programación básica de movimiento

| Criterio | Logrado | En proceso | No logrado |
|---|---|---|---|
| Programa el robot para avanzar y retroceder de forma intencional. | | | |
| Programa al menos un giro (izquierda o derecha) de forma controlada. | | | |
| Prueba el programa varias veces y ajusta valores cuando el resultado no es el esperado. | | | |

### Trabajo en equipo

| Criterio | Logrado | En proceso | No logrado |
|---|---|---|---|
| Participa activamente en las tareas del equipo, no solo observa. | | | |
| Escucha y considera las ideas de sus compañeros y compañeras antes de decidir. | | | |
| Asume o rota roles dentro del equipo (armado, programación, pruebas, registro). | | | |

### Documentación del proceso

| Criterio | Logrado | En proceso | No logrado |
|---|---|---|---|
| Registra en una bitácora los pasos seguidos durante el armado y la programación. | | | |
| Anota al menos un error encontrado y cómo se resolvió. | | | |
| Presenta o explica su proceso al finalizar la sesión (show your work). | | | |

## Aplicación en Maker Academy

Esta lista de cotejo se usa durante las sesiones de armado y programación básica del bloque de Robótica, tanto en trabajo individual como en equipo. Sirve como primer filtro antes de aplicar la rúbrica de robótica básica, especialmente en grupos que están comenzando con el bloque.

## Nota docente

Esta lista de cotejo funciona mejor como acompañamiento formativo, no solo como registro final. Ir marcando las casillas junto con el estudiante, explicando por qué un criterio queda en "En proceso", convierte el instrumento en una conversación de aprendizaje y no en un simple trámite de evaluación. Guardar las listas de varias sesiones también permite ver el progreso real de cada estudiante a lo largo del bloque.
