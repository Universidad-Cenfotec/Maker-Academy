## Descripción

Así como la calibración de motores necesita una hoja de registro, el comportamiento completo del SumoBot también necesita documentarse antes de una competencia. Este archivo ofrece una plantilla para registrar pruebas del robot completo: si detecta el borde, si detecta al rival y si ataca correctamente.

**Si el SumoBot fuera un piloto de carreras antes de una competencia: no basta con probar el carro una vez, hay que hacer vueltas de práctica y anotar qué funcionó y qué no, para no repetir el mismo error el día de la carrera.**

## Propósito

Que el docente cuente con una plantilla clara para que los equipos registren de forma sistemática las pruebas de comportamiento completo del SumoBot antes de una competencia, diferenciando entre la calibración de sensores individuales y el comportamiento integrado del robot.

---

## Qué comportamientos se deben probar

Antes de dar por listo un SumoBot para competencia, conviene verificar por separado:

1. **Detección del borde:** el robot reacciona correctamente al acercarse al borde blanco del dohyo, sin cruzarlo.
2. **Detección del rival:** el robot identifica un objeto u otro robot dentro del rango esperado y cambia de "modo búsqueda" a "modo ataque".
3. **Ataque correcto:** al detectar al rival, el robot avanza en la dirección correcta con suficiente velocidad para empujarlo.
4. **Recuperación tras el borde:** después de retroceder y girar por detección de borde, el robot retoma la búsqueda o el ataque sin quedar atascado en un ciclo repetido.

## Cómo usar esta tabla con el grupo

- Cada equipo debe completar al menos una fila por cada comportamiento probado, no solo una prueba general.
- Es importante registrar el **ajuste realizado**, no solo si la prueba falló, para que el proceso quede documentado y se pueda repetir si algo deja de funcionar.
- Se recomienda repetir la "prueba combinada" (fila 5) al menos dos veces antes de la competencia, en distintos momentos del día, para verificar que la calibración se mantenga estable.

## Nota docente

Registrar pruebas por escrito, aunque parezca un paso administrativo, es una de las prácticas más valiosas que un estudiante de robótica puede adquirir. Enseña a distinguir entre "el robot funcionó una vez" y "el robot funciona de forma confiable", que es justamente lo que se necesita para competir con tranquilidad.
