## Descripción

Esta carpeta ayuda a elegir un medio de trabajo según la pregunta pedagógica y las condiciones reales del centro. La programación puede comenzar con tarjetas, continuar en un entorno por bloques y pasar al texto sin obligar a todo el grupo a completar el mismo catálogo de cursos.

## Propósito

Ofrecer criterios para decidir si una herramienta permite crear, probar y explicar una solución; prever idioma, edad, dispositivos, conexión, accesibilidad y resguardo de trabajos antes de llevarla al aula.

## Contenido

### Recurso disponible

[Code.org en Maker Academy](code-org-en-maker-academy.md) reúne una selección por propósito: actividades iniciales de CS Fundamentals, Sprite Lab para creaciones por bloques y Python Lab cuando conviene a mayores de 13 años y el idioma no impide participar. También distingue Game Lab y App Lab como opciones JavaScript. La selección no reemplaza la [progresión K–11](../01.%20Mapa%20de%20Progresi%C3%B3n.md).

### Antes de elegir

| Pregunta | Decisión docente posible |
| --- | --- |
| ¿Qué quiere crear o resolver el grupo? | Formular un producto y una prueba antes de abrir la plataforma. |
| ¿Quién puede usarla con autonomía? | Ajustar lectura, idioma, apoyos, tiempo y forma de participación. |
| ¿Qué necesita guardar? | Confirmar si una cuenta, un archivo local o una foto autorizada cumple el propósito. |
| ¿Cómo se comprobará la idea? | Preparar una entrada habitual y otra que pueda revelar un error. |
| ¿Qué pasa si falla la red? | Tener tarjetas, bosquejo o programa local para continuar la misma pregunta. |

Un recurso externo puede modificar interfaz, disponibilidad o requisitos. Revise la herramienta antes de cada aplicación y siga las políticas del centro sobre cuentas de menores, datos y publicación de proyectos. Las producciones del estudiantado se comparten solo por canales autorizados.

## Aplicación en Maker Academy

### Inspiración

Escuche qué necesitan comunicar o construir los equipos. Una herramienta se presenta como posibilidad concreta para ese reto, con un ejemplo breve y una alternativa accesible.

### Experimentación

Reserve tiempo para que cada equipo pruebe una primera versión y reciba una lectura externa. Si la interfaz impide llegar a la lógica, reduzca las funciones usadas o pase al prototipo en papel.

### Reflexión y evaluación formativa

Pida que expliquen qué decisión pudieron representar, qué prueba realizaron y qué cambiarían. Terminar niveles de una plataforma es información de avance en ella; la evidencia de Maker Academy es lo que el estudiante logra transferir a su creación.

## Nota docente

Pruebe de antemano el enlace, el idioma visible y el modo de recuperar el trabajo. En clase, detenga la actividad cuando el grupo necesite discutir una condición: resolver veinte pantallas seguidas no sustituye explicar por qué una versión propia respondió de cierta manera.
