## Propósito del módulo

Un robot que solo sirve para una tarea es un robot que hay que rehacer cada vez que cambia el reto. Este módulo introduce la idea de construir el robot por partes que se puedan cambiar, mover o reemplazar sin rehacerlo todo: adaptar el CenfoBot a retos distintos, diseñarlo de forma modular para que sus piezas se acoplen y se intercambien, y cuidar el peso, el balance y el centro de gravedad para que esas piezas no le quiten estabilidad.

Al finalizar, los estudiantes entenderán el CenfoBot no como un objeto terminado, sino como una plataforma que se puede reconfigurar, y sabrán justificar por qué una pieza va en un lugar y no en otro. Los recursos están organizados en archivos numerados para mantener el flujo de aprendizaje propuesto.

## Conceptos clave del módulo

**Adaptación a retos.** Un mismo robot puede enfrentar retos distintos si se le cambian las piezas correctas. Adaptar es decidir qué parte del robot resuelve el problema nuevo y qué parte se puede dejar como está, en lugar de empezar de cero.

**Diseño modular.** Un módulo es una pieza que cumple una función completa y se conecta con las demás por una interfaz clara: tornillos, conectores, pines. Si cada módulo se puede probar y reemplazar por separado, el robot se vuelve más fácil de arreglar, de mejorar y de reutilizar.

**Peso, balance y centro de gravedad.** El centro de gravedad es el punto donde se puede considerar concentrado todo el peso del robot. Si queda alto o muy adelante, el robot pierde tracción o vuelca al girar; si queda bajo y centrado entre las ruedas, se mantiene estable.
