## Descripción

Este glosario reúne términos de control, navegación, diseño modular e inteligencia artificial presentes en el bloque. Las definiciones apoyan la lectura y la conversación técnica; no se espera memorizar todos los términos antes de utilizarlos en contexto.

## Términos de control y medición

**Calibración**  
Proceso de comparar una lectura con una referencia conocida y ajustar la interpretación del sensor o sistema. No elimina todos los errores ni garantiza que sirva bajo otras condiciones.

**Referencia**  
Valor o estado deseado con el que se compara una medición para decidir una corrección.

**Medición**  
Dato producido por un sensor o instrumento. Requiere contexto, unidad y condiciones de captura para poder interpretarse.

**Error de control**  
Diferencia entre la referencia y la medición. La convención de signo depende de cómo se definió el sistema.

**Lazo de realimentación**  
Ciclo en que el sistema mide el resultado de una acción, lo compara con una referencia y modifica la acción siguiente.

**Control proporcional (P)**  
Control que calcula una corrección proporcional al error actual. Una ganancia mayor puede acelerar la respuesta, pero también provocar oscilaciones o saturación.

**PID**  
Controlador que combina términos proporcional, integral y derivativo. Su uso requiere interpretar las unidades, el período de muestreo y las limitaciones de los sensores.

**Ganancia**  
Factor que determina cuánto cambia la salida ante una señal de entrada o error. Debe ajustarse mediante pruebas seguras y documentadas.

**Deriva**  
Acumulación gradual de error en una estimación, por ejemplo, en el ángulo o posición calculados a partir de mediciones sucesivas.

**Odometría**  
Estimación del movimiento y la posición a partir del desplazamiento de las ruedas u otras mediciones internas. Su error suele acumularse y requiere referencias externas.

**Encoder**  
Sensor que produce señales relacionadas con el giro de un eje. Puede ayudar a estimar desplazamiento de rueda; no se debe asumir que forma parte del kit CenfoBot si no está instalado y documentado.

## Sensores, navegación y estrategia

**Sensor infrarrojo (IR)**  
Sensor que emite o detecta radiación infrarroja. En el CenfoBot, los IR de piso detectan contraste o borde; no equivalen a sensores de distancia laterales.

**Sensor ultrasónico**  
Sensor que estima distancia usando el tiempo de retorno de una onda sonora. El campo de detección y las lecturas dependen del objeto y el montaje.

**Navegación reactiva**  
Selección de una acción a partir de lecturas actuales, sin mantener necesariamente un mapa global.

**Localización**  
Estimación de dónde está el robot respecto a un marco o mapa. La odometría puede contribuir, pero por sí sola puede derivar.

**Mapa**  
Representación estructurada de lugares o regiones y de sus relaciones; no implica que el robot conozca automáticamente su posición dentro de él.

**Estado**  
Descripción resumida de la condición relevante del robot o una estrategia, como «buscando» o «protegiendo borde».

**Máquina de estados**  
Modelo que define estados posibles y condiciones para cambiar entre ellos. Ayuda a hacer explícita y probar la lógica de una estrategia.

**Telemetría**  
Datos de estado o medición transmitidos para monitorear o coordinar un sistema. No es por sí misma una decisión ni un comando de movimiento.

## Diseño y evaluación

**Robot diferencial**  
Robot móvil cuyo giro se obtiene controlando de manera distinta las ruedas o motores de sus lados.

**Módulo**  
Parte funcional de un sistema con una responsabilidad definida, comunicada a otras partes mediante interfaces.

**Interfaz**  
Conjunto de conexiones, señales o reglas de intercambio que permite que dos módulos trabajen juntos.

**Centro de gravedad**  
Punto en el que puede considerarse concentrado el peso de un cuerpo para analizar su equilibrio. Su ubicación influye en la estabilidad y la tracción.

**Prueba controlada**  
Prueba que modifica una variable relevante mientras intenta mantener las demás condiciones comparables.

**Evidencia**  
Registro observable que respalda una explicación o decisión: lecturas, bitácoras, diagramas, código, video o resultados de una prueba.

## Inteligencia artificial y visión

**Inteligencia artificial (IA)**  
Métodos computacionales que realizan tareas como clasificación, predicción o generación a partir de datos. No implica comprensión humana ni garantiza resultados correctos.

**Modelo**  
Sistema computacional ajustado o configurado para transformar entradas en predicciones o salidas.

**Inferencia**  
Uso de un modelo ya preparado para producir una salida a partir de una entrada nueva.

**Aprendizaje automático (ML)**  
Métodos que ajustan modelos con datos para realizar predicciones o clasificaciones. Un sistema de visión también puede usar reglas y procesamiento clásico sin ML.

**Visión por computadora**  
Procesamiento de imágenes o video para extraer información, como posición, forma o categoría de objetos.

**API (interfaz de programación de aplicaciones)**  
Interfaz definida para que un programa solicite datos o servicios a otro sistema, por ejemplo, un modelo de IA alojado externamente. Usarla requiere conexión, gestión segura de credenciales y validación de respuestas.

**Latencia**  
Tiempo entre enviar una solicitud y recibir su respuesta. Puede impedir que un servicio externo sirva para control de movimiento en tiempo real.

**Sesgo de datos**  
Limitación sistemática de los ejemplos o mediciones que puede llevar a resultados menos fiables para casos que no están representados.

## Notas docentes

Introduzca los términos cuando el grupo los necesite para describir una observación o decisión. Diferencie sensor y modelo, detección y estrategia, inferencia y entrenamiento, telemetría y control.
