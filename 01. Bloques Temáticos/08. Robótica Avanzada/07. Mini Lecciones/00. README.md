## Estado

- **Estado:** Plantilla inicial
- **Versión:** v0.1
- **Uso:** Índice y organización de futuras mini-lecciones

## Descripción

Esta carpeta reunirá mini-lecciones conceptuales breves que preparen, amplíen o conecten los módulos de Robótica Avanzada. Por ahora contiene únicamente la estructura de carpetas, los índices por nivel y una plantilla de redacción; no contiene actividades desarrolladas.

## Organización

| Carpeta | Nivel | Enfoque |
|---|---|---|
| [`03. Secundaria/`](03.%20Secundaria/00.%20README.md) | Secundaria | Navegación de la colección. |
| [`01. Nivel 1 - Diseñadores Maker/`](03.%20Secundaria/01.%20Nivel%201%20-%20Dise%C3%B1adores%20Maker/00.%20README.md) | Nivel 4, 7.º–9.º | Comprender, medir y explicar sistemas robóticos con apoyos. |
| [`02. Nivel 2 - Innovation Lab/`](03.%20Secundaria/02.%20Nivel%202%20-%20Innovation%20Lab/00.%20README.md) | Nivel 5, 10.º–11.º | Integrar conceptos, evaluar alternativas y documentar decisiones. |

El grupo puede requerir apoyos distintos independientemente del grado. No se crean mini-lecciones para niveles 1–3 porque Robótica Avanzada no se prioriza para esos niveles en la progresión actual.

## Formato base

Cada futura mini-lección se redactará usando [Plantilla de Mini Lección](01.%20Plantilla%20de%20Mini%20Lecci%C3%B3n.md). La plantilla define encabezados; no representa una lección disponible.
