## Descripción

Esta lección aplica el ciclo de realimentación y el error proporcional de [Control Proporcional](../01.%20Control%20De%20Precisión/02.%20Control%20Proporcional.md) a una tarea concreta: mantener un robot sobre una línea. Aquí el error ya no se obtiene del giroscopio; se estima a partir de los sensores que observan la superficie.

## Propósito

Comprender cómo los términos proporcional, integral y derivativo convierten el error de seguimiento en una corrección para los motores, y reconocer qué puede y qué no puede resolver un seguidor sencillo de dos sensores.

## Contenido

### El error cambia con la tarea

En la lección de Control Proporcional se comparaba una referencia con la medición del giro. En un seguidor de línea se conserva la misma estructura:

```text
error = referencia - medición
salida = Kp × error
```

Lo que cambia es la medición: los sensores infrarrojos indican si cada lado del frente está sobre el fondo negro o sobre la línea blanca. Con esa información se estima hacia qué lado debe corregirse el movimiento.

### Una demostración posible con los sensores 1 y 2

El código del Sumobot identifica los sensores 1 y 2 como los infrarrojos delanteros izquierdo y derecho (IO36 e IO39). Aunque se usan principalmente para detectar el borde del dojo, pueden demostrar un seguimiento **discreto y limitado** en una superficie negra con una línea blanca de alto contraste. Para este montaje, coloca ambos sensores a los lados de una línea blanca estrecha: cuando la línea queda entre ellos, ambos observan el fondo; cuando se desplaza bajo uno, ese sensor ve blanco y señala hacia qué lado está la línea.

Esta geometría importa. Con solo dos sensores, el estado «ambos ven negro» puede significar que la línea está centrada entre ellos o que se perdió por completo. El programa de ejemplo asume que la línea sigue entre los sensores cuando ambos ven negro; no puede confirmar la pérdida de línea. Si se requiere reconocerla con fiabilidad en más posiciones, hace falta un arreglo de tres o más sensores.

Los valores analógicos y su polaridad dependen del sensor y de la superficie. Por eso los programas calibran cada sensor sobre negro y blanco al inicio, en vez de asumir que el blanco siempre produce una lectura mayor. La calibración se hace con los motores detenidos.

El archivo [`code_line_follow.py`](https://github.com/Universidad-Cenfotec/Sumobot/blob/main/c%C3%b3digos_de_ejemplo/code_line_follow.py) del repositorio sirve para ubicar los sensores y la idea del ejemplo. Sus comentarios no son consistentes con la conversión de lecturas a blanco/negro y una de las salidas de motor está comentada; los programas de esta lección hacen la clasificación explícita, actualizan ambos motores y se detienen al terminar la prueba.

### De la lectura a un error discreto

En esta demostración, el error toma tres valores:

| Sensor izquierdo sobre blanco | Sensor derecho sobre blanco | Error | Acción esperada* |
|---|---|---:|---|
| Sí | No | -1 | Corregir hacia la izquierda |
| No | Sí | +1 | Corregir hacia la derecha |
| No | No | 0 | Avanzar recto; se asume que la línea pasa entre los sensores |
| Sí | Sí | 0 | Avanzar más despacio; la línea puede ser ancha para esta separación |

\*La asignación de los signos a los motores depende del montaje. En los programas se supone que el motor 1 impulsa el lado izquierdo y el motor 2 el derecho. Si una corrección aleja el robot de la línea, invierte `SENTIDO_CORRECCION`.

Este error `-1, 0, +1` es menos preciso que la posición continua que puede calcular una barra de sensores. Aun así permite observar cómo una medición se convierte en una salida y cómo la ganancia afecta la respuesta.

### Qué agrega cada término

Para un controlador discreto, la salida se puede expresar así:

```text
u = Kp × error + Ki × integral(error × dt) + Kd × cambio(error) / dt
```

- **P (proporcional):** responde al error de esta lectura. Una `Kp` mayor produce una corrección más fuerte.
- **I (integral):** acumula errores a lo largo del tiempo. Puede compensar un sesgo persistente, pero se limita para evitar que la acumulación domine la salida.
- **D (derivativo):** responde a qué tan rápido cambia el error. Puede amortiguar cambios, pero en un sensor binario el error salta entre pocos valores y la derivada puede ser ruidosa; por eso se usa con cuidado.

`dt` es el tiempo real entre lecturas, en segundos. La salida se limita antes de repartirse entre los motores, que a su vez reciben valores entre `-1` y `1`. Las ganancias iniciales de los programas son solo un punto de partida y deben ajustarse en incrementos pequeños.

### Límites del ejemplo

Este seguidor de dos sensores es una demostración para una línea blanca estrecha sobre fondo negro; no es un sistema universal ni una barra lineal. No distingue una línea centrada entre sensores de una línea perdida cuando ambos leen el fondo, y no reemplaza la protección de borde durante un combate. Para recorrer una pista con curvas cerradas, detectar pérdida de línea o estimar una posición más fina se necesita más información de sensores y una práctica de calibración específica.

## Ejemplos completos

Los dos programas siguientes usan los sensores delanteros 1 y 2, calibran negro y blanco al encender, siguen la línea durante ocho segundos y luego detienen los motores. Durante la calibración, coloca **ambos sensores primero sobre una superficie negra uniforme y después sobre una superficie blanca suficientemente ancha para cubrir los dos**. Prueba en una pista despejada y con velocidad baja.

### CircuitPython

```python
import time
import board
from ideaboard import IdeaBoard

ib = IdeaBoard()
sensor_izquierdo = ib.AnalogIn(board.IO36)  # Sensor 1, delantero izquierdo
sensor_derecho = ib.AnalogIn(board.IO39)    # Sensor 2, delantero derecho

# Parámetros iniciales: ajustar después de observar el robot en la pista.
VELOCIDAD_BASE = 0.20
Kp = 0.12
Ki = 0.02
Kd = 0.0003
MAX_CORRECCION = 0.20
MAX_INTEGRAL = 1.0
SENTIDO_CORRECCION = 1.0  # Cambiar a -1 si la corrección aleja de la línea
DURACION_PRUEBA = 8.0
PERIODO_MUESTREO = 0.01
DURACION_MUESTRA = 1.0
ESPERA_CAMBIO_SUPERFICIE = 3.0
CONTRASTE_MINIMO = 100.0


def limitar(valor, minimo, maximo):
    return max(minimo, min(maximo, valor))


def detener_motores():
    ib.motor_1.throttle = 0
    ib.motor_2.throttle = 0


def mover(izquierdo, derecho):
    ib.motor_1.throttle = limitar(izquierdo, -1.0, 1.0)
    ib.motor_2.throttle = limitar(derecho, -1.0, 1.0)


def promedio(sensor, segundos):
    suma = 0.0
    muestras = 0
    inicio = time.monotonic()
    while time.monotonic() - inicio < segundos:
        suma += sensor.value
        muestras += 1
        time.sleep(PERIODO_MUESTREO)
    if muestras == 0:
        raise RuntimeError("No se obtuvieron lecturas del sensor.")
    return suma / muestras


def calibrar():
    detener_motores()
    print("Coloca ambos sensores sobre negro. Muestreo en 3 segundos...")
    time.sleep(ESPERA_CAMBIO_SUPERFICIE)
    negro_izq = promedio(sensor_izquierdo, DURACION_MUESTRA)
    negro_der = promedio(sensor_derecho, DURACION_MUESTRA)

    print("Coloca ambos sensores sobre blanco. Muestreo en 3 segundos...")
    time.sleep(ESPERA_CAMBIO_SUPERFICIE)
    blanco_izq = promedio(sensor_izquierdo, DURACION_MUESTRA)
    blanco_der = promedio(sensor_derecho, DURACION_MUESTRA)

    if abs(blanco_izq - negro_izq) < CONTRASTE_MINIMO:
        raise RuntimeError("El sensor izquierdo no distingue suficiente entre negro y blanco.")
    if abs(blanco_der - negro_der) < CONTRASTE_MINIMO:
        raise RuntimeError("El sensor derecho no distingue suficiente entre negro y blanco.")

    umbral_izq = (blanco_izq + negro_izq) / 2
    umbral_der = (blanco_der + negro_der) / 2
    blanco_mayor_izq = blanco_izq > negro_izq
    blanco_mayor_der = blanco_der > negro_der
    print("Umbrales izquierdo/derecho:", umbral_izq, umbral_der)
    print("Calibración lista. Mantén los sensores a los lados de la línea.")
    return umbral_izq, umbral_der, blanco_mayor_izq, blanco_mayor_der


def es_blanco(lectura, umbral, blanco_mayor):
    if blanco_mayor:
        return lectura >= umbral
    return lectura <= umbral


detener_motores()
try:
    umbral_izq, umbral_der, blanco_mayor_izq, blanco_mayor_der = calibrar()
    inicio = time.monotonic()
    tiempo_anterior = inicio
    siguiente_mensaje = inicio
    error_anterior = 0.0
    integral = 0.0

    while time.monotonic() - inicio < DURACION_PRUEBA:
        ahora = time.monotonic()
        dt = ahora - tiempo_anterior
        if dt <= 0:
            continue
        tiempo_anterior = ahora

        lectura_izq = sensor_izquierdo.value
        lectura_der = sensor_derecho.value
        blanco_izq = es_blanco(lectura_izq, umbral_izq, blanco_mayor_izq)
        blanco_der = es_blanco(lectura_der, umbral_der, blanco_mayor_der)

        if blanco_izq and not blanco_der:
            error = -1.0
        elif blanco_der and not blanco_izq:
            error = 1.0
        else:
            error = 0.0

        integral = limitar(integral + error * dt, -MAX_INTEGRAL, MAX_INTEGRAL)
        derivada = (error - error_anterior) / dt
        correccion = limitar(Kp * error + Ki * integral + Kd * derivada,
                             -MAX_CORRECCION, MAX_CORRECCION)

        velocidad_base = VELOCIDAD_BASE * 0.6 if blanco_izq and blanco_der else VELOCIDAD_BASE
        mover(velocidad_base + SENTIDO_CORRECCION * correccion,
              velocidad_base - SENTIDO_CORRECCION * correccion)
        error_anterior = error

        if ahora >= siguiente_mensaje:
            print("IR:", blanco_izq, blanco_der,
                  "error:", error, "corrección:", round(correccion, 3))
            siguiente_mensaje = ahora + 0.5

        time.sleep(PERIODO_MUESTREO)
finally:
    detener_motores()
    print("Motores detenidos.")
```

### C++ / Arduino

Este ejemplo usa las entradas analógicas delanteras IO36 e IO39 y los pines de motor que aparecen en la prueba Arduino del Sumobot. No necesita una biblioteca PID externa: el ciclo P/I/D está implementado en el programa. Selecciona la placa ESP32 correspondiente a la IdeaBoard en Arduino IDE.

```cpp
#include <Arduino.h>
#include <math.h>

const uint8_t SENSOR_IZQUIERDO = 36;  // Sensor 1, delantero izquierdo
const uint8_t SENSOR_DERECHO = 39;    // Sensor 2, delantero derecho
const uint8_t M1_IN1 = 12;
const uint8_t M1_IN2 = 14;
const uint8_t M2_IN1 = 13;
const uint8_t M2_IN2 = 15;

const float VELOCIDAD_BASE = 0.20f;
const float KP = 0.12f;
const float KI = 0.02f;
const float KD = 0.0003f;
const float MAX_CORRECCION = 0.20f;
const float MAX_INTEGRAL = 1.0f;
const float SENTIDO_CORRECCION = 1.0f;  // Cambiar a -1 si corrige al lado contrario
const float CONTRASTE_MINIMO = 20.0f;  // Ajustar a la escala ADC de la placa
const unsigned long DURACION_MUESTRA_MS = 1000;
const unsigned long ESPERA_CAMBIO_SUPERFICIE_MS = 3000;
const unsigned long DURACION_PRUEBA_MS = 8000;
const unsigned long PERIODO_MUESTREO_MS = 10;

float umbralIzq = 0.0f;
float umbralDer = 0.0f;
bool blancoMayorIzq = true;
bool blancoMayorDer = true;
bool calibracionValida = false;
bool pruebaTerminada = false;
unsigned long inicioPrueba = 0;
unsigned long tiempoAnterior = 0;
unsigned long siguienteMensaje = 0;
float errorAnterior = 0.0f;
float integral = 0.0f;

float limitar(float valor, float minimo, float maximo) {
  return fmaxf(minimo, fminf(maximo, valor));
}

void detenerMotores() {
  digitalWrite(M1_IN1, LOW);
  digitalWrite(M1_IN2, LOW);
  digitalWrite(M2_IN1, LOW);
  digitalWrite(M2_IN2, LOW);
}

void escribirMotor(uint8_t adelante, uint8_t atras, float velocidad) {
  velocidad = limitar(velocidad, -1.0f, 1.0f);
  int pwm = (int)lroundf(fabsf(velocidad) * 255.0f);
  if (velocidad > 0.0f) {
    analogWrite(adelante, pwm);
    digitalWrite(atras, LOW);
  } else if (velocidad < 0.0f) {
    digitalWrite(adelante, LOW);
    analogWrite(atras, pwm);
  } else {
    digitalWrite(adelante, LOW);
    digitalWrite(atras, LOW);
  }
}

void mover(float izquierdo, float derecho) {
  escribirMotor(M1_IN1, M1_IN2, izquierdo);
  escribirMotor(M2_IN1, M2_IN2, derecho);
}

float promedioAnalogico(uint8_t pin) {
  double suma = 0.0;
  unsigned long muestras = 0;
  unsigned long inicio = millis();
  while (millis() - inicio < DURACION_MUESTRA_MS) {
    suma += analogRead(pin);
    muestras++;
    delay(PERIODO_MUESTREO_MS);
  }
  return muestras > 0 ? (float)(suma / muestras) : -1.0f;
}

bool calibrarSensores() {
  detenerMotores();
  Serial.println("Coloca ambos sensores sobre negro; muestreo en 3 segundos...");
  delay(ESPERA_CAMBIO_SUPERFICIE_MS);
  float negroIzq = promedioAnalogico(SENSOR_IZQUIERDO);
  float negroDer = promedioAnalogico(SENSOR_DERECHO);

  Serial.println("Coloca ambos sensores sobre blanco; muestreo en 3 segundos...");
  delay(ESPERA_CAMBIO_SUPERFICIE_MS);
  float blancoIzq = promedioAnalogico(SENSOR_IZQUIERDO);
  float blancoDer = promedioAnalogico(SENSOR_DERECHO);

  if (negroIzq < 0 || negroDer < 0 || blancoIzq < 0 || blancoDer < 0) {
    return false;
  }
  if (fabsf(blancoIzq - negroIzq) < CONTRASTE_MINIMO ||
      fabsf(blancoDer - negroDer) < CONTRASTE_MINIMO) {
    return false;
  }

  umbralIzq = (blancoIzq + negroIzq) / 2.0f;
  umbralDer = (blancoDer + negroDer) / 2.0f;
  blancoMayorIzq = blancoIzq > negroIzq;
  blancoMayorDer = blancoDer > negroDer;
  Serial.print("Umbrales izquierdo/derecho: ");
  Serial.print(umbralIzq);
  Serial.print(" / ");
  Serial.println(umbralDer);
  return true;
}

bool esBlanco(int lectura, float umbral, bool blancoMayor) {
  return blancoMayor ? lectura >= umbral : lectura <= umbral;
}

void setup() {
  pinMode(M1_IN1, OUTPUT);
  pinMode(M1_IN2, OUTPUT);
  pinMode(M2_IN1, OUTPUT);
  pinMode(M2_IN2, OUTPUT);
  pinMode(SENSOR_IZQUIERDO, INPUT);
  pinMode(SENSOR_DERECHO, INPUT);
  analogReadResolution(12);
  Serial.begin(115200);
  detenerMotores();

  calibracionValida = calibrarSensores();
  if (!calibracionValida) {
    Serial.println("Calibración sin contraste suficiente; motores permanecen detenidos.");
    detenerMotores();
    return;
  }

  inicioPrueba = millis();
  tiempoAnterior = micros();
  siguienteMensaje = millis();
  Serial.println("Calibración lista. Mantén los sensores a los lados de la línea.");
}

void loop() {
  if (!calibracionValida || pruebaTerminada) {
    detenerMotores();
    delay(100);
    return;
  }
  if (millis() - inicioPrueba >= DURACION_PRUEBA_MS) {
    detenerMotores();
    pruebaTerminada = true;
    Serial.println("Prueba terminada; motores detenidos.");
    return;
  }

  unsigned long ahoraMicros = micros();
  float dt = (ahoraMicros - tiempoAnterior) / 1000000.0f;
  tiempoAnterior = ahoraMicros;
  if (dt <= 0.0f) {
    detenerMotores();
    return;
  }

  int lecturaIzq = analogRead(SENSOR_IZQUIERDO);
  int lecturaDer = analogRead(SENSOR_DERECHO);
  bool blancoIzq = esBlanco(lecturaIzq, umbralIzq, blancoMayorIzq);
  bool blancoDer = esBlanco(lecturaDer, umbralDer, blancoMayorDer);

  float error = 0.0f;
  if (blancoIzq && !blancoDer) {
    error = -1.0f;
  } else if (blancoDer && !blancoIzq) {
    error = 1.0f;
  }

  integral = limitar(integral + error * dt, -MAX_INTEGRAL, MAX_INTEGRAL);
  float derivada = (error - errorAnterior) / dt;
  float correccion = limitar(KP * error + KI * integral + KD * derivada,
                             -MAX_CORRECCION, MAX_CORRECCION);
  float velocidadBase = (blancoIzq && blancoDer) ? VELOCIDAD_BASE * 0.6f : VELOCIDAD_BASE;
  mover(velocidadBase + SENTIDO_CORRECCION * correccion,
        velocidadBase - SENTIDO_CORRECCION * correccion);
  errorAnterior = error;

  if (millis() >= siguienteMensaje) {
    Serial.print("IR: ");
    Serial.print(blancoIzq);
    Serial.print(" ");
    Serial.print(blancoDer);
    Serial.print(" | error: ");
    Serial.print(error, 2);
    Serial.print(" | corrección: ");
    Serial.println(correccion, 3);
    siguienteMensaje = millis() + 500;
  }

  delay(PERIODO_MUESTREO_MS);
}
```

### Secuencia equivalente en bloques

1. Detener motores y pedir una lectura promedio de los sensores 1 y 2 sobre negro; repetir sobre blanco y calcular un umbral independiente para cada sensor.
2. En cada ciclo, leer ambos sensores y clasificar cuál detecta blanco.
3. Si solo el izquierdo detecta blanco, fijar error `-1`; si solo el derecho detecta blanco, fijar error `+1`; si ambos tienen el mismo estado, fijar error `0`.
4. Calcular `integral = limitar(integral + error × dt)` y `derivada = (error - error_anterior) / dt`.
5. Calcular `corrección = limitar(Kp × error + Ki × integral + Kd × derivada)`.
6. Asignar `motor_1 = velocidad_base + sentido × corrección` y `motor_2 = velocidad_base - sentido × corrección`; limitar ambos motores a `-1..1`.
7. Repetir durante la prueba y detener motores al finalizar.

Los nombres anteriores describen la lógica; los bloques concretos disponibles dependen de la versión de IdeaScratch. El usuario agregará la imagen de bloques.

## Notas docentes

Empiece con la pista y la geometría: la línea debe ser más estrecha que la separación entre sensores para que el estado «ambos negros» pueda representar una línea centrada entre ellos. Después pida al grupo que prediga qué motor debe cambiar cuando cada sensor vea blanco. Ajuste una ganancia a la vez y mantenga baja la velocidad. Aclare que con dos sensores no se puede distinguir «línea centrada entre ambos» de «línea completamente perdida» si los dos leen negro.
