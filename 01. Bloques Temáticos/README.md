# Bloques Temáticos

Esta carpeta organiza los contenidos tecnológicos de **Maker Academy**. Los bloques temáticos funcionan como la base curricular para la dimensión de **aprender de tecnología**: programación, robótica, electrónica, fabricación digital, IoT, creatividad digital, datos, IA y cultura maker.

Los bloques no son una planificación anual por grado. Su función es servir como referencia para diseñar proyectos, seleccionar contenidos, revisar vocabulario, preparar recursos, cuidar la seguridad y conectar las experiencias maker con competencias tecnológicas.

---

## ¿Para qué sirven los bloques temáticos?

Los bloques ayudan a responder preguntas como:

* ¿Qué contenidos tecnológicos se trabajan en Maker Academy?
* ¿Qué competencias desarrolla cada tipo de experiencia?
* ¿Qué vocabulario técnico necesita conocer el docente?
* ¿Qué medidas de seguridad deben considerarse?
* ¿Cómo se conecta cada bloque con XperiencED Kids y el PNFT?
* ¿Qué mini lecciones, prácticas guiadas o evaluaciones pueden apoyar un proyecto?

## Estructura de cada bloque

Cada bloque puede incluir recursos como:

| Recurso              | Propósito                                                                |
| -------------------- | ------------------------------------------------------------------------ |
| `README.md`          | Presenta el propósito del bloque y orienta la navegación.                |
| `mapa-progresion.md` | Explica cómo se desarrolla el bloque por niveles o grados.               |
| `vocabulario.md`     | Define conceptos clave para docentes y estudiantes.                      |
| `seguridad.md`       | Indica cuidados, riesgos y recomendaciones de uso.                       |
| `alineacion-pnft.md` | Relaciona el bloque con competencias del PNFT.                           |
| `mini-lecciones/`    | Contiene explicaciones o actividades breves para introducir conceptos.   |
| `practicas-guiadas/` | Propone ejercicios paso a paso para desarrollar habilidades específicas. |
| `recursos-docentes/` | Incluye presentaciones, guías, preguntas de mediación o checklists.      |
| `evaluacion/`        | Reúne listas de cotejo, rúbricas y evidencias esperadas.                 |

## Cómo usar esta carpeta

### Si está planificando desde el Programa Anual K11

1. Revise el proyecto o módulo correspondiente en `02. Programa Anual K11`.
2. Identifique el bloque temático principal y los bloques secundarios.
3. Ingrese al bloque correspondiente en esta carpeta.
4. Consulte vocabulario, seguridad, mini lecciones y recursos de evaluación.
5. Adapte los recursos al nivel del grupo y al contexto de la escuela.

### Si está diseñando un proyecto nuevo

1. Defina qué competencia o contenido desea desarrollar.
2. Seleccione el bloque temático principal.
3. Revise el mapa de progresión y las prácticas guiadas.
4. Conecte el proyecto con XperiencED Kids: Inspiración, Experimentación y Reflexión.
5. Verifique seguridad, materiales y evidencias esperadas antes de implementar.

---

## Relación con XperiencED Kids

Cada bloque debe apoyar experiencias diseñadas con tres momentos:

| Momento             | Aplicación en los bloques                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| **Inspiración**     | Conectar el contenido tecnológico con preguntas, retos, ejemplos, intereses o situaciones reales. |
| **Experimentación** | Construir, programar, probar, medir, modificar, depurar y mejorar.                                |
| **Reflexión**       | Documentar el proceso, explicar decisiones, compartir evidencias y proponer mejoras.              |

## Recomendación para docentes

Use esta carpeta como una **biblioteca de contenidos tecnológicos**.
Para conocer la ruta oficial por grado, consulte `02. Programa Anual K11`.
Para encontrar ejemplos de proyectos aislados o complementarios, consulte `03. Proyectos por Grado`.

Los bloques temáticos explican **qué se aprende de tecnología**.
XperiencED Kids orienta **cómo se aprende**.
El Programa Anual K11 indica **cuándo y en qué progresión se trabaja**.
