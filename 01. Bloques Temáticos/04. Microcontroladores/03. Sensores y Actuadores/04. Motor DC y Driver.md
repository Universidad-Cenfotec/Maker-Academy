# Motor DC y Driver L298N

Un motor DC (corriente directa) convierte energía eléctrica en movimiento rotatorio. Es el actuador más básico para robots con ruedas, cintas transportadoras, ventiladores y cualquier mecanismo que requiera rotación continua sin control de posición. La velocidad se controla con PWM y la dirección con la polaridad de la alimentación. El problema es que los microcontroladores no pueden suministrar la corriente que los motores necesitan, por eso siempre se usa un driver entre ambos.

---

## Por qué no conectar el motor directamente al Arduino

Un motor DC pequeño (tipo N20 o TT de juguete) consume 200 mA a 800 mA cuando trabaja con carga. Un pin de Arduino puede suministrar como máximo 40 mA. Conectar un motor directamente a un pin destruye el pin (y a veces el chip completo) en cuestión de segundos.

Además, los motores generan "back-EMF" (fuerza contraelectromotriz): cuando se corta la alimentación, el motor, por inercia, actúa como generador y produce un pulso de voltaje inverso que puede dañar el microcontrolador si no hay protección. Los drivers de motor incluyen diodos de protección para absorber ese pulso.

---

## El driver L298N: puente H doble

El L298N es un circuito integrado de puente H doble. "Puente H" describe su topología interna: cuatro transistores (o MOSFETs) en forma de H que permiten que la corriente fluya en ambas direcciones a través del motor. Al cambiar qué transistores están activos, se invierte la dirección de la corriente y por lo tanto la dirección de giro del motor.

El módulo L298N de placa roja (el más común en makerspaces) puede controlar dos motores DC de forma independiente. Sus terminales son:

| Terminal | Función |
|---|---|
| IN1, IN2 | Dirección del Motor A |
| IN3, IN4 | Dirección del Motor B |
| ENA | Habilitación (velocidad) Motor A, señal PWM |
| ENB | Habilitación (velocidad) Motor B, señal PWM |
| OUT1, OUT2 | Salida al Motor A |
| OUT3, OUT4 | Salida al Motor B |
| +12V | Alimentación de los motores (hasta 35V) |
| 5V | Puede suministrar 5V al Arduino si el jumper de regulación está puesto |
| GND | Tierra común (motor + Arduino) |

---

## Tabla de control de dirección (Motor A)

| IN1 | IN2 | Resultado |
|---|---|---|
| HIGH | LOW | Giro adelante |
| LOW | HIGH | Giro atrás |
| HIGH | HIGH | Freno |
| LOW | LOW | Libre (sin freno) |

Lo mismo aplica a IN3/IN4 para el Motor B.

---

## Conexión básica (un motor, Arduino UNO)

```
Arduino → L298N
GND     → GND
pin 7   → IN1
pin 8   → IN2
pin 9   → ENA (pin PWM ~)

L298N → Motor
OUT1  → terminal + del motor
OUT2  → terminal - del motor

Fuente externa → L298N
+       → +12V (o el voltaje de los motores, 6V a 12V)
-       → GND (compartido con Arduino)
```

## Programa básico: adelante, atrás, parar

```cpp
const int IN1 = 7;
const int IN2 = 8;
const int ENA = 9;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}

void adelante(int velocidad) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, velocidad);  // 0 a 255
}

void atras(int velocidad) {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, velocidad);
}

void parar() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, 0);
}

void loop() {
  adelante(200);  // ~78% de velocidad máxima
  delay(2000);
  parar();
  delay(500);
  atras(150);
  delay(2000);
  parar();
  delay(1000);
}
```

## Robot de dos ruedas: giros y curvas

Con dos motores se puede construir un robot diferencial. La dirección se controla variando la velocidad relativa de cada motor:

```cpp
// pines Motor A (rueda derecha)
const int IN1 = 7, IN2 = 8, ENA = 9;
// pines Motor B (rueda izquierda)
const int IN3 = 4, IN4 = 5, ENB = 6;

void configurarPines() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(ENA, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); pinMode(ENB, OUTPUT);
}

void moverRobot(int velDerecha, int velIzquierda) {
  // Motor A
  if (velDerecha >= 0) {
    digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  } else {
    digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH);
    velDerecha = -velDerecha;
  }
  analogWrite(ENA, velDerecha);

  // Motor B
  if (velIzquierda >= 0) {
    digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
  } else {
    digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
    velIzquierda = -velIzquierda;
  }
  analogWrite(ENB, velIzquierda);
}

void setup() { configurarPines(); }

void loop() {
  moverRobot(200, 200);   // adelante
  delay(2000);
  moverRobot(200, 100);   // curva izquierda (rueda derecha más rápida)
  delay(1000);
  moverRobot(200, -200);  // giro en sitio (motores en sentidos opuestos)
  delay(800);
  moverRobot(0, 0);       // parar
  delay(1000);
}
```

## Velocidad mínima de arranque

Los motores DC tienen inercia estática: se necesita una corriente mínima para que comiencen a girar. En la mayoría de los motores de robot de juguete, valores de PWM menores a 80-100 (de 255) no logran moverlos, aunque sí hacen que el motor vibre y consuma corriente sin girar. Si el robot "no arranca", el problema puede ser que el valor de PWM está por debajo de la velocidad mínima de ese motor específico.

---

## Alimentación: la regla de las dos fuentes

El Arduino y los motores deben tener fuentes de alimentación independientes. Los motores generan picos de corriente al arrancar que, si comparten la misma fuente con el microcontrolador, pueden causar reseteos o comportamientos erráticos del programa.

**Lo que sí se comparte:** el GND. El GND del Arduino y el GND de la fuente de los motores deben estar conectados para que las señales de los pines tengan la misma referencia.

**Lo que NO se comparte:** el VCC. La fuente de los motores (4× AA para motores pequeños, o batería de litio de 7.4V-11.1V para motores más potentes) va al terminal +12V del L298N. El Arduino se alimenta por su propio USB o por su propio regulador.

## En MicroPython (ESP32)

```python
from machine import Pin, PWM

# Motor A
in1 = Pin(26, Pin.OUT)
in2 = Pin(27, Pin.OUT)
ena = PWM(Pin(14), freq=1000)

def adelante(vel):  # vel: 0 a 1023
    in1.value(1)
    in2.value(0)
    ena.duty(vel)

def atras(vel):
    in1.value(0)
    in2.value(1)
    ena.duty(vel)

def parar():
    in1.value(0)
    in2.value(0)
    ena.duty(0)

adelante(800)  # 800/1023 ≈ 78% velocidad
```

En MicroPython para ESP32, la escala de duty es 0 a 1023 en lugar de 0 a 255.
