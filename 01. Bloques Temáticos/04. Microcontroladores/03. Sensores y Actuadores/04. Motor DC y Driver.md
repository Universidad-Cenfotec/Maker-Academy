Un motor DC (corriente directa) convierte electricidad en movimiento giratorio. Es el actuador más básico para robots con ruedas, cintas transportadoras, ventiladores y cualquier mecanismo que necesite rotación continua. La velocidad se controla con la cantidad de electricidad que recibe, y la dirección con la polaridad.

**El problema:** los microcontroladores como Arduino no pueden suministrar la corriente que los motores necesitan para girar. Si se conecta un motor directamente a un pin, ese pin se puede dañar de forma permanente. Por eso siempre se usa un **driver** (controlador de motor) como intermediario.


## Propósito

Documentar el uso de motores DC con el driver L298N para que los docentes puedan crear proyectos de robótica móvil con control de velocidad y dirección.

---

## ¿Por qué necesito un driver?

Piénsalo así: el Arduino es como un interruptor de luz muy delicado que solo puede controlar objetos pequeños. Un motor DC es como un electrodoméstico grande. Necesitas un tomacorriente especial (el driver) que recibe la señal de control pequeña del Arduino y la convierte en suficiente energía para mover el motor.

## El driver L298N

El L298N es el módulo controlador de motores más común en proyectos educativos. Puede controlar **dos motores DC** de forma independiente. La placa tiene una serie de terminales:

---

| Terminal | ¿Para qué sirve? |
|---|---|
| IN1, IN2 | Controlan la dirección del Motor A (adelante/atrás) |
| IN3, IN4 | Controlan la dirección del Motor B |
| ENA | Controla la velocidad del Motor A (señal PWM) |
| ENB | Controla la velocidad del Motor B |
| OUT1, OUT2 | Salida al Motor A (los cables del motor van aquí) |
| OUT3, OUT4 | Salida al Motor B |
| +12V | Alimentación de los motores (5V–12V según el motor) |
| GND | Tierra (compartida entre Arduino y fuente de motores) |
| 5V | Puede suministrar 5V al Arduino (con el jumper puesto) |

## Tabla de control de dirección

| IN1 | IN2 | El motor hace: |
|---|---|---|
| HIGH | LOW | Gira hacia adelante |
| LOW | HIGH | Gira hacia atrás |
| HIGH | HIGH | Frena de golpe |
| LOW | LOW | Se detiene sin fuerza |

---

## Conexión básica (un motor)

```
Arduino pin 7  →  L298N IN1
Arduino pin 8  →  L298N IN2
Arduino pin 9  →  L298N ENA  (pin con PWM, marcado con ~)
Arduino GND    →  L298N GND

L298N OUT1     →  cable + del motor
L298N OUT2     →  cable - del motor

Fuente externa →  L298N +12V (5V–12V según el motor)
Fuente externa →  L298N GND (el mismo GND de Arduino)
```

## Programa básico: adelante, atrás, parar

```cpp
const int IN1 = 7;
const int IN2 = 8;
const int ENA = 9;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}

void adelante(int velocidad) {  // velocidad: 0 a 255
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, velocidad);
}

void atras(int velocidad) {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, velocidad);
}

void parar() {
  analogWrite(ENA, 0);
}

void loop() {
  adelante(200);  // girar a ~78% de velocidad
  delay(2000);
  parar();
  delay(500);
  atras(150);
  delay(2000);
  parar();
  delay(1000);
}
```

## Robot de dos ruedas

Con dos motores se puede construir un robot diferencial. La dirección se controla variando la velocidad de cada rueda:

```cpp
// Motor A (rueda derecha): IN1=7, IN2=8, ENA=9
// Motor B (rueda izquierda): IN3=4, IN4=5, ENB=6

void adelante()      { /* ambos motores hacia adelante */ }
void girarDerecha()  { /* rueda izquierda rápida, derecha lenta o parada */ }
void girarIzquierda(){ /* rueda derecha rápida, izquierda lenta o parada */ }
void parar()         { /* ambos motores detenidos */ }
```

## La regla más importante: dos fuentes de alimentación

Los motores y el Arduino deben usar **fuentes de alimentación separadas**. Los motores consumen mucha corriente cuando arrancan, y si están conectados a la misma fuente que el Arduino, pueden causar que el Arduino se reinicie o se comporte de forma rara.

**Lo que sí comparten:** el GND (tierra). Es obligatorio que la tierra del Arduino y la tierra de la fuente de los motores estén conectadas entre sí. Sin esto, el control no funciona.

**Lo que NO comparten:** el voltaje. La fuente de los motores va al terminal `+12V` del L298N, nunca al Arduino directamente.

## Ideas de proyectos

- **Robot seguidor de línea:** detecta una línea negra en el piso con sensores y la sigue automáticamente
- **Robot que evita obstáculos:** usa el sensor de distancia para girar antes de chocar
- **Banda transportadora:** mueve objetos de un punto a otro controlada por botones
- **Ventilador automático:** enciende o cambia la velocidad según la temperatura detectada
- **Control remoto por Bluetooth:** controlar los motores desde el celular con una app

## Aplicación en Maker Academy

Se usa en robots con ruedas que necesitan moverse en diferentes direcciones. Es el componente central de los proyectos de robótica terrestre en Maker Academy.

## Nota docente

El proyecto de robot con dos motores y un sensor de distancia es uno de los más motivadores en secundaria porque combina múltiples conceptos: programación, electrónica y diseño mecánico. El resultado es un objeto que "toma decisiones" en el mundo real.

Para docentes sin experiencia en electrónica: empezar con un solo motor, sin el robot completo. Hacer que gire hacia adelante y hacia atrás es un logro en sí mismo, y permite entender el L298N antes de complicar el proyecto.

**Advertencia importante:** los motores hacen ruido cuando se conectan al Arduino (puede haber interferencias). Si el programa parece "reiniciarse" o comportarse de forma extraña al arrancar los motores, el problema generalmente es que comparten la misma fuente de alimentación. Separar las fuentes soluciona el 90% de esos problemas.
