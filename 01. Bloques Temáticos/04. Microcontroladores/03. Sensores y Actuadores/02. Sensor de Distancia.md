# Sensor de Distancia Ultrasónico (HC-SR04)

![Módulo HC-SR04 con sus dos transductores ultrasónicos circulares](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e7/Ultrasonic_distance_sensor_-_HC-SR04.jpg/320px-Ultrasonic_distance_sensor_-_HC-SR04.jpg)

El HC-SR04 mide distancias usando sonido. Emite un pulso ultrasónico (inaudible para humanos, a 40 kHz), espera a que el eco rebote en un obstáculo y mide el tiempo que tarda en regresar. Con ese tiempo y la velocidad del sonido, calcula la distancia. Es exactamente el mismo principio que usa el sonar de un submarino o el sistema de aparcamiento de un coche moderno.

---

## Especificaciones del HC-SR04

| Parámetro | Valor |
|---|---|
| Voltaje de operación | 5 V |
| Rango de medición | 2 cm a 400 cm |
| Precisión | ± 3 mm |
| Ángulo efectivo | < 15° |
| Frecuencia ultrasónica | 40 kHz |
| Pines | VCC, TRIG, ECHO, GND |

---

## Conexión

```
HC-SR04 → Arduino UNO
VCC     → 5V
GND     → GND
TRIG    → pin 9 (OUTPUT)
ECHO    → pin 10 (INPUT)
```

El pin TRIG dispara el pulso ultrasónico y el pin ECHO devuelve una señal cuya duración es proporcional a la distancia. Son funciones distintas y se conectan a pines distintos.

---

## Cómo funciona el tiempo de vuelo

El microcontrolador envía un pulso de 10 microsegundos a TRIG. El HC-SR04 emite 8 pulsos ultrasónicos a 40 kHz y luego pone ECHO en HIGH. ECHO vuelve a LOW cuando el eco regresa. La duración de ECHO en HIGH es el tiempo que tardó el sonido en ir al obstáculo y regresar.

La velocidad del sonido en el aire a 20 °C es aproximadamente 343 m/s, equivalente a 0.0343 cm/µs. Como el sonido recorre el camino dos veces (ida y vuelta):

```
distancia (cm) = duración (µs) × 0.0343 / 2
              = duración / 58.3
              ≈ duración / 58
```

La función `pulseIn()` de Arduino mide la duración de un pulso en microsegundos, que es exactamente lo que se necesita.

## Programa básico: medir distancia

```cpp
const int TRIG = 9;
const int ECHO = 10;

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  Serial.begin(9600);
}

long medirDistancia() {
  // enviar pulso de disparo
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  // medir duración del eco
  long duracion = pulseIn(ECHO, HIGH, 30000);  // timeout 30 ms

  // convertir a centímetros
  long distancia = duracion / 58;

  return distancia;
}

void loop() {
  long d = medirDistancia();
  Serial.print("Distancia: ");
  Serial.print(d);
  Serial.println(" cm");
  delay(100);
}
```

El tercer parámetro de `pulseIn()` es un timeout en microsegundos. Sin timeout, si el sensor no recibe eco (objeto demasiado lejos o fuera del ángulo), la función espera indefinidamente. Con 30000 µs de timeout (30 ms), si no llega eco la función devuelve 0.

## Programa con lógica: robot que evita obstáculos

```cpp
const int TRIG = 9;
const int ECHO = 10;
const int LED_ROJO = 13;
const int LED_VERDE = 12;
const int DISTANCIA_MINIMA = 20;  // cm

long medirDistancia() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long dur = pulseIn(ECHO, HIGH, 30000);
  return dur / 58;
}

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED_ROJO, OUTPUT);
  pinMode(LED_VERDE, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  long d = medirDistancia();

  Serial.print(d);
  Serial.println(" cm");

  if (d > 0 && d < DISTANCIA_MINIMA) {
    // obstáculo cercano
    digitalWrite(LED_ROJO, HIGH);
    digitalWrite(LED_VERDE, LOW);
  } else {
    // camino libre
    digitalWrite(LED_ROJO, LOW);
    digitalWrite(LED_VERDE, HIGH);
  }

  delay(100);
}
```

La condición `d > 0` filtra las lecturas de timeout (que devuelven 0 o valores muy grandes).

## Librería NewPing: más limpia y robusta

La librería NewPing simplifica el código y agrega filtrado automático de lecturas erróneas:

```cpp
#include <NewPing.h>

NewPing sonar(9, 10, 400);  // TRIG, ECHO, distancia máxima en cm

void setup() {
  Serial.begin(9600);
}

void loop() {
  int distancia = sonar.ping_cm();  // devuelve 0 si fuera de rango
  Serial.println(distancia);
  delay(100);
}
```

También ofrece `sonar.ping_median(5)` que toma 5 lecturas y devuelve la mediana, lo cual filtra lecturas atípicas de forma efectiva.

## En MicroPython (ESP32 o micro:bit con adaptador)

```python
from machine import Pin, time_pulse_us
import time

TRIG = Pin(5, Pin.OUT)
ECHO = Pin(18, Pin.IN)

def medir():
    TRIG.value(0)
    time.sleep_us(2)
    TRIG.value(1)
    time.sleep_us(10)
    TRIG.value(0)

    duracion = time_pulse_us(ECHO, 1, 30000)  # timeout 30 ms
    if duracion < 0:
        return 0
    return duracion // 58

while True:
    d = medir()
    print("Distancia:", d, "cm")
    time.sleep_ms(100)
```

`time_pulse_us()` es la equivalencia de `pulseIn()` en MicroPython. El valor negativo indica timeout.

## Limitaciones a conocer

**Ángulo de cobertura:** El HC-SR04 detecta objetos dentro de un cono de aproximadamente 15° de apertura. Objetos en los laterales no generan eco detectable.

**Superficies blandas o anguladas:** Materiales absorbentes (telas, espumas) o superficies inclinadas más de 45° reflejan el eco en otra dirección. La distancia medida puede ser incorrecta o el sensor puede no detectar el objeto.

**Rango mínimo:** El sensor no puede medir menos de 2 cm. Por debajo de esa distancia, el pulso de TRIG y el eco de retorno se solapan y la lectura es incorrecta.

**Lecturas múltiples rápidas:** Si se mide muy seguido (menos de 60 ms entre mediciones), el eco de una medición puede interferir con la siguiente. El delay de 100 ms entre lecturas es suficiente para evitar esto.

**Temperatura:** La velocidad del sonido varía con la temperatura (aproximadamente 0.6 m/s por grado Celsius). Para aplicaciones de alta precisión se mide la temperatura ambiente y se corrige la constante de conversión.
