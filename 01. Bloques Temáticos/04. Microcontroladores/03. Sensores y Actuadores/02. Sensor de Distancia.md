## Descripción

Explica el funcionamiento del sensor ultrasónico HC-SR04 para medir distancias, con conexión, código de ejemplo y proyectos de robótica que detectan obstáculos.

El HC-SR04 mide distancias usando sonido. Funciona igual que el sonar de un murciélago o el sensor de estacionamiento de un carro: emite un sonido muy agudo (inaudible para las personas) y mide cuánto tiempo tarda en rebotar en un objeto y regresar. Con ese tiempo calcula la distancia.


## Propósito

Documentar el uso del sensor ultrasónico HC-SR04 para que los docentes puedan crear proyectos que detecten obstáculos, midan distancias y desarrollen comportamientos de evasión.

---

## ¿Cómo funciona?

1. El sensor emite un "ping" de sonido ultrasónico (40,000 Hz, los humanos escuchamos hasta ~20,000 Hz).
2. El sonido viaja, choca con un objeto y rebota de vuelta.
3. El sensor mide el tiempo que tardó en ir y volver.
4. Con ese tiempo y la velocidad del sonido (343 m/s), calcula la distancia.

**Rango:** detecta objetos entre 2 cm y 400 cm.

---

## Los 4 pines del HC-SR04

| Pin | ¿Para qué sirve? |
|---|---|
| VCC | Alimentación (5V) |
| GND | Tierra |
| TRIG | "Disparador": le dice al sensor que emita el sonido |
| ECHO | "Eco": devuelve la señal que indica cuánto tiempo tardó |

## Conexión a Arduino

```
HC-SR04    →    Arduino UNO
VCC        →    5V
GND        →    GND
TRIG       →    pin 9
ECHO       →    pin 10
```

## Programa básico: medir distancia

```cpp
const int TRIG = 9;
const int ECHO = 10;

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  Serial.begin(9600);
}

void loop() {
  // enviar el "ping"
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  // medir el tiempo que tardó en volver
  long duracion = pulseIn(ECHO, HIGH);
  long distancia = duracion / 58;  // convertir a centímetros

  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.println(" cm");
  delay(100);
}
```

## Programa con lógica: alarma de proximidad

```cpp
const int TRIG = 9;
const int ECHO = 10;
const int LED_ROJO = 13;
const int DISTANCIA_MINIMA = 20;  // en centímetros

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED_ROJO, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  long duracion = pulseIn(ECHO, HIGH);
  long distancia = duracion / 58;

  Serial.print(distancia);
  Serial.println(" cm");

  if (distancia < DISTANCIA_MINIMA) {
    digitalWrite(LED_ROJO, HIGH);  // objeto muy cerca → alerta
  } else {
    digitalWrite(LED_ROJO, LOW);   // espacio libre → sin alerta
  }

  delay(100);
}
```

## Librería NewPing (más fácil)

La librería **NewPing** simplifica mucho el código. Se instala desde el Gestor de Librerías del Arduino IDE:

```cpp
#include <NewPing.h>

NewPing sonar(9, 10, 400);  // pin TRIG, pin ECHO, distancia máxima

void setup() {
  Serial.begin(9600);
}

void loop() {
  int distancia = sonar.ping_cm();
  Serial.println(distancia);
  delay(100);
}
```

Solo 3 líneas para medir y mostrar la distancia. Ideal para que el grupo se enfoque en la lógica del proyecto y no en los detalles del sensor.

## Cosas importantes a saber

- El sensor **no detecta objetos a menos de 2 cm**. Si el objeto está muy cerca, la lectura será incorrecta.
- Funciona mejor con superficies **planas y sólidas** (madera, plástico, paredes). Materiales blandos como telas o espumas absorben el sonido y dan lecturas imprecisas.
- El sensor "ve" en un cono de unos 15° de apertura. Objetos en los laterales no se detectan.

---

## Ideas de proyectos

- **Robot que evita obstáculos:** el robot se detiene o gira cuando detecta algo cerca
- **Alarma de puerta:** avisa cuando alguien entra a un espacio
- **Medidor de estacionamiento:** LED verde si hay espacio, rojo si está muy cerca
- **Instrumento musical de distancia:** el tono del sonido cambia según la distancia detectada
- **Juego de "no toques la pared":** el estudiante mueve la mano sin tocar un umbral

## Nota docente

El sensor de distancia es uno de los más motivadores para trabajar con grupos de secundaria porque el resultado es inmediatamente visible en el Monitor Serial y porque habilita proyectos de robótica accesibles (un robot que no choca con paredes es un logro muy satisfactorio).

Para introducirlo, se recomienda hacer primero el ejercicio básico de medir distancias de diferentes objetos y registrar los valores. Esto ayuda a entender el rango del sensor y a elegir umbrales con criterio.
