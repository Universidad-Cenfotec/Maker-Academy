La LDR (Light Dependent Resistor, también llamada **fotorresistencia**) es el sensor más fácil para empezar con entradas del mundo real. Su funcionamiento es muy simple: **cuando hay más luz, deja pasar más electricidad; cuando hay menos luz, deja pasar menos**. El microcontrolador lee ese cambio y puede tomar decisiones.

Es el mismo principio que usan las lámparas de calle que se encienden solas cuando oscurece.


## Propósito

Documentar el uso del sensor de luz (LDR y módulo KY-018) para que los docentes puedan crear proyectos que respondan a los cambios en la iluminación del ambiente.

---

## ¿Cómo funciona?

Imagina la LDR como una puerta que se abre o se cierra según cuánta luz le llega:
- **Mucha luz** → la puerta se abre → la electricidad pasa fácil → valor bajo en el sensor
- **Poca luz / oscuridad** → la puerta casi cerrada → poco paso de electricidad → valor alto en el sensor

El microcontrolador no "ve" la luz directamente, pero sí puede leer ese cambio de electricidad y convertirlo en un número.

## Circuito básico

Para conectar una LDR a un Arduino se necesita también una resistencia de 10 kΩ:

```
5V ──┤ Resistencia 10kΩ ├──┬── A0 (Arduino)
                            │
                           LDR
                            │
                           GND
```

## Programa básico: leer la luz

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(A0);    // lee un número entre 0 y 1023
  Serial.println(luz);         // muestra el número en el monitor serial
  delay(100);
}
```

Abrir el Monitor Serial mientras se tapa y destapa la LDR con la mano permite ver cómo cambian los números en tiempo real.

---

## Programa con lógica: encender un LED cuando oscurece

```cpp
const int PIN_LED = 13;
const int UMBRAL = 400;   // ajustar según el ambiente

void setup() {
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  int luz = analogRead(A0);

  if (luz < UMBRAL) {
    digitalWrite(PIN_LED, HIGH);  // oscuro → enciende el LED
  } else {
    digitalWrite(PIN_LED, LOW);   // claro → apaga el LED
  }

  delay(200);
}
```

> **Nota para docentes:** el valor del umbral (400 en este ejemplo) varía según el ambiente. No existe un número "correcto" en abstracto. Lo mejor es que los estudiantes lean los valores primero y luego elijan el umbral que tiene sentido para su espacio.

## En micro:bit

El micro:bit tiene un sensor de luz integrado que usa la propia pantalla de LEDs para detectar la luz:

```python
from microbit import *

while True:
    nivel = display.read_light_level()  # devuelve un número de 0 a 255
    display.scroll(str(nivel))          # muestra el número en pantalla
    sleep(500)
```

No se necesita ningún componente adicional.

## Módulo KY-018 (versión en plaquita)

El módulo KY-018 es una LDR ya montada en una pequeña placa con 3 pines (GND, VCC, S). Es funcionalmente igual al circuito anterior, pero sin necesidad de armar nada en protoboard. Perfecto para primeras sesiones.

## Ideas de proyectos

- **Lámpara automática:** enciende un LED cuando oscurece, como las lámparas de emergencia
- **Alarma de luz:** activa un buzzer cuando alguien abre una caja o cajón oscuro
- **Medidor de ambiente:** muestra en pantalla si el aula está bien iluminada
- **Jardín inteligente:** detecta si una planta está recibiendo suficiente luz

## Nota docente

La LDR es ideal para **introducir el concepto de "entrada analógica"**: a diferencia de un botón (que solo dice sí o no), la LDR da valores continuos que cambian gradualmente. Eso ayuda a los estudiantes a entender que el mundo real es analógico y la programación puede capturarlo.

El ejercicio de tapar y destapar la LDR mientras se ven los números en el Monitor Serial es uno de los más efectivos para hacer tangible la relación entre el mundo físico y el código. Hacerlo antes de escribir cualquier lógica.
