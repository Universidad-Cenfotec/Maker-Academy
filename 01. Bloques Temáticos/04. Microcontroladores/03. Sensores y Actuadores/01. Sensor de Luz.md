# Sensor de Luz (LDR)

![Fotorresistencia LDR GL5528 usada en proyectos educativos de electrónica](https://upload.wikimedia.org/wikipedia/commons/thumb/b/bb/LDR_1480405_6_7_HDR_Enhancer_1.jpg/320px-LDR_1480405_6_7_HDR_Enhancer_1.jpg)

La LDR (Light Dependent Resistor, fotorresistencia) es el sensor más accesible para comenzar con entradas analógicas. Su principio es simple: es una resistencia cuyo valor cambia con la intensidad de luz que recibe. Baja en presencia de luz, sube en oscuridad. Con un divisor de tensión y una línea de código, ya se está leyendo el ambiente lumínico del entorno.

---

## Cómo funciona

El material semiconductor de la LDR (normalmente sulfuro de cadmio, CdS) libera electrones cuando absorbe fotones de luz. Más luz equivale a más electrones libres y por lo tanto a menos resistencia. En oscuridad total, una LDR típica puede medir entre 100 kΩ y 1 MΩ. Con luz solar directa puede bajar hasta 100 Ω o menos.

Esta variación de resistencia es inútil por sí sola para el microcontrolador, que no mide resistencia sino voltaje. El divisor de tensión convierte la variación de resistencia en variación de voltaje.

---

## Circuito básico: divisor de tensión

```
VCC (5V)
  │
[10 kΩ fija]   ← resistencia de referencia
  │
  ├──────────────→ A0 (Arduino)
  │
[LDR]          ← resistencia que varía con la luz
  │
GND
```

La resistencia fija se elige del mismo orden de magnitud que la LDR en condiciones de uso. Una LDR GL5528 típica varía entre 1 kΩ (luz) y 100 kΩ (oscuridad), entonces 10 kΩ es una buena resistencia fija para que el divisor produzca voltajes distintos en ambos extremos.

El voltaje en A0 es:

```
Vout = 5V × LDR / (10kΩ + LDR)
```

En oscuridad (LDR = 100 kΩ): Vout ≈ 4.55 V → ADC ≈ 931
En luz intensa (LDR = 1 kΩ): Vout ≈ 0.45 V → ADC ≈ 92

Estos valores son aproximados. El rango real en el ambiente del makerspace puede ser diferente y siempre se debe medir.

## Programa básico: solo leer y mostrar

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(A0);    // 0 a 1023
  Serial.println(luz);
  delay(100);
}
```

Abrir el Serial Plotter mientras se tapa y destapa la LDR con la mano permite ver el rango real de valores. Este paso de observación es obligatorio antes de poner cualquier umbral.

## Programa con lógica: encender LED según luz

```cpp
const int PIN_LDR = A0;
const int PIN_LED = 13;
const int UMBRAL = 400;   // ajustar según el ambiente

void setup() {
  pinMode(PIN_LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(PIN_LDR);

  Serial.print("Luz: ");
  Serial.print(luz);

  if (luz < UMBRAL) {
    digitalWrite(PIN_LED, HIGH);
    Serial.println(" → OSCURO (LED ON)");
  } else {
    digitalWrite(PIN_LED, LOW);
    Serial.println(" → CLARO (LED OFF)");
  }

  delay(200);
}
```

El valor del umbral depende completamente del ambiente. No existe un umbral "correcto" en abstracto.

## Histéresis: evitar parpadeo en el umbral

Cuando el nivel de luz oscila justo alrededor del umbral, el LED puede parpadear rápidamente. La solución es usar dos umbrales separados:

```cpp
const int UMBRAL_ENCENDER = 350;  // encender cuando luz baja de este valor
const int UMBRAL_APAGAR   = 500;  // apagar cuando luz sube de este valor

bool ledEncendido = false;

void loop() {
  int luz = analogRead(A0);

  if (luz < UMBRAL_ENCENDER && !ledEncendido) {
    digitalWrite(13, HIGH);
    ledEncendido = true;
    Serial.println("LED ON");
  } else if (luz > UMBRAL_APAGAR && ledEncendido) {
    digitalWrite(13, LOW);
    ledEncendido = false;
    Serial.println("LED OFF");
  }

  delay(100);
}
```

Este es exactamente el principio del termostato: no enciende y apaga la calefacción en el mismo grado, sino que la enciende a 18 °C y la apaga cuando llega a 22 °C.

## Módulo KY-018

El módulo KY-018 monta una LDR junto con una resistencia de pull-down en una pequeña placa de tres pines (GND, VCC, S). Es funcionalmente equivalente al circuito de divisor de tensión anterior, pero sin necesidad de armar nada en protoboard:

```
KY-018
  GND → GND Arduino
  VCC → 5V Arduino
  S   → A0 Arduino
```

La lectura de código es idéntica al circuito con LDR suelta. La diferencia es que el módulo invierte la relación: más luz produce valores más altos porque la resistencia de referencia está entre la señal y GND en lugar de entre la señal y VCC. Siempre verificar con el monitor serial.

## En micro:bit

```python
from microbit import *

while True:
    # sensor de luz interno del micro:bit (basado en la matriz LED)
    nivel = display.read_light_level()  # 0 a 255
    display.scroll(str(nivel))
    sleep(500)
```

El micro:bit tiene un sensor de luz interno que usa la matriz de LEDs como fotodetector. Es menos sensible que una LDR externa pero no requiere ningún componente adicional. Para usar una LDR externa, conectar el circuito de divisor de tensión a P0:

```python
from microbit import *

while True:
    luz = pin0.read_analog()  # 0 a 1023
    if luz < 400:
        display.show(Image.SAD)
    else:
        display.show(Image.HAPPY)
    sleep(200)
```

## Calibración en el ambiente de uso

La calibración no es un paso opcional: es parte del diseño del proyecto. El procedimiento es:

1. Instalar el sensor en la posición final donde quedará en el proyecto
2. Medir los valores en las condiciones extremas (máxima luz esperada, mínima luz esperada)
3. Elegir el umbral o los umbrales en el rango entre esos extremos
4. Si el rango es muy pequeño (por ejemplo, el sensor vive bajo una caja y la variación es de 200 a 220), cambiar la resistencia fija del divisor para ampliar el rango

La diferencia entre un proyecto que funciona bien y uno que falla intermitentemente casi siempre está en si se hizo o no esta calibración.
