# Servomotor

![Servomotor SG90 con sus tres cables de conexión y accesorios de brazo](https://upload.wikimedia.org/wikipedia/commons/thumb/a/af/Micro_servo_motor_SG-90.jpg/320px-Micro_servo_motor_SG-90.jpg)

Un servomotor es un motor con posición controlable. A diferencia de un motor DC que solo gira mientras recibe corriente, un servo puede moverse a un ángulo específico y mantenerse ahí. Esa capacidad de control de posición lo convierte en el actuador de elección para pinzas robóticas, timones, mecanismos de apertura y cualquier proyecto que necesite movimiento preciso y repetible.

---

## Tipos de servomotor

**Servo de posición (estándar):** Gira entre 0° y 180°. Al enviarle un comando de 90° se mueve a esa posición y la mantiene aunque una fuerza externa intente moverlo. Son los más comunes en proyectos educativos. El SG90 (plástico, 1.8 kg·cm de torque) y el MG996R (metal, 11 kg·cm) son los modelos más usados.

**Servo de rotación continua:** Modificado para girar indefinidamente. El "ángulo" ya no es una posición sino la velocidad y dirección de giro (90° equivale a parado, < 90° gira en un sentido, > 90° en el otro). Se usa en robots con ruedas pequeñas.

---

## Los tres cables y su función

| Color del cable | Función |
|---|---|
| Marrón / Negro | GND (tierra) |
| Rojo | VCC (alimentación: 4.8 V a 6 V) |
| Naranja / Amarillo / Blanco | Señal de control (PWM) |

El orden típico del conector es GND, VCC, Señal de izquierda a derecha visto desde el frente del conector. Siempre verificar con el datasheet del modelo específico porque hay variaciones.

---

## Cómo funciona el control por PWM

El servo espera una señal PWM a 50 Hz (un ciclo cada 20 ms). Dentro de ese ciclo, la duración del pulso en HIGH determina el ángulo:

```
Pulso de 1000 µs → 0°
Pulso de 1500 µs → 90° (posición central)
Pulso de 2000 µs → 180°
```

El circuito interno del servo compara la posición actual (medida por un potenciómetro interno) con la posición objetivo codificada en la señal PWM y activa el motor para mover el eje hasta que coincidan. Este es un sistema de control en bucle cerrado.

La librería `Servo.h` de Arduino abstrae completamente este mecanismo: el programador solo indica el ángulo en grados y la librería genera el pulso de duración correcta.

---

## Conexión del SG90 a Arduino

```
SG90        → Arduino UNO
Marrón/GND  → GND
Rojo/VCC    → 5V (para uno o dos servos ligeros)
Naranja     → pin 9
```

Para más de dos servos, o para servos con carga real (MG996R), alimentar VCC desde una fuente externa de 5V-6V y compartir solo el GND con el Arduino.

## Programa básico con Servo.h

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);  // pin de señal
  miServo.write(90);  // posición central al inicio
}

void loop() {
  miServo.write(0);
  delay(1000);
  miServo.write(90);
  delay(1000);
  miServo.write(180);
  delay(1000);
}
```

## Control de ángulo con potenciómetro

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(A0);                   // 0 a 1023
  int angulo  = map(lectura, 0, 1023, 0, 180);   // 0 a 180°
  miServo.write(angulo);

  Serial.print("ADC: ");
  Serial.print(lectura);
  Serial.print(" → Ángulo: ");
  Serial.println(angulo);

  delay(15);  // tiempo mínimo para que el servo se posicione
}
```

Este programa muestra en tiempo real la cadena completa: giro físico → voltaje → número → señal PWM → movimiento mecánico. Es uno de los más didácticos del bloque.

## Movimiento suave: servo con aceleración

Enviar directamente el ángulo destino hace que el servo salte de golpe. Para movimientos más suaves se incrementa el ángulo gradualmente:

```cpp
#include <Servo.h>

Servo miServo;

void moverSuave(int anguloInicio, int anguloFin, int velocidad) {
  if (anguloInicio < anguloFin) {
    for (int a = anguloInicio; a <= anguloFin; a++) {
      miServo.write(a);
      delay(velocidad);
    }
  } else {
    for (int a = anguloInicio; a >= anguloFin; a--) {
      miServo.write(a);
      delay(velocidad);
    }
  }
}

void setup() {
  miServo.attach(9);
  miServo.write(90);
}

void loop() {
  moverSuave(90, 0, 10);    // de 90° a 0° con 10 ms por grado
  delay(500);
  moverSuave(0, 180, 10);   // de 0° a 180°
  delay(500);
  moverSuave(180, 90, 10);  // volver al centro
  delay(500);
}
```

## Alimentación externa para servos con carga

Un SG90 sin carga consume unos 10 mA en reposo y hasta 250 mA cuando trabaja contra resistencia. Un MG996R puede consumir hasta 2.5 A bajo carga máxima. El regulador de 5V de un Arduino UNO puede suministrar solo 500 mA, insuficiente para varios servos o para servos grandes.

La solución es alimentar el VCC de los servos desde una fuente externa (por ejemplo, 4× pilas AA = 6 V, o una fuente de 5 V de mayor corriente):

```
Fuente externa 6V:
  (+) → VCC de todos los servos
  (-) → GND de todos los servos Y GND del Arduino

Arduino:
  pin 9 → Señal del servo
  GND   → GND compartido con la fuente externa
  (NO conectar 5V del Arduino al VCC de los servos)
```

Compartir el GND es obligatorio. Sin un GND común entre el Arduino y los servos, la señal de control no tiene referencia y el servo se comporta de forma impredecible.

## En MicroPython (ESP32)

```python
from machine import Pin, PWM
import time

servo = PWM(Pin(13), freq=50)  # 50 Hz para servo

def angulo_a_duty(angulo):
    # 0° = 1 ms = duty 51, 180° = 2 ms = duty 102 (en escala 0-1023)
    duty = int((angulo / 180) * 51 + 26)
    return duty

def mover(angulo):
    servo.duty(angulo_a_duty(angulo))

mover(0)
time.sleep(1)
mover(90)
time.sleep(1)
mover(180)
time.sleep(1)
```

Los valores de duty para MicroPython en ESP32 dependen de la resolución del timer. Los valores 26 y 77 corresponden aproximadamente a 0.5 ms y 2.5 ms con la frecuencia de 50 Hz. Siempre calibrar observando el movimiento real del servo.

## Límites mecánicos y protección del servo

Algunos servos físicamente no alcanzan los extremos completos de 0° y 180°. Forzar un servo contra su tope mecánico con la señal eléctrica activa consume corriente continuamente y calienta el motor. Si el proyecto requiere usar los extremos, probar primero con 10° y 170° en lugar de 0° y 180°.

Los servos también pueden dañarse si se los fuerza mecánicamente mientras están activos (intentar girar el eje a mano mientras el programa los mantiene en posición). Para manipular el servo sin programa activo, usar `miServo.detach()` antes.
