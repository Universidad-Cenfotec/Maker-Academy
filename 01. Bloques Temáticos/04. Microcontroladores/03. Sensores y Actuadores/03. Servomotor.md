Un servomotor es un motor que se puede mover a un **ángulo específico y quedarse ahí**. A diferencia de un motor DC normal que solo gira mientras recibe electricidad, el servo puede ir exactamente a 45°, a 90° o a 170° y mantenerse en esa posición. Eso lo convierte en el actuador ideal para brazos robóticos, puertas automáticas, timones de botes y cualquier proyecto que necesite movimiento preciso.


## Propósito

Documentar el uso de servomotores (SG90 y MG996R) para que los docentes puedan crear proyectos con movimiento preciso y controlado, como brazos robóticos o puertas automáticas.

---

## Tipos de servomotor

**Servo de posición (el más común en educación):** se mueve entre 0° y 180°. Al darle una orden de 90° va a esa posición y la sostiene aunque alguien intente moverlo con la mano.

**Servo de rotación continua:** modificado para girar indefinidamente. Se controla la velocidad y dirección, no el ángulo. Se usa en robots con ruedas pequeñas.

## Conexión a Arduino

```
SG90 (Marrón/GND) → GND de Arduino
SG90 (Rojo)       → 5V de Arduino
SG90 (Naranja)    → pin 9 de Arduino
```

Para uno o dos servos pequeños, la alimentación del Arduino es suficiente. Para más servos o servos más grandes, usar una fuente externa.

## Programa básico

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);   // conectado al pin 9
  miServo.write(90);   // posición central al inicio
}

void loop() {
  miServo.write(0);    // ir a 0°
  delay(1000);
  miServo.write(90);   // ir a 90° (centro)
  delay(1000);
  miServo.write(180);  // ir a 180°
  delay(1000);
}
```

Solo con `miServo.write(ángulo)` se controla la posición. La librería `Servo.h` hace todo el trabajo técnico internamente.

## Control con potenciómetro

Un potenciómetro (la perilla giratoria) permite controlar el servo manualmente, en tiempo real:

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);
}

void loop() {
  int lectura = analogRead(A0);                 // 0 a 1023
  int angulo  = map(lectura, 0, 1023, 0, 180); // convertir a 0°–180°
  miServo.write(angulo);
  delay(15);
}
```

Este es uno de los programas más didácticos: girar la perilla → el número cambia → el servo se mueve. La relación entre el mundo físico y el código se hace completamente visible.

## Movimiento suave (sin saltos bruscos)

En vez de ir directamente al ángulo destino, se puede mover gradualmente:

```cpp
#include <Servo.h>
Servo miServo;

void moverSuave(int inicio, int fin, int velocidad) {
  if (inicio < fin) {
    for (int a = inicio; a <= fin; a++) {
      miServo.write(a);
      delay(velocidad);
    }
  } else {
    for (int a = inicio; a >= fin; a--) {
      miServo.write(a);
      delay(velocidad);
    }
  }
}

void setup() { miServo.attach(9); }

void loop() {
  moverSuave(0, 180, 10);   // de 0° a 180° lentamente
  delay(500);
  moverSuave(180, 0, 10);   // volver a 0°
  delay(500);
}
```

## Ideas de proyectos

- **Barrera de estacionamiento:** el servo levanta un brazo cuando el sensor detecta un carro
- **Brazo robótico:** controlar la posición de un brazo con potenciómetros o botones
- **Ventilador de ángulo variable:** el servo gira un ventilador según la temperatura detectada
- **Personaje animatrónico:** mover partes de una figura con servos controlados desde el computador
- **Abrepuertas automático:** el servo gira una cerradura cuando se presiona un botón o se detecta proximidad

## Aplicación en Maker Academy

Se usa en proyectos que requieren movimiento angular preciso. Apropiado para primaria alta y secundaria. Permite crear garras, brazos, puertas y mecanismos con posición controlada.

## Nota docente

El servomotor es uno de los actuadores más fáciles de usar en educación porque la librería `Servo.h` abstrae toda la complejidad técnica. El estudiante solo escribe el ángulo y el servo va ahí.

El proyecto del control con potenciómetro es especialmente recomendado para introducir el concepto de **mapeo de rangos**: un número entre 0 y 1023 (lo que lee el potenciómetro) se convierte en un número entre 0 y 180 (los grados del servo). Es un concepto matemático concreto que se ve y se siente físicamente.

Un detalle práctico: algunos servos no llegan exactamente a 0° y 180°. Si el servo hace ruido en los extremos, probar con 10° y 170° en su lugar.
