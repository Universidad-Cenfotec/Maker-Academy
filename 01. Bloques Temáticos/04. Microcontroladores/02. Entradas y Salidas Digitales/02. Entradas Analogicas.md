# Entradas Analógicas y el ADC

![Diagrama conceptual de conversión analógico-digital, señal continua convertida a valores discretos](https://upload.wikimedia.org/wikipedia/commons/thumb/b/b3/Analog_digital_sar.gif/320px-Analog_digital_sar.gif)

El mundo físico es analógico: la temperatura sube y baja gradualmente, la luz cambia con la hora del día, el volumen de un sonido varía de forma continua. Un microcontrolador, en cambio, solo maneja números enteros. El ADC (Convertidor Analógico a Digital) es el traductor entre estos dos mundos.

---

## Qué hace el ADC

El ADC toma un voltaje entre 0 V y el voltaje de referencia (5 V en Arduino UNO, 3.3 V en micro:bit y ESP32) y lo convierte en un número entero. La cantidad de valores posibles depende de la resolución del ADC:

| Placa | Resolución ADC | Valores posibles | Voltaje por paso |
|---|---|---|---|
| Arduino UNO / Nano | 10 bits | 0 a 1023 | 4.9 mV |
| micro:bit | 10 bits | 0 a 1023 | 3.2 mV |
| ESP32 | 12 bits | 0 a 4095 | 0.8 mV |
| Circuit Playground Express | 12 bits | 0 a 4095 | 0.8 mV |

Un ADC de 10 bits divide el rango de voltaje en 1024 partes iguales. Si el voltaje de referencia es 5 V, cada "paso" representa 5/1024 ≈ 4.9 mV. Si la entrada tiene 2.5 V, el ADC devuelve 512.

---

## analogRead(): leer el ADC en Arduino

En Arduino, los pines analógicos se nombran A0, A1, A2... hasta A5 en el UNO. La lectura es una sola línea:

```cpp
int valor = analogRead(A0);  // devuelve 0 a 1023
```

No es necesario llamar a `pinMode()` para los pines analógicos cuando solo se leen. La conversión toma aproximadamente 0.1 ms, lo cual es relevante si se necesitan lecturas muy frecuentes.

## Potenciómetro: el sensor analógico más simple

Un potenciómetro es una resistencia variable con tres terminales: los dos extremos se conectan a VCC y GND, y el terminal central (cursor) produce un voltaje proporcional a la posición del eje. Es el divisor de tensión más fácil de usar en educación porque no requiere cálculos: girar el eje mueve el valor entre 0 y 1023.

```
VCC (5V)
  │
  ┤ ← terminal 1
  │
[POT 10kΩ]  ← el cuerpo del potenciómetro
  │
  ├─── cursor → A0 del Arduino
  │
  ┤ ← terminal 3
  │
GND
```

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  int posicion = analogRead(A0);
  Serial.println(posicion);
  delay(100);
}
```

El potenciómetro es el mejor primer sensor analógico para enseñar porque el estudiante puede ver directamente la relación entre el giro físico y el número en pantalla.

## Divisor de tensión para sensores resistivos

Muchos sensores del mundo real son resistencias que cambian su valor según una variable física: la LDR (luz), el termistor (temperatura), el sensor de humedad de suelo (conductividad). Para convertir una variación de resistencia en una variación de voltaje que el ADC pueda leer, se usa un divisor de tensión.

```
VCC (5V)
  │
[R_fija: 10kΩ]  ← resistencia conocida
  │
  ├─── A0 (punto de medición)
  │
[R_sensor]  ← LDR o termistor
  │
GND
```

El voltaje en el punto de medición es:

```
Vout = VCC × R_sensor / (R_fija + R_sensor)
```

Cuando la LDR recibe mucha luz, su resistencia baja (por ejemplo a 1 kΩ), y Vout es bajo. En oscuridad, la resistencia sube (hasta 100 kΩ o más) y Vout sube. El ADC convierte ese voltaje en un número entre 0 y 1023.

## La función map(): cambiar el rango de un valor

El valor crudo del ADC (0 a 1023) rara vez es el número útil para el programa. Puede interesar convertirlo en un ángulo de 0 a 180° para un servo, en un porcentaje de 0 a 100, o en un rango de colores de 0 a 255. La función `map()` hace esa conversión de forma lineal:

```cpp
int valorRaw = analogRead(A0);          // 0 a 1023
int angulo = map(valorRaw, 0, 1023, 0, 180);  // 0 a 180
int brillo = map(valorRaw, 0, 1023, 0, 255);  // 0 a 255
```

`map(valor, inMin, inMax, outMin, outMax)` hace una proporción lineal: si `valor` es la mitad de `inMax`, el resultado será la mitad de `outMax`. La función no verifica que el valor esté dentro del rango de entrada, por lo que si el sensor produce valores fuera del rango esperado, el resultado puede salirse del rango de salida. `constrain()` se usa junto con `map()` para mantener el resultado dentro de límites seguros:

```cpp
int brillo = map(valorRaw, 0, 1023, 0, 255);
brillo = constrain(brillo, 0, 255);  // garantiza que no salga del rango
```

## Ruido en lecturas analógicas

Los pines analógicos son sensibles a interferencias electromagnéticas. Un ADC de 10 bits puede mostrar variaciones de ±5 a ±15 unidades aunque el sensor esté completamente quieto, simplemente por el ruido eléctrico del ambiente y del propio microcontrolador.

Para datos más estables, se promedia varias lecturas seguidas:

```cpp
int leerPromedio(int pin, int muestras) {
  long suma = 0;
  for (int i = 0; i < muestras; i++) {
    suma += analogRead(pin);
    delay(2);
  }
  return suma / muestras;
}

void loop() {
  int valorFiltrado = leerPromedio(A0, 10);
  Serial.println(valorFiltrado);
}
```

Promediar 10 lecturas reduce el ruido significativamente sin introducir una latencia perceptible (10 × 2 ms = 20 ms adicionales por lectura).

## Entradas analógicas en micro:bit

El micro:bit expone pines analógicos en P0, P1 y P2 (los grandes con agujeros). En MicroPython:

```python
from microbit import *

while True:
    luz = pin0.read_analog()      # devuelve 0 a 1023
    display.scroll(str(luz))
    sleep(200)
```

El micro:bit también tiene un sensor de luz interno basado en la matriz de LEDs (que puede funcionar como fotodetector) y un termistor interno, accesibles con `display.read_light_level()` y `temperature()` sin necesidad de componentes externos.

## Entradas analógicas en ESP32

El ESP32 tiene ADC de 12 bits en los pines ADC1 (GPIO 32-39) y ADC2 (GPIO 0-21, pero ADC2 no funciona cuando WiFi está activo). En Arduino para ESP32:

```cpp
int valor = analogRead(34);  // pin GPIO34, ADC1
```

En MicroPython para ESP32:

```python
from machine import ADC, Pin

adc = ADC(Pin(34))
adc.atten(ADC.ATTN_11DB)   # rango hasta 3.3V
adc.width(ADC.WIDTH_12BIT) # resolución 12 bits (0-4095)

valor = adc.read()
```

El ESP32 tiene una no-linealidad conocida en los extremos del rango ADC. Para mediciones precisas se usa el modo de atenuación correcta y se aplica la curva de corrección de Espressif.
