El mundo físico es **analógico**: la temperatura sube y baja gradualmente, la luz cambia con la hora del día, el volumen de un sonido varía de forma continua. Un microcontrolador, en cambio, solo entiende números enteros. Las **entradas analógicas** son las que permiten capturar esa información del mundo real y convertirla en números que el programa puede usar.

## Propósito

Explicar el concepto de señales analógicas y la conversión analógico-digital (ADC) para que los docentes puedan enseñar a leer sensores de luz, temperatura y otros valores continuos.

---

## ¿Cómo funciona?

La placa tiene un componente interno llamado ADC (Convertidor Analógico-Digital) que mide el voltaje que llega al pin y lo convierte en un número:

| Placa | Valores posibles |
|---|---|
| Arduino UNO / Nano | 0 a 1023 |
| micro:bit | 0 a 1023 |
| ESP32 | 0 a 4095 |
| Circuit Playground Express | 0 a 4095 |

En Arduino, un voltaje de 0V da el número 0 y 5V da el número 1023. Si el voltaje es 2.5V (la mitad), el número es aproximadamente 512.

## El sensor analógico más simple: potenciómetro

Un potenciómetro (la perilla giratoria) convierte el giro físico en un voltaje que cambia. Es el mejor primer sensor analógico porque la relación es directa y visible: girar la perilla → el número cambia.

<img width="300" alt="Potenciómetro de 10kΩ con sus tres terminales y perilla giratoria" src="https://upload.wikimedia.org/wikipedia/commons/b/b5/Potentiometer.jpg" />

Conexión:
```
Terminal 1 (extremo) → 5V de Arduino
Terminal 2 (centro)  → A0 de Arduino (la señal)
Terminal 3 (extremo) → GND de Arduino
```

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  int posicion = analogRead(A0);  // devuelve 0 a 1023
  Serial.println(posicion);
  delay(100);
}
```

## analogRead(): leer un sensor analógico

En Arduino, la lectura de cualquier pin analógico es una sola línea:

```cpp
int valor = analogRead(A0);  // devuelve 0 a 1023
```

Los pines analógicos en Arduino UNO se llaman A0, A1, A2, A3, A4, A5.

---

## map(): convertir a otro rango

El número crudo del sensor (0–1023) casi nunca es lo que se necesita. La función `map()` convierte un rango en otro de forma proporcional:

```cpp
int lectura = analogRead(A0);                     // 0 a 1023
int angulo  = map(lectura, 0, 1023, 0, 180);      // convierte a 0–180° para servo
int brillo  = map(lectura, 0, 1023, 0, 255);      // convierte a 0–255 para LED
int porcentaje = map(lectura, 0, 1023, 0, 100);   // convierte a 0–100%
```

`map(valor, de_min, de_max, a_min, a_max)` es como una regla de tres: si el valor es la mitad del rango original, el resultado es la mitad del rango nuevo.

## Sensores resistivos: LDR y termistor

Muchos sensores del mundo real son resistencias que cambian su valor según una variable física:
- **LDR (fotorresistencia):** cambia con la luz
- **Termistor NTC:** cambia con la temperatura
- **Sensor de humedad de suelo:** cambia con el agua en el suelo

Para conectarlos se usa el mismo circuito simple (divisor de tensión) explicado en la ficha de Sensor de Luz.

---

## En micro:bit

Los pines P0, P1 y P2 del micro:bit pueden leer señales analógicas:

```python
from microbit import *

while True:
    valor = pin0.read_analog()     # devuelve 0 a 1023
    display.scroll(str(valor))
    sleep(200)
```

El micro:bit también tiene sensores internos que devuelven valores analógicos sin necesitar pines externos:
- `display.read_light_level()` → nivel de luz (0 a 255)
- `temperature()` → temperatura en Celsius

## Ruido en lecturas analógicas

Los sensores analógicos pueden mostrar pequeñas variaciones aunque el sensor esté completamente quieto. Esto es normal (se llama "ruido eléctrico"). Para datos más estables, se promedia varias lecturas:

```cpp
int leerEstable(int pin) {
  long suma = 0;
  for (int i = 0; i < 10; i++) {
    suma += analogRead(pin);
    delay(2);
  }
  return suma / 10;
}
```

## Ideas de proyectos

- **Termómetro visual:** leer la temperatura y mostrar el nivel en LEDs (más LEDs = más calor)
- **Control de brillo:** girar una perilla para controlar el brillo de un LED
- **Instrumento musical:** el tono del sonido cambia según la posición de la perilla
- **Indicador de batería:** medir el voltaje de una batería y mostrar el nivel
- **Agua en el suelo:** detectar si una planta necesita riego

## Nota docente

La gran idea conceptual detrás de las entradas analógicas es que **el mundo no es de solo sí/no**. Un botón dice sí o no, pero un sensor de temperatura dice exactamente cuánto calor hay. Eso abre la posibilidad de proyectos mucho más ricos.

El potenciómetro es el mejor punto de entrada porque el estudiante puede ver directamente la relación: giro la perilla → el número cambia → el servo se mueve (o el LED cambia de brillo). La cadena completa es visible y comprensible.

Para docentes que nunca han trabajado con esto: hacer primero el ejercicio del potenciómetro con el Monitor Serial abierto, sin ninguna lógica adicional. Solo mirar los números cambiar al girar la perilla ya es un momento de comprensión importante.
