El Monitor Serial es una ventana de texto que muestra mensajes enviados desde la placa al computador en tiempo real. Es la herramienta más valiosa para entender qué está pasando dentro de un programa: permite ver los valores de los sensores, confirmar que el programa está llegando a cierta parte del código y detectar errores sin necesidad de pantallas o LEDs adicionales.

**Imagínalo como el cuaderno de notas de la placa:** todo lo que quieras "ver" de lo que está pasando adentro, lo mandás al Monitor Serial con un `Serial.println()`.

## Propósito

Explicar el Monitor Serial como herramienta de depuración y comunicación para que los docentes puedan enseñar a visualizar datos del microcontrolador en tiempo real desde el computador.

---

## Activar el Monitor Serial en Arduino IDE

1. Abrir el Arduino IDE con el sketch cargado.
2. Clic en el ícono de lupa en la esquina superior derecha (o `Herramientas > Monitor Serie`).
3. Asegurarse de que la velocidad del Monitor Serial coincida con la del programa. Si el programa dice `Serial.begin(9600)`, el monitor debe estar en 9600 baudios.

---

## Configuración en el programa

```cpp
void setup() {
  Serial.begin(9600);  // iniciar la comunicación a 9600 baudios
}

void loop() {
  // ...
}
```

La velocidad (9600, 115200, etc.) tiene que ser la misma en el programa y en el Monitor Serial. Si no coinciden, se verán caracteres raros en la pantalla.

---

## Comandos básicos

| Comando | Qué hace |
|---|---|
| `Serial.print("texto")` | Muestra texto sin saltar a la siguiente línea |
| `Serial.println("texto")` | Muestra texto y salta a la siguiente línea |
| `Serial.print(variable)` | Muestra el valor de una variable |
| `Serial.println(variable)` | Muestra el valor y salta de línea |

## Usar el Monitor Serial para ver sensores

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(A0);
  int temperatura = analogRead(A1);
  
  Serial.print("Luz: ");
  Serial.print(luz);
  Serial.print("  |  Temperatura: ");
  Serial.println(temperatura);
  
  delay(200);
}
```

Esto mostraría en pantalla algo como:
```
Luz: 423  |  Temperatura: 312
Luz: 418  |  Temperatura: 315
Luz: 505  |  Temperatura: 311
```

## Serial Plotter: ver los datos como gráfica

El Arduino IDE 2.x tiene también un **Serial Plotter** que convierte los números del Monitor Serial en una gráfica en tiempo real. Es especialmente útil para ver cómo cambian los valores de sensores:

1. En el IDE, ir a `Herramientas > Serial Plotter`.
2. El programa debe enviar solo números con `Serial.println(valor)`.
3. La gráfica se actualiza automáticamente.

Tapar y destapar un sensor de luz mientras se mira el Serial Plotter es uno de los ejercicios más visuales para entender cómo funcionan los sensores analógicos.

## En micro:bit (MicroPython)

En MicroPython para micro:bit, la función `print()` envía mensajes al monitor serial del editor:

```python
from microbit import *

while True:
    luz = display.read_light_level()
    temp = temperature()
    
    print("Luz:", luz, "| Temperatura:", temp)
    sleep(500)
```

En el editor `python.microbit.org`, hay una consola serial en la parte inferior donde aparecen estos mensajes.

## Serial para depurar el programa

El Monitor Serial es especialmente útil cuando el programa no funciona como se espera. Agregar mensajes en puntos clave ayuda a entender qué está pasando:

```cpp
void loop() {
  int lectura = analogRead(A0);
  Serial.print("Leí: ");
  Serial.println(lectura);

  if (lectura > 500) {
    Serial.println("→ Condición activa");
    digitalWrite(13, HIGH);
  } else {
    Serial.println("→ Condición inactiva");
    digitalWrite(13, LOW);
  }
}
```

Si el LED no enciende y se esperaba que sí, los mensajes del Serial revelan si el problema está en la lectura del sensor o en la condición del `if`.

## Ideas de actividades con Monitor Serial

- **Explorar sensores:** conectar diferentes sensores y ver cómo cambian sus valores en distintas condiciones
- **Calibrar umbrales:** observar el rango de valores antes de escribir cualquier condición (¿cuánto vale "oscuro" en este salón?)
- **Depurar un robot:** entender por qué el robot no gira cuando se esperaba
- **Registrar datos:** anotar los valores que aparecen en el serial para un proyecto de ciencias

## Nota docente

El Monitor Serial es quizás la herramienta pedagógica más subutilizada en la enseñanza con Arduino. Los docentes tienden a saltar directo a los circuitos y el código, pero dedicar 10 minutos a explorar el Monitor Serial con cualquier sensor da a los estudiantes una comprensión mucho más sólida de lo que está pasando "adentro" del programa.

Una actividad muy efectiva para secundaria: dar a los estudiantes un sensor sin decirles qué mide, y pedirles que determinen qué hace basándose en los valores que ven en el Monitor Serial mientras interactúan con el sensor. Es una pequeña experiencia de "ciencia real".
