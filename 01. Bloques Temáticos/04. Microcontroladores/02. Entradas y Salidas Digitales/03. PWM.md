PWM (Pulse Width Modulation, en español: Modulación por Ancho de Pulso) es la técnica que usan los microcontroladores para simular voltajes intermedios cuando solo pueden producir señales de encendido o apagado.

**La idea clave:** si encendés y apagás algo muy rápido, el efecto es parecido a tenerlo a media potencia. Si está encendido el 50% del tiempo y apagado el otro 50%, el resultado es como si estuviera a la mitad.


## Propósito

Explicar la modulación por ancho de pulso (PWM) para que los docentes puedan enseñar a controlar la intensidad de LEDs, la velocidad de motores y la posición de servos.

---

## ¿Por qué es útil?

Un pin digital de Arduino solo puede estar en 0V (apagado) o 5V (encendido). Pero con PWM se puede lograr que un LED brille con distintas intensidades, o que un motor gire a diferentes velocidades. No es magia: el pin se enciende y apaga tan rápido (miles de veces por segundo) que el ojo humano o el motor no lo perciben como parpadeo, sino como un nivel constante.

---

## El ciclo de trabajo (duty cycle)

El **ciclo de trabajo** es qué porcentaje del tiempo está encendida la señal:

| Ciclo de trabajo | Efecto en un LED | Efecto en un motor |
|---|---|---|
| 0% | Apagado | Detenido |
| 25% | Brillo bajo | Velocidad baja |
| 50% | Brillo medio | Velocidad media |
| 75% | Brillo alto | Velocidad alta |
| 100% | Brillo máximo | Velocidad máxima |

---

## analogWrite(): usar PWM en Arduino

En Arduino, la función `analogWrite()` controla el PWM. El valor va de 0 (0%, apagado) a 255 (100%, encendido completo).

**Importante:** no todos los pines admiten PWM. En Arduino UNO, los pines con PWM están marcados con una tilde (`~`): son los pines 3, 5, 6, 9, 10 y 11.

```cpp
const int LED = 9;  // pin 9 tiene PWM

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  // efecto de respiración: el LED aumenta y disminuye el brillo gradualmente
  for (int brillo = 0; brillo <= 255; brillo++) {
    analogWrite(LED, brillo);
    delay(5);
  }
  for (int brillo = 255; brillo >= 0; brillo--) {
    analogWrite(LED, brillo);
    delay(5);
  }
}
```

## Controlar velocidad de motor con PWM

```cpp
const int ENA = 9;   // pin PWM conectado al driver L298N
const int IN1 = 7;
const int IN2 = 8;

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  
  // configurar dirección del motor
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
}

void loop() {
  // velocidad media
  analogWrite(ENA, 128);    // 50% de velocidad
  delay(2000);
  
  // velocidad máxima
  analogWrite(ENA, 255);    // 100% de velocidad
  delay(2000);
  
  // parar
  analogWrite(ENA, 0);
  delay(1000);
}
```

## PWM en micro:bit

El micro:bit también puede hacer PWM en sus pines de expansión:

```python
from microbit import *

# aumentar brillo de un LED externo gradualmente
while True:
    for brillo in range(0, 1024, 50):  # 0 a 1023
        pin0.write_analog(brillo)
        sleep(50)
    for brillo in range(1023, 0, -50):
        pin0.write_analog(brillo)
        sleep(50)
```

## ¿Dónde se usa PWM en proyectos reales?

- **Control de velocidad de motores:** el robot va más lento o más rápido según el número enviado
- **Brillo de LEDs:** desde completamente apagado hasta brillo máximo, pasando por cualquier nivel intermedio
- **Control de servomotores:** la librería Servo.h de Arduino usa PWM internamente (el docente no lo ve, pero es lo que ocurre)
- **Zumbido de buzzer:** un buzzer controlado con PWM produce diferentes tonos según la frecuencia

---

## Ideas de proyectos

- **Lámpara con atenuador:** girar una perilla cambia el brillo de la lámpara
- **Robot de velocidad variable:** los motores aceleran y desaceleran suavemente
- **Ventilador inteligente:** la velocidad del ventilador cambia según la temperatura
- **Indicador de nivel:** más LEDs encendidos a mayor brillo según un sensor

## Nota docente

PWM es un concepto que puede sonar complejo pero tiene una analogía muy cotidiana: **el dímmer de una lámpara**. El dímmer no cambia el voltaje que llega a la bombilla, sino que la enciende y apaga muy rápido. Si está encendida solo el 30% del tiempo, brilla al 30%.

Para enseñarlo en clase, el efecto de "respiración" del LED (que aumenta y disminuye el brillo gradualmente) es más llamativo y memorable que simplemente cambiar el brillo a un valor fijo. Los estudiantes inevitablemente preguntan "¿cómo lo hace?" y ese es el momento perfecto para explicar PWM.
