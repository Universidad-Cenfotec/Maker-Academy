# PWM: Modulación por Ancho de Pulso

![Diagrama de señal PWM con distintos ciclos de trabajo: 0%, 25%, 50%, 75%, 100%](https://upload.wikimedia.org/wikipedia/commons/thumb/b/b8/Duty_Cycle_Examples.png/640px-Duty_Cycle_Examples.png)

Los microcontroladores son dispositivos digitales: sus pines de salida solo pueden estar en HIGH o LOW. Pero muchas aplicaciones necesitan valores intermedios: un LED a mitad de brillo, un motor a 60% de velocidad, un servo en un ángulo específico. La solución es PWM: encender y apagar la señal digital tan rápido que el efecto promedio sea el de una señal intermedia.

---

## El principio del ciclo de trabajo

PWM mantiene la frecuencia de la señal constante y varía la duración del pulso en HIGH dentro de cada ciclo. Esa duración relativa se llama ciclo de trabajo (duty cycle):

```
Ciclo de trabajo = (tiempo en HIGH / período total) × 100%
```

Un ciclo de trabajo del 0% equivale a salida siempre en LOW (apagado total). Un ciclo de trabajo del 100% equivale a salida siempre en HIGH (encendido total). Un ciclo de trabajo del 50% equivale a la señal en HIGH la mitad del tiempo y en LOW la otra mitad.

La frecuencia en Arduino es típicamente 490 Hz o 980 Hz dependiendo del pin. A 490 Hz, un período completo dura 2.04 ms. Con 50% de duty cycle, el pin está en HIGH por 1.02 ms y en LOW por 1.02 ms. Un LED conectado a esa señal enciende y apaga 490 veces por segundo, demasiado rápido para que el ojo humano lo perciba como parpadeo: simplemente parece a la mitad de brillo.

## analogWrite(): generar PWM en Arduino

En Arduino, la función `analogWrite()` genera una señal PWM en los pines que soportan esta función. Esos pines se identifican con el símbolo `~` en la placa:

| Arduino UNO / Nano | Pines PWM |
|---|---|
| Pines con ~ | 3, 5, 6, 9, 10, 11 |
| Resolución | 8 bits (valores 0 a 255) |
| Frecuencia | 490 Hz (pines 3, 9, 10, 11) o 980 Hz (pines 5, 6) |

```cpp
void setup() {
  pinMode(9, OUTPUT);
}

void loop() {
  analogWrite(9, 0);    // 0% duty cycle → apagado
  delay(1000);
  analogWrite(9, 127);  // ~50% duty cycle → mitad de brillo
  delay(1000);
  analogWrite(9, 255);  // 100% duty cycle → brillo máximo
  delay(1000);
}
```

## Efecto fade: variar el brillo gradualmente

El fade de un LED es la primera demostración visual del PWM. Se usa un bucle para aumentar y disminuir el valor de 0 a 255 y de vuelta:

```cpp
void loop() {
  // aumentar brillo
  for (int brillo = 0; brillo <= 255; brillo++) {
    analogWrite(9, brillo);
    delay(10);  // 10 ms por paso → 2.55 s para ir de 0 a 255
  }
  // disminuir brillo
  for (int brillo = 255; brillo >= 0; brillo--) {
    analogWrite(9, brillo);
    delay(10);
  }
}
```

Este es el ejemplo "Fade" incluido en Arduino IDE (Archivo > Ejemplos > Basics > Fade).

## Control de velocidad de motor DC con PWM

Un motor DC gira más rápido cuando recibe más voltaje. Con PWM se puede variar la velocidad efectiva cambiando el duty cycle. Si el motor está conectado a través de un transistor o driver L298N, la señal PWM va al pin de habilitación del driver:

```cpp
int velocidad = 0;  // 0 a 255

void loop() {
  // acelerar gradualmente
  for (velocidad = 0; velocidad <= 200; velocidad += 5) {
    analogWrite(9, velocidad);  // pin ENA del L298N
    delay(50);
  }
  delay(2000);
  // frenar
  analogWrite(9, 0);
  delay(1000);
}
```

Conectar un motor directamente al pin PWM del Arduino sin driver destruirá el microcontrolador. El driver es obligatorio.

## Servomotor: PWM con frecuencia específica

Los servomotores usan PWM de 50 Hz (período de 20 ms), pero no responden al duty cycle genérico: responden a la duración del pulso en microsegundos. Un pulso de 1000 µs mueve el servo a 0°, uno de 1500 µs lo lleva a 90°, y uno de 2000 µs lo lleva a 180°.

La librería `Servo.h` de Arduino abstrae completamente este mecanismo:

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);  // cualquier pin digital (no solo los ~)
}

void loop() {
  miServo.write(0);    // mover a 0 grados
  delay(1000);
  miServo.write(90);   // mover a 90 grados
  delay(1000);
  miServo.write(180);  // mover a 180 grados
  delay(1000);
}
```

Cuando se usa la librería Servo en Arduino UNO, los pines 9 y 10 dejan de generar PWM estándar (no se puede usar `analogWrite()` en esos pines mientras Servo esté activo).

## Control de servo con potenciómetro

La combinación potenciómetro + servo es uno de los proyectos más didácticos del bloque. Muestra en tiempo real la conversión analógico-digital-PWM:

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);
}

void loop() {
  int lectura = analogRead(A0);              // 0 a 1023
  int angulo  = map(lectura, 0, 1023, 0, 180);  // 0 a 180
  miServo.write(angulo);
  delay(15);  // dar tiempo al servo para moverse
}
```

## tone(): PWM para sonido

La función `tone(pin, frecuencia)` genera una señal cuadrada al 50% de duty cycle en la frecuencia especificada. Es suficiente para hacer sonar un buzzer piezoeléctrico pasivo:

```cpp
void loop() {
  tone(8, 262);   // Do (C4) = 262 Hz
  delay(500);
  tone(8, 294);   // Re (D4) = 294 Hz
  delay(500);
  tone(8, 330);   // Mi (E4) = 330 Hz
  delay(500);
  noTone(8);      // silencio
  delay(500);
}
```

El buzzer activo (que tiene oscilador integrado) solo necesita HIGH/LOW para sonar, mientras que el buzzer pasivo requiere la señal de frecuencia variable que `tone()` genera.

## PWM en micro:bit

En MicroPython para micro:bit, los pines analógicos escribibles soportan PWM:

```python
from microbit import *

while True:
    for brillo in range(0, 1024, 10):
        pin0.write_analog(brillo)  # 0 a 1023 en micro:bit
        sleep(10)
    for brillo in range(1023, -1, -10):
        pin0.write_analog(brillo)
        sleep(10)
```

El micro:bit usa una escala de 0 a 1023 para `write_analog()`, a diferencia de Arduino que usa 0 a 255.

## PWM en ESP32

El ESP32 tiene un controlador LEDC (LED Control) que permite configurar la frecuencia y resolución de cada canal PWM de forma independiente, hasta 16 canales simultáneos:

```cpp
// ESP32 con Arduino IDE
int canal = 0;
int frecuencia = 5000;  // 5 kHz
int resolucion = 8;     // 8 bits, valores 0 a 255

void setup() {
  ledcSetup(canal, frecuencia, resolucion);
  ledcAttachPin(16, canal);  // pin GPIO16
}

void loop() {
  for (int dc = 0; dc <= 255; dc++) {
    ledcWrite(canal, dc);
    delay(10);
  }
}
```

Esta flexibilidad hace al ESP32 ideal para proyectos que necesitan múltiples motores o LEDs con control fino de frecuencia.
