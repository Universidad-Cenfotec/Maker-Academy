## Descripción

Guía el uso de MakeCode, entorno de programación por bloques en el navegador, como primera herramienta de código para micro:bit y Circuit Playground.

---

## Propósito

Guiar a los docentes en el uso de MakeCode con micro:bit para introducir la programación por bloques a estudiantes sin experiencia previa en programación.

---

## ¿Qué es MakeCode?

MakeCode es un entorno de programación visual desarrollado por Microsoft que funciona **directamente en el navegador**, sin instalar nada. Se programa arrastrando y conectando bloques de colores, igual que un rompecabezas. Antes de conectar cualquier placa física, se puede probar el programa en un simulador en pantalla.

Es la herramienta principal para empezar a programar la micro:bit y el Circuit Playground Express.

## ¿Cómo entrar?

- micro:bit: `makecode.microbit.org`
- Circuit Playground: `makecode.adafruit.com`

No necesita cuenta ni instalación. Solo un navegador y conexión a internet.

## La pantalla de MakeCode

La interfaz tiene tres partes:

**Izquierda — Simulador:** muestra una representación virtual de la placa. Cada vez que se cambia un bloque, el simulador actualiza el comportamiento automáticamente. Se puede probar el programa sin tener la placa física.

**Centro — Categorías de bloques:** bloques organizados por colores y temas. Los más usados para empezar son:
- **Básico** (azul): mostrar texto e imágenes en la pantalla de LEDs
- **Entrada** (dorado): detectar botones, sacudidas, temperatura
- **Lógica** (verde): si/entonces, comparaciones
- **Variables** (naranja): guardar y cambiar datos
- **Bucles** (verde oscuro): repetir instrucciones

**Derecha — Área de trabajo:** donde se construye el programa arrastrando bloques del centro.

## Primer programa: mostrar texto al presionar un botón

```
al presionar botón A →
    mostrar cadena "¡Hola!"
```

**Pasos:**
1. De la categoría "Entrada", arrastrar el bloque "al presionar botón A" al área de trabajo.
2. De la categoría "Básico", arrastrar "mostrar cadena" y soltarlo dentro del bloque de arriba.
3. Escribir "¡Hola!" en el campo de texto.
4. El simulador muestra el texto desplazándose cuando se hace clic en el botón A virtual.

## Variables y lógica: contador de presiones

```
al iniciar →
    establecer [contador] a 0

al presionar botón A →
    cambiar [contador] en 1
    mostrar número [contador]

al presionar botón B →
    establecer [contador] a 0
    mostrar número 0
```

Este programa enseña tres conceptos clave:
- **Variable** (`contador`): un cajón donde se guarda un número que puede cambiar
- **Evento** ("al presionar"): el programa reacciona cuando ocurre algo
- **Acumulación**: el número crece cada vez que se presiona A

## Bucle con sensor: reaccionar a la temperatura

```
para siempre →
    si temperatura > 25 →
        mostrar imagen (🌡️ alta)
    si no →
        mostrar imagen (❄️ fría)
    esperar 1000 ms
```

Este ejemplo conecta un sensor real (el termómetro interno de la micro:bit) con una decisión del programa. No necesita ningún componente externo.

## Ver el código en texto

En cualquier momento se puede hacer clic en "JavaScript" (en la parte superior del editor) para ver el código equivalente en texto. Esto sirve para:
- Que los estudiantes vean que los bloques son "la misma cosa" que el código de texto
- Comenzar la transición hacia MicroPython de forma gradual
- Copiar el código si alguien quiere profundizar más

---

## Transferir el programa a la placa

1. Conectar la micro:bit o Circuit Playground por USB.
2. Hacer clic en "Descargar" (flecha hacia abajo).
3. Se descarga un archivo (`.hex` para micro:bit, `.uf2` para Circuit Playground).
4. Copiar ese archivo a la unidad que aparece en el computador (como si fuera un pendrive).
5. La placa parpadea brevemente y ejecuta el programa.

## Nota docente

MakeCode tiene una característica muy valiosa: **el simulador funciona en tiempo real**. Esto significa que el docente puede demostrar un programa en proyector sin tener la placa física, y los estudiantes pueden probar sus ideas aunque no tengan placa ese día.

Para grupos sin ninguna experiencia: empezar con el bloque "al presionar botón A → mostrar cadena [nombre]". La satisfacción de ver su nombre apareciendo en la pantalla en la primera sesión es el mejor gancho para continuar.

Si un estudiante tiene problemas con el español, MakeCode está disponible en muchos idiomas incluyendo inglés, y los bloques tienen el mismo significado.
