## Descripción

Explica, desde cero, cómo un programa toma decisiones (`if` / `else`) y cómo repite acciones (`for` / `while`), con ejemplos aplicables a cualquier sensor o actuador.

---

## Propósito

Leer un sensor no sirve de mucho si el programa no puede **decidir** qué hacer con ese número, ni **repetir** la lectura una y otra vez. Estos dos conceptos —decidir y repetir— son la base de prácticamente todo programa de microcontroladores: encender un LED si está oscuro, mover un motor mientras no haya un obstáculo, sonar una alarma si la temperatura sube demasiado.

---

## Condicionales: tomar decisiones con `if` / `else`

Un condicional le dice al programa: "si se cumple esta condición, hacé esto; si no, hacé otra cosa". Es exactamente la misma lógica que se usa al hablar: "si llueve, llevo paraguas; si no, no lo llevo".

```cpp
if (luz < umbral) {
  // esto se ejecuta SOLO si la condición es verdadera
  digitalWrite(PIN_LED, HIGH);   // enciende el LED porque está oscuro
} else {
  // esto se ejecuta cuando la condición es falsa
  digitalWrite(PIN_LED, LOW);    // apaga el LED porque hay suficiente luz
}
```

La misma lógica en Python:

```python
if luz < umbral:
    pin_led.write_digital(1)   # enciende el LED porque está oscuro
else:
    pin_led.write_digital(0)   # apaga el LED porque hay suficiente luz
```

### Operadores de comparación

Para construir una condición se necesita comparar dos valores. Estos son los operadores más usados en proyectos de sensores:

| Operador | Significado | Ejemplo |
|---|---|---|
| `<` | menor que | `luz < 400` |
| `>` | mayor que | `distancia > 20` |
| `<=` | menor o igual que | `bateria <= 10` |
| `>=` | mayor o igual que | `temperatura >= 30` |
| `==` | igual a (comparar, no asignar) | `boton == 1` |
| `!=` | distinto de | `estado != 0` |

> **Nota para docentes:** `==` (dos signos igual) compara dos valores. `=` (un solo signo igual) asigna un valor a una variable. Confundir ambos es uno de los errores más comunes al empezar a programar, y el programa no siempre avisa del error de forma clara.

### Condicionales con varias opciones: `else if`

Cuando hay más de dos posibles resultados, se encadenan varios `else if`:

```cpp
if (distancia < 10) {
  Serial.println("Muy cerca");        // primera opción: distancia menor a 10 cm
} else if (distancia < 30) {
  Serial.println("Cerca");            // segunda opción: entre 10 y 30 cm
} else {
  Serial.println("Lejos");            // opción por defecto: 30 cm o más
}
```

## Bucles: repetir acciones con `while` y `for`

Un bucle repite un bloque de código sin tener que copiarlo muchas veces.

### `while`: repetir mientras se cumpla una condición

```cpp
while (distancia > 5) {
  moverAdelante();     // seguí avanzando mientras no haya nada cerca
  distancia = leerSensor();  // volvé a medir la distancia en cada vuelta
}
```

El `loop()` de Arduino y el `while True:` de Python son, en el fondo, un bucle que se repite todo el tiempo que la placa esté encendida:

```cpp
void loop() {
  // todo lo que está aquí adentro se repite para siempre
}
```

```python
while True:
    # todo lo que está aquí adentro (con la misma indentación) se repite para siempre
    pass
```

### `for`: repetir un número exacto de veces

Cuando se sabe exactamente cuántas veces hay que repetir algo, `for` es más claro que `while`:

```cpp
for (int i = 0; i < 5; i++) {
  digitalWrite(PIN_LED, HIGH);   // encendé el LED
  delay(200);                     // esperá 200 ms
  digitalWrite(PIN_LED, LOW);    // apagá el LED
  delay(200);                     // esperá 200 ms
}
// este bloque hace parpadear el LED exactamente 5 veces y después continúa el programa
```

En Python, la forma equivalente es:

```python
for i in range(5):          # repetir 5 veces (i toma los valores 0, 1, 2, 3, 4)
    pin_led.write_digital(1)  # encender el LED
    sleep(200)                # esperar 200 ms
    pin_led.write_digital(0)  # apagar el LED
    sleep(200)                # esperar 200 ms
```

## Ejemplo progresivo: alarma de distancia con condicionales y bucle

Este ejemplo combina condicionales y bucles usando un sensor de distancia genérico, con cada línea comentada:

```cpp
const int PIN_TRIG = 9;      // pin que envía el pulso ultrasónico
const int PIN_ECHO = 10;     // pin que recibe el eco de vuelta
const int UMBRAL_CM = 15;    // distancia mínima segura, en centímetros

void setup() {
  pinMode(PIN_TRIG, OUTPUT);  // configuramos el pin de disparo como salida
  pinMode(PIN_ECHO, INPUT);   // configuramos el pin de eco como entrada
  Serial.begin(9600);         // iniciamos el Monitor Serial
}

void loop() {
  long duracion;
  int distanciaCm;

  digitalWrite(PIN_TRIG, LOW);   // aseguramos que el pin de disparo empiece apagado
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);  // enviamos el pulso ultrasónico
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);   // terminamos el pulso

  duracion = pulseIn(PIN_ECHO, HIGH);   // medimos cuánto tardó en volver el eco
  distanciaCm = duracion / 58;          // convertimos el tiempo a centímetros

  if (distanciaCm < UMBRAL_CM) {
    // si algo está demasiado cerca, avisamos varias veces con un bucle for
    for (int i = 0; i < 3; i++) {
      Serial.println("¡Objeto cerca!");   // repetimos el aviso 3 veces
      delay(150);
    }
  } else {
    Serial.println("Camino libre");       // si no hay nada cerca, avisamos una sola vez
  }

  delay(300);   // esperamos antes de volver a medir
}
```
