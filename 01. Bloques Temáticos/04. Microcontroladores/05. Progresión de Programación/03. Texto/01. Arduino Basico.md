## Descripción

El lenguaje Arduino es una simplificación de C++ diseñada para hacer accesible la programación de microcontroladores. Elimina muchas complejidades de C++ estándar (como la gestión manual de memoria) mientras conserva la estructura que lo hace tan eficiente: tipado estático, compilación a código máquina y acceso directo al hardware.

Un programa Arduino (llamado "sketch") es un archivo de texto con extensión `.ino` que siempre tiene la misma estructura mínima: dos funciones obligatorias.

---

## Estructura mínima de un sketch

```cpp
// setup() se ejecuta una sola vez al encender o resetear la placa
void setup() {
  // Aquí se configuran los pines y se inicia la comunicación
}

// loop() se ejecuta indefinidamente, en un bucle sin fin
void loop() {
  // Aquí va el comportamiento principal del programa
}
```

Analogía: `setup()` es como preparar la cocina antes de empezar a cocinar (configurar, encender cosas, acomodar materiales). `loop()` es el proceso de cocinar que se repite: la cocina está funcionando mientras alguien trabaje en ella.

## Tipos de datos

```cpp
int numero = 42;           // entero (de -32768 a 32767 en Arduino)
long numeroGrande = 100000;// entero largo
float decimal = 3.14;      // número con decimales
bool bandera = true;       // verdadero o falso
char letra = 'A';          // un solo carácter
String texto = "Hola";    // cadena de caracteres
```

En C++, el tipo de dato se declara junto con la variable y no puede cambiar. `int distancia = "lejos";` es un error de tipo.

## Estructura de control: if / else

```cpp
int temperatura = analogRead(A0);

if (temperatura > 500) {
  digitalWrite(13, HIGH);  // encender LED si hay calor
} else {
  digitalWrite(13, LOW);   // apagar LED si no hay calor
}
```

Las llaves `{ }` delimitan el bloque de código que pertenece a cada rama. Olvidar las llaves y tener más de una instrucción en la rama es un error frecuente y difícil de detectar.

## Bucles

```cpp
// for: repetir un número definido de veces
for (int i = 0; i < 5; i++) {
  digitalWrite(13, HIGH);
  delay(200);
  digitalWrite(13, LOW);
  delay(200);
}

// while: repetir mientras la condición sea verdadera
int contador = 0;
while (contador < 10) {
  Serial.println(contador);
  contador++;
}
```

## Funciones personalizadas

Las funciones permiten agrupar instrucciones con un nombre y reutilizarlas:

```cpp
// Definición de la función (puede ir antes o después de setup/loop)
void parpadear(int veces, int velocidad) {
  for (int i = 0; i < veces; i++) {
    digitalWrite(13, HIGH);
    delay(velocidad);
    digitalWrite(13, LOW);
    delay(velocidad);
  }
}

void loop() {
  parpadear(3, 100);   // parpadear 3 veces rápido
  delay(1000);
  parpadear(1, 500);   // parpadear 1 vez lento
  delay(1000);
}
```

## Funciones con valor de retorno

```cpp
// Función que devuelve la distancia en cm
float medirDistancia() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  long duracion = pulseIn(pinEcho, HIGH);
  return duracion / 58.0;  // devolver el valor calculado
}

void loop() {
  float distancia = medirDistancia();  // recibir el valor devuelto
  Serial.println(distancia);
}
```

## Variables globales vs. locales

```cpp
int contador = 0;  // variable global: existe en todo el programa

void loop() {
  int local = 5;   // variable local: solo existe dentro de loop()
  contador++;      // modificar variable global
  // local existe solo aquí, desaparece al terminar loop()
}
```

Una variable global se declara fuera de cualquier función. Una variable local se declara dentro de una función y desaparece al terminar esa función. El estado que debe persistir entre ejecuciones del loop debe guardarse en variables globales.

## Manejo de tiempo sin delay()

`delay()` detiene completamente el programa. Si se necesita hacer varias cosas al mismo tiempo (medir sensor Y parpadear LED simultáneamente), hay que usar `millis()`:

```cpp
unsigned long ultimoTiempo = 0;
int intervalo = 500;

void loop() {
  unsigned long ahora = millis();
  
  if (ahora - ultimoTiempo >= intervalo) {
    ultimoTiempo = ahora;
    // hacer la acción periódica aquí
    digitalWrite(13, !digitalRead(13));  // alternar LED
  }
  
  // Este código se ejecuta en cada ciclo del loop, sin bloquearse
  int sensor = analogRead(A0);
}
```

## Librerías: extender las capacidades

```cpp
#include <Servo.h>       // para servomotores
#include <Wire.h>        // para comunicación I2C
#include <NewPing.h>     // para sensor ultrasónico HC-SR04

// Instalar librerías de terceros:
// Arduino IDE > Herramientas > Gestionar librerías > buscar el nombre
```

Las librerías son código ya escrito por otros que se puede usar directamente. Importar una librería es como contratar a un especialista: no hay que saber cómo está implementado internamente, solo saber cómo usarlo.

## Notas docentes

El error de compilación más frecuente en primeras sesiones es el punto y coma faltante: `expected ';' before '}'`. El IDE resalta la línea donde detectó el error, pero el punto y coma faltante puede estar en la línea anterior. Enseñar a los estudiantes a leer el número de línea del error y revisar las dos líneas anteriores a ese número suele resolver el 80% de los errores de sintaxis.

Una convención útil para establecer desde el principio: comentar cada función con una línea que describa qué hace. `// Lee la distancia del sensor ultrasónico y la devuelve en cm`. Esa disciplina de documentación tiene un valor enorme cuando el proyecto crece.
