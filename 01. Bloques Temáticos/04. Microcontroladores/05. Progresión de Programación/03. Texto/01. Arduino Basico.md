## ¿Qué es el lenguaje Arduino?

Arduino usa una versión simplificada del lenguaje C++. No es necesario conocer C++ profesional: el lenguaje de Arduino está diseñado para ser accesible y tiene muchas funciones ya listas para usar con sensores, LEDs y motores.

Un programa Arduino se llama **sketch** y siempre tiene la misma estructura básica de dos funciones.

---

## La estructura de todo programa Arduino

```cpp
// Esto se ejecuta UNA SOLA VEZ al encender la placa
void setup() {
  // Aquí se configuran pines y se inicia la comunicación
}

// Esto se repite PARA SIEMPRE, sin parar
void loop() {
  // Aquí va el comportamiento principal del programa
}
```

**Analogía para docentes:** `setup()` es como preparar el salón antes de clase (una sola vez). `loop()` es la clase misma, que se repite día a día indefinidamente.

## Variables: guardar información

```cpp
int edad = 15;              // número entero
float temperatura = 24.5;   // número con decimales
bool encendido = true;      // verdadero (true) o falso (false)
String nombre = "María";    // texto
```

A diferencia de Scratch o MakeCode, en Arduino hay que indicar **qué tipo de dato** va en la variable antes de usarla.

## Tomar decisiones: if / else

```cpp
int luz = analogRead(A0);  // leer sensor de luz

if (luz < 300) {
  digitalWrite(13, HIGH);   // oscuro → encender LED
} else {
  digitalWrite(13, LOW);    // hay luz → apagar LED
}
```

Las llaves `{ }` delimitan qué instrucciones pertenecen a cada caso. Es el error más común en principiantes: olvidar una llave de cierre `}`.

---

## Repetir instrucciones: bucles

```cpp
// Repetir exactamente 5 veces
for (int i = 0; i < 5; i++) {
  digitalWrite(13, HIGH);
  delay(200);
  digitalWrite(13, LOW);
  delay(200);
}

// Repetir mientras una condición sea verdadera
while (digitalRead(2) == HIGH) {
  // hace esto mientras el botón esté suelto
}
```

El `for` se usa cuando se sabe cuántas veces repetir. El `while` cuando se repite según una condición.

---

## Funciones: organizar el código

```cpp
// Definir la función
void parpadear(int veces) {
  for (int i = 0; i < veces; i++) {
    digitalWrite(13, HIGH);
    delay(300);
    digitalWrite(13, LOW);
    delay(300);
  }
}

// Usar la función
void loop() {
  parpadear(3);   // parpadea 3 veces
  delay(1000);
  parpadear(5);   // parpadea 5 veces
  delay(1000);
}
```

Las funciones permiten reutilizar código y mantener el programa organizado. En lugar de repetir las mismas 5 líneas 10 veces, se escribe una función y se llama.

## Programa completo: termómetro con alerta

```cpp
const int LED_ROJO  = 13;
const int LED_VERDE = 12;
const int UMBRAL    = 30;  // grados Celsius

void setup() {
  pinMode(LED_ROJO, OUTPUT);
  pinMode(LED_VERDE, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Leer temperatura (sensor LM35 conectado a A0)
  int lectura = analogRead(A0);
  float temperatura = lectura * 0.488;  // conversión para LM35 a 5V

  Serial.print("Temperatura: ");
  Serial.print(temperatura);
  Serial.println(" °C");

  if (temperatura > UMBRAL) {
    digitalWrite(LED_ROJO, HIGH);
    digitalWrite(LED_VERDE, LOW);
    Serial.println("¡Alerta: temperatura alta!");
  } else {
    digitalWrite(LED_ROJO, LOW);
    digitalWrite(LED_VERDE, HIGH);
  }

  delay(1000);
}
```

## Del simulador al código: diferencias con MakeCode

| MakeCode (bloques) | Arduino (texto) |
|---|---|
| "establecer [luz] a 0" | `int luz = 0;` |
| "si [luz] > 300 entonces" | `if (luz > 300) {` |
| "mostrar número [luz]" | `Serial.println(luz);` |
| "esperar 1000 ms" | `delay(1000);` |

El concepto es el mismo; solo cambia la forma de escribirlo. Los estudiantes que ya manejan MakeCode tienen ventaja porque ya entienden la lógica; solo necesitan aprender la sintaxis.

---

## Errores comunes y cómo solucionarlos

| Error | Causa probable | Solución |
|---|---|---|
| "expected ';'" | Olvidó el punto y coma al final de la línea | Agregar `;` al final |
| "was not declared in this scope" | Variable usada sin declararla | Declarar la variable antes de usarla |
| "'analogRead' was not declared" | Función escrita incorrectamente | Verificar mayúsculas/minúsculas |
| El programa compila pero no carga | Puerto COM incorrecto | Verificar en Herramientas > Puerto |

## Nota docente

La transición de bloques a texto suele generar ansiedad en los estudiantes porque "el programa puede estar mal escrito" y aparecen mensajes de error en rojo. Es importante normalizar los errores como parte del proceso: incluso programadores profesionales tienen errores de sintaxis constantemente.

Una estrategia efectiva para la transición: mostrar el mismo programa primero en MakeCode (bloques) y luego hacer clic en "JavaScript" para ver el código equivalente. Luego reproducir ese código en Arduino IDE. El estudiante ve que el código "dice lo mismo" que los bloques, solo con diferente forma.

Para grupos de secundaria sin experiencia previa en programación de texto: dedicar la primera sesión solo a entender la estructura setup/loop y hacer parpadear el LED integrado. No agregar sensores ni lógica hasta que todos dominen ese primer paso.
