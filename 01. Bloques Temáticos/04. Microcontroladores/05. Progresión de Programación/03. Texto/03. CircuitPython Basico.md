## Descripción

CircuitPython es una variante de MicroPython mantenida y desarrollada por Adafruit, diseñada específicamente para maximizar la facilidad de uso en contextos educativos. Su diferencia más práctica respecto a MicroPython: la placa aparece como unidad de disco cuando se conecta por USB, y cualquier cambio guardado en el archivo `code.py` se ejecuta inmediatamente sin ningún proceso de carga.

Eso elimina completamente la fricción del ciclo editar-compilar-cargar-probar. El flujo es: editar → guardar → ver resultado. Para estudiantes que se frustran con los pasos de carga de Arduino, esto es transformador.

## Flujo de trabajo

1. Conectar la placa por USB. Aparece como unidad de disco llamada `CIRCUITPY`.
2. Abrir el archivo `code.py` en la unidad (con cualquier editor de texto, Mu Editor recomendado).
3. Escribir o modificar el código.
4. Guardar el archivo (Ctrl+S).
5. La placa reinicia automáticamente y ejecuta el nuevo código en segundos.

No hay que instalar ningún IDE especial. Funciona con el Bloc de Notas de Windows o con TextEdit de Mac si es necesario.

## Hola mundo: LEDs NeoPixel (Circuit Playground)

```python
import board
import neopixel
import time

# Los 10 LEDs del Circuit Playground están en el pin NEOPIXEL
pixels = neopixel.NeoPixel(board.NEOPIXEL, 10, brightness=0.3)

while True:
    pixels.fill((255, 0, 0))   # rojo
    time.sleep(0.5)
    pixels.fill((0, 255, 0))   # verde
    time.sleep(0.5)
    pixels.fill((0, 0, 255))   # azul
    time.sleep(0.5)
```

## Pines en CircuitPython

En lugar de números de pin, CircuitPython usa nombres descriptivos del módulo `board`:

```python
import board
import digitalio

# LED integrado del Circuit Playground
led = digitalio.DigitalInOut(board.LED)
led.direction = digitalio.Direction.OUTPUT

# Botón A del Circuit Playground
boton_a = digitalio.DigitalInOut(board.BUTTON_A)
boton_a.direction = digitalio.Direction.INPUT
boton_a.pull = digitalio.Pull.DOWN

while True:
    if boton_a.value:          # True si el botón está presionado
        led.value = True
    else:
        led.value = False
```

## Sensor de luz (Circuit Playground)

```python
import board
import analogio
import time

sensor_luz = analogio.AnalogIn(board.LIGHT)

while True:
    valor = sensor_luz.value      # 0 a 65535 (16 bits en CircuitPython)
    porcentaje = (valor / 65535) * 100
    print(f"Luz: {porcentaje:.1f}%")
    time.sleep(0.2)
```

Nota: CircuitPython usa 16 bits (0 a 65535) para lecturas analógicas, a diferencia de Arduino (10 bits, 0 a 1023) o MicroPython (12 bits, 0 a 4095). Tener esto en cuenta al calcular umbrales.

## Ventana de comunicación serial: la consola de Mu Editor

Mu Editor incluye una consola serial que muestra la salida de `print()` en tiempo real. También permite interactuar con el REPL de CircuitPython. Descarga: `codewith.mu`.

Acceder al REPL de CircuitPython: en la consola de Mu Editor, presionar `Ctrl+C` para interrumpir el programa en ejecución y entrar al modo REPL interactivo. `Ctrl+D` reinicia el programa.

## Librerías de Adafruit

Adafruit mantiene una biblioteca de librerías para CircuitPython que cubre cientos de sensores y módulos. Las librerías se copian manualmente a la carpeta `lib` de la unidad `CIRCUITPY`.

Ejemplo: para usar la librería de la pantalla OLED:
1. Descargar el Bundle de librerías de CircuitPython desde `circuitpython.org/libraries`.
2. Copiar `adafruit_ssd1306.mpy` y `adafruit_framebuf.mpy` a la carpeta `lib` de la unidad `CIRCUITPY`.
3. Importar en el código: `import adafruit_ssd1306`.

## Diferencias con MicroPython estándar

| Aspecto | CircuitPython | MicroPython |
|---|---|---|
| Módulo de pines | `board`, `digitalio`, `analogio` | `machine.Pin`, `machine.ADC` |
| Unidad de disco | Sí (CIRCUITPY) | No (requiere herramienta de carga) |
| Soporte de NeoPixel | Módulo `neopixel` incluido | Requiere módulo adicional |
| Actualización de código | Guardar el archivo, carga automática | Requiere herramienta (Thonny, ampy) |
| Compatibilidad MicroPython | Parcial (misma sintaxis, módulos distintos) | Estándar MicroPython |
| Plataformas soportadas | Adafruit y algunas más | Más amplias (ESP32, ESP8266, RP2040, etc.) |

## Notas docentes

CircuitPython es probablemente la opción con menor fricción técnica para introducir programación en texto. El ciclo de editar-guardar-ver resultado sin pasos de carga es especialmente valioso en grupos que trabajan con laptops de distintos sistemas operativos, donde los drivers USB de Arduino pueden ser problemáticos.

El único punto de fricción es la gestión manual de librerías (copiar archivos a la unidad). Una solución: preparar una imagen de la tarjeta con las librerías más comunes ya instaladas, y distribuirla al grupo antes de la sesión.
