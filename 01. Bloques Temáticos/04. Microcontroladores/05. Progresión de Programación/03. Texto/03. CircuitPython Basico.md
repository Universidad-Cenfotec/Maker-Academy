## ¿Qué es CircuitPython?

CircuitPython es una versión de Python creada por Adafruit, diseñada específicamente para hacer la programación de microcontroladores lo más sencilla posible. Se usa en el Circuit Playground Express/Bluefruit y en la **IdeaBoard** de CRCibernética, entre otras placas.

**Su característica más especial:** la placa aparece como una **memoria USB** en el computador. El código se edita en un archivo llamado `code.py` y, al guardarlo, la placa lo ejecuta automáticamente. No hay botones de "cargar" ni pasos extra.

---

## ¿Cómo funciona el flujo de trabajo?

1. Conectar la placa por USB. Aparece en el computador como una unidad llamada `CIRCUITPY`.
2. Abrir el archivo `code.py` con el editor IdeaCode (`ideacode.crcibernetica.com`) o con cualquier editor de texto.
3. Escribir o modificar el código.
4. Guardar (Ctrl+S). La placa reinicia y ejecuta el nuevo código en segundos.
5. Si hay un error, la placa lo muestra en la consola serial con el número de línea exacto.

**No hay compilación. No hay carga. Solo guardar y ver.**

## Circuit Playground con CircuitPython

```python
import time
from adafruit_circuitplayground import cp

while True:
    # Leer el sensor de luz
    nivel_luz = cp.light
    print("Luz:", nivel_luz)
    
    # Encender LEDs según la luz
    if nivel_luz < 50:
        cp.pixels.fill((255, 0, 0))   # rojo = oscuro
    else:
        cp.pixels.fill((0, 255, 0))   # verde = claro
    
    # Leer botones
    if cp.button_a:
        cp.play_tone(440, 0.5)        # nota La, 0.5 segundos
    
    time.sleep(0.1)
```

La librería `adafruit_circuitplayground` pone todos los sensores y actuadores del Circuit Playground detrás de nombres muy legibles: `cp.light`, `cp.temperature`, `cp.button_a`, `cp.pixels`.

## IdeaBoard con CircuitPython

Para la IdeaBoard de CRCibernética, se usa la librería `ideaboard`:

```python
import time
from ideaboard import IdeaBoard

ib = IdeaBoard()

while True:
    # Controlar motores DC
    ib.motor1.throttle = 0.8    # motor 1 al 80% hacia adelante
    ib.motor2.throttle = 0.8    # motor 2 al 80% hacia adelante
    time.sleep(2)
    
    ib.motor1.throttle = 0      # detener motores
    ib.motor2.throttle = 0
    time.sleep(1)
    
    # Cambiar color del LED RGB
    ib.pixel[0] = (255, 0, 0)  # rojo
    time.sleep(0.5)
    ib.pixel[0] = (0, 0, 255)  # azul
    time.sleep(0.5)
```

## IdeaSense con CircuitPython

La IdeaSense usa la librería `ideasense`:

```python
import time
from ideasense import IdeaSense

idea = IdeaSense()

while True:
    # Leer sensores
    temp = idea.temp       # temperatura en Celsius
    humedad = idea.humid   # humedad relativa %
    luz = idea.light       # nivel de luz

    print(f"Temperatura: {temp:.1f}°C | Humedad: {humedad:.0f}% | Luz: {luz}")
    
    # Mostrar temperatura en la pantalla de LEDs
    idea.matrix.fill(0)    # limpiar pantalla
    # Si hace calor, encender toda la pantalla
    if temp > 28:
        idea.matrix.fill(1)
    idea.matrix.show()
    
    time.sleep(1)
```

## Diferencias entre CircuitPython y MicroPython

| | CircuitPython | MicroPython |
|---|---|---|
| Creado por | Adafruit | Damien George |
| Flujo de trabajo | Editar y guardar (sin pasos extra) | Cargar archivo con herramienta |
| Placas compatibles | Circuit Playground, IdeaBoard, IdeaSense, muchas más | micro:bit, ESP32, muchas más |
| Librerías | Gran colección de Adafruit | Módulos estándar + librerías de la comunidad |
| Sintaxis | Idéntica a Python estándar | Idéntica a Python estándar |

La sintaxis de ambos es exactamente igual (son Python). La diferencia está en las librerías y en el flujo de trabajo.

## Nota docente

CircuitPython en la IdeaBoard o en el Circuit Playground tiene el flujo de trabajo más rápido de todas las plataformas educativas: editar, guardar, ver el resultado. No hay pasos intermedios que puedan generar confusión.

Esto lo hace especialmente bueno para grupos con tiempo de clase limitado: el ciclo de prueba y error es muy rápido, lo que permite hacer más intentos en el mismo tiempo.

Para introducir Python con la IdeaBoard, IdeaCode (`ideacode.crcibernetica.com`) es el editor más accesible: funciona en el navegador, no requiere instalación y tiene resaltado de sintaxis y consola integrada.
