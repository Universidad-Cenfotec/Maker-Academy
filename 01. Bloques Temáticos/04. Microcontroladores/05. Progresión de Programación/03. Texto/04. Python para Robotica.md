## Descripción

Python estándar, corriendo en una computadora de placa única como Raspberry Pi, abre posibilidades que los microcontroladores tradicionales (Arduino, ESP32, micro:bit) no pueden ofrecer: visión computacional, procesamiento de audio, acceso a bases de datos, integración con APIs de Internet y control simultáneo de múltiples procesos.

En robótica educativa, Python en Raspberry Pi es el nivel donde los proyectos pueden ser genuinamente complejos: un robot que reconoce objetos por cámara, una estación meteorológica que publica datos en la web, un sistema domótico que responde a comandos de voz.

---

## Plataformas

### Raspberry Pi (serie 4, 3B+, Zero 2W)

Raspberry Pi es una computadora completa que corre Linux (Raspberry Pi OS) y tiene pines GPIO para conectar hardware electrónico. A diferencia de Arduino o ESP32, puede correr múltiples procesos simultáneamente, mostrar una interfaz gráfica, reproducir video y acceder a todo el ecosistema de Python.

La librería principal para acceder a los pines GPIO desde Python es `RPi.GPIO` o la más moderna `gpiozero`.

### Raspberry Pi Pico

A diferencia de la Raspberry Pi regular, el Pico es un microcontrolador (no una computadora) basado en el chip RP2040. Se programa con MicroPython o CircuitPython, no con Python estándar. No tiene capacidad de correr Linux ni aplicaciones complejas, pero es más económico y consume menos energía.

## GPIO con gpiozero (Raspberry Pi)

`gpiozero` es la librería recomendada para principiantes en Raspberry Pi. Su diseño es orientado a objetos: en lugar de configurar pines manualmente, se crean objetos que representan los componentes.

```python
from gpiozero import LED, Button
from time import sleep

led = LED(17)       # LED conectado al GPIO 17
boton = Button(3)   # Botón conectado al GPIO 3

while True:
    if boton.is_pressed:
        led.on()
    else:
        led.off()
    sleep(0.01)
```

## Eventos asíncronos con gpiozero

```python
from gpiozero import Button, LED
from signal import pause

led = LED(17)
boton = Button(3)

# Asignar funciones a eventos (sin while True)
boton.when_pressed = led.on
boton.when_released = led.off

pause()  # mantener el programa corriendo sin bloquear
```

Este patrón permite que el programa responda a eventos de hardware sin un bucle de polling activo.

## Sensor de distancia ultrasónico con gpiozero

```python
from gpiozero import DistanceSensor
from time import sleep

sensor = DistanceSensor(echo=24, trigger=23, max_distance=4)

while True:
    distancia_cm = sensor.distance * 100  # gpiozero devuelve metros
    print(f"Distancia: {distancia_cm:.1f} cm")
    sleep(0.2)
```

## Control de motores DC con gpiozero

```python
from gpiozero import Motor
from time import sleep

# Motor conectado a los pines 17 y 18 (con driver L298N o similar)
motor_izq = Motor(forward=17, backward=18)
motor_der = Motor(forward=22, backward=23)

def avanzar(velocidad=1.0):
    motor_izq.forward(velocidad)
    motor_der.forward(velocidad)

def girar_derecha():
    motor_izq.forward(0.8)
    motor_der.backward(0.8)

def detener():
    motor_izq.stop()
    motor_der.stop()

# Secuencia de movimiento
avanzar()
sleep(2)
girar_derecha()
sleep(0.5)
avanzar()
sleep(2)
detener()
```

## Visión computacional con OpenCV

OpenCV es la librería de visión computacional más usada en el mundo. En Raspberry Pi permite procesar la imagen de la cámara en tiempo real para detectar colores, formas, rostros y objetos.

```python
import cv2

camara = cv2.VideoCapture(0)  # cámara 0 (la primera conectada)

while True:
    ret, frame = camara.read()
    if not ret:
        break
    
    # Convertir a escala de grises
    gris = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    
    # Mostrar la imagen en pantalla
    cv2.imshow("Camara", gris)
    
    # Presionar 'q' para salir
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

camara.release()
cv2.destroyAllWindows()
```

## Detección de color: seguidor de línea visual

```python
import cv2
import numpy as np

camara = cv2.VideoCapture(0)

while True:
    ret, frame = camara.read()
    
    # Convertir a espacio de color HSV (mejor para detección de color)
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    
    # Definir rango de color rojo en HSV
    rojo_bajo = np.array([0, 120, 70])
    rojo_alto = np.array([10, 255, 255])
    
    # Crear máscara: pixeles que están en el rango de rojo
    mascara = cv2.inRange(hsv, rojo_bajo, rojo_alto)
    
    # Encontrar contornos del área roja
    contornos, _ = cv2.findContours(mascara, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    
    if contornos:
        # Tomar el contorno más grande
        c = max(contornos, key=cv2.contourArea)
        M = cv2.moments(c)
        if M["m00"] > 0:
            cx = int(M["m10"] / M["m00"])  # posición x del centro
            print(f"Objeto rojo en x={cx}")
            # Usar cx para ajustar dirección del robot
    
    cv2.imshow("Máscara", mascara)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
```

## Comunicación con microcontroladores desde Python

Raspberry Pi puede comunicarse con Arduino u otros microcontroladores por UART o I2C, funcionando como un sistema distribuido donde cada dispositivo hace lo que mejor sabe:

```python
import serial
import time

# Comunicación serial con Arduino
arduino = serial.Serial('/dev/ttyUSB0', 9600, timeout=1)
time.sleep(2)  # esperar que Arduino se inicialice

# Enviar comando al Arduino
arduino.write(b'E')       # enviar letra 'E' para encender LED

# Recibir datos del Arduino
if arduino.in_waiting:
    linea = arduino.readline().decode('utf-8').strip()
    print("Arduino dice:", linea)
```

## Notas docentes

Python en Raspberry Pi requiere que el grupo ya tenga experiencia sólida con Python como lenguaje (no necesariamente en contexto electrónico). La curva de dificultad en este nivel no está en la programación del hardware, sino en la gestión del entorno Linux: permisos, instalación de paquetes, resolución de dependencias.

Una estrategia efectiva: usar imágenes de sistema ya configuradas con todas las librerías necesarias pre-instaladas. La distribución de tarjetas SD pre-configuradas al inicio del proyecto ahorra horas de configuración y permite que el grupo se concentre en los objetivos de aprendizaje del proyecto, no en la administración del sistema.
