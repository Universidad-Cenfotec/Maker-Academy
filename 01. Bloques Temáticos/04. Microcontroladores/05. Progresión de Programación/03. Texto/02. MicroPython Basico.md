## Descripción

MicroPython es una implementación del lenguaje Python 3 optimizada para correr en microcontroladores con recursos limitados (desde 256 KB de flash y 16 KB de RAM). Mantiene la sintaxis y la filosofía de Python estándar: código legible, indentación como estructura, tipos dinámicos y un REPL (consola interactiva) que permite experimentar instrucción por instrucción.

Para estudiantes que ya conocen Python o que van a continuar hacia ciencia de datos o automatización, MicroPython es la opción natural: el conocimiento acumulado en el microcontrolador es directamente transferible a Python en la computadora.

## Herramienta de desarrollo: Thonny IDE

Thonny es el IDE recomendado para MicroPython. Incluye un gestor de placas que permite instalar el firmware de MicroPython directamente desde la interfaz, un editor de archivos del microcontrolador y una consola interactiva (REPL).

Descarga: `thonny.org`

Para conectar al ESP32:
1. Conectar el ESP32 por USB.
2. En Thonny: Herramientas > Opciones > Intérprete > Seleccionar "MicroPython (ESP32)" y el puerto COM correcto.
3. La consola en la parte inferior muestra `>>>` cuando la conexión es exitosa.

## Hola mundo: parpadear un LED

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)  # GPIO 2, modo salida (LED onboard del ESP32)

while True:
    led.on()          # encender
    time.sleep(0.5)   # esperar 0.5 segundos
    led.off()         # apagar
    time.sleep(0.5)
```

## Estructura del programa: sin setup/loop

A diferencia de Arduino, MicroPython no tiene setup() y loop() fijos. El programa se ejecuta de arriba hacia abajo, y si se necesita un bucle continuo, se crea explícitamente con `while True:`.

```python
# Código de inicialización (equivalente a setup)
from machine import Pin, ADC
import time

led = Pin(2, Pin.OUT)
sensor = ADC(Pin(34))
sensor.atten(ADC.ATTN_11DB)  # rango de 0 a 3.3V

# Bucle principal (equivalente a loop)
while True:
    valor = sensor.read()        # 0 a 4095 (12 bits)
    print("Sensor:", valor)
    
    if valor > 2000:
        led.on()
    else:
        led.off()
    
    time.sleep(0.2)
```

## REPL: la consola interactiva

El REPL (Read-Eval-Print Loop) es uno de los grandes diferenciales de MicroPython respecto a Arduino. En la consola de Thonny, se pueden escribir instrucciones una por una y ver el resultado inmediatamente, sin compilar ni cargar un programa completo:

```
>>> from machine import Pin
>>> led = Pin(2, Pin.OUT)
>>> led.on()    # el LED enciende inmediatamente
>>> led.off()   # el LED se apaga
>>> led.value(1)
>>> led.value(0)
```

Esto permite explorar el hardware de forma interactiva y entender el funcionamiento de cada función antes de incorporarla a un programa completo.

## Archivos en el microcontrolador

MicroPython organiza el código en archivos dentro del microcontrolador. Los archivos principales son:

- `boot.py`: se ejecuta al encender la placa (antes que nada). Para configuración básica.
- `main.py`: es el programa principal que se ejecuta después de `boot.py`.

Para guardar el programa en el microcontrolador (que persiste aunque se desconecte el USB), en Thonny: Archivo > Guardar como > "MicroPython device" > `main.py`.

---

## Notas docentes

El REPL es la herramienta pedagógica más poderosa de MicroPython. Antes de escribir un programa completo, guiar a los estudiantes a explorar la API del hardware línea por línea en la consola. Cuando ya saben exactamente qué hace cada función, escribir el programa completo se convierte en combinar piezas que ya entienden.

Una sesión efectiva de introducción: explorar el hardware del ESP32 (encender LED, leer sensor, hacer parpadear) completamente desde el REPL antes de crear ningún archivo `main.py`. La comprensión que se construye es mucho más profunda que la de copiar y pegar un programa completo.
