## ¿Qué es MicroPython?

MicroPython es una versión de Python diseñada para funcionar en microcontroladores pequeños. Python es uno de los lenguajes de programación más populares del mundo —se usa en ciencia de datos, inteligencia artificial, desarrollo web y mucho más— y MicroPython trae esa misma sintaxis amigable a placas como la micro:bit y el ESP32.

**¿Por qué es ideal para educación?**
- Su sintaxis es muy cercana al lenguaje natural
- No necesita declarar tipos de variables (a diferencia de Arduino)
- Los errores se explican claramente con el número de línea
- Es el mismo Python que se usaría en una universidad o trabajo

## MicroPython en micro:bit

El editor oficial es `python.microbit.org`. También funciona con Mu Editor (instalable).

### Estructura básica

```python
from microbit import *   # importar todo lo de la placa

# Este código corre de arriba a abajo
# Para un bucle infinito, se usa "while True:"

while True:
    display.show(Image.HEART)   # mostrar corazón
    sleep(1000)                 # esperar 1 segundo
    display.show(Image.HAPPY)   # mostrar cara feliz
    sleep(1000)
```

No hay `setup()` ni `loop()` como en Arduino. El código se lee de arriba a abajo, y el bucle infinito es un `while True:` explícito.

## Condicionales

```python
from microbit import *

while True:
    temperatura = temperature()   # leer termómetro interno

    if temperatura > 25:
        display.show(Image.SAD)
        print("Hace calor:", temperatura)
    elif temperatura < 15:
        display.show(Image.SURPRISED)
        print("Hace frío:", temperatura)
    else:
        display.show(Image.HAPPY)
        print("Temperatura agradable:", temperatura)

    sleep(500)
```

`elif` es la abreviatura de "else if" (si no, si). Permite encadenar múltiples condiciones.

## Bucles

```python
# Repetir un número fijo de veces
for i in range(5):
    display.show(str(i))
    sleep(500)

# Repetir con una lista
colores = ["rojo", "verde", "azul"]
for color in colores:
    print(color)
    sleep(300)

# Repetir siempre
while True:
    # se ejecuta indefinidamente
    pass
```

## Funciones

```python
def parpadear(veces, tiempo):
    for i in range(veces):
        display.show(Image.HEART)
        sleep(tiempo)
        display.clear()
        sleep(tiempo)

# Llamar la función
parpadear(3, 200)   # 3 parpadeos rápidos
parpadear(1, 1000)  # 1 parpadeo lento
```

En Python, las funciones se definen con `def` y la indentación (los espacios al inicio de la línea) delimita el bloque de código. No hay llaves `{}` como en Arduino.

## Sensores de la micro:bit

```python
from microbit import *

while True:
    # Temperatura interna
    temp = temperature()
    
    # Nivel de luz (usando los LEDs como fotodetector)
    luz = display.read_light_level()
    
    # Acelerómetro
    x, y, z = accelerometer.get_values()
    
    # Botones
    if button_a.is_pressed():
        display.show("A")
    if button_b.is_pressed():
        display.show("B")
    
    # Mostrar en consola
    print("Temp:", temp, "Luz:", luz, "Acc:", x, y, z)
    sleep(200)
```

## MicroPython en ESP32

En el ESP32, se usa Thonny IDE (`thonny.org`) o el editor `code.circuitpython.org`. El código es prácticamente idéntico al de micro:bit, pero con módulos diferentes:

```python
from machine import Pin, ADC
import time

led = Pin(2, Pin.OUT)     # pin 2 como salida
sensor = ADC(Pin(34))     # pin 34 como entrada analógica

while True:
    valor = sensor.read()       # leer sensor (0 a 4095)
    print("Sensor:", valor)
    
    if valor > 2000:
        led.value(1)            # encender LED
    else:
        led.value(0)            # apagar LED
    
    time.sleep(0.5)
```

## Comparación: MicroPython vs. Arduino

| | MicroPython | Arduino (C++) |
|---|---|---|
| Sintaxis | Fácil, como inglés | Más estricta |
| Tipos de variables | No se declaran | Obligatorio declarar |
| Velocidad de ejecución | Más lenta | Más rápida |
| Transición a otros usos | Python estándar (ciencias, web) | C/C++ |
| Error en el código | Mensaje claro con línea | Mensaje técnico |

Para grupos de secundaria que van a continuar con programación después del makerspace, MicroPython/Python tiene la ventaja de ser directamente útil en otras materias y carreras.

## Nota docente

MicroPython en micro:bit es la transición más natural desde MakeCode: el hardware es exactamente el mismo, y el estudiante puede ver que "el bloque de mostrar texto" se convierte en `display.show("texto")`. El código dice casi lo mismo que los bloques, solo con diferente formato.

La indentación (los espacios al inicio de cada línea) es el concepto más desafiante para quienes vienen de lenguajes con llaves `{}`. Una buena práctica: usar siempre 4 espacios (o la tecla Tab configurada para 4 espacios en el editor) y mostrar en proyector qué pasa cuando la indentación está incorrecta.
