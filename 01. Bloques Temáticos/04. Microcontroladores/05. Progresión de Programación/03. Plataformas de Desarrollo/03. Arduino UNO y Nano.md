## Único entorno: Arduino IDE

A diferencia de micro:bit o Circuit Playground, Arduino UNO y Nano no tienen entorno de bloques oficial en este repositorio: se programan directamente en C++ con el Arduino IDE, disponible en [`arduino.cc/en/software`](https://www.arduino.cc/en/software) o en la versión en línea [`create.arduino.cc`](https://create.arduino.cc/).

Todo sketch de Arduino tiene la misma estructura de dos funciones:

```cpp
void setup() {
  // este bloque se ejecuta UNA SOLA VEZ al encender la placa
  // aquí se configuran los pines con pinMode()
}

void loop() {
  // este bloque se repite PARA SIEMPRE mientras la placa esté encendida
  // aquí va la lógica principal del programa
}
```

## Ejemplo mínimo: parpadear el LED integrado

```cpp
void setup() {
  pinMode(13, OUTPUT);   // configuramos el pin 13 (LED integrado) como salida
}

void loop() {
  digitalWrite(13, HIGH);   // encendemos el LED
  delay(1000);                // esperamos 1 segundo
  digitalWrite(13, LOW);    // apagamos el LED
  delay(1000);                // esperamos 1 segundo
}
```

Este programa, llamado "Blink", es el primer ejemplo que cualquier persona ejecuta en Arduino. Viene incluido en el IDE: `Archivo > Ejemplos > 01.Basics > Blink`.

## Conectar un sensor: siguiendo la progresión

**Sensor de luz (LDR), siguiendo [`01. Sensor de Luz (LDR).md`](../02.%20Sensores%20y%20Actuadores/01.%20Sensor%20de%20Luz%20%28LDR%29.md):**

```cpp
const int PIN_LDR = A0;   // declaramos el pin analógico del sensor de luz
const int UMBRAL = 400;    // definido después de medir el ambiente del aula

void setup() {
  Serial.begin(9600);      // iniciamos el Monitor Serial
}

void loop() {
  int luz = analogRead(PIN_LDR);   // aquí llamamos al sensor de luz
  Serial.println(luz);
  delay(200);
}
```

**Sensor de distancia (HC-SR04), siguiendo [`02. Sensor de Distancia (HC-SR04).md`](../02.%20Sensores%20y%20Actuadores/02.%20Sensor%20de%20Distancia%20%28HC-SR04%29.md):**

```cpp
const int PIN_TRIG = 9;
const int PIN_ECHO = 10;

void setup() {
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);   // emitimos el pulso ultrasónico
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);

  long duracion = pulseIn(PIN_ECHO, HIGH);   // medimos el tiempo de vuelta
  Serial.println(duracion / 58);              // mostramos la distancia en centímetros
  delay(100);
}
```

**Servomotor, siguiendo [`03. Servomotor.md`](../02.%20Sensores%20y%20Actuadores/03.%20Servomotor.md):**

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);   // conectamos el objeto servo al pin 9
}

void loop() {
  miServo.write(90);   // aquí movemos el servo a 90°
}
```

## ¿Cómo se carga el programa a la placa?

1. Instalar el Arduino IDE desde [`arduino.cc/en/software`](https://www.arduino.cc/en/software).
2. Conectar la placa por USB.
3. Seleccionar el modelo de placa y el puerto correcto (`Herramientas > Placa` y `Herramientas > Puerto`).
4. Escribir o abrir el sketch.
5. Hacer clic en "Cargar" (la flecha →). El IDE compila el programa y lo envía a la placa.

## Ejemplo progresivo: robot simple con sensor de distancia y motor

Este ejemplo integra un sensor de entrada, un actuador de salida y un condicional, usando únicamente lo cubierto en esta progresión:

```cpp
const int PIN_TRIG = 9;      // pin del sensor de distancia
const int PIN_ECHO = 10;
const int IN1 = 7;           // pines del driver del motor
const int IN2 = 8;
const int ENA = 6;
const int UMBRAL_CM = 20;    // definido después de medir el espacio real

int medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long duracion = pulseIn(PIN_ECHO, HIGH);
  return duracion / 58;
}

void detener() {
  analogWrite(ENA, 0);   // llevamos la velocidad a 0: el motor se detiene
}

void avanzar(int velocidad) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, velocidad);
}

void setup() {
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int distancia = medirDistanciaCm();   // leemos el sensor
  Serial.println(distancia);

  if (distancia < UMBRAL_CM) {
    detener();          // hay algo cerca: nos detenemos
  } else {
    avanzar(180);        // camino libre: avanzamos
  }

  delay(100);
}
```
