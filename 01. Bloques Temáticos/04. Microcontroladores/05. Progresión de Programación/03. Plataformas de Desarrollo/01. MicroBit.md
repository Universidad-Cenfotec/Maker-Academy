## Entorno 1: MakeCode (bloques)

MakeCode funciona en el navegador, en [`makecode.microbit.org`](https://makecode.microbit.org/). El programa se arma arrastrando bloques, y en todo momento se puede abrir la pestaña **JavaScript** para ver el código de texto equivalente a los bloques usados. Esa vista es clave en esta progresión: permite comparar bloque y texto lado a lado.

**Ejemplo mínimo — encender la pantalla al presionar el botón A:**

Bloques: `al presionar botón A → mostrar ícono corazón`.

Código JavaScript equivalente (visible en la pestaña "JavaScript" de MakeCode):

```javascript
input.onButtonPressed(Button.A, function () {
    // esto se ejecuta cada vez que se presiona el botón A
    basic.showIcon(IconNames.Heart)   // muestra un corazón en la pantalla de LEDs
})
```

**Leer un sensor integrado con bloques:** el bloque `nivel de luz` (dentro de la categoría "Entrada") devuelve un número de 0 a 255. Su equivalente en texto es:

```javascript
basic.forever(function () {
    // esto se repite todo el tiempo, igual que loop() en Arduino
    let luz = input.lightLevel()   // aquí llamamos al sensor de luz integrado
    basic.showNumber(luz)           // mostramos el número en la pantalla
})
```

## Entorno 2: MicroPython (texto)

MicroPython se usa en [`python.microbit.org`](https://python.microbit.org/v/3) o con el programa Mu Editor. El mismo programa anterior, en MicroPython:

```python
from microbit import *

while True:
    luz = display.read_light_level()   # aquí llamamos al sensor de luz integrado
    display.scroll(str(luz))            # mostramos el número, convertido a texto, en la pantalla
    sleep(200)                           # esperamos antes de repetir
```

**Botones en MicroPython:**

```python
from microbit import *

while True:
    if button_a.is_pressed():        # preguntamos si el botón A está presionado
        display.show(Image.HEART)    # mostramos un corazón
    else:
        display.clear()               # apagamos la pantalla
    sleep(50)
```

## Conectar sensores y actuadores externos

La micro:bit tiene 25 pines en su borde inferior. Los pines `pin0`, `pin1` y `pin2` son los más fáciles de usar porque tienen anillos grandes para cables lagarto, y funcionan tanto como entrada digital, entrada analógica o salida, según cómo se declaren en el código.

> **Importante:** los pines de la micro:bit trabajan a 3.3V, no a 5V. Revisar siempre esta diferencia antes de conectar un sensor pensado originalmente para Arduino.

**Sensor de luz externo (LDR) en `pin0`, siguiendo [`01. Sensor de Luz (LDR).md`](../02.%20Sensores%20y%20Actuadores/01.%20Sensor%20de%20Luz%20%28LDR%29.md):**

```python
from microbit import *

PIN_LDR = pin0     # declaramos el pin donde está conectada la LDR
UMBRAL = 400        # definido después de medir el ambiente

while True:
    luz = PIN_LDR.read_analog()   # leemos el sensor de luz externo
    if luz < UMBRAL:
        display.show(Image.YES)   # oscuro
    else:
        display.show(Image.NO)    # con luz
    sleep(200)
```

**Servomotor en `pin1`, siguiendo [`03. Servomotor.md`](../02.%20Sensores%20y%20Actuadores/03.%20Servomotor.md):**

```python
from microbit import *

pin_servo = pin1

while True:
    pin_servo.write_analog(180)    # posición mínima
    sleep(1000)
    pin_servo.write_analog(1023)   # posición máxima
    sleep(1000)
```

## ¿Cómo se carga el programa a la placa?

1. Conectar la micro:bit al computador con un cable USB. Aparece como una unidad llamada `MICROBIT`.
2. En MakeCode o en `python.microbit.org`, hacer clic en "Descargar". Se genera un archivo `.hex`.
3. Copiar ese archivo a la unidad `MICROBIT`, como si fuera una memoria USB.
4. La placa parpadea un momento y ejecuta el programa de inmediato.

## Ejemplo progresivo: estación de luz con umbral, función y pantalla

Este ejemplo integra un sensor externo, una función, un umbral y la pantalla de LEDs, en MicroPython:

```python
from microbit import *

PIN_LDR = pin0     # pin donde está conectada la LDR externa
UMBRAL = 400        # definido después de medir el ambiente del aula

def mostrar_estado(nivel_de_luz):
    # función que recibe la lectura como parámetro y decide qué mostrar
    if nivel_de_luz < UMBRAL:
        display.show(Image.YES)   # está oscuro
    else:
        display.show(Image.NO)    # hay suficiente luz

while True:
    luz = PIN_LDR.read_analog()   # leemos el sensor de luz
    mostrar_estado(luz)            # llamamos a la función con la lectura actual
    sleep(200)
```
