## Entorno 1: MakeCode (bloques)

En [`makecode.adafruit.com`](https://makecode.adafruit.com/), el bloque `establecer todos los píxeles a` enciende los 10 LEDs con un color. Su código equivalente en JavaScript:

```javascript
light.setAll(light.rgb(0, 255, 0))   // enciende los 10 NeoPixels en color verde
```

**Leer el sensor de luz integrado con bloques:** el bloque `nivel de luz` devuelve un número. Su equivalente en texto:

```javascript
basic.forever(function () {
    let luz = light.lightLevel()   // aquí llamamos al sensor de luz integrado
    if (luz < 30) {
        light.setAll(light.rgb(0, 0, 255))   // oscuro: encendemos azul
    } else {
        light.setAll(light.rgb(0, 0, 0))     // con luz: apagamos
    }
})
```

## Entorno 2: CircuitPython (texto)

La placa aparece como una unidad `CIRCUITPY` con un archivo `code.py`. Cualquier cambio guardado en ese archivo se ejecuta de inmediato, sin compilar.

```python
from adafruit_circuitplayground import cp

while True:
    cp.pixels.fill((0, 255, 0))   # aquí llamamos a los 10 NeoPixels y los ponemos en verde
```

**El mismo condicional con el sensor de luz integrado:**

```python
from adafruit_circuitplayground import cp
import time

UMBRAL = 30   # definido después de medir el ambiente del aula

while True:
    luz = cp.light   # aquí llamamos al sensor de luz integrado
    if luz < UMBRAL:
        cp.pixels.fill((0, 0, 255))   # oscuro: azul
    else:
        cp.pixels.fill((0, 0, 0))     # con luz: apagado
    time.sleep(0.2)
```

**Botones integrados:**

```python
from adafruit_circuitplayground import cp
import time

while True:
    if cp.button_a:                     # preguntamos si el botón A está presionado
        cp.pixels.fill((255, 0, 0))     # rojo
    elif cp.button_b:
        cp.pixels.fill((0, 0, 255))     # azul
    else:
        cp.pixels.fill((0, 0, 0))       # apagado
    time.sleep(0.05)
```

## Conectar sensores y actuadores externos

El Circuit Playground tiene 8 pines de expansión con orificios grandes, ideales para cables lagarto sin protoboard. En CircuitPython se declaran con el módulo `board`:

**Servomotor en el pin A1, siguiendo [`03. Servomotor.md`](../02.%20Sensores%20y%20Actuadores/03.%20Servomotor.md):**

```python
import board
import pwmio
from adafruit_motor import servo

pwm = pwmio.PWMOut(board.A1, duty_cycle=2 ** 15, frequency=50)   # configuramos el pin A1 para PWM
mi_servo = servo.Servo(pwm)                                        # creamos el objeto servo

mi_servo.angle = 0     # aquí movemos el servomotor a 0°
```

## ¿Cómo se carga el programa a la placa?

1. Conectar la placa por USB. Aparece como una unidad de disco.
2. Para bloques: abrir `makecode.adafruit.com` y hacer clic en "Descargar".
3. Para CircuitPython: abrir el archivo `code.py` con cualquier editor de texto, escribir el código y guardar.
4. La placa ejecuta el nuevo programa automáticamente al guardar (CircuitPython) o al copiar el archivo `.uf2` (MakeCode).

## Ejemplo progresivo: semáforo de luz con función y umbral

Este ejemplo integra el sensor de luz integrado, un umbral y una función, en CircuitPython:

```python
from adafruit_circuitplayground import cp
import time

UMBRAL = 30   # definido después de medir el ambiente del aula

def mostrar_estado(nivel_de_luz):
    # función que recibe la lectura como parámetro y decide qué color mostrar
    if nivel_de_luz < UMBRAL:
        cp.pixels.fill((0, 0, 255))   # oscuro: azul
    else:
        cp.pixels.fill((0, 255, 0))   # con luz: verde

while True:
    luz = cp.light           # leemos el sensor de luz integrado
    mostrar_estado(luz)       # llamamos a la función con la lectura actual
    time.sleep(0.2)
```

## Nota docente

Un grupo con estudiantes de distinto nivel puede trabajar en la misma placa sin conflicto: quienes recién empiezan usan MakeCode, y quienes ya programan en texto usan CircuitPython directamente sobre el archivo `code.py`. Ambos códigos, al final, encienden los mismos LEDs físicos, lo que hace muy tangible que "bloques" y "texto" son dos formas de decir lo mismo.
