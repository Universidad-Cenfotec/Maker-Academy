## Único entorno: IdeaCode (CircuitPython)

La IdeaSense se programa únicamente en CircuitPython, con el editor en línea [`ideacode.crcibernetica.com`](https://ideacode.crcibernetica.com/). La placa aparece como una unidad `CIRCUITPY` con un archivo `code.py` que se ejecuta de inmediato al guardar.

La librería `ideasense` simplifica el acceso a todos los sensores integrados en un solo objeto:

```python
from ideasense import IdeaSense

idea = IdeaSense()   # creamos el objeto que representa toda la placa y sus sensores
```

---

## Leer el sensor de temperatura integrado

```python
from ideasense import IdeaSense
import time

idea = IdeaSense()

while True:
    temperatura = idea.temp   # aquí llamamos al sensor de temperatura integrado
    print(temperatura)
    time.sleep(1)
```

## Umbral con el sensor de luz integrado

Siguiendo el mismo proceso de [`03. Funciones, Pines y Umbrales.md`](../01.%20Fundamentos%20de%20Programación/03.%20Funciones%2C%20Pines%20y%20Umbrales.md): medir primero, definir el umbral después.

```python
from ideasense import IdeaSense
import time

idea = IdeaSense()
umbral = 300   # definido después de medir el ambiente del aula

while True:
    luz = idea.light   # aquí llamamos al sensor de luz integrado

    if luz < umbral:
        idea.matrix.fill(1)   # oscuro: encendemos toda la matriz de LEDs
    else:
        idea.matrix.fill(0)   # con luz: apagamos la matriz

    idea.matrix.show()          # aplicamos el cambio a la pantalla
    time.sleep(0.2)
```

## Leer el acelerómetro

```python
from ideasense import IdeaSense
import time

idea = IdeaSense()

while True:
    ax, ay, az = idea.accel   # aceleración en los tres ejes: x, y, z
    if abs(ax) > 5 or abs(ay) > 5:
        print("¡Sacudida detectada!")
    time.sleep(0.1)
```

## Botones integrados

```python
from ideasense import IdeaSense
import time

idea = IdeaSense()

while True:
    botones = idea.pressed   # lista con el estado de los botones A, B y C

    if botones[0]:           # botón A
        idea.matrix.fill(1)
    else:
        idea.matrix.fill(0)
    idea.matrix.show()

    time.sleep(0.05)
```

## ¿Cómo se carga el programa a la placa?

1. Conectar la IdeaSense por USB. Aparece como una unidad `CIRCUITPY`.
2. Abrir [`ideacode.crcibernetica.com`](https://ideacode.crcibernetica.com/) en el navegador.
3. Escribir el código en Python y guardar.
4. La placa ejecuta el programa de inmediato. Si hay un error, aparece en el monitor serial con el número de línea exacto.

## Ejemplo progresivo: estación de temperatura con función y umbral

Este ejemplo integra el sensor de temperatura, un umbral, una función y la matriz de LEDs:

```python
from ideasense import IdeaSense
import time

idea = IdeaSense()
umbral_calor = 28.0   # grados Celsius, definido después de medir el aula

def avisar_si_hace_calor(temperatura):
    # función que recibe la temperatura como parámetro y decide qué mostrar
    if temperatura > umbral_calor:
        idea.matrix.fill(1)   # hace calor: encendemos toda la matriz
    else:
        idea.matrix.fill(0)   # temperatura normal: apagamos
    idea.matrix.show()

while True:
    temperatura = idea.temp        # leemos el sensor de temperatura
    print(temperatura)
    avisar_si_hace_calor(temperatura)   # llamamos a la función con la lectura actual
    time.sleep(1)
```
