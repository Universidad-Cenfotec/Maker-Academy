## Entorno 1: Arduino IDE (recomendado)

El ESP32 usa la misma estructura `setup()` / `loop()` que Arduino UNO, una vez instalado el soporte de placas de Espressif en el IDE. Todo lo aprendido en [`03. Arduino UNO y Nano.md`](./03.%20Arduino%20UNO%20y%20Nano.md) se traslada directamente:

```cpp
const int PIN_LDR = 34;   // en ESP32, los pines analógicos se numeran distinto a Arduino UNO
const int UMBRAL = 2000;   // el ESP32 lee hasta 4095, no 1023 como Arduino UNO: hay que remedir el umbral

void setup() {
  Serial.begin(115200);   // el ESP32 suele usar 115200 baudios en vez de 9600
}

void loop() {
  int luz = analogRead(PIN_LDR);   // aquí llamamos al sensor de luz
  Serial.println(luz);
  delay(200);
}
```

> **Nota para docentes:** el ESP32 lee sus pines analógicos en una escala de 0 a 4095 (12 bits), no de 0 a 1023 (10 bits) como Arduino UNO. Cualquier umbral definido en Arduino UNO hay que volver a medirlo en el ESP32; no se puede reutilizar el mismo número.

## Entorno 2: MicroPython

Requiere instalar una sola vez el firmware de MicroPython en la placa y usar Thonny IDE. La misma lectura de sensor, en MicroPython:

```python
from machine import ADC, Pin
import time

pin_ldr = ADC(Pin(34))       # declaramos el pin analógico del sensor de luz
pin_ldr.atten(ADC.ATTN_11DB)  # ajuste necesario en ESP32 para leer el rango completo de voltaje
umbral = 2000                 # definido después de medir el ambiente

while True:
    luz = pin_ldr.read()       # aquí llamamos al sensor de luz
    print(luz)
    time.sleep(0.2)
```

## La diferencia clave: WiFi

Lo que distingue al ESP32 de las demás placas de esta progresión es el WiFi integrado, disponible desde el primer sketch con la librería `WiFi.h`:

```cpp
#include <WiFi.h>

const char* ssid = "NombreDeTuRed";        // nombre de la red WiFi
const char* password = "ContraseñaDeTuRed"; // contraseña de esa red

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);   // aquí le pedimos al ESP32 conectarse a la red

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");           // mostramos puntos mientras espera la conexión
  }
  Serial.println("Conectado a WiFi");
}

void loop() {
  // el resto del programa va aquí, ya con conexión a internet disponible
}
```

## Conectar un sensor y publicarlo por WiFi

Este ejemplo combina lo visto en [`01. Sensor de Luz (LDR).md`](../02.%20Sensores%20y%20Actuadores/01.%20Sensor%20de%20Luz%20%28LDR%29.md) con la conectividad del ESP32:

```cpp
#include <WiFi.h>

const char* ssid = "NombreDeTuRed";
const char* password = "ContraseñaDeTuRed";
const int PIN_LDR = 34;

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
  Serial.println("Conectado a WiFi");
}

void loop() {
  int luz = analogRead(PIN_LDR);        // leemos el sensor de luz
  Serial.print("Nivel de luz: ");
  Serial.println(luz);                    // en un proyecto real, aquí se enviaría el dato a un servidor
  delay(1000);
}
```

## ¿Cómo se carga el programa a la placa?

1. En el Arduino IDE, agregar el soporte de placas ESP32 desde `Archivo > Preferencias` (ver [`04. ESP32.md`](../../01.%20Plataformas%20de%20Desarrollo/04.%20ESP32.md) para la URL exacta).
2. Seleccionar `ESP32 Dev Module` en `Herramientas > Placa`.
3. Conectar la placa por USB y seleccionar el puerto correcto.
4. Escribir o abrir el sketch y hacer clic en "Cargar".

## Ejemplo progresivo: alarma de distancia con umbral propio del ESP32

Este ejemplo integra un sensor, un umbral remedido para la escala del ESP32 y una función:

```cpp
const int PIN_TRIG = 12;
const int PIN_ECHO = 14;
const int PIN_LED = 2;         // el ESP32 DevKit trae un LED integrado en el pin 2
const int UMBRAL_CM = 20;      // definido después de medir el espacio real

int medirDistanciaCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  long duracion = pulseIn(PIN_ECHO, HIGH);
  return duracion / 58;
}

void setup() {
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_LED, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  int distancia = medirDistanciaCm();   // llamamos a la función
  Serial.println(distancia);

  if (distancia < UMBRAL_CM) {
    digitalWrite(PIN_LED, HIGH);   // objeto cerca: encendemos el LED integrado
  } else {
    digitalWrite(PIN_LED, LOW);
  }

  delay(100);
}
```

## Nota docente

El error más frecuente al pasar de Arduino UNO a ESP32 es reutilizar un umbral definido en Arduino UNO sin remedirlo. Como el ESP32 lee de 0 a 4095 en vez de 0 a 1023, un umbral de 400 (típico en Arduino UNO) casi nunca tiene sentido en un ESP32. Conviene recordarle al grupo que cada placa nueva exige volver a medir antes de definir cualquier umbral.
