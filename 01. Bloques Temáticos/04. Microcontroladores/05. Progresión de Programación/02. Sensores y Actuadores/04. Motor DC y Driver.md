## Bajo qué estándar funciona

El L298N necesita **tres señales** para controlar un solo motor: dos digitales para la dirección y una PWM para la velocidad. Ninguna de estas señales se conecta directamente al motor: siempre pasan primero por el driver.

| Parámetro | Valor típico |
|---|---|
| Pines de dirección (IN1, IN2) | Digitales, configurados como `OUTPUT` |
| Pin de velocidad (ENA) | Digital con PWM (marcado con `~`), usa `analogWrite()` |
| Rango de velocidad | 0 a 255 (0 = detenido, 255 = velocidad máxima) |
| Comando de dirección | `digitalWrite(pin, HIGH)` / `digitalWrite(pin, LOW)` |

---

## Paso 1: declarar los tres pines

```cpp
const int IN1 = 7;   // controla el sentido de giro (junto con IN2)
const int IN2 = 8;   // controla el sentido de giro (junto con IN1)
const int ENA = 9;   // controla la velocidad (debe ser un pin con PWM)

void setup() {
  pinMode(IN1, OUTPUT);   // los tres pines son salidas: el Arduino envía la orden
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}
```

## Paso 2: entender la tabla de dirección

La dirección del motor depende únicamente de la combinación de `HIGH` y `LOW` en IN1 e IN2:

| IN1 | IN2 | El motor hace: |
|---|---|---|
| HIGH | LOW | Gira hacia adelante |
| LOW | HIGH | Gira hacia atrás |
| LOW | LOW | Se detiene sin fuerza |

```cpp
digitalWrite(IN1, HIGH);   // aquí le decimos al driver que el motor gire hacia adelante
digitalWrite(IN2, LOW);
```

## Paso 3: controlar la velocidad con PWM

El pin ENA no se enciende o apaga: recibe un valor de 0 a 255 con `analogWrite()`, igual que se explicó en [`03. Funciones, Pines y Umbrales.md`](../01.%20Fundamentos%20de%20Programación/03.%20Funciones%2C%20Pines%20y%20Umbrales.md) para los pines PWM.

```cpp
analogWrite(ENA, 200);   // velocidad alta, aproximadamente 78% de la máxima
```

## Paso 4: organizar la dirección y la velocidad en funciones

```cpp
void adelante(int velocidad) {
  // "velocidad" es un parámetro: cambia según lo que se le pida a la función
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  analogWrite(ENA, velocidad);
}

void atras(int velocidad) {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  analogWrite(ENA, velocidad);
}

void parar() {
  analogWrite(ENA, 0);   // llevar la velocidad a 0 detiene el motor sin cambiar la dirección
}
```

## En Python (IdeaBoard, con driver de motores integrado)

La IdeaBoard tiene dos puentes H integrados, por lo que no necesita un módulo L298N externo, pero la lógica de programación es la misma: dirección más velocidad.

```python
from ideaboard import IdeaBoard
import time

placa = IdeaBoard()

def adelante(velocidad):
    # velocidad: un número entre 0 y 100 (porcentaje) en la librería de IdeaBoard
    placa.motor_a.forward(velocidad)   # aquí llamamos al motor A y le pedimos ir hacia adelante

def atras(velocidad):
    placa.motor_a.backward(velocidad)  # aquí le pedimos ir hacia atrás

def parar():
    placa.motor_a.stop()                # detenemos el motor

adelante(70)     # avanzar al 70% de velocidad
time.sleep(2)
parar()
```

## Ejemplo progresivo: adelante, atrás y giro con dos motores

Este ejemplo integra la declaración de pines para dos motores, funciones con parámetros y la lógica de dirección para construir el movimiento básico de un robot con ruedas.

```cpp
// Motor A (rueda derecha)
const int IN1 = 7;
const int IN2 = 8;
const int ENA = 9;

// Motor B (rueda izquierda)
const int IN3 = 4;
const int IN4 = 5;
const int ENB = 6;

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  pinMode(ENB, OUTPUT);
}

void moverMotor(int in1, int in2, int en, int velocidad) {
  // función genérica: sirve tanto para el motor A como para el motor B
  if (velocidad > 0) {
    digitalWrite(in1, HIGH);
    digitalWrite(in2, LOW);
  } else {
    digitalWrite(in1, LOW);
    digitalWrite(in2, HIGH);
  }
  analogWrite(en, abs(velocidad));   // abs() convierte un número negativo en positivo
}

void adelante(int velocidad) {
  moverMotor(IN1, IN2, ENA, velocidad);   // ambas ruedas hacia adelante
  moverMotor(IN3, IN4, ENB, velocidad);
}

void girarDerecha(int velocidad) {
  moverMotor(IN1, IN2, ENA, -velocidad);  // rueda derecha hacia atrás
  moverMotor(IN3, IN4, ENB, velocidad);   // rueda izquierda hacia adelante
}

void parar() {
  analogWrite(ENA, 0);
  analogWrite(ENB, 0);
}

void loop() {
  adelante(200);       // avanzar
  delay(2000);
  girarDerecha(150);   // girar en su propio eje
  delay(500);
  parar();
  delay(1000);
}
```

## Nota docente

Antes de combinar motores con sensores (por ejemplo, un robot que evita obstáculos), es recomendable que el grupo programe y pruebe el movimiento de los motores por separado: adelante, atrás, parar y girar. Depurar un robot que no se mueve bien es mucho más difícil cuando, al mismo tiempo, tampoco se sabe si el sensor está funcionando correctamente.
