## Bajo qué estándar funciona

El servomotor es un **actuador**, no un sensor: en vez de leer información del ambiente, recibe una orden y se mueve. Se controla con una señal PWM que la librería `Servo.h` traduce automáticamente a un ángulo entre 0° y 180°. Por eso no se usa `digitalWrite()` ni `analogWrite()` directamente, sino los propios comandos de la librería.

| Parámetro | Valor típico |
|---|---|
| Librería | `Servo.h` (incluida en el Arduino IDE) |
| Pin recomendado | Cualquier pin digital con PWM (marcado con `~`) |
| Rango de ángulo | 0° a 180° |
| Comando de movimiento | `nombreDelServo.write(ángulo)` |

---

## Paso 1: incluir la librería y declarar el objeto

A diferencia de un sensor (que se declara como una simple constante de pin), un servomotor se declara como un **objeto** de la librería `Servo`:

```cpp
#include <Servo.h>   // incluimos la librería que controla servomotores

Servo miServo;        // creamos un objeto llamado "miServo" para controlar el actuador
```

## Paso 2: conectar el objeto al pin físico

```cpp
void setup() {
  miServo.attach(9);   // le decimos al objeto "miServo" que está conectado al pin 9
}
```

`attach()` es el equivalente, para un servo, de lo que `pinMode()` hace con un pin normal: declara para qué se va a usar ese pin.

## Paso 3: mover el servo a una posición

```cpp
void loop() {
  miServo.write(0);     // aquí llamamos al servomotor y le pedimos ir a 0°
  delay(1000);
  miServo.write(90);    // ahora le pedimos ir a 90° (posición central)
  delay(1000);
  miServo.write(180);   // ahora le pedimos ir a 180°
  delay(1000);
}
```

`write(ángulo)` es el único comando necesario para mover el servo. La librería se encarga de generar la señal PWM correcta por dentro.

## Controlar el servo con un sensor: mapeo de rangos

Un uso muy común es traducir la lectura de un sensor analógico (0 a 1023) al rango de ángulos del servo (0 a 180). Para eso se usa la función `map()`:

```cpp
#include <Servo.h>

Servo miServo;
const int PIN_POTENCIOMETRO = A0;   // sensor analógico que va a controlar el ángulo

void setup() {
  miServo.attach(9);
}

void loop() {
  int lectura = analogRead(PIN_POTENCIOMETRO);        // leemos el sensor: 0 a 1023
  int angulo = map(lectura, 0, 1023, 0, 180);          // convertimos ese rango a 0–180°
  miServo.write(angulo);                                 // movemos el servo a ese ángulo
  delay(15);                                              // pequeña pausa para que el servo responda
}
```

`map(valor, rangoOrigenMin, rangoOrigenMax, rangoDestinoMin, rangoDestinoMax)` es la función que traduce un número de una escala a otra. Es el mismo patrón que se usa para conectar prácticamente cualquier sensor con cualquier actuador.

## En Python (IdeaBoard, CircuitPython)

```python
import board
import pwmio
from adafruit_motor import servo

pwm = pwmio.PWMOut(board.D9, duty_cycle=2 ** 15, frequency=50)  # configuramos la señal PWM en el pin 9
mi_servo = servo.Servo(pwm)                                       # creamos el objeto servo

mi_servo.angle = 0     # aquí llamamos al servomotor y le pedimos ir a 0°
```

En micro:bit, usando una extensión de servo en MakeCode o el módulo `servo` de MicroPython:

```python
from microbit import *

pin_servo = pin1   # pin donde está conectado el servo

while True:
    pin_servo.write_analog(180)   # posición mínima (equivalente a 0°)
    sleep(1000)
    pin_servo.write_analog(512)   # posición central
    sleep(1000)
    pin_servo.write_analog(1023)  # posición máxima
    sleep(1000)
```

## Ejemplo progresivo: función de movimiento suave con parámetros

Este ejemplo integra la declaración del objeto, el mapeo de rangos y una función con parámetros para mover el servo de forma gradual, sin saltos bruscos:

```cpp
#include <Servo.h>

Servo miServo;                       // objeto que controla el servomotor
const int PIN_SERVO = 9;             // pin donde está conectado el servo

void moverSuave(int inicio, int fin, int velocidad) {
  // función que mueve el servo grado por grado, del ángulo "inicio" al ángulo "fin"
  if (inicio < fin) {
    for (int angulo = inicio; angulo <= fin; angulo++) {
      miServo.write(angulo);    // movemos un grado a la vez
      delay(velocidad);          // controlamos qué tan rápido se mueve
    }
  } else {
    for (int angulo = inicio; angulo >= fin; angulo--) {
      miServo.write(angulo);
      delay(velocidad);
    }
  }
}

void setup() {
  miServo.attach(PIN_SERVO);   // conectamos el objeto al pin físico
}

void loop() {
  moverSuave(0, 180, 10);    // de 0° a 180°, esperando 10 ms entre cada grado
  delay(500);
  moverSuave(180, 0, 10);    // de vuelta a 0°
  delay(500);
}
```

## Nota docente

El concepto de `map()` suele ser el punto donde algunos estudiantes se pierden por primera vez, porque mezcla dos escalas numéricas distintas. Una forma efectiva de introducirlo es con una analogía cotidiana: convertir grados Celsius a Fahrenheit, o convertir una nota de 0 a 100 en una nota de 0 a 10. `map()` hace exactamente eso, pero entre la lectura de un sensor y el ángulo de un servo.
