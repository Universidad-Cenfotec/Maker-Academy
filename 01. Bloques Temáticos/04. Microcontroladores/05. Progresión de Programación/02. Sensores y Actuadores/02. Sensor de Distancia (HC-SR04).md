## Bajo qué estándar funciona

El HC-SR04 no entrega un número directamente: entrega **un pulso eléctrico cuya duración hay que medir**. Por eso necesita dos pines digitales distintos, uno de salida y otro de entrada, y una función especial para medir tiempo: `pulseIn()`.

| Parámetro | Valor típico |
|---|---|
| Pin TRIG | Digital, configurado como `OUTPUT` |
| Pin ECHO | Digital, configurado como `INPUT` |
| Función de medición | `pulseIn(pin, HIGH)`, devuelve microsegundos |
| Conversión a centímetros | `duración / 58` |
| Rango del sensor | 2 cm a 400 cm |

---

## Paso 1: declarar los dos pines

A diferencia de la LDR (que usa un solo pin analógico), el HC-SR04 necesita **dos pines digitales** con roles distintos: uno para "preguntar" y otro para "escuchar la respuesta".

```cpp
const int PIN_TRIG = 9;   // pin que le ordena al sensor emitir el pulso ultrasónico
const int PIN_ECHO = 10;  // pin que recibe la señal de vuelta

void setup() {
  pinMode(PIN_TRIG, OUTPUT);   // TRIG envía la señal: es una salida
  pinMode(PIN_ECHO, INPUT);    // ECHO recibe la señal: es una entrada
}
```

## Paso 2: emitir el pulso y medir el tiempo de vuelta

Cada medición sigue siempre la misma secuencia de tres líneas para generar el pulso:

```cpp
digitalWrite(PIN_TRIG, LOW);    // primero, aseguramos que el pin esté en apagado
delayMicroseconds(2);
digitalWrite(PIN_TRIG, HIGH);   // enviamos el pulso ultrasónico
delayMicroseconds(10);
digitalWrite(PIN_TRIG, LOW);    // terminamos el pulso

long duracion = pulseIn(PIN_ECHO, HIGH);   // medimos cuánto tiempo tardó en volver, en microsegundos
```

## Paso 3: convertir el tiempo en distancia

El sonido viaja a una velocidad conocida, así que ese tiempo se puede convertir en centímetros con una sola operación:

```cpp
int distanciaCm = duracion / 58;   // fórmula estándar del HC-SR04 para convertir a centímetros
```

## Paso 4: mostrar y decidir

```cpp
Serial.println(distanciaCm);   // mostramos el valor mientras se calibra el proyecto

if (distanciaCm < 20) {
  // el umbral (20 cm en este caso) se define después de medir el espacio real del proyecto
  Serial.println("Objeto cerca");
}
```

## En Python (IdeaBoard, IdeaSense con módulo externo)

La lógica de medir un pulso también existe en CircuitPython, aunque cada librería puede simplificarla:

```python
import board
import digitalio
import time
import pulseio

pin_trig = digitalio.DigitalInOut(board.D9)   # pin que envía el pulso
pin_trig.direction = digitalio.Direction.OUTPUT
pin_echo = pulseio.PulseIn(board.D10)         # pin que mide la duración del eco

umbral_cm = 20   # definido después de medir el espacio real

while True:
    pin_trig.value = False
    time.sleep(0.000002)
    pin_trig.value = True                     # enviamos el pulso ultrasónico
    time.sleep(0.00001)
    pin_trig.value = False

    if len(pin_echo) > 0:
        duracion = pin_echo[0]                # duración del pulso, en microsegundos
        distancia_cm = duracion / 58          # convertimos a centímetros
        print(distancia_cm)

        if distancia_cm < umbral_cm:
            print("Objeto cerca")

    pin_echo.clear()
    time.sleep(0.1)
```

## Simplificar con una librería

En Arduino, la librería **NewPing** reduce todo el proceso anterior a tres líneas, útil una vez que el grupo ya entendió cómo funciona el pulso por dentro:

```cpp
#include <NewPing.h>

NewPing sonar(9, 10, 400);   // (pin TRIG, pin ECHO, distancia máxima en cm)

void setup() {
  Serial.begin(9600);
}

void loop() {
  int distanciaCm = sonar.ping_cm();   // la librería hace todo el cálculo internamente
  Serial.println(distanciaCm);
  delay(100);
}
```

> **Nota para docentes:** enseñar primero la versión larga (con `pulseIn`) ayuda a entender qué está pasando realmente. Usar la librería después, una vez comprendido el concepto, agiliza proyectos más grandes.

## Ejemplo progresivo: alarma de proximidad con función y umbral

Este ejemplo integra la declaración de dos pines, la medición de un pulso, un umbral definido a partir de datos reales y una función para organizar la lógica.

```cpp
const int PIN_TRIG = 9;         // pin que envía el pulso ultrasónico
const int PIN_ECHO = 10;        // pin que recibe el eco de vuelta
const int PIN_LED = 13;         // pin del LED de alerta
const int UMBRAL_CM = 20;       // definido después de medir el espacio del proyecto

int medirDistanciaCm() {
  // función que devuelve la distancia medida, en centímetros
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);

  long duracion = pulseIn(PIN_ECHO, HIGH);
  return duracion / 58;
}

void setup() {
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int distancia = medirDistanciaCm();   // llamamos a la función y guardamos el resultado
  Serial.println(distancia);

  if (distancia < UMBRAL_CM) {
    digitalWrite(PIN_LED, HIGH);   // objeto cerca: encendemos la alerta
  } else {
    digitalWrite(PIN_LED, LOW);    // camino libre: apagamos la alerta
  }

  delay(100);
}
```

## Nota docente

Un error frecuente al empezar es intercambiar los pines TRIG y ECHO en el código respecto a como están conectados físicamente. El síntoma es que el Monitor Serial siempre muestra 0 o un número absurdamente grande. Revisar que `pinMode(PIN_TRIG, OUTPUT)` y `pinMode(PIN_ECHO, INPUT)` correspondan exactamente al cableado es el primer paso de depuración.
