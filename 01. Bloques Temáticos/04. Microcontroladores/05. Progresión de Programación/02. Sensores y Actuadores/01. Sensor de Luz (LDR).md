## Bajo qué estándar funciona

La LDR es un componente **analógico**: no entrega solo "sí" o "no", sino un rango de valores. Por eso siempre se conecta a un **pin analógico** (marcado `A0`, `A1`, etc.) y se lee con la función `analogRead()`, que en Arduino devuelve un número entre 0 y 1023.

| Parámetro | Valor típico |
|---|---|
| Tipo de pin | Analógico (`A0`–`A5` en Arduino UNO) |
| Función de lectura | `analogRead(pin)` |
| Rango de lectura | 0 a 1023 (Arduino) |
| Alimentación | 5V (con resistencia de 10 kΩ en divisor de voltaje) |

## Paso 1: declarar el pin

Como se explicó en [`03. Funciones, Pines y Umbrales.md`](../01.%20Fundamentos%20de%20Programación/03.%20Funciones%2C%20Pines%20y%20Umbrales.md), un pin analógico no necesita `pinMode()`, pero sí conviene declararlo como constante para que el resto del código sea legible:

```cpp
const int PIN_LDR = A0;   // declaramos en qué pin analógico está conectada la LDR
```

## Paso 2: leer el sensor

```cpp
void setup() {
  Serial.begin(9600);          // iniciamos el Monitor Serial para ver los valores
}

void loop() {
  int luz = analogRead(PIN_LDR);   // aquí llamamos al sensor de luz y guardamos lo que lee
  Serial.println(luz);              // mostramos el número en el Monitor Serial
  delay(100);                        // esperamos antes de volver a leer
}
```

Abrir el Monitor Serial y tapar/destapar la LDR con la mano es el primer paso obligatorio antes de escribir cualquier lógica: permite ver los números reales del ambiente, en vez de adivinar un umbral.

## Paso 3: definir el umbral con base en lo medido

Siguiendo el proceso descrito en [`03. Funciones, Pines y Umbrales.md`](../01.%20Fundamentos%20de%20Programación/03.%20Funciones%2C%20Pines%20y%20Umbrales.md), se elige un número entre los valores observados con luz y sin luz:

```cpp
const int UMBRAL = 400;   // definido después de medir el ambiente: ajustar según el espacio
```

## Paso 4: tomar una decisión con un condicional

```cpp
const int PIN_LED = 13;

void setup() {
  pinMode(PIN_LED, OUTPUT);   // el LED es una salida digital
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(PIN_LDR);   // leemos el sensor de luz

  if (luz < UMBRAL) {
    digitalWrite(PIN_LED, HIGH);   // oscuro → encendemos el LED
  } else {
    digitalWrite(PIN_LED, LOW);    // hay luz → apagamos el LED
  }

  delay(200);
}
```

## En Python (micro:bit, IdeaSense, IdeaBoard)

La lógica es idéntica; solo cambia la sintaxis. En micro:bit, usando un pin analógico externo:

```python
from microbit import *

# constante: el pin donde está conectada la LDR
PIN_LDR = pin0
UMBRAL = 400   # ajustar después de medir el ambiente

while True:
    luz = PIN_LDR.read_analog()      # leemos el sensor de luz
    if luz < UMBRAL:
        display.show(Image.YES)      # oscuro: mostramos un ícono en la pantalla
    else:
        display.show(Image.NO)       # hay luz: mostramos otro ícono
    sleep(200)
```

La micro:bit también tiene un sensor de luz integrado en su propia pantalla, sin necesitar una LDR externa:

```python
from microbit import *

UMBRAL = 100   # la escala de este sensor va de 0 a 255, distinta a la de una LDR externa

while True:
    luz = display.read_light_level()   # sensor de luz integrado en la pantalla
    if luz < UMBRAL:
        display.scroll("oscuro")
    else:
        display.scroll("luz")
    sleep(500)
```

## Ejemplo progresivo: umbral con aviso por Monitor Serial y LED

Este ejemplo integra todo lo visto en este archivo: declaración de pines, lectura analógica, umbral definido a partir de datos reales y una función para no repetir código.

```cpp
const int PIN_LDR = A0;      // pin analógico del sensor de luz
const int PIN_LED = 13;      // pin digital del LED indicador
const int UMBRAL = 400;      // definido después de medir el ambiente del aula

void avisarSegunLuz(int nivelDeLuz) {
  // función que recibe la lectura como parámetro y decide qué hacer
  if (nivelDeLuz < UMBRAL) {
    digitalWrite(PIN_LED, HIGH);          // está oscuro: encendemos el LED
    Serial.println("Oscuro: LED encendido");
  } else {
    digitalWrite(PIN_LED, LOW);           // hay suficiente luz: apagamos el LED
    Serial.println("Con luz: LED apagado");
  }
}

void setup() {
  pinMode(PIN_LED, OUTPUT);   // configuramos el LED como salida
  Serial.begin(9600);         // iniciamos el Monitor Serial
}

void loop() {
  int luz = analogRead(PIN_LDR);   // leemos el sensor de luz
  avisarSegunLuz(luz);              // llamamos a la función con la lectura actual
  delay(200);                        // esperamos antes de repetir
}
```

## Nota docente

El error más común al programar la LDR por primera vez es olvidar que el valor cambia de forma **inversa** en algunos módulos: en el circuito con resistencia divisora, más luz da un número más bajo; en otros módulos (como algunos sensores de luz integrados), es al revés. La solución siempre es la misma: leer el número en el Monitor Serial antes de escribir cualquier condicional, y confirmar en qué dirección cambia.
