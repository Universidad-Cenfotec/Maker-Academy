La IdeaSense es una placa educativa creada por **CRCibernética** (Costa Rica), diseñada para introducir la programación física con Python en el aula. Su nombre viene de "Idea + Sense" (sentido, sensación): es una placa llena de sensores que permiten al estudiante "sentir" el entorno y reaccionar a él con código.

A diferencia de la IdeaBoard (orientada a robótica e internet), la IdeaSense es una placa compacta enfocada en **sensores y visualización**, similar a la micro:bit pero con más capacidades de medición del ambiente: temperatura, humedad, luz y movimiento, todo integrado en una sola placa sin necesitar módulos externos.

**Imagínala como un pequeño laboratorio de ciencias en miniatura: puede sentir si hace calor o frío, si está oscuro o iluminado, si alguien la está sacudiendo o inclinando, y mostrar todo eso en su pantalla de LEDs.**

## Propósito

Documentar la plataforma IdeaSense de CRCibernética para que los docentes de Maker Academy conozcan esta placa costarricense con sensores integrados de temperatura, luz, movimiento y una matriz de LEDs 5x5.

## ¿Qué tiene integrado?

| Componente | ¿Qué detecta o hace? |
|---|---|
| Matriz de LEDs 5×5 | Muestra imágenes, letras, números y animaciones |
| Sensor de temperatura y humedad (SHT31D) | Mide la temperatura del ambiente y la humedad del aire |
| Sensor de luz (LTR303) | Detecta cuánta luz hay en el ambiente |
| Acelerómetro + Giroscopio (LSM6DS3TRC) | Detecta movimiento, inclinación y agitación en 6 direcciones |
| 3 botones (A, B, C) | Para que el usuario interactúe con el programa |

**Todo esto integrado en la placa, sin necesitar ningún componente extra.** Desde la primera sesión se puede medir temperatura, detectar movimiento y mostrar datos en la pantalla.

---

## Entorno de programación: IdeaCode (CircuitPython)

La IdeaSense se programa con **IdeaCode**, un editor en línea de CircuitPython desarrollado por CRCibernética. CircuitPython es una versión de Python diseñada para placas educativas: el código se escribe en Python normal, y la placa lo ejecuta en cuanto se guarda el archivo.

URL: [`https://ideacode.crcibernetica.com/`](https://ideacode.crcibernetica.com/)

**¿Cómo funciona?**
1. Conectar la IdeaSense por USB. Aparece como una memoria USB llamada `CIRCUITPY`.
2. Abrir `ideacode.crcibernetica.com` en el navegador.
3. Escribir el código en Python.
4. Guardar. La placa ejecuta el programa de inmediato.
5. Si hay un error, aparece en el monitor serial con el número de línea exacta.

**No hay pasos de compilación, ni instalación de software.** El ciclo de prueba es instantáneo: cambiar, guardar, ver el resultado.

## Primeros pasos con la placa

```python
# Este programa muestra la temperatura en la pantalla de LEDs
from ideasense import IdeaSense
import time

idea = IdeaSense()

while True:
    temp = idea.temp          # leer temperatura en Celsius
    idea.matrix.fill(0)       # limpiar pantalla
    print("Temperatura:", temp)
    time.sleep(1)
```

Para usar los botones:

```python
from ideasense import IdeaSense
import time

idea = IdeaSense()

while True:
    botones = idea.pressed    # detectar qué botón se presionó
    
    if botones[0]:            # Botón A
        print("¡Presionaste A!")
    elif botones[1]:          # Botón B
        print("¡Presionaste B!")
    elif botones[2]:          # Botón C
        print("¡Presionaste C!")
    
    time.sleep(0.05)
```

## Sensores en detalle

### ️ Temperatura y Humedad

Mide la temperatura del aire en grados Celsius y el porcentaje de humedad relativa del ambiente. Ideal para estaciones meteorológicas, experimentos de ciencias o proyectos de monitoreo ambiental.

```python
temperatura = idea.temp    # ejemplo: 24.5 (°C)
humedad = idea.humid       # ejemplo: 65.2 (%)
```

###  Sensor de Luz

Detecta cuánta luz hay en el ambiente, incluyendo luz visible e infrarroja. Permite proyectos como lámparas automáticas o detectores de día/noche.

```python
nivel_luz = idea.light     # valor numérico: más alto = más luz
```

###  Acelerómetro y Giroscopio

El acelerómetro detecta cuánta fuerza de movimiento hay en cada dirección (x, y, z). El giroscopio detecta la velocidad de rotación. Juntos, permiten detectar si la placa se sacude, se inclina o se lanza al aire.

```python
ax, ay, az = idea.accel    # aceleración en x, y, z (m/s²)
gx, gy, gz = idea.gyro    # rotación en x, y, z (grados/segundo)
```

###  Matriz de LEDs 5×5

La pantalla es una cuadrícula de 25 LEDs (5 filas × 5 columnas). Cada LED se puede encender o apagar individualmente usando coordenadas (x, y) de 0 a 4.

```python
idea.matrix.fill(0)        # apagar todos los LEDs
idea.matrix[2, 2] = 1     # encender el LED del centro
idea.matrix.brightness(0.5)  # ajustar brillo (0.0 a 1.0)
idea.matrix.show()         # aplicar los cambios a la pantalla
```

## Ventajas y limitaciones

**Ventajas:**
- 5 tipos de sensores integrados permiten proyectos de ciencias reales desde la primera clase
- CircuitPython en IdeaCode es muy accesible: el flujo de editar → guardar → ver resultado elimina la fricción del proceso de carga
- La librería IdeaSense simplifica el uso de todos los sensores a comandos de una sola línea
- Es un producto costarricense con soporte local
- Similar a micro:bit en concepto pero con más capacidades de medición ambiental

**Limitaciones:**
- Solo se puede programar en Python (CircuitPython), no tiene entorno de bloques como MakeCode
- No tiene WiFi ni Bluetooth integrado (para conectividad inalámbrica se necesita la IdeaBoard)
- La comunidad y los recursos disponibles en internet son más limitados que los de micro:bit
- La matriz de LEDs 5×5 solo muestra blanco/negro (no tiene colores)
- Requiere acceso a internet para usar IdeaCode (editor en línea)

## Nota docente

La IdeaSense es especialmente valiosa para proyectos de ciencias integradas con tecnología. Un grupo de secundaria puede diseñar una investigación real: "¿Cómo cambia la temperatura y la humedad en distintos espacios del colegio?" y usar la IdeaSense para recopilar los datos.

La curva de entrada con CircuitPython es mayor que con bloques (MakeCode de micro:bit), por lo que se recomienda introducirla con grupos que ya tengan alguna base de programación. Sin embargo, la librería IdeaSense hace que leer sensores sea muy simple: `idea.temp` devuelve la temperatura en una sola palabra.

La IdeaSense e IdeaBoard se complementan bien: la IdeaSense es ideal para proyectos de ciencias y visualización de datos, mientras que la IdeaBoard es mejor para robótica y proyectos conectados a internet.
