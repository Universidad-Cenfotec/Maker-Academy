## Descripción

Arduino es la plataforma de hardware y software de código abierto más influyente en la historia de la educación tecnológica. Desde su creación en 2005 en el Instituto de Diseño de Interacción de Ivrea (Italia), se convirtió en el estándar de facto para introducir la programación de microcontroladores en todos los niveles: desde talleres de artistas hasta programas universitarios de ingeniería.

El Arduino UNO es la placa más popular y documentada del ecosistema. El Arduino Nano es funcionalmente casi idéntico pero en un formato más pequeño y económico, ideal para proyectos donde el tamaño importa o para usar como componente embebido dentro de un ensamble.

A diferencia de micro:bit o Circuit Playground, Arduino UNO no tiene casi nada integrado (solo un LED en el pin 13 y un LED de encendido). Todo lo que el proyecto necesita debe conectarse externamente. Eso lo hace más versátil pero también más demandante en cuanto a conocimiento de electrónica básica.

## Entorno de programación: Arduino IDE

El Arduino IDE es la aplicación oficial para escribir, compilar y cargar programas en placas Arduino. Existe en dos versiones: Arduino IDE 1.8 (más estable, compatible con más shields) y Arduino IDE 2.x (más moderno, con autocompletado y depurador).

**Instalación:** Se descarga desde `arduino.cc/en/software`. Requiere instalación en el sistema operativo y, en algunos sistemas, la instalación manual del driver USB (especialmente en versiones chinas del Arduino con chip CH340).

**Estructura de un programa Arduino (sketch):**

```cpp
// Este código se ejecuta una sola vez al encender la placa
void setup() {
  pinMode(13, OUTPUT);  // configura el pin 13 como salida
}

// Este código se ejecuta repetidamente, para siempre
void loop() {
  digitalWrite(13, HIGH);  // enciende el LED
  delay(1000);              // espera 1 segundo
  digitalWrite(13, LOW);   // apaga el LED
  delay(1000);              // espera 1 segundo
}
```

El programa más simple de Arduino (Blink) hace parpadear el LED integrado del pin 13. Es el "Hola Mundo" de la programación física.

## Pines del Arduino UNO

### Pines digitales (D0 a D13)
Pueden configurarse como entrada o salida. En modo salida, producen 0V (LOW) o 5V (HIGH). Los pines marcados con tilde (~) admiten PWM: D3, D5, D6, D9, D10, D11.

### Pines analógicos (A0 a A5)
Leen voltajes entre 0V y 5V y los convierten en números de 0 a 1023 (resolución de 10 bits). También pueden usarse como pines digitales adicionales.

### Pines de alimentación
- **5V:** Suministra 5V regulados desde el USB o la fuente externa.
- **3.3V:** Suministra 3.3V (máximo 50mA). Para módulos de bajo voltaje.
- **GND:** Dos pines de tierra disponibles.
- **VIN:** Entrada para fuente externa (7-12V).

## Flujo de trabajo

1. Instalar Arduino IDE en la computadora.
2. Conectar la placa por USB.
3. En el IDE, seleccionar el modelo de placa (Herramientas > Placa > Arduino UNO) y el puerto COM correcto.
4. Escribir el sketch.
5. Hacer clic en "Cargar" (flecha hacia la derecha). El IDE compila y envía el programa a la placa.
6. La placa ejecuta el programa inmediatamente.

El paso más problemático para usuarios nuevos suele ser seleccionar el puerto COM correcto. Si no aparece ningún puerto, generalmente es un problema de driver USB.

## Diferencias entre UNO y Nano

El Arduino Nano usa exactamente el mismo microcontrolador (ATmega328P) y tiene el mismo conjunto de instrucciones. Las diferencias prácticas son:

- El Nano es más pequeño y se inserta directamente en el protoboard.
- El UNO tiene un conector USB tipo B (como las impresoras antiguas), el Nano usa mini-USB o micro-USB.
- El Nano tiene 2 pines analógicos extra (A6 y A7), pero solo pueden usarse como entradas analógicas, no como digitales.
- Los Nanos genéricos (chinos) suelen traer el chip CH340 en lugar del FTDI, lo que requiere instalar un driver adicional en algunos sistemas operativos.

En el Arduino IDE, al seleccionar el modelo de placa para Nano genérico con CH340: `Herramientas > Placa > Arduino Nano` y en "Procesador": `ATmega328P (Old Bootloader)`.

## Ventajas y limitaciones

**Ventajas:**
- El ecosistema más amplio del mundo: millones de proyectos documentados, miles de librerías, foros activos en todos los idiomas
- Compatible con la mayor variedad de sensores, módulos y shields
- Opera a 5V, que es el voltaje de la mayoría de los sensores y módulos económicos del mercado
- El lenguaje (C++ simplificado) es la base de muchos otros lenguajes de programación

**Limitaciones:**
- Requiere instalación de software en la computadora (no funciona solo en navegador)
- Sin conectividad inalámbrica integrada (necesita módulos HC-05, ESP8266, NRF24L01)
- La memoria RAM de 2KB es muy limitada para proyectos complejos
- La curva de entrada es más pronunciada que con micro:bit o Circuit Playground para grupos sin experiencia

## Notas docentes

Arduino es la plataforma adecuada cuando el objetivo es que el estudiante aprenda programación en texto y electrónica real. No es la mejor entrada para grupos sin experiencia porque requiere instalar software, entender la estructura setup/loop y conectar todo externamente. Pero cuando el grupo ya tiene ese contexto, Arduino ofrece la mayor versatilidad y la mejor preparación para proyectos avanzados.

Un tip práctico: antes de la primera sesión, instalar Arduino IDE y probar el sketch "Blink" (incluido en Archivo > Ejemplos) en todas las placas. Esto confirma que el driver USB funciona y que las placas están en buen estado.
