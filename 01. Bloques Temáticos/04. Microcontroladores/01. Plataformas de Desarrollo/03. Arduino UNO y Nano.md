## Descripción

<img width="300" alt="Arduino Nano, versión compacta del Arduino UNO ideal para proyectos donde el espacio es limitado" src="https://upload.wikimedia.org/wikipedia/commons/thumb/8/8d/Arduino_Nano.jpg/320px-Arduino_Nano.jpg" />

Arduino es la plataforma de hardware y software educativo más usada en el mundo para aprender electrónica y programación. Existe desde 2005 y se convirtió en el estándar en talleres, colegios y universidades de todo el planeta.

El **Arduino UNO** es la placa más popular. El **Arduino Nano** es funcionalmente casi idéntico pero más pequeño y económico, ideal para proyectos donde el tamaño importa.

A diferencia de la micro:bit o el Circuit Playground, el Arduino UNO prácticamente no tiene nada integrado (solo un LED en el pin 13). Todo lo que el proyecto necesita —sensores, motores, pantallas— se conecta externamente. Eso lo hace más versátil, pero también requiere más conocimiento de electrónica básica para comenzar.

## Propósito

Documentar las placas Arduino UNO y Nano para que los docentes de Maker Academy puedan utilizarlas en proyectos de nivel intermedio-avanzado que requieran mayor control sobre el hardware.

## ¿Qué tiene integrado?

Muy poco, y eso es intencional:

| Componente | Detalle |
|---|---|
| 1 LED (pin 13) | Para pruebas básicas |
| 14 pines digitales | Para conectar LEDs, botones, sensores, etc. |
| 6 pines analógicos | Para leer sensores de luz, temperatura, potenciómetros, etc. |
| Puerto USB | Para conectar al computador y cargar programas |
| Conector de alimentación | Para usar con pilas o fuente externa |

Todo lo demás (pantallas, motores, sensores, LEDs de colores) se agrega conectando módulos externos.

## El entorno de programación: Arduino IDE

El Arduino IDE es el programa donde se escribe el código y se envía a la placa. Se descarga desde `arduino.cc/en/software` e instala en el computador. También existe una versión en línea en `create.arduino.cc`.

Los programas de Arduino se llaman **sketches** y tienen una estructura básica:

```cpp
// Este código se ejecuta UNA SOLA VEZ al encender la placa
void setup() {
  pinMode(13, OUTPUT);  // configurar el pin 13 como salida
}

// Este código se repite PARA SIEMPRE
void loop() {
  digitalWrite(13, HIGH);  // encender el LED
  delay(1000);              // esperar 1 segundo
  digitalWrite(13, LOW);   // apagar el LED
  delay(1000);              // esperar 1 segundo
}
```

El programa más simple hace parpadear el LED integrado del pin 13. Es el "Hola Mundo" de la programación física, y viene incluido en el IDE: `Archivo > Ejemplos > 01.Basics > Blink`.

## ¿Cómo se usa por primera vez?

1. Instalar el Arduino IDE desde `arduino.cc/en/software`.
2. Conectar la placa por USB.
3. En el IDE, seleccionar el modelo de placa (`Herramientas > Placa > Arduino UNO`) y el puerto correcto.
4. Escribir o abrir el ejemplo Blink.
5. Hacer clic en "Cargar" (la flecha →). El IDE compila y envía el programa.
6. La placa ejecuta el programa inmediatamente.

> El paso más problemático para quienes empiezan suele ser seleccionar el puerto correcto. Si no aparece ningún puerto en la lista, generalmente es un problema del cable USB o del driver.

## Diferencia entre UNO y Nano

| | Arduino UNO | Arduino Nano |
|---|---|---|
| Tamaño | Más grande | Pequeño (entra en protoboard) |
| Precio aprox. | USD 5–15 | USD 3–8 |
| Conector USB | Tipo B (cuadrado) | Mini o Micro USB |
| Funcionalidad | Igual | Igual + 2 pines analógicos extra |

Los Nano genéricos (fabricados en China) suelen necesitar instalar un driver adicional (CH340) la primera vez.

## Ventajas y limitaciones

**Ventajas:**
- El ecosistema más grande del mundo: millones de proyectos documentados, miles de librerías, comunidad activa
- Compatible con la mayor variedad de sensores y módulos del mercado
- Opera a 5V, el voltaje de la mayoría de los sensores económicos
- La base para muchas carreras técnicas y universitarias

**Limitaciones:**
- Requiere instalar software en el computador (no funciona solo en el navegador)
- Sin conectividad inalámbrica integrada (necesita módulos adicionales)
- La curva de entrada es más pronunciada que con micro:bit o Circuit Playground

## Nota docente

Arduino es la plataforma correcta cuando el objetivo es que el estudiante aprenda a programar en texto y a conectar circuitos electrónicos reales. No es la mejor entrada para grupos sin ninguna experiencia, porque requiere instalar software, entender la estructura del programa y conectar todo manualmente.

Pero cuando el grupo ya tiene esa base, Arduino ofrece la mayor versatilidad y la mejor preparación para continuar en proyectos avanzados.

**Consejo práctico:** antes de la primera sesión con el grupo, probar el ejemplo Blink en todas las placas. Esto confirma que el driver USB funciona y que las placas están en buen estado. Si alguna falla, es mejor saberlo antes de la clase.

Para niveles de secundaria que todavía no programan en texto, se puede empezar con la versión en línea de Arduino (`create.arduino.cc`) que tiene menos pasos de configuración.
