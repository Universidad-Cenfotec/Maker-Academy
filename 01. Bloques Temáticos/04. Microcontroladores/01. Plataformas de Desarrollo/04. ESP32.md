## Descripción

<img width="400" alt="Módulo NodeMCU ESP8266, predecesor del ESP32, mostrando el formato compacto de los módulos WiFi para microcontroladores" src="https://upload.wikimedia.org/wikipedia/commons/thumb/e/eb/A-nodemcu-esp8266.jpg/320px-A-nodemcu-esp8266.jpg" />

El ESP32 es un microcontrolador de la empresa Espressif Systems (China) que desde su lanzamiento en 2016 se volvió enormemente popular por una razón sencilla: tiene WiFi y Bluetooth integrados a un precio muy bajo (entre USD 5 y 10), cuando otras opciones con conectividad equivalente cuestan mucho más.

Es la plataforma ideal para proyectos de **Internet de las Cosas (IoT)**: sistemas que envían datos a internet, se controlan desde el celular, o se comunican entre sí de forma inalámbrica.

Técnicamente es mucho más potente que un Arduino UNO, pero esa potencia viene con mayor complejidad de configuración. Por eso se recomienda para grupos que ya tienen experiencia previa con programación y electrónica.

## Propósito

Documentar la plataforma ESP32 para que los docentes de Maker Academy puedan utilizarla en proyectos avanzados con conectividad WiFi y Bluetooth, apropiados para proyectos de IoT educativo.

## ¿Qué tiene integrado?

| Característica | Detalle |
|---|---|
| WiFi | Conecta a redes inalámbricas (802.11 b/g/n, 2.4 GHz) |
| Bluetooth | Clásico + BLE para comunicarse con celulares |
| Pines digitales | Hasta 34 pines para conectar sensores y actuadores |
| Entradas analógicas | 18 canales para leer sensores de temperatura, luz, etc. |
| Precio aproximado | USD 5–10 (módulo) / USD 8–15 (placa de desarrollo) |

Lo que **no** tiene integrado (y hay que agregar externamente): sensores, pantalla, altavoz, botones, LEDs de colores.

---

## Variantes más comunes

**ESP32 DevKit / DOIT ESP32 DEVKIT V1** — La más usada en educación. Tiene todos los pines accesibles y se conecta directo al computador por USB.

**ESP32-C3** — Versión económica de núcleo único. Compatible con Arduino y MicroPython. Buena opción cuando el costo es lo más importante.

## Entornos de programación

### Arduino IDE (recomendado para secundaria)

Se puede programar el ESP32 con el mismo Arduino IDE que Arduino, agregando el soporte de placas de Espressif. Una vez configurado, el código sigue la misma estructura (setup y loop) y se pueden usar librerías para WiFi, Bluetooth y más.

**Cómo agregar el soporte ESP32 en Arduino IDE:**
1. Abrir Arduino IDE.
2. Ir a `Archivo > Preferencias`.
3. En "URLs adicionales para gestor de placas", agregar: `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
4. Ir a `Herramientas > Placa > Gestor de placas`, buscar "esp32" e instalar.
5. Seleccionar `ESP32 Dev Module`.

### MicroPython

El ESP32 también funciona con MicroPython, una versión de Python para microcontroladores. Para usarlo hay que instalar el firmware de MicroPython en la placa (proceso de una sola vez) y luego usar Thonny IDE.

## Ejemplo: conectar al WiFi

```cpp
#include <WiFi.h>

const char* ssid = "NombreDeTuRed";
const char* password = "ContraseñaDeTuRed";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("¡Conectado a WiFi!");
}

void loop() {
  // el resto del programa va aquí
}
```

## Cosas importantes a saber

**Los pines trabajan a 3.3V**, no a 5V como Arduino. Algunos sensores económicos de 5V no son directamente compatibles sin un adaptador.

**WiFi consume bastante energía**: si el proyecto va a funcionar con pilas, hay que considerar estrategias de ahorro de energía o usar una batería más grande.

---

## Ventajas y limitaciones

**Ventajas:**
- WiFi y Bluetooth integrados al precio más bajo del mercado
- Mucho más potente que Arduino UNO
- Compatible con el ecosistema Arduino (librerías, proyectos)
- MicroPython disponible sin modificaciones de hardware

**Limitaciones:**
- No tiene entorno de bloques educativo oficial (no hay MakeCode para ESP32)
- La configuración inicial puede ser un obstáculo para grupos sin experiencia
- Menos recursos educativos en español que para Arduino UNO o micro:bit

## Nota docente

El ESP32 es la plataforma correcta cuando el proyecto requiere conectividad inalámbrica y el grupo ya tiene experiencia con Arduino. No es una buena entrada para grupos sin experiencia porque la configuración inicial puede consumir tiempo valioso de clase.

**Consejo clave:** tener las placas ya configuradas y probadas antes de que el grupo llegue. Dejar la configuración del software para la clase puede frustrar a quienes todavía no dominan los pasos técnicos.

Para secundaria que ya programó con Arduino, el salto al ESP32 es relativamente natural porque el código tiene la misma estructura (setup y loop). La principal novedad es el acceso al WiFi y Bluetooth.
