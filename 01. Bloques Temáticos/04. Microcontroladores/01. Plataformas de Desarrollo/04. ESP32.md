## Descripción

El ESP32 es un microcontrolador diseñado por la empresa china Espressif Systems. Desde su lanzamiento en 2016 se volvió enormemente popular en el mundo maker y en la industria por una razón simple: ofrece WiFi y Bluetooth integrados a un precio que ronda los 5 a 10 dólares, cuando otras placas con conectividad inalámbrica equivalente cuestan 5 a 10 veces más.

Técnicamente es significativamente más potente que un Arduino UNO: procesador de doble núcleo, mucha más memoria, mayor velocidad, más pines y capacidades que el ATmega328P de Arduino simplemente no tiene. Sin embargo, esa potencia viene con mayor complejidad de configuración inicial.

Es la plataforma de elección para proyectos de Internet de las Cosas (IoT): sistemas que envían datos a la nube, reciben comandos desde una app, o se comunican entre sí de forma inalámbrica.

## Especificaciones técnicas

| Característica | Detalle |
|---|---|
| Procesador | Xtensa LX6 dual-core, hasta 240 MHz |
| Memoria RAM | 520 KB SRAM |
| Memoria Flash | 4 MB (típico, depende del módulo) |
| Voltaje de operación | 3.3V |
| Pines digitales | Hasta 34 pines GPIO |
| Pines analógicos | 18 canales ADC de 12 bits (0 a 4095) |
| PWM | Hasta 16 canales |
| WiFi | 802.11 b/g/n (2.4 GHz) |
| Bluetooth | Bluetooth clásico + BLE 4.2 |
| Protocolos | UART, I2C, SPI, I2S, CAN |
| Precio aproximado | USD 4-10 (módulo) / USD 8-15 (placa de desarrollo) |

## Variantes más comunes

**ESP32 DevKit / DOIT ESP32 DEVKIT V1**
La placa de desarrollo más usada en educación y proyectos maker. Tiene el módulo ESP32-WROOM soldado sobre una placa con regulador de voltaje, chip USB-serial (CP2102 o CH340) y pines en ambos lados. Se inserta directamente en el protoboard, aunque al ser tan ancha puede tapar todos los rieles si se usa un protoboard estándar de 400 puntos.

**ESP32-S2 y ESP32-S3**
Versiones más recientes con mejoras en seguridad (S2) y en procesamiento (S3, con núcleo de IA). Para educación básica no hay diferencia práctica con el ESP32 original.

**ESP32-C3**
Versión de núcleo único (RISC-V) y precio muy bajo. Compatible con Arduino y MicroPython. Buena opción cuando el costo es determinante.

## Entornos de programación

### Arduino IDE (recomendado para secundaria)

Se puede programar el ESP32 con el Arduino IDE agregando el soporte de placas Espressif. El proceso es:

1. Abrir Arduino IDE.
2. Ir a Archivo > Preferencias.
3. En "URLs adicionales para gestor de placas", agregar: `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
4. Ir a Herramientas > Placa > Gestor de placas.
5. Buscar "esp32" e instalar el paquete de Espressif.
6. Seleccionar la placa: `ESP32 Dev Module`.

Una vez configurado, el código sigue la misma estructura que Arduino (setup y loop), con acceso a librerías adicionales para WiFi, Bluetooth y otros periféricos del ESP32.

### MicroPython

El ESP32 soporta MicroPython. Para usarlo, primero hay que "flashear" el firmware de MicroPython en la placa (proceso de una sola vez), luego se puede usar con Thonny IDE o con `ampy` desde la terminal.

MicroPython en ESP32 incluye módulos para WiFi, I2C, SPI, PWM y más, directamente en el lenguaje.

## WiFi con Arduino (ejemplo básico)

```cpp
#include <WiFi.h>

const char* ssid = "NombreDeTuRed";
const char* password = "ContraseñaDeTuRed";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("Conectado a WiFi");
  Serial.println(WiFi.localIP());
}

void loop() {
  // El resto del programa va aquí
}
```

## Consideraciones importantes

**Voltaje de 3.3V**
Los GPIO del ESP32 operan a 3.3V. Conectar señales de 5V directamente puede dañar el pin. Si se usan sensores o módulos de 5V, se necesita un divisor de voltaje o un convertidor de nivel lógico.

**Corriente por pin**
Los pines del ESP32 pueden suministrar hasta 40 mA individualmente, pero la corriente total de todos los GPIO simultáneamente no debe superar 1200 mA. Para LEDs o motores, usar resistencias y drivers.

**Pines con restricciones**
Algunos pines del ESP32 tienen funciones especiales que pueden causar comportamientos inesperados al inicio. Los GPIO6 a GPIO11 están conectados a la flash interna y no deben usarse. GPIO34 a GPIO39 son solo entradas.

**Consumo de WiFi**
El módulo WiFi consume considerablemente más corriente que un Arduino en reposo. Un ESP32 con WiFi activo consume entre 100 mA y 300 mA. No es conveniente alimentarlo con pilas AA para proyectos permanentes.

## Ventajas y limitaciones

**Ventajas:**
- WiFi y Bluetooth integrados a precio accesible
- Mucho más potente que Arduino UNO (más velocidad, más memoria, más pines)
- Compatible con el ecosistema Arduino (librerías, shields adaptados)
- MicroPython disponible sin modificaciones de hardware

**Limitaciones:**
- No hay entorno de bloques educativo oficial con soporte completo (no tiene MakeCode)
- La configuración inicial (instalar soporte de placas en IDE) puede ser un obstáculo
- Operar a 3.3V requiere cuidado con módulos de 5V
- La comunidad educativa hispana tiene menos recursos específicos para ESP32 que para Arduino UNO o micro:bit

## Notas docentes

El ESP32 es la plataforma correcta cuando el proyecto requiere conectividad inalámbrica y el grupo tiene experiencia previa con Arduino. No es una buena entrada para grupos sin experiencia porque la configuración inicial puede consumir una sesión entera si hay problemas de drivers o de red.

Una estrategia eficaz: tener las placas ya configuradas y probadas antes de que el grupo llegue. El tiempo de clase es muy valioso para usarlo resolviendo problemas de instalación que pueden hacerse antes.
