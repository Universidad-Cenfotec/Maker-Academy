## Descripción

La micro:bit es una placa de desarrollo educativa creada originalmente por la BBC en 2015 para distribuir en escuelas del Reino Unido. Desde entonces se convirtió en una de las herramientas más adoptadas mundialmente para enseñar programación y electrónica en contextos escolares. Su fortaleza principal es que tiene suficiente hardware integrado para hacer proyectos significativos sin necesitar componentes externos.

La versión actual (micro:bit V2) incluye: matriz de 25 LEDs programables, 2 botones, acelerómetro, magnetómetro, termómetro, micrófono, altavoz, radio (2.4 GHz), Bluetooth y conector de pines en la parte inferior (borde edge connector).

Analogía: si una computadora de escritorio es una cocina completa, la micro:bit es una cocina de camping. Tiene todo lo que necesitas para preparar algo real, en un formato compacto que puedes llevar a cualquier parte.

## Especificaciones técnicas

| Característica | Detalle |
|---|---|
| Procesador | Nordic nRF52833, ARM Cortex-M4 a 64 MHz |
| Memoria RAM | 128 KB |
| Memoria Flash | 512 KB |
| Voltaje de operación | 3.3V |
| Pines de E/S | 25 (edge connector), 5 con anillos grandes (P0, P1, P2, 3V, GND) |
| Display | Matriz 5x5 LEDs rojos |
| Botones | 2 botones táctiles (A y B) + logo táctil (V2) |
| Sensores integrados | Acelerómetro, magnetómetro, termómetro, micrófono (V2) |
| Audio | Altavoz integrado (V2) |
| Comunicación | Radio 2.4GHz, Bluetooth 5.0 |
| Alimentación | USB micro o 2 pilas AAA |

## Entorno de programación

### MakeCode (principal para primaria y secundaria inicial)

MakeCode para micro:bit es un entorno de bloques que funciona directamente en el navegador sin instalar nada. El programa se construye arrastrando bloques de colores y el resultado se visualiza en un simulador antes de cargarlo a la placa física.

URL: `makecode.microbit.org`

Características clave:
- Simulador en tiempo real: se puede probar el programa antes de tener la placa
- Vista JavaScript: permite ver el código en texto equivalente a los bloques en cualquier momento
- Sin instalación: solo se necesita un navegador y un cable USB
- Descarga como archivo .hex que se copia a la placa como si fuera una memoria USB

### MicroPython (para secundaria y transición a texto)

MicroPython es una versión de Python optimizada para microcontroladores. En la micro:bit se puede usar a través del editor en línea `python.microbit.org` o con Mu Editor (instalable).

Es ideal para el momento en que el grupo ya domina los bloques y quiere ver cómo es el código "real" detrás de los bloques visuales.

## Primeros pasos con la placa

1. Conectar la micro:bit al computador con cable USB. Aparece como unidad de disco llamada `MICROBIT`.
2. Abrir `makecode.microbit.org` en el navegador.
3. Crear un programa simple (por ejemplo, mostrar un corazón al presionar el botón A).
4. Hacer clic en "Descargar". Se descarga un archivo `.hex`.
5. Copiar ese archivo a la unidad `MICROBIT` (como si fuera un pendrive).
6. La placa parpadea brevemente y ejecuta el programa.

## Pines y conexiones externas

La micro:bit tiene 25 pines accesibles mediante el conector de borde (edge connector). Para conectar componentes externos se recomienda usar una placa breakout (expansión de pines) que convierte el conector de borde en pines estándar de 2.54mm.

Los pines P0, P1 y P2 tienen anillos grandes en la placa base que permiten conectar caimanes directamente sin accesorios adicionales. Son ideales para primeros proyectos con LEDs externos o sensores simples.

**Voltaje importante:** Los pines operan a 3.3V. No conectar componentes de 5V directamente.

## Ventajas y limitaciones

**Ventajas:**
- Hardware integrado permite proyectos desde la primera sesión sin circuitos externos
- Simulador facilita la depuración sin necesidad de la placa física
- Comunidad educativa muy activa: miles de proyectos documentados disponibles
- La transición de bloques a texto (MicroPython) es natural dentro de la misma plataforma

**Limitaciones:**
- No tiene WiFi ni puede conectarse a Internet directamente (solo Bluetooth y radio)
- Los pines son de 3.3V, lo que limita la compatibilidad con algunos módulos comunes de 5V
- El edge connector requiere una placa breakout para proyectos más complejos
- El display de 5x5 LEDs solo puede mostrar texto e imágenes de baja resolución

## Notas docentes

La micro:bit es probablemente la plataforma más fácil para comenzar con grupos sin experiencia. El simulador de MakeCode es especialmente valioso porque permite al estudiante probar el programa y ver que funciona antes de transferirlo a la placa, lo que separa los errores de lógica de los problemas de hardware.

Una advertencia frecuente: la micro:bit guarda un solo programa a la vez. Al cargar uno nuevo, el anterior se borra. Esto es normal y no es un error.
