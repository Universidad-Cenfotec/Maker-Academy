I2C es un protocolo de comunicación que permite conectar **múltiples sensores y módulos usando solo dos cables**. Sin importar cuántos dispositivos se conecten, siempre son los mismos dos cables de señal. Es como un bus escolar: un solo camino por donde viajan todos los pasajeros, pero cada uno sabe cuándo le toca subir o bajar.


## Propósito

Explicar el protocolo I2C para que los docentes puedan conectar múltiples sensores y pantallas OLED al microcontrolador usando solo dos cables de datos.

---

## Los dos cables

| Cable | ¿Para qué sirve? |
|---|---|
| **SDA** (Serial Data) | Por aquí viajan los datos |
| **SCL** (Serial Clock) | Marca el ritmo de la comunicación |

En Arduino UNO/Nano: SDA = pin A4, SCL = pin A5
En ESP32: SDA = pin 21, SCL = pin 22

## Cada dispositivo tiene una "dirección"

Cuando varios dispositivos comparten los mismos dos cables, ¿cómo sabe el Arduino cuál es cuál? Cada dispositivo tiene una **dirección única** (un número). El Arduino llama a esa dirección antes de enviar o pedir datos.

| Dispositivo | Dirección típica |
|---|---|
| Pantalla OLED SSD1306 | 0x3C |
| Reloj de tiempo real DS3231 | 0x68 |
| Acelerómetro MPU6050 | 0x68 o 0x69 |
| Sensor de temperatura MCP9808 | 0x18 |

---

## Encontrar la dirección de un módulo: I2C Scanner

Si no se conoce la dirección de un módulo nuevo, este programa la detecta automáticamente:

```cpp
#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  Serial.println("Buscando dispositivos I2C...");

  for (int addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.print("Dispositivo encontrado en dirección: 0x");
      Serial.println(addr, HEX);
    }
  }
  Serial.println("Búsqueda completada.");
}

void loop() {}
```

## Pantalla OLED con I2C

La pantalla OLED SSD1306 (128×64 píxeles, negro y blanco) es uno de los módulos I2C más populares en proyectos educativos. Solo necesita 4 cables para funcionar: VCC, GND, SDA y SCL.

<img width="648" height="353" alt="image" src="https://github.com/user-attachments/assets/6ef77616-5ff9-42d3-9788-eff71fa1cbee" />

```cpp
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 pantalla(128, 64, &Wire, -1);

void setup() {
  pantalla.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  pantalla.clearDisplay();
  pantalla.setTextSize(2);
  pantalla.setTextColor(WHITE);
  pantalla.setCursor(10, 20);
  pantalla.println("Hola!");
  pantalla.display();
}

void loop() {}
```

Instalar desde el Gestor de Librerías del IDE: `Adafruit SSD1306` y `Adafruit GFX Library`.

## Módulos I2C más útiles en educación

| Módulo | ¿Para qué sirve? |
|---|---|
| **OLED SSD1306** | Pantalla pequeña para mostrar texto y datos |
| **DS3231 RTC** | Reloj de tiempo real (hora y fecha exactas) |
| **BME280** | Temperatura, humedad y presión barométrica |
| **MPU6050** | Acelerómetro y giroscopio (detecta movimiento) |
| **PCF8574** | Agrega 8 pines digitales adicionales al Arduino |

## Ventaja de I2C: múltiples módulos, dos cables

Se pueden conectar varios módulos I2C al mismo tiempo en los mismos cables SDA y SCL, siempre que cada uno tenga una dirección diferente:

```
Arduino → SDA ─────┬──────────┬──────────┐
          SCL ─────┴──────────┴──────────┘
                   │          │          │
                OLED       DS3231    BME280
               (0x3C)     (0x68)    (0x76)
```

## Ideas de proyectos

- **Reloj de tiempo real:** mostrar la hora y fecha en una pantalla OLED
- **Estación meteorológica:** temperatura, humedad y presión en pantalla
- **Nivel de actividad:** acelerómetro MPU6050 detecta si alguien está caminando o corriendo
- **Pantalla de información:** mostrar el valor de sensores en una pantalla OLED en tiempo real

## Aplicación en Maker Academy

Se usa cuando se conectan sensores de temperatura/humedad, pantallas OLED u otros módulos que usan el bus I2C. Muy común con la IdeaSense y módulos STEMMA/QWIIC.

## Nota docente

I2C es el protocolo ideal para proyectos educativos donde se quieren conectar múltiples módulos porque simplifica mucho el cableado. Donde antes necesitabas 8 o 10 cables para conectar una pantalla, con I2C solo necesitas 4 (VCC, GND, SDA, SCL).

El I2C Scanner es la primera herramienta que usar cuando un módulo I2C no funciona: si no aparece ninguna dirección, el problema es de conexión física. Si aparece, el módulo está bien conectado y el problema es de código o librería.

Para docentes sin experiencia técnica: los módulos OLED con I2C son ideales porque la diferencia entre "el número apareció en pantalla" y "el número está solo en el Monitor Serial" es muy motivadora para los estudiantes.
