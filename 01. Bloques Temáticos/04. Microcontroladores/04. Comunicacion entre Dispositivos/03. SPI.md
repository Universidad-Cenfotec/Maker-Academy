## Descripción

Explica el protocolo SPI (bus de alta velocidad) y cómo se usa para conectar módulos de tarjeta SD y pantallas TFT que necesitan transferir grandes cantidades de datos rápidamente.

---

---
SPI es el protocolo de comunicación más rápido disponible en microcontroladores educativos. Se usa cuando se necesita transferir grandes cantidades de datos muy rápido: mostrar imágenes en pantallas de color, guardar archivos en una tarjeta SD o comunicarse con módulos de radio.

Para la mayoría de proyectos educativos, **no necesitás entender SPI en profundidad**: las librerías lo manejan automáticamente. Lo importante es saber cuándo se usa y cómo conectar los módulos.


## Propósito

Explicar el protocolo SPI para que los docentes puedan enseñar el uso de módulos de tarjeta SD y otros periféricos de alta velocidad en proyectos de registro de datos.

---

## Los cuatro cables de SPI

| Cable | ¿Para qué sirve? |
|---|---|
| **MOSI** | Datos del Arduino al módulo |
| **MISO** | Datos del módulo al Arduino |
| **SCK** | Reloj (marca el ritmo) |
| **CS / SS** | Selecciona cuál módulo habla ahora |

En Arduino UNO: MOSI=11, MISO=12, SCK=13, CS=10

---

## La diferencia con I2C

| | I2C | SPI |
|---|---|---|
| Cables | 2 | 4 |
| Velocidad | Lenta | Rápida |
| Para qué | Sensores, pantallas OLED | Tarjetas SD, pantallas TFT, radio |
| Múltiples módulos | Sí (por dirección) | Sí (un pin CS por módulo) |

## Uso más común: tarjeta SD

> *Insertar próximamente una imagen: fotografía de un módulo lector de tarjetas microSD conectado a un Arduino UNO mediante los pines SPI.*

Guardar datos de sensores en una tarjeta SD es uno de los proyectos más útiles para ciencias:

```cpp
#include <SD.h>
#include <SPI.h>

const int CS = 10;

void setup() {
  Serial.begin(9600);
  if (!SD.begin(CS)) {
    Serial.println("Error: tarjeta SD no encontrada");
    return;
  }
  Serial.println("Tarjeta SD lista");
  
  // escribir en un archivo
  File archivo = SD.open("datos.txt", FILE_WRITE);
  if (archivo) {
    archivo.println("Temperatura, Humedad");
    archivo.println("25.3, 68");
    archivo.close();
    Serial.println("Datos guardados");
  }
}

void loop() {}
```

## Pantalla TFT de color

Las pantallas TFT (color, alta resolución) también usan SPI. Son más impactantes visualmente que las OLED pero requieren más código para manejar colores e imágenes.

## Ideas de proyectos con SPI

- **Datalogger de temperatura:** guardar lecturas de temperatura cada 5 minutos en una tarjeta SD para un experimento de ciencias
- **Panel de información visual:** mostrar datos de sensores en una pantalla TFT a color
- **Cajero automático didáctico:** pantalla TFT con menú interactivo y botones
- **Estación de monitoreo:** registrar datos en SD y también mostrarlos en pantalla

---

## Aplicación en Maker Academy

Se usa principalmente para conectar módulos de tarjeta SD y guardar datos de sensores. Permite crear proyectos de monitoreo ambiental que registran información a lo largo del tiempo.

## Nota docente

SPI es un protocolo más técnico que I2C. Para niveles de primaria y secundaria inicial, no es necesario entender cómo funciona internamente. Lo importante es saber usarlo: conectar los 4 cables en los pines correctos y usar la librería correspondiente.

El proyecto de datalogger con tarjeta SD es especialmente valioso para proyectos interdisciplinarios con ciencias: los estudiantes pueden registrar temperatura durante una semana, exportar el archivo CSV a Excel y hacer gráficas de los datos. El puente entre la tecnología y el análisis de datos es muy enriquecedor.
