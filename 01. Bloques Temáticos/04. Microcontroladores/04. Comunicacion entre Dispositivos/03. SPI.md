# SPI: Bus de Alta Velocidad

![Diagrama del protocolo SPI con maestro, MOSI, MISO, SCK y líneas CS hacia múltiples esclavos](https://upload.wikimedia.org/wikipedia/commons/thumb/e/ed/SPI_single_slave.svg/640px-SPI_single_slave.svg.png)

SPI (Serial Peripheral Interface) es el protocolo de comunicación más rápido disponible en microcontroladores de uso educativo. Mientras I2C trabaja a 100-400 kHz, SPI puede alcanzar 20 MHz o más. Esa velocidad lo hace necesario para aplicaciones que transfieren volúmenes grandes de datos: mostrar imágenes en pantallas TFT de color, escribir y leer archivos en una tarjeta SD, o comunicarse con módulos de radio de largo alcance.

---

## Los cuatro cables de SPI

| Cable | Nombre completo | Función |
|---|---|---|
| MOSI | Master Out Slave In | Datos del maestro hacia el esclavo |
| MISO | Master In Slave Out | Datos del esclavo hacia el maestro |
| SCK | Serial Clock | Reloj generado por el maestro |
| CS / SS | Chip Select / Slave Select | Activa un esclavo específico (LOW = activo) |

A diferencia de I2C (que distingue dispositivos por dirección), SPI distingue dispositivos por la línea CS. Cada dispositivo necesita su propia línea CS conectada a un pin diferente del microcontrolador.

---

## Pines SPI en Arduino

| Arduino UNO / Nano | Pin |
|---|---|
| MOSI | 11 |
| MISO | 12 |
| SCK | 13 |
| SS (por defecto) | 10 |

En el Arduino UNO, el pin 13 es también el LED integrado. Si se usa SPI, el LED puede parpadear con la actividad del bus, lo cual es normal.

En ESP32: MOSI=23, MISO=19, SCK=18, CS=5 por defecto, pero todos son reconfigurables.

## Tarjeta SD con la librería SD

La tarjeta SD es probablemente el módulo SPI más útil en proyectos educativos: permite registrar datos de sensores, leer archivos de configuración o reproducir audio.

**Módulo SD card típico:**
```
SD Module → Arduino UNO
VCC       → 5V (o 3.3V según el módulo)
GND       → GND
MOSI      → pin 11
MISO      → pin 12
SCK       → pin 13
CS        → pin 10
```

```cpp
#include <SPI.h>
#include <SD.h>

const int CS_SD = 10;

void setup() {
  Serial.begin(9600);

  if (!SD.begin(CS_SD)) {
    Serial.println("Error al inicializar la SD");
    return;
  }
  Serial.println("SD lista");

  // crear o abrir archivo
  File archivo = SD.open("datos.csv", FILE_WRITE);
  if (archivo) {
    archivo.println("tiempo,temperatura,luz");
    archivo.close();
    Serial.println("Archivo creado");
  }
}

void loop() {
  int temperatura = analogRead(A0);
  int luz = analogRead(A1);

  File archivo = SD.open("datos.csv", FILE_WRITE);
  if (archivo) {
    archivo.print(millis());
    archivo.print(",");
    archivo.print(temperatura);
    archivo.print(",");
    archivo.println(luz);
    archivo.close();
  }

  delay(1000);
}
```

El archivo CSV resultante se puede abrir directamente en Excel o Google Sheets para graficar los datos registrados.

## Pantalla TFT ILI9341 (240×320 píxeles, color)

Una pantalla TFT de color agrega una dimensión visual imposible con una OLED monocromática. Puede mostrar imágenes, gráficos de barras, indicadores y texto coloreado:

```cpp
#include <SPI.h>
#include <Adafruit_GFX.h>
#include <Adafruit_ILI9341.h>

#define TFT_CS   10
#define TFT_DC   9
#define TFT_RST  8

Adafruit_ILI9341 tft = Adafruit_ILI9341(TFT_CS, TFT_DC, TFT_RST);

void setup() {
  tft.begin();
  tft.setRotation(1);   // horizontal
  tft.fillScreen(ILI9341_BLACK);

  tft.setTextSize(3);
  tft.setTextColor(ILI9341_GREEN);
  tft.setCursor(20, 80);
  tft.println("Makerspace");

  tft.setTextColor(ILI9341_YELLOW);
  tft.setCursor(20, 130);
  tft.println("Academy");
}

void loop() {}
```

## Radio NRF24L01: comunicación inalámbrica a 2.4 GHz

El NRF24L01 es un módulo transceptor de radio que permite comunicación inalámbrica entre dos o más Arduinos a distancias de hasta 100 m en campo abierto (con la versión de antena externa, hasta 1 km):

```cpp
#include <SPI.h>
#include <RF24.h>

RF24 radio(7, 8);  // CE=7, CSN=8
const byte CANAL[6] = "00001";

// Transmisor
void setup() {
  radio.begin();
  radio.openWritingPipe(CANAL);
  radio.setPALevel(RF24_PA_MIN);
  radio.stopListening();
}

void loop() {
  const char mensaje[] = "Hola!";
  bool ok = radio.write(&mensaje, sizeof(mensaje));
  delay(1000);
}
```

```cpp
// Receptor
void setup() {
  radio.begin();
  radio.openReadingPipe(0, CANAL);
  radio.setPALevel(RF24_PA_MIN);
  radio.startListening();
  Serial.begin(9600);
}

void loop() {
  if (radio.available()) {
    char texto[32] = "";
    radio.read(&texto, sizeof(texto));
    Serial.println(texto);
  }
}
```

## Múltiples dispositivos SPI en el mismo bus

Cuando hay varios dispositivos SPI, comparten MOSI, MISO y SCK, pero cada uno tiene su propia línea CS. Solo el dispositivo cuya línea CS está en LOW está activo en un momento dado:

```
Arduino → SD Card   (CS en pin 10)
Arduino → TFT ILI9341 (CS en pin 9)
Arduino → NRF24L01  (CS en pin 8)

Los pines MOSI=11, MISO=12, SCK=13 son compartidos por los tres.
```

Las librerías de Arduino manejan la activación/desactivación de CS automáticamente al llamar a sus funciones, así que normalmente no se gestiona manualmente.

## SPI en MicroPython (ESP32)

```python
from machine import SPI, Pin
import sdcard
import uos

spi = SPI(1, baudrate=1000000, polarity=0, phase=0,
          sck=Pin(18), mosi=Pin(23), miso=Pin(19))
cs = Pin(5, Pin.OUT)

sd = sdcard.SDCard(spi, cs)
uos.mount(sd, '/sd')

# escribir archivo
with open('/sd/datos.txt', 'w') as f:
    f.write('temperatura,luz\n')
    f.write('25,512\n')

# leer archivo
with open('/sd/datos.txt', 'r') as f:
    print(f.read())

uos.umount('/sd')
```

La librería `sdcard.py` de MicroPython se descarga del repositorio oficial de MicroPython-lib.
