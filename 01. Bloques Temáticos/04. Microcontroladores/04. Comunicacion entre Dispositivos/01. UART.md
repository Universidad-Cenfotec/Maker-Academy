# UART: Comunicación Serial

UART (Universal Asynchronous Receiver-Transmitter) es el protocolo de comunicación más básico y más usado en proyectos con microcontroladores. Es el mismo protocolo que usa el cable USB de Arduino para cargar programas y para el monitor serial. Entenderlo permite conectar módulos Bluetooth, GPS, reproductores de audio, pantallas seriales y otros microcontroladores con apenas dos cables.

---

## El principio básico: TX y RX cruzados

UART usa dos cables de señal: TX (Transmit, transmitir) y RX (Receive, recibir). La regla de conexión es siempre la misma: el TX de un dispositivo va al RX del otro, y viceversa. El flujo de datos siempre va de TX hacia RX.

```
Dispositivo A        Dispositivo B
    TX ──────────────→ RX
    RX ←────────────── TX
   GND ─────────────── GND
```

Si se conecta TX con TX o RX con RX, no hay comunicación.

---

## Baudrate: el acuerdo de velocidad

UART es "asíncrono" porque no usa una señal de reloj compartida. En su lugar, ambos dispositivos se ponen de acuerdo en la velocidad de transmisión antes de empezar. Esa velocidad se llama baudrate y se mide en bits por segundo (bps).

| Baudrate | Uso |
|---|---|
| 9600 | Módulos GPS, aplicaciones lentas, depuración |
| 57600 | Balance entre velocidad y estabilidad |
| 115200 | Carga de programas, depuración rápida, Arduino IDE |

Si los baudrates no coinciden, los datos llegan como caracteres ilegibles. Es uno de los errores más comunes al conectar módulos nuevos.

## UART en Arduino: Serial y SoftwareSerial

El Arduino UNO tiene un solo puerto UART hardware (pines 0/RX y 1/TX), que es el mismo que usa el cable USB. Si se conecta un módulo serial a esos pines, el monitor serial deja de funcionar y la carga de programas puede fallar.

Para conectar módulos externos manteniendo el monitor serial disponible, se usa la librería `SoftwareSerial`, que emula UART en pines digitales cualesquiera:

```cpp
#include <SoftwareSerial.h>

SoftwareSerial bluetooth(2, 3);  // RX del Arduino=2, TX del Arduino=3

void setup() {
  Serial.begin(9600);        // monitor serial (USB)
  bluetooth.begin(9600);     // módulo Bluetooth (pines 2 y 3)
}

void loop() {
  // reenviar desde Bluetooth al monitor serial
  if (bluetooth.available()) {
    char c = bluetooth.read();
    Serial.print(c);
  }
  // reenviar desde monitor serial al Bluetooth
  if (Serial.available()) {
    char c = Serial.read();
    bluetooth.print(c);
  }
}
```

El Arduino Mega tiene 4 puertos UART hardware (Serial, Serial1, Serial2, Serial3), lo cual lo hace más conveniente para proyectos con múltiples módulos.

## Conectar el módulo HC-05 (Bluetooth)

El HC-05 es el módulo más común para añadir Bluetooth a un Arduino. Funciona como un "cable serial inalámbrico": todo lo que Arduino envía por SoftwareSerial aparece en el teléfono via Bluetooth, y lo que el teléfono envía aparece en el buffer de SoftwareSerial.

```
HC-05         → Arduino UNO
VCC           → 5V
GND           → GND
TX (del HC05) → pin 2 (RX de SoftwareSerial)
RX (del HC05) → pin 3 (TX de SoftwareSerial) con divisor de tensión a 3.3V
```

El pin RX del HC-05 trabaja a 3.3 V. Si el Arduino es de 5 V, se debe usar un divisor de tensión (resistencias 1 kΩ y 2 kΩ) para reducir la señal a 3.3 V antes de llegar al HC-05. De lo contrario puede dañarse.

## Recibir comandos por Bluetooth desde el celular

```cpp
#include <SoftwareSerial.h>

SoftwareSerial bt(2, 3);
const int LED = 13;

void setup() {
  bt.begin(9600);
  Serial.begin(9600);
  pinMode(LED, OUTPUT);
  bt.println("Listo. Enviar '1' para encender, '0' para apagar");
}

void loop() {
  if (bt.available()) {
    char cmd = bt.read();
    Serial.print("Recibido: ");
    Serial.println(cmd);
    if (cmd == '1') {
      digitalWrite(LED, HIGH);
      bt.println("LED ON");
    } else if (cmd == '0') {
      digitalWrite(LED, LOW);
      bt.println("LED OFF");
    }
  }
}
```

Para probar este programa, conectar el HC-05 desde el celular (la contraseña por defecto es 1234 o 0000) y usar una app de terminal Bluetooth como "Serial Bluetooth Terminal" (Android).

## Conectar el GPS NEO-6M

```cpp
#include <SoftwareSerial.h>
#include <TinyGPS++.h>

SoftwareSerial gpsSerial(4, 5);  // RX=4, TX=5
TinyGPSPlus gps;

void setup() {
  Serial.begin(9600);
  gpsSerial.begin(9600);
}

void loop() {
  while (gpsSerial.available() > 0) {
    gps.encode(gpsSerial.read());
  }

  if (gps.location.isUpdated()) {
    Serial.print("Lat: ");
    Serial.print(gps.location.lat(), 6);
    Serial.print(" | Lon: ");
    Serial.println(gps.location.lng(), 6);
  }
}
```

El GPS necesita visión del cielo para recibir señal de los satélites. En interiores puede tardar varios minutos en fijar posición o no fijarla nunca.

## UART entre dos Arduinos

También se puede usar UART para comunicar dos Arduinos entre sí. Uno actúa como transmisor y el otro como receptor:

```cpp
// Arduino transmisor
#include <SoftwareSerial.h>
SoftwareSerial enlace(2, 3);

void setup() { enlace.begin(9600); }
void loop() {
  int sensor = analogRead(A0);
  enlace.println(sensor);  // enviar valor del sensor
  delay(500);
}
```

```cpp
// Arduino receptor
#include <SoftwareSerial.h>
SoftwareSerial enlace(2, 3);

void setup() {
  enlace.begin(9600);
  Serial.begin(9600);
}
void loop() {
  if (enlace.available()) {
    String dato = enlace.readStringUntil('\n');
    Serial.println(dato);
  }
}
```
