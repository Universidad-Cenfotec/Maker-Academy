UART es el protocolo de comunicación más básico entre dispositivos electrónicos. Es el mismo sistema que usa el cable USB de Arduino para cargar programas y para el Monitor Serial. Entenderlo permite conectar módulos Bluetooth, GPS, altavoces MP3 y otros componentes con apenas dos cables.

**La idea central:** dos dispositivos acuerdan una "velocidad de conversación" y se turnan para enviar y recibir información a través de dos cables.


## Propósito

Explicar el protocolo UART para que los docentes puedan conectar módulos Bluetooth al microcontrolador y crear proyectos de control inalámbrico básico.

---

## Los tres cables: TX, RX y GND

| Cable | ¿Qué hace? |
|---|---|
| **TX** (Transmit) | Envía datos desde este dispositivo |
| **RX** (Receive) | Recibe datos de otro dispositivo |
| **GND** | Tierra compartida (obligatoria) |

**La regla de conexión:** el TX de un dispositivo siempre va al RX del otro, y viceversa. Si se conecta TX con TX, no hay comunicación.

```
Dispositivo A          Dispositivo B
    TX ──────────────→ RX
    RX ←────────────── TX
   GND ─────────────── GND
```

---

## Baudrate: la velocidad acordada

Los dos dispositivos deben usar exactamente la misma velocidad de comunicación. Esa velocidad se llama **baudrate** y se mide en bits por segundo. Los más comunes:

| Baudrate | ¿Para qué se usa? |
|---|---|
| 9600 | La mayoría de módulos (GPS, Bluetooth, sensores) |
| 115200 | Arduino IDE al cargar programas |

Si los baudrates no coinciden, los mensajes llegan como caracteres extraños (✣✕✙). Es el error más común al conectar módulos nuevos.

## UART en Arduino

El Arduino UNO tiene un puerto UART en los pines 0 (RX) y 1 (TX), que es el mismo que usa el cable USB. Para conectar módulos externos sin interferir con el USB, se usa la librería `SoftwareSerial` que crea un UART en otros pines:

```cpp
#include <SoftwareSerial.h>

SoftwareSerial modulo(2, 3);  // pin 2 = RX del Arduino, pin 3 = TX del Arduino

void setup() {
  Serial.begin(9600);         // monitor serial (USB)
  modulo.begin(9600);         // módulo externo (pines 2 y 3)
}

void loop() {
  // reenviar del módulo al monitor serial
  if (modulo.available()) {
    Serial.write(modulo.read());
  }
  // reenviar del monitor serial al módulo
  if (Serial.available()) {
    modulo.write(Serial.read());
  }
}
```

## Módulos más comunes que usan UART

| Módulo | ¿Para qué sirve? | Baudrate |
|---|---|---|
| HC-05 / HC-06 | Bluetooth para controlar robots | 9600 |
| NEO-6M | GPS (ubicación por satélite) | 9600 |
| DFPlayer Mini | Reproductor de audios MP3 | 9600 |
| SIM800L | Enviar SMS o datos por red celular | 9600 |

## Conectar el módulo HC-05 (Bluetooth)

```
HC-05 VCC → 5V de Arduino
HC-05 GND → GND de Arduino
HC-05 TX  → pin 2 de Arduino
HC-05 RX  → pin 3 de Arduino (con resistencias para bajar a 3.3V)
```

Una vez conectado, el módulo aparece en el celular como un dispositivo Bluetooth. Al emparejar (contraseña por defecto: **1234**), se puede enviar texto desde el celular y el Arduino lo recibe como si viniera del Monitor Serial.

## Ejemplo: controlar un LED por Bluetooth

```cpp
#include <SoftwareSerial.h>

SoftwareSerial bt(2, 3);
const int LED = 13;

void setup() {
  bt.begin(9600);
  pinMode(LED, OUTPUT);
  bt.println("Envía '1' para encender, '0' para apagar");
}

void loop() {
  if (bt.available()) {
    char comando = bt.read();
    if (comando == '1') {
      digitalWrite(LED, HIGH);
      bt.println("LED encendido");
    } else if (comando == '0') {
      digitalWrite(LED, LOW);
      bt.println("LED apagado");
    }
  }
}
```

Para probar, usar la app **"Serial Bluetooth Terminal"** en Android. Conectar al HC-05 y enviar los caracteres 1 y 0.

## Ideas de proyectos

- **Control de robot por Bluetooth:** enviar W/A/S/D desde el celular para mover un robot
- **Alarma por SMS:** el Arduino envía un mensaje de texto cuando detecta algo (con SIM800L)
- **Localizador GPS:** mostrar en pantalla las coordenadas GPS del dispositivo
- **Altavoz de proyectos:** reproducir sonidos MP3 con el DFPlayer Mini cuando ocurre un evento

## Nota docente

UART es el tipo de comunicación más fácil de entender conceptualmente porque es como una conversación entre personas: uno habla (TX) y el otro escucha (RX), y los dos se ponen de acuerdo en "hablar al mismo ritmo" (baudrate).

El módulo HC-05 con Bluetooth es el mejor punto de entrada para enseñar comunicación inalámbrica en secundaria: la satisfacción de controlar un robot desde el celular es inmediata y motivadora. Y conceptualmente, el código es casi idéntico al Monitor Serial, lo que hace la transición muy natural.
