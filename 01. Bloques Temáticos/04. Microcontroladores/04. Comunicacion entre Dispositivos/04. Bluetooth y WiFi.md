# Bluetooth y WiFi

La comunicación inalámbrica transforma un proyecto local en un sistema conectado. Un robot que solo funciona con cable conectado al computador tiene aplicaciones limitadas, mientras que el mismo robot controlado por Bluetooth desde un celular o reportando sus datos a internet vía WiFi es un dispositivo con autonomía real. Este archivo cubre las dos tecnologías inalámbricas más usadas en el makerspace.

---

## Bluetooth con el módulo HC-05

El HC-05 es un módulo de Bluetooth clásico (versión 2.0) que convierte una conexión UART en un enlace inalámbrico transparente. Para el Arduino, enviar datos por Bluetooth es idéntico a enviarlos por Serial. Todo lo que el Arduino escribe al HC-05 aparece en el dispositivo Bluetooth conectado, y viceversa.

### Conexión del HC-05

```
HC-05           → Arduino UNO
VCC             → 5V
GND             → GND
TX (del módulo) → pin 2 (RX de SoftwareSerial)
RX (del módulo) → pin 3 con divisor de tensión 1kΩ/2kΩ
```

El pin RX del HC-05 es tolerante a 3.3 V, no a 5 V. Sin el divisor de tensión puede dañarse con el tiempo aunque suele no fallar inmediatamente.

### Programa: robot controlado por Bluetooth

```cpp
#include <SoftwareSerial.h>

SoftwareSerial bt(2, 3);  // RX=2, TX=3

const int IN1 = 7, IN2 = 8, ENA = 9;   // motor izquierdo
const int IN3 = 4, IN4 = 5, ENB = 6;   // motor derecho

void configurar() {
  for (int p : {IN1, IN2, ENA, IN3, IN4, ENB}) pinMode(p, OUTPUT);
}

void adelante() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);  analogWrite(ENA, 180);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);  analogWrite(ENB, 180);
}
void atras() {
  digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH); analogWrite(ENA, 180);
  digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH); analogWrite(ENB, 180);
}
void izquierda() {
  digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH); analogWrite(ENA, 180);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);  analogWrite(ENB, 180);
}
void derecha() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);  analogWrite(ENA, 180);
  digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH); analogWrite(ENB, 180);
}
void parar() {
  for (int p : {IN1, IN2, IN3, IN4}) digitalWrite(p, LOW);
  analogWrite(ENA, 0); analogWrite(ENB, 0);
}

void setup() {
  configurar();
  bt.begin(9600);
  bt.println("Robot listo. W=adelante S=atras A=izq D=der X=stop");
}

void loop() {
  if (bt.available()) {
    char cmd = bt.read();
    if      (cmd == 'W' || cmd == 'w') adelante();
    else if (cmd == 'S' || cmd == 's') atras();
    else if (cmd == 'A' || cmd == 'a') izquierda();
    else if (cmd == 'D' || cmd == 'd') derecha();
    else if (cmd == 'X' || cmd == 'x') parar();
  }
}
```

Para controlar el robot, usar la app "Serial Bluetooth Terminal" o "Bluetooth Electronics" en Android. Conectar al HC-05 (contraseña 1234 por defecto) y enviar los caracteres W, S, A, D, X.

## Bluetooth en micro:bit

El micro:bit tiene Bluetooth integrado y se puede controlar directamente desde la app oficial "micro:bit" disponible para iOS y Android, sin módulos adicionales.

En MakeCode se activa el servicio Bluetooth desde la categoría "Bluetooth":

```
// Bloques equivalentes en JavaScript
bluetooth.startUartService()
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.Newline), () => {
    let cmd = bluetooth.uartReadUntil(serial.delimiters(Delimiters.Newline))
    if (cmd == "ON") {
        led.plot(2, 2)
    } else {
        led.unplot(2, 2)
    }
})
```

## WiFi con el ESP32

El ESP32 tiene WiFi 802.11 b/g/n integrado en el chip, sin módulos adicionales. Puede funcionar como cliente de una red existente (modo Station) o como punto de acceso propio (modo AP). El modo más útil para proyectos educativos es Station, donde el ESP32 se conecta al WiFi del makerspace y crea un servidor web accesible desde cualquier dispositivo en la misma red.

### Servidor web básico: controlar un LED desde el navegador

```cpp
#include <WiFi.h>
#include <WebServer.h>

const char* SSID     = "NombreDeRedWiFi";
const char* PASSWORD = "ContrasenaWiFi";

WebServer server(80);
const int LED = 2;

void paginaPrincipal() {
  String html = R"(
<!DOCTYPE html>
<html>
<head><meta charset='UTF-8'><title>ESP32 Control</title>
<style>body{font-family:sans-serif;text-align:center;padding:40px;}
button{padding:20px 40px;font-size:18px;margin:10px;border-radius:8px;cursor:pointer;}</style>
</head>
<body>
<h1>Control ESP32</h1>
<form action='/on'><button style='background:#4CAF50;color:white;'>Encender LED</button></form>
<form action='/off'><button style='background:#f44336;color:white;'>Apagar LED</button></form>
</body>
</html>
)";
  server.send(200, "text/html", html);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED, OUTPUT);

  WiFi.begin(SSID, PASSWORD);
  Serial.print("Conectando a WiFi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nConectado! IP: " + WiFi.localIP().toString());

  server.on("/",    paginaPrincipal);
  server.on("/on",  []() { digitalWrite(LED, HIGH); server.sendHeader("Location", "/"); server.send(302); });
  server.on("/off", []() { digitalWrite(LED, LOW);  server.sendHeader("Location", "/"); server.send(302); });

  server.begin();
}

void loop() {
  server.handleClient();
}
```

Abrir el monitor serial para ver la IP asignada. Ingresar esa IP en el navegador del celular o computador (en la misma red WiFi) para ver los botones de control.

## Publicar datos en plataformas IoT

Para proyectos de monitoreo continuo, el ESP32 puede enviar datos a plataformas IoT gratuitas que almacenan y grafican las lecturas:

| Plataforma | Protocolo | Gratuito | Destacado |
|---|---|---|---|
| ThingSpeak | HTTP REST | Sí (límites) | Visualización con MATLAB |
| Adafruit IO | MQTT | Sí (límites) | Muy fácil de configurar |
| Blynk | MQTT | Sí (límites) | App móvil lista |
| Node-RED | MQTT / HTTP | Sí | Muy flexible, corre local |
| MQTT Broker local | MQTT | Sí | Sin dependencia de internet |

Ejemplo con ThingSpeak (enviar temperatura cada 15 segundos):

```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* SSID       = "MiRed";
const char* PASSWORD   = "MiClave";
const char* API_KEY    = "XXXXXXXXXXXXXXXX";  // API Key de ThingSpeak
const char* TS_URL     = "http://api.thingspeak.com/update";

void setup() {
  Serial.begin(115200);
  WiFi.begin(SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) delay(500);
  Serial.println("WiFi conectado");
}

void loop() {
  float temperatura = 25.4;  // reemplazar con lectura real del sensor

  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    String url = String(TS_URL) + "?api_key=" + API_KEY + "&field1=" + temperatura;
    http.begin(url);
    int codigo = http.GET();
    Serial.print("HTTP: ");
    Serial.println(codigo);
    http.end();
  }

  delay(15000);  // ThingSpeak acepta mínimo cada 15 segundos en cuenta gratuita
}
```

## Comparación Bluetooth vs. WiFi

| Aspecto | Bluetooth (HC-05) | WiFi (ESP32) |
|---|---|---|
| Alcance | ~10 m en interiores | ~50 m en interiores |
| Requiere internet | No | No (solo para IoT) |
| Facilidad de uso | Alta (app de terminal) | Media (configurar SSID) |
| Latencia | Muy baja | Baja |
| Consumo de energía | Bajo | Medio-alto |
| Ideal para | Control directo de robot | Monitoreo remoto, IoT |
| Costo del módulo | Módulo HC-05 aparte | Integrado en ESP32 |

Para la mayoría de proyectos de control de robots en el makerspace, Bluetooth es más sencillo y suficiente. Para proyectos de monitoreo ambiental, estación meteorológica o control desde fuera de la red local, WiFi con ESP32 es la elección correcta.

## WiFi en MicroPython (ESP32)

```python
import network
import urequests
import time

# conectar a WiFi
wifi = network.WLAN(network.STA_IF)
wifi.active(True)
wifi.connect("MiRed", "MiClave")

while not wifi.isconnected():
    time.sleep(0.5)

print("IP:", wifi.ifconfig()[0])

# enviar dato a ThingSpeak
API_KEY = "XXXXXXXXXXXXXXXX"
temperatura = 25.4

url = f"http://api.thingspeak.com/update?api_key={API_KEY}&field1={temperatura}"
respuesta = urequests.get(url)
print("Respuesta:", respuesta.text)
respuesta.close()
```
