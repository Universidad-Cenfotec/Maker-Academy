La comunicación inalámbrica convierte un proyecto local en un sistema conectado. Un robot que solo funciona con cable tiene aplicaciones limitadas; el mismo robot controlado por Bluetooth desde el celular o enviando datos a internet es un dispositivo con autonomía real.


## Propósito

Explicar las tecnologías de comunicación inalámbrica Bluetooth y WiFi para que los docentes puedan crear proyectos conectados y de control remoto en el aula.

## Bluetooth con el módulo HC-05

El HC-05 es el módulo Bluetooth más común en proyectos educativos. Funciona como un "cable sin cable": lo que Arduino envía, aparece en el celular; lo que el celular envía, llega al Arduino. El código es idéntico al del Monitor Serial.

<img width="340" height="395" alt="image" src="https://github.com/user-attachments/assets/043181e0-27ed-49e3-bc11-33a5d1b868af" />

**Conexión:**
```
HC-05 VCC → 5V de Arduino
HC-05 GND → GND de Arduino
HC-05 TX  → pin 2 de Arduino
HC-05 RX  → pin 3 de Arduino
```

**App recomendada para el celular:** "Serial Bluetooth Terminal" (Android, gratis). Emparejar con el HC-05 (contraseña: 1234) y ya se puede enviar comandos.

## Programa: robot controlado por Bluetooth

```cpp
#include <SoftwareSerial.h>

SoftwareSerial bt(2, 3);  // pines Bluetooth

const int IN1=7, IN2=8, ENA=9;  // motor izquierdo
const int IN3=4, IN4=5, ENB=6;  // motor derecho

void setup() {
  pinMode(IN1,OUTPUT); pinMode(IN2,OUTPUT); pinMode(ENA,OUTPUT);
  pinMode(IN3,OUTPUT); pinMode(IN4,OUTPUT); pinMode(ENB,OUTPUT);
  bt.begin(9600);
  bt.println("Robot listo: W=adelante S=atrás A=izq D=der X=stop");
}

void loop() {
  if (bt.available()) {
    char cmd = tolower(bt.read());  // aceptar mayúsculas y minúsculas
    
    if (cmd == 'w') {                // adelante
      digitalWrite(IN1,HIGH); digitalWrite(IN2,LOW); analogWrite(ENA,180);
      digitalWrite(IN3,HIGH); digitalWrite(IN4,LOW); analogWrite(ENB,180);
    } else if (cmd == 's') {         // atrás
      digitalWrite(IN1,LOW); digitalWrite(IN2,HIGH); analogWrite(ENA,180);
      digitalWrite(IN3,LOW); digitalWrite(IN4,HIGH); analogWrite(ENB,180);
    } else if (cmd == 'x') {         // parar
      analogWrite(ENA, 0); analogWrite(ENB, 0);
    }
  }
}
```

## WiFi con el ESP32

El ESP32 tiene WiFi integrado en el chip. La manera más sencilla de usarlo en educación es crear un **servidor web**: el ESP32 crea una pequeña página web accesible desde cualquier celular o computador en la misma red WiFi.

## Programa: servidor web para controlar un LED

```cpp
#include <WiFi.h>
#include <WebServer.h>

const char* SSID     = "NombreDeRedWiFi";
const char* PASSWORD = "ContrasenaWiFi";

WebServer server(80);
const int LED = 2;

void paginaWeb() {
  String html = "<html><body style='text-align:center;font-family:sans-serif;'>";
  html += "<h1>Control ESP32</h1>";
  html += "<a href='/on'><button style='padding:20px;font-size:20px;background:green;color:white;'>Encender</button></a> ";
  html += "<a href='/off'><button style='padding:20px;font-size:20px;background:red;color:white;'>Apagar</button></a>";
  html += "</body></html>";
  server.send(200, "text/html", html);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED, OUTPUT);
  
  WiFi.begin(SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\n¡Conectado! Abrir en el navegador: http://" + WiFi.localIP().toString());
  
  server.on("/", paginaWeb);
  server.on("/on",  []() { digitalWrite(LED, HIGH); server.sendHeader("Location","/"); server.send(302); });
  server.on("/off", []() { digitalWrite(LED, LOW);  server.sendHeader("Location","/"); server.send(302); });
  server.begin();
}

void loop() {
  server.handleClient();
}
```

El Monitor Serial muestra la dirección IP. Desde cualquier celular en la misma red WiFi, se abre esa dirección en el navegador y aparecen los botones de control.

## Enviar datos a internet (IoT)

Para proyectos de monitoreo ambiental, el ESP32 puede enviar datos a plataformas gratuitas que los almacenan y grafican:

| Plataforma | Ideal para | Gratuito |
|---|---|---|
| **ThingSpeak** | Gráficas de sensores | ✅ |
| **Adafruit IO** | Fácil de configurar, dashboard visual | ✅ |
| **Blynk** | Control desde app móvil | ✅ (básico) |

## IdeaBoard con WiFi

La IdeaBoard también tiene WiFi integrado y se puede programar con CircuitPython para conectarse a internet y enviar o recibir datos. Esto la hace una alternativa accesible al ESP32 para proyectos IoT en el aula.

---

## Comparación: ¿Bluetooth o WiFi?

| | Bluetooth (HC-05) | WiFi (ESP32 / IdeaBoard) |
|---|---|---|
| Alcance | ~10 metros | ~50 metros |
| Necesita internet | No | No (para servidor local) |
| Facilidad | Alta | Media |
| Ideal para | Control de robot en tiempo real | Monitoreo, datos a internet |
| Dispositivos compatibles | Celulares con app | Cualquier navegador |

**Regla general:**
- ¿Quiero controlar algo desde el celular en el mismo cuarto? → **Bluetooth**
- ¿Quiero enviar datos a internet o controlar desde cualquier lugar? → **WiFi**

## Ideas de proyectos

- **Robot manejado por celular:** control por Bluetooth con la app Serial Bluetooth Terminal
- **Estación meteorológica en la nube:** el ESP32 envía temperatura y humedad a ThingSpeak cada hora
- **Alarma remota:** el ESP32 manda un aviso a una plataforma IoT cuando detecta movimiento o luz
- **Control de luz del aula:** botones en una página web encienden y apagan LEDs en el aula
- **Monitor de calidad del aire:** visualizar datos de CO2 o partículas en un dashboard en tiempo real

## Nota docente

Para docentes sin experiencia en redes o internet: el proyecto de servidor web del ESP32 es más sencillo de lo que parece. Los estudiantes solo necesitan conocer el nombre y contraseña del WiFi del centro, y en pocos minutos tienen una página web funcionando desde el ESP32.

Lo más motivador de estos proyectos es que el resultado es inmediatamente útil: controlar una lámpara del aula desde el celular o ver la temperatura del salón en una gráfica en el celular son experiencias que conectan la tecnología con situaciones reales.

Para empezar con Bluetooth, la app "Serial Bluetooth Terminal" de Android es gratuita y no requiere crear cuenta. Perfecta para las primeras experiencias.
