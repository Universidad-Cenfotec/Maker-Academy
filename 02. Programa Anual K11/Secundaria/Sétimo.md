## Información general

| Elemento                     | Descripción                                                                                           |
| ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Grado**                    | 7.º                                                                                                   |
| **Nivel**                    | Nivel 4: Diseñadores Maker                                                                            |
| **Duración**                 | 40 semanas / 4 módulos de 10 semanas                                                                  |
| **Frecuencia sugerida**      | 1 sesión semanal de 80 a 120 minutos                                                                  |
| **Lenguaje de programación** | Bloques + introducción a Python                                                                       |
| **Herramientas base**        | Arduino Starter Kit, sensores, motores, servos, drivers, chasis, impresión 3D, láser y kit de Sumobot |
| **Metodología**              | XperiencED Kids: Inspiración 20%, Experimentación 60%, Reflexión 20%                                  |

---

## Objetivo anual

Diseñar sistemas automáticos simples con sensores, actuadores, programación, fabricación de soportes, depuración y documentación técnica, aplicando entrada-proceso-salida y seguridad tecnológica.

---

## Proyecto eje anual

**Sistema automatizado que responde al entorno**

---

## Módulos anuales

| Módulo   | Semanas | Nombre del módulo        | Producto esperado                                                |
| -------- | ------: | ------------------------ | ---------------------------------------------------------------- |
| Módulo 1 |    1–10 | Detectives de Sensores   | Sistema automático simple                                        |
| Módulo 2 |   11–20 | Código en Acción         | Sistema programado con condición                                 |
| Módulo 3 |   21–30 | Máquinas que Responden   | Máquina automatizada                                             |
| Módulo 4 |   31–40 | Reto Máquina Inteligente | Proyecto integrador, documentación, exposición final y reflexión |

## Evidencias esperadas

* Prototipo funcional por módulo.
* Bocetos, diagramas, fotografías o bitácora.
* Registro de pruebas, errores y mejoras.
* Demo, presentación breve o reflexión final.
* Documentación del proyecto integrador.

---

## Nota de implementación

Este plan puede utilizarse como propuesta base para 7.º grado. Cada centro educativo puede adaptarlo según su calendario, recursos, nivel del grupo y condiciones del makerspace.
