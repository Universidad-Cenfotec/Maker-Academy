## Descripción

Esta carpeta centraliza las **gemas**, **prompts base** y **criterios de revisión humana** que apoyan el diseño, adaptación, evaluación, documentación y mejora de experiencias **Maker Academy**.

Las gemas y prompts son herramientas de apoyo para docentes, coordinación y equipos educativos. No sustituyen el criterio pedagógico, la revisión humana ni la adaptación al contexto de cada grupo.

El marco institucional para el uso responsable de IA se desarrolla en:

[11. Uso de IA y Gemas](../00.%20Modelo%20Pedag%C3%B3gico/11.%20Uso%20de%20IA%20y%20Gemas.md)

---

## Propósito de la carpeta

El propósito de esta carpeta es ofrecer recursos operativos para usar IA en Maker Academy de forma clara, práctica y alineada con el modelo pedagógico.

Esta carpeta permite:

- Planificar sesiones con la metodología XperiencED Kids.
- Adaptar proyectos por nivel educativo.
- Integrar proyectos maker con otras materias.
- Diseñar retos por niveles de dificultad.
- Crear instrumentos de evaluación.
- Documentar proyectos para el repositorio.
- Revisar condiciones de seguridad.
- Promover el uso ético y responsable de IA.
- Reducir tiempo operativo sin perder criterio docente.

---

## Idea clave

Las gemas y prompts no generan productos finales sin revisión.

Funcionan como asistentes para pensar, ordenar, adaptar y mejorar propuestas.

El flujo recomendado es:

> Idea docente → uso de gema o prompt → revisión humana → adaptación al contexto → implementación → documentación → mejora.

---

## ¿Qué son las gemas?

Las **gemas** son asistentes de IA configurados para cumplir una función específica dentro de Maker Academy.

Cada gema tiene un propósito definido. Por ejemplo, una puede ayudar a planificar sesiones con XperiencED Kids, otra puede adaptar actividades por nivel, otra puede crear rúbricas y otra puede revisar aspectos de seguridad.

Las gemas permiten ahorrar tiempo, pero sus respuestas deben ser revisadas por el equipo docente antes de usarse con estudiantes.

## Gemas sugeridas

Las siguientes gemas pueden utilizarse como asistentes base para apoyar la implementación de Maker Academy.

| Gema | Función principal | Producto generado |
|---|---|---|
| **Diseñador XperiencED Kids** | Convierte un tema o proyecto en planificación con Inspiración, Experimentación y Reflexión. | Plan de sesión o unidad. |
| **Adaptador por Nivel** | Ajusta lenguaje, dificultad, materiales y autonomía según edad o nivel educativo. | Versión para preescolar, primaria o secundaria. |
| **Integrador Curricular** | Conecta el proyecto maker con otras materias. | Matriz interdisciplinaria. |
| **Diseñador de Retos Maker** | Propone retos por niveles de dificultad. | Reto inicial, intermedio y avanzado. |
| **Evaluador Maker** | Crea rúbricas, listas de cotejo y preguntas de reflexión. | Instrumentos de evaluación. |
| **Documentador de Proyectos** | Genera plantillas de bitácora, README y guía de evidencias. | Documentación lista para repositorio. |
| **Asistente de Seguridad** | Revisa riesgos, materiales y cuidados del espacio. | Checklist de seguridad. |
| **Asistente de IA Ética** | Sugiere usos responsables de IA y criterios de transparencia. | Guía de uso de IA por proyecto. |

## Criterios de revisión humana

Todo producto generado por una gema o prompt debe revisarse antes de usarse.

| Criterio | Pregunta orientadora |
|---|---|
| **Propósito pedagógico** | ¿La respuesta ayuda a lograr el aprendizaje esperado? |
| **Alineación con Maker Academy** | ¿Respeta XperiencED Kids, cultura maker y PNFT? |
| **Nivel adecuado** | ¿Es pertinente para la edad, autonomía y experiencia del grupo? |
| **Viabilidad** | ¿Se puede implementar con los recursos y tiempo disponibles? |
| **Seguridad** | ¿Incluye cuidados claros y suficientes? |
| **Motivación** | ¿Conecta con intereses reales de los estudiantes? |
| **Interdisciplinariedad** | Si aplica, ¿respeta el objetivo curricular de la materia? |
| **Evaluación** | ¿Propone evidencias e instrumentos coherentes? |
| **Privacidad** | ¿Evita datos personales o información sensible? |
| **Calidad técnica** | ¿Las instrucciones técnicas deben verificarse antes de aplicar? |
| **Claridad** | ¿El texto es comprensible para docentes y estudiantes? |
| **Adaptación** | ¿Requiere ajustes al contexto específico de la escuela? |

## Recomendaciones de uso

Antes de usar una gema o prompt:

1. Definir el objetivo de aprendizaje.
2. Indicar grado, nivel, duración y recursos disponibles.
3. Incluir intereses reales del grupo.
4. Aclarar si el proyecto es K11 o interdisciplinario.
5. Especificar restricciones de tiempo, materiales o seguridad.
6. Revisar la respuesta generada.
7. Adaptar el resultado al contexto.
8. Validar seguridad y evaluación.
9. Implementar.
10. Documentar evidencias y mejoras.

---

## Errores comunes que conviene evitar

Al usar gemas y prompts, conviene evitar:

- Usar prompts demasiado generales.
- Copiar respuestas sin revisión.
- Generar actividades sin objetivo de aprendizaje.
- Olvidar la metodología XperiencED Kids.
- Proponer proyectos demasiado complejos para el nivel.
- Ignorar condiciones de seguridad.
- Pedir demasiada documentación.
- Usar IA para sustituir la creatividad estudiantil.
- Ingresar datos personales de estudiantes.
- Evaluar proyectos interdisciplinarios solo desde lo tecnológico.
- Desconectar las propuestas del contexto real de la escuela.

## Nota docente

Las gemas y prompts son herramientas para apoyar el trabajo docente, no para reemplazarlo.

Una buena respuesta de IA siempre debe pasar por revisión humana, adaptación al contexto y validación pedagógica.

La pregunta clave antes de usar una gema es:

> ¿Esta herramienta me ayuda a diseñar una experiencia más clara, segura, creativa y significativa para mis estudiantes?
